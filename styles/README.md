# Styles

แต่ละโฟลเดอร์ = 1 สไตล์: `ref.*` รูปตัวอย่าง, `base.html` โครงภาพ (Claude ทำจากรูปตัวอย่าง), `preview.png` หน้าตาที่ได้

| โฟลเดอร์ | แบบ | เหมาะกับ |
|---|---|---|
| `1-type-behind` | ตัวอักษรใหญ่เบลอหลังเลนส์ แว่นมุมเอียงบนระนาบกระดาษ | กรอบใหม่ อารมณ์แบรนด์ |
| `2-titanium-center` | แว่นใหญ่ล้นขอบ ครอปช่วงสะพาน หัวข้อ serif | กรอบพรีเมียม / ไทเทเนียม |
| `3-detail-split` | แว่นเต็มตัว + ซูมรายละเอียด ข้อมูล m/ c/ | อธิบายรุ่น + เลนส์ |
| `4-bold-promo` | คำใหญ่หนา แขนสวมสูทเนกไทเขียวเข้าจากขวาล่าง นิ้วจีบถือกรอบแว่น ป้ายส่วนลด | โปรโมชัน |
| `5-tonal` | พื้นโทนเดียวกับสีกรอบ ตัวหนาพิมพ์ใหญ่ | กรอบสีเด่น |
| `6-feature-grid` | ชื่อแบรนด์ใหญ่ + 4 ช่องไอคอน กรอบ/เลนส์/coating | เล่าเลนส์ + coating |
| `7-float-blue` | พื้นฟ้าไล่สี แว่นและเลนส์ลอย (จากคลิป) | เน้นเทคโนโลยีเลนส์ |
| `8-luxury-minimal` | พื้น Snow ไล่ Timberwolf ที่ว่างเกินครึ่งภาพ แว่นกลางไม่ล้นขอบ เส้น Peach-orange เส้นเดียว หัวข้อ serif บาง | กรอบพรีเมียม งานเงียบ ๆ ดูแพง |
| `9-spec-callout` | พื้นเข้มไล่แสง สินค้าเอียงกลางภาพ ป้ายข้อดี 4 จุดโยงเส้นบาง + จุด Peach | เล่าคุณสมบัติเลนส์/coating เป็นข้อ ๆ |
| `10-tint-lineup` | เลนส์สีโปร่งซ้อนเรียงครึ่งบน หัวข้อหนาซ้ายล่างขีดเส้นใต้ | เลนส์ย้อมสี ปรอท โฟโตโครมิก เน้นว่ามีหลายสี |
| `11-color-swap` | พื้นสีเรียบ หัวข้อ 3 บรรทัดคำกลางหนามาก สินค้าเอียงมีเงาทอด | ทำเป็นคลิป เปลี่ยนสีพื้น+ตัวแว่นทีละจังหวะ |
| `12-still-lockup` | ล็อกอัปกลางจอ (โลโก้+หัวข้อ+ย่อหน้า) ค้างนิ่งสนิท พื้นเวทีมืด สินค้าอยู่หลังม่านบาง | ทำเป็นคลิปแนะนำร้าน/คอลเลกชัน เปลี่ยนเฉพาะเวทีกับตัวสินค้า ห้ามขยับตัวอักษร |
| `13-model-promo` | หัวข้อหนักซ้ายบน + ตัวอักษรยักษ์ซ้อนจางหลังตัวแบบ + ป้ายสเปกสองข้าง + บล็อกส่วนลด | โปรโมชัน ใช้รูปคนจาก `data/models/` (มี `model-a_1.png` แล้ว) กรอบแว่นจริงประกบทีหลัง |
| `14-word-as-lens` | คำสั้นเว้นวรรคกว้าง แว่นยืนแทนตัวอักษรกลางคำ พื้นสตูดิโอสว่าง | เล่นคำ อ่านสนุก ใช้ได้เฉพาะรูปหน้าตรง `_1` |

`8-luxury-minimal` ไม่มี `ref.*` — ทำขึ้นจาก `color_palete.jpg` ล้วน กติกาของสไตล์นี้: accent สีเดียว ตัวอักษรเล็กและห่าง ที่ว่างอย่างน้อยครึ่งภาพ ไม่มีของประดับที่ไม่ใช่ข้อมูล

ทุกสไตล์เป็น **1080×1080 จัตุรัส** ตั้งแต่ 2026-09-16 ถ้าต้องการ 1080×1350 หรือ story 1080×1920 ต้องสั่งเป็นรายครั้ง

`color_palete.jpg` คือชุดสีกลาง: Phthalo green `#123A29`, Peach-orange `#EFCF9C`, Timberwolf `#D9D4CB`, Pastel gray `#CFD0BF`, Raisin black `#212121`, Snow `#FAFAFA`

## เพิ่มสไตล์ใหม่
