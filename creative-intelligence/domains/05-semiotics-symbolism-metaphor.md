**ความคิดเปลี่ยนอย่างไร (สรุป):**
1. **จากระบบ → ผู้อ่าน:** Saussure/Barthes มองหารหัสใน "ตัวบท"; Eco และ Hall ย้ายจุดสนใจไปที่ **ผู้ถอดรหัส** — ความหมายที่ผู้ผลิตตั้งใจ ≠ ความหมายที่ผู้ชมได้ [Hall1973], [Eco1976]
2. **จากภาษา → ความคิด:** CMT อ้างว่าอุปมาอยู่ในความคิด ไม่ใช่แค่ถ้อยคำ [LakoffJohnson1980] แต่หลักฐานส่วนใหญ่ยังเป็นภาษา [Murphy1996]
3. **จากคำอธิบาย → การทดลอง → การแก้ไข:** ปี 2000s มีผลทดลอง "ร่างกายกำหนดความคิด" มากมาย; ปี 2014–2024 การทำซ้ำอิสระส่วนใหญ่ล้มเหลว [MacGiolla2024] → ปัจจุบันเชื่อได้ว่า **อุปมาช่วยจัดโครงสาร (organise) และเปลี่ยนความเชื่อได้เล็กน้อย** [Brugman2019] แต่ **"prime" พฤติกรรมด้วยสัมผัส/วัตถุ ไม่น่าเชื่อ**
4. **จาก pictorial → multimodal:** ในวิดีโอ/คลิป source กับ target อาจอยู่ในเสียง ภาพ ข้อความ คนละช่อง [ForcevilleUrios2009]

## 2. หลักการพื้นฐาน (Fundamentals)

### 2.1 นิยามที่ใช้ในสตูดิโอ
| คำ | นิยาม (สั้น) | key |
|---|---|---|
| **sign / sign-function** | สิ่งที่ถูกใช้แทนอย่างอื่น โดยความสัมพันธ์ถูกกำหนดด้วยรหัส (code) ของสังคม | [Eco1976], [SEP_PeirceSemiotics] |
| **code** | ชุดกฎที่ทำให้ sign มีความหมาย: textual codes (มุมกล้อง, ขนาดช็อต) และ social codes (ภาษากาย, การแต่งกาย) | [Chandler_S4B] |
| **icon / index / symbol** | เหมือน / มีเหตุโยงจริง / ตกลงกัน | [SEP_PeirceSemiotics] |
| **denotation / connotation** | ความหมายตามตัว / ความหมายแฝงที่ผูกกับวัฒนธรรมและอุดมการณ์ — Hall: แยกได้แค่ "เชิงวิเคราะห์" ในการใช้จริงมาด้วยกันเสมอ | [Barthes1977], [Hall1973] |
| **myth** | connotation ที่ถูกทำให้ดูเป็นธรรมชาติจนคนไม่รู้ว่าเป็นรหัส (second-order system) | [Barthes1957] |
| **anchorage / relay** | ข้อความ "ล็อก" ความหมายของภาพ / ข้อความกับภาพ "ส่งต่อ" เล่าเรื่องร่วมกัน | [Barthes1977] |
| **preferred reading** | การอ่านที่ตัวบทและบริบทสังคม "เชิญชวน" ให้อ่าน; ผู้ชมอาจอ่านแบบ negotiated หรือ oppositional | [Hall1973] |
| **polysemy / purposeful polysemy** | สารหนึ่งตีความได้หลายแบบ / ตั้งใจให้กำกวมเชิงกลยุทธ์ | [Puntoni2010] |
| **aberrant decoding** | ถอดด้วยรหัสคนละชุดกับที่เข้ารหัส | [Eco1976] |
| **metaphor (conceptual)** | การ map โครงสร้างจาก source domain (รูปธรรม) ไป target domain (นามธรรม) เช่น LIFE IS A JOURNEY | [LakoffJohnson1980] |
| **linguistic metaphor (MIP)** | คำที่ "ความหมายในบริบท" ต่างจาก "ความหมายพื้นฐาน" (รูปธรรม เกี่ยวกับร่างกาย แม่นยำ เก่ากว่า) แต่เข้าใจได้โดยเปรียบเทียบกัน | [Pragglejaz2007] |
| **metaphorical-words vs -concepts frame** | อุปมาระดับคำเดี่ยว vs อุปมาที่จัดตรรกะทั้งสาร | [Brugman2019] |
| **pictorial / multimodal metaphor** | target และ source แสดงในภาพทั้งคู่ / อยู่คนละ mode (ภาพ+คำ, ภาพ+เสียง) | [Forceville1996], [ForcevilleUrios2009] |
| **juxtaposition / fusion / replacement** | วางคู่ / หลอมเป็นวัตถุเดียว / แทนที่ของที่ควรอยู่ | [PhillipsMcQuarrie2004] |
| **conventional (dead) vs novel metaphor** | ใช้จนไม่รู้สึกว่าเป็นอุปมา (ใจร้อน, ใจดี) vs ใหม่ต้องตีความ | [BowdleGentner2005], [Doherty2025] |
| **optimal innovation** | ความใหม่ที่ยังกู้ความหมายคุ้นเคยกลับมาได้ ("a peace of paper") | [Giora2004] |
| **pareidolia** | เห็นหน้าในวัตถุ — ระบบจับหน้า "ไวเกิน" | [Wardle2020] |
| **sound symbolism** | เสียงของคำ/ชื่อสื่อคุณสมบัติ (เล็ก-ใหญ่, แหลม-มน) | [Klink2000], [Cwiek2022] |

### 2.2 หลักการแกน (core principles)
- **P1 ความหมายอยู่ในรหัสร่วม ไม่ใช่ในภาพ** — FACT-level (กรอบคิดที่ทุกสำนักยอมรับ): รหัสยิ่งแพร่หลายและเรียนรู้เร็ว ยิ่งดู "เป็นธรรมชาติ" แต่แม้รหัสภาพ "ธรรมชาติ" ก็ยังเฉพาะวัฒนธรรม [Hall1973]
- **P2 เจตนาไม่ควบคุมการถอดรหัส** — Burberry ตั้งใจ "nautical" แต่คนอ่าน "บ่วงแขวนคอ" [Burberry2019_Noose]; Eco: ทุก sign "ใช้โกหกได้" — รวมถึงโกหกแบบไม่ตั้งใจ [Eco1976]
- **P3 connotation คือพื้นที่เสี่ยงและพื้นที่สร้างสรรค์** — ระดับ connotation เปิดกว้างให้ตีความใหม่ จึงเป็นที่ที่ทั้งความคิดสร้างสรรค์และความผิดพลาดเกิด [Hall1973]
- **P4 อุปมาที่มีพลังคืออุปมาที่จัดโครงทั้งสาร** — concept-level d = 0.22 vs word-level d = 0.04 [Brugman2019]; "superior organization" [SoporyDillard2002]
- **P5 ใหม่แบบมีหลักยึด** — ความใหม่ที่ยังจำของเดิมได้ ชอบที่สุด; ใหม่ล้วนชอบน้อยสุด [Giora2004]; ภาพคู่ที่เข้าใจง่ายชอบกว่า [Lagerwerf2023]
- **P6 anchor ด้วย "คำใบ้" ไม่ใช่ "เฉลย"** — hint เพิ่มความชอบผ่านความเข้าใจ; อธิบายหมดลดความชอบ [Phillips2000]
- **P7 ทุกภาพมีหลายความหมาย (polysemy)** — ต้องตัดสินใจว่าจะล็อกหรือปล่อย และตรวจว่าความหมายส่วนเกินไม่เป็นพิษ [Puntoni2010]
- **P8 สัญลักษณ์ ≠ คันโยกพฤติกรรม** — ภาพ "อบอุ่น/สะอาด" เป็นรหัสความหมาย ไม่ใช่ตัว prime ที่พิสูจน์แล้ว [LynottEtAl2014], [EarpEtAl2014], [MacGiolla2024]

## 3. ทฤษฎีขั้นสูง (Advanced theory)

### 3.1 Myth: ความหมายชั้นสอง (THEORY)
- **กลไก:** ระบบแรก: signifier (ภาพทหาร) + signified (ทหารวันทยหัตถ์) = sign → ระบบที่สองใช้ sign ทั้งก้อนเป็น "form" แล้วผูกกับ concept ใหม่ (ความยิ่งใหญ่ของจักรวรรดิ) [Barthes1957]
- **ทำไมสำคัญกับงานโฆษณา:** สินค้าแทบทุกชิ้นขาย myth (แว่น = ฉลาด/มีระดับ, ชุดขาว = บริสุทธิ์) — Oswald เสนอว่า brand equity คือการจัดการความหมายเหล่านี้ [Oswald2012]
- **ข้อจำกัด:** เป็นวิธีตีความเชิงวิพากษ์ วัดไม่ได้โดยตรง; อ่านแค่ excerpt + สรุปรอง

### 3.2 Encoding/Decoding และ aberrant decoding (THEORY)
- Hall: meaning structures 1 (ผู้ผลิต) และ 2 (ผู้ชม) อาจไม่ตรงกัน; ระดับ "เข้าใจ/เข้าใจผิด" ขึ้นกับความเหมือนของรหัส [Hall1973]
- **3 ตำแหน่ง:** dominant-hegemonic (รับเต็ม), **negotiated** (รับกรอบใหญ่ แต่มีข้อยกเว้นท้องถิ่น — Hall เห็นว่า "เข้าใจผิด" ส่วนใหญ่เกิดตรงนี้), oppositional (เข้าใจแต่อ่านกลับด้าน) [Hall1973]
- **การใช้:** ก่อนปล่อยงาน เขียน 3 บรรทัด: preferred / negotiated / oppositional reading — ถ้า oppositional reading แรงและน่าแชร์ (เช่น "แบรนด์ล้อคนอ้วน") ให้แก้
- **ข้อวิจารณ์ (ความรู้ทั่วไป ไม่ได้หาแหล่งใน session นี้):** โมเดล 3 ตำแหน่งถูกมองว่าแข็งเกินไปและเน้นข่าว/การเมือง → ใช้เป็น heuristic

### 3.3 CMT: แบบแรง vs แบบอ่อน (THEORY, contested)
- **CMT:** คนคิดเรื่องนามธรรมผ่าน source domain รูปธรรม; ภาษาเป็นร่องรอยของ mapping ในความคิด [LakoffJohnson1980]
- **Murphy (1996):** (ก) แบบแรง — target เข้าใจได้ *ผ่าน* source เท่านั้น — ไม่ coherent; (ข) แบบอ่อน — metaphor ปรับโครงสร้าง representation ของ target — เป็นไปได้แต่มีปัญหาเชิงประจักษ์; ข้อมูลจำนวนมากอธิบายได้ด้วย **structural similarity** ระหว่างโดเมน; หลักฐานส่วนใหญ่เป็นภาษา (circular) [Murphy1996]
- **Kövecses:** อุปมาระดับ generic (คนโกรธ = ภาชนะมีแรงดัน) พบในหลายภาษาที่ไม่เกี่ยวกัน แต่ระดับรายละเอียดแปรตามวัฒนธรรม [Kovecses2005]
- **ภาษาไทย:** อุปมา "ใจ" แบ่งได้ 4 กลุ่ม — ใจเป็นคน / วัตถุ / พื้นที่ / ภาชนะ [Bovonwiwat2023]; ในกลอนนิราศ "ใจ" เป็น source domain เด่นสุด ส่วนใหญ่เป็นคำประสมแบบ conventional และมี novel บ้าง [Doherty2025]
- **ข้อสรุปสำหรับสตูดิโอ:** ใช้ CMT เป็น **เครื่องมือค้นหา source domain ที่ผู้ชมคุ้นอยู่แล้ว** ไม่ใช่ข้อพิสูจน์ว่าภาพเราจะ "เปลี่ยนความคิด"

### 3.4 Embodied metaphor experiments และการพังของมัน (FACT ระดับ replication)
| ผลเดิม | การทำซ้ำ | สถานะ |
|---|---|---|
| ถือถุงอุ่น → เลือกให้รางวัลเพื่อน (Williams & Bargh 2008) | 3 แล็บ N = 861 ไม่พบผล [LynottEtAl2014] | **ไม่ผ่าน** |
| ล้างมือ/ความสะอาด → ตัดสินศีลธรรมเบาลง (Schnall et al. 2008) | direct replication power > .99 ไม่พบผล; ผู้เขียนเดิมแย้งเรื่อง ceiling effect [JohnsonCheungDonnellan2014] | **ไม่ผ่าน (มีข้อโต้แย้ง)** |
| เขียนเรื่องผิดศีลธรรม → อยากได้สบู่ (Macbeth effect; original d ≈ 1.08, N = 27) | UK N = 153, US, อินเดีย — ไม่พบในทุกการทดลอง [EarpEtAl2014] | **ไม่ผ่าน** |
| คำบวกประเมินเร็วเมื่ออยู่บน (up = good) | ผลในแล็บเดิมมี; รายงานทำซ้ำหนึ่งไม่สนับสนุน (อ่านไม่ได้) [MeierRobinson2004]; งานต่อยอดจากแล็บเดียวได้ผลเล็ก r ≈ .10–.16 ไม่สม่ำเสมอ [Gottwald2015] | **อ่อน/ไม่แน่นอน** |
| Action-sentence compatibility effect | pre-registered 18 แล็บ ≈ 0 [Morey2022] | **ไม่ผ่าน** |
| social priming ทั้งสาย | 70 replications: ทีมอิสระ 0/52 significant, d = 0.002 [MacGiolla2024] | **burden of proof กลับไปที่ผู้เสนอ** |
- review ยุคก่อนวิกฤตเสนอ "metaphoric transfer strategy" [LandauMeierKeefer2010] — อ่านเป็นแผนที่ทฤษฎี ไม่ใช่หลักฐาน
- **บทเรียน:** อุปมาเชิงร่างกาย (อุ่น=ใจดี, สะอาด=บริสุทธิ์, สูง=ดี) **มีอยู่จริงในภาษาและรหัสวัฒนธรรม** แต่ **การใช้ภาพ/วัตถุเพื่อ "ทำให้" คนรู้สึกหรือทำอะไร ไม่มีหลักฐานที่ทนการทำซ้ำ**

### 3.5 Metaphor framing: ผลจริงแต่เล็ก (FACT-meta, with caveats)
- Thibodeau & Boroditsky: "อาชญากรรมคือสัตว์ร้าย" vs "ไวรัส" → ข้อเสนอเน้นปราบปราม 74% vs 56%; ไม่มีผลถ้าอุปมาอยู่ท้ายข้อความ; คนแทบไม่รู้ตัวว่าอุปมามีผล (3–15%) [ThibodeauBoroditsky2011]
- Steen et al. 4 การทดลอง (N รวม ~1,790) เพิ่มเงื่อนไข literal → **ไม่พบผล**; การอ่านเรื่องอาชญากรรมเฉย ๆ ก็ดันไปทางปราบปราม [SteenReijnierseBurgers2014]
- Meta-analysis 91 studies N = 34,783: d รวม 0.11; beliefs 0.29; attitudes 0.10; intentions n.s.; concept-level 0.22 vs word-level 0.04; มีสัญญาณ publication bias บางส่วน [Brugman2019]
- Sopory & Dillard: metaphor > literal เล็กน้อย; "superior organization" อธิบายได้ดีสุด [SoporyDillard2002]
- **การตีความ:** อุปมา "ระดับเรื่อง" ที่ใช้ตลอดสาร เปลี่ยนความเชื่อได้เล็กน้อย; อุปมาคำเดียวแทบไม่มีผล; **ไม่มีผลต่อความตั้งใจซื้อ/ทำ** ในข้อมูลการเมือง

### 3.6 การประมวลอุปมาใหม่ vs เก่า (THEORY, partly tested)
- **Career of metaphor:** อุปมาใหม่ถูกประมวลแบบ "เปรียบเทียบ" (A เหมือน B) — คนชอบรูป simile; เมื่อใช้บ่อยจะกลายเป็น "จัดหมวด" (A เป็น B) [BowdleGentner2005]; ฝ่ายค้านว่า aptness (ความเหมาะเจาะ) ทำนายได้ดีกว่า conventionality (Estes 2006 ตามที่อ้างใน search) — ยังถกกัน
- **Optimal innovation:** ใหม่ + กู้ของคุ้นได้ = ชอบสุด; คุ้นเฉย ๆ = อันดับสอง; ใหม่ล้วน = แย่สุด; ใช้ได้ทั้งคำและภาพ [Giora2004]
- **ผลต่องานภาพ:** อุปมาภาพใหม่ → เริ่มจาก juxtaposition (รูปแบบ "เหมือน") ก่อน fusion; Lagerwerf พบคู่ภาพง่าย (ประเภทเดียวกัน) เร็วและชอบสุด ไม่พบ inverted-U → fluency สำคัญ [Lagerwerf2023]
- **Visual rhetoric:** figure ภาพเพิ่ม elaboration และความชอบโดยไม่ลดความเข้าใจ แต่ trope ได้ผลน้อยลงในคนที่ไม่มี cultural competency [McQuarrieMick1999]

### 3.7 Multimodal metaphor (THEORY → PRACTICE)
- target/source อยู่คนละ mode: ภาพแว่น (target) + เสียงชัตเตอร์กล้อง (source: "คมชัดเหมือนเลนส์กล้อง") [ForcevilleUrios2009]
- เกณฑ์ Forceville: ต้องระบุได้ว่า target คืออะไร source คืออะไร และคุณสมบัติใด map จาก source → target [Forceville1996]
- **คลิป/TTS:** เสียงพูดฟังครั้งเดียวผ่าน (ย้อนอ่านไม่ได้) → อุปมาในเสียงต้องสั้นและ conventional กว่าในภาพนิ่ง **(craft)**

### 3.8 Polysemy, unintended meaning และ pareidolia (THEORY + neuro FACT)
- **Polysemy เป็นปกติ** — ไม่ใช่ข้อผิดพลาด; purposeful polysemy ใช้เป็นกลยุทธ์ได้ [Puntoni2010]
- **กลไกความหมายแฝงที่ไม่ตั้งใจ (สังเคราะห์, (opinion) บนฐาน [Hall1973], [Eco1976], [Wardle2020]):**
  1. **Shape-icon collision** — รูปทรงบังเอิญเหมือน icon ที่มีพลังสูง (วงเชือกที่คอ/หัว = บ่วง; กากบาท = ศาสนา/ผิด; สวัสดิกะ)
  2. **Index misfire** — ร่องรอยที่ตั้งใจเป็นของตกแต่งถูกอ่านเป็นเหตุการณ์ (คราบแดง = เลือด)
  3. **Pareidolia** — ระบบจับหน้า "เน้นความไวมากกว่าความแม่น" จึงเห็นหน้าในวัตถุภายใน ~100–200 ms ก่อนสมองแก้เป็นวัตถุ (~250 ms) [Wardle2020] → ภาพเลื่อนผ่านเร็ว = เห็น "หน้า" ก่อน
  4. **Anchorage collision** — คำ + คน รวมกันเกิดความหมายใหม่ ("coolest monkey" บนเด็กผิวดำ) [HM2018_Monkey]
  5. **Code-community mismatch** — รหัสท้องถิ่นอ่านต่างจากรหัสโลก (Hitler เป็น "ตัวร้ายเท่ ๆ" vs สัญลักษณ์ฆ่าล้างเผ่าพันธุ์) [Chula2013_Hitler], [Dunkin2013_Thailand]
  6. **Myth leak** — ภาพสื่อ "ลำดับชั้น" ที่ไม่ตั้งใจ (ผิวขาว = สำเร็จ) — ดู CULTURAL_CHECK F1

### 3.9 Brand semiotics (THEORY + some FACT)
- โลโก้แต่ละแบบเป็น sign ประเภทต่างกัน: **icon** (รูปแว่น), **index** (เลนส์สะท้อนแสง = ของจริง), **symbol** (ตัวอักษร wordmark, สีแบรนด์) — โลโก้ที่ "natural + harmonious + elaborate ปานกลาง" จำได้ดี (ตามสรุปของ Kim & Lim) [HendersonCote1998]
- **Sound symbolism:** front vowels (อี, เอ) → เล็ก เบา เร็ว คม; back vowels (โอ, อู) → ใหญ่ ช้า หนัก [Klink2000]; ผล bouba/kiki เสถียรใน 25 ภาษา 10 ระบบเขียน และแทบไม่ขึ้นกับรูปตัวอักษร [Cwiek2022] → ชื่อ/wordmark ควร "ฟัง" สอดคล้องกับรูปทรง
- **Hidden secondary sign:** ลูกศรใน FedEx = "hidden bonus" — โลโก้ต้องทำงานได้แม้ไม่มีใครเห็นลูกศร [Leader_FedEx]
- **Category-level icon:** คนวาด "ซอสมะเขือเทศ" แล้ว 97% วาด Heinz (ตามที่ D&AD รายงาน) = แบรนด์เป็นเจ้าของ icon ของหมวด [Heinz_DrawKetchup]
- **Myth management:** brand equity = การจัดการความหมาย [Oswald2012]; distinctive assets และ cover-the-logo test → `creative-intelligence/knowledge/branding/README.md`

### 3.10 สีและสัญลักษณ์ข้ามวัฒนธรรม (FACT ระดับ association, ไม่ใช่ causal)
- 4,598 คน 30 ชาติ 22 ภาษา: แบบแผน สี–อารมณ์ คล้ายกันสูง (r = .88) และคล้ายยิ่งขึ้นเมื่อภาษา/ภูมิศาสตร์ใกล้กัน; ใช้ **ชื่อสี** ไม่ใช่สีจริง [Jonauskaite2020]; โปสเตอร์ของกลุ่มเดียวกันไม่แสดงรหัส TH ในรายชื่อที่มองเห็น → **ยังยืนยันไม่ได้ว่ามีคนไทยในข้อมูล**
- ไทย (แหล่ง tier B–C): ขาว = ความบริสุทธิ์ (คติพราหมณ์: ขาว=บริสุทธิ์, แดง=เคลื่อนไหว, ดำ=หนัก) และพระพุทธรูปปิดทอง/ทาสีขาวเพื่อสื่อบริสุทธิ์ [ThailandFoundation2021_Colours]; ดำ/ขาว = ไว้ทุกข์ (ปี 2016 ทั้งประเทศ) [AlJazeera2016_Mourning]; สีวัน/สีวันเกิดเป็นความเชื่อส่วนบุคคล ไม่ใช่มาตรฐานสังคม [ThailandFoundation2021_Colours]; ดอกบัว = บริสุทธิ์/ตื่นรู้ในพุทธทุกสาย [AsianArt_Lotus]; เลข 9 = ก้าวหน้า (พ้องเสียง "ก้าว") [Naresuan2023_Nine]
- **ความขัดแย้งของแหล่ง:** สีวันศุกร์/เสาร์ไม่ตรงกันระหว่างแหล่ง (ฟ้า/ม่วง) → ตรวจก่อนใช้

| Metaphor framing เปลี่ยน belief/attitude | **medium** (meta-analysis, แต่ d เล็ก ~0.1–0.3, bias บางส่วน) | [Brugman2019], [SoporyDillard2002]; ข้อโต้แย้ง [SteenReijnierseBurgers2014] |

| Metaphor เปลี่ยน *ความตั้งใจซื้อ/ทำ* | **low** (meta: n.s.) | [Brugman2019] |
| ใหม่ที่ยังจำของเดิมได้ = ชอบที่สุด | **medium** (6 การทดลอง, ภาษาฮีบรู, กลุ่มเดียว) | [Giora2004] |
| Hint caption ดีกว่าเฉลย | **medium** (งานเดียว + งานต่อยอด) | [Phillips2000] |
| ภาพคู่เข้าใจง่ายชอบกว่า; ไม่มี inverted-U | **medium** (ขัดกับ van Mulken — ดู semiotics README §3) | [Lagerwerf2023] |
| Visual figure เพิ่ม liking แต่ trope ต้องการรหัสร่วม | **medium** (abstract, กลุ่มอเมริกัน) | [McQuarrieMick1999] |
| Pareidolia เกิดเร็วและอัตโนมัติ | **high** (neuroimaging + ลิงก็มี) | [Wardle2020] |
| สี–อารมณ์มีแกนร่วมข้ามชาติ | **medium-high** สำหรับ association; ไม่รู้ว่ามีไทยไหม | [Jonauskaite2020] |
| Bouba/kiki ข้ามภาษา | **high** | [Cwiek2022] |
| Sound symbolism ในชื่อแบรนด์ | **medium** (ภาษาอังกฤษ; ไทยมีวรรณยุกต์ ยังไม่ทดสอบ) | [Klink2000] |
| ความหมายสัญลักษณ์ไทย (สีวัน, ขาว, ดำ, บัว, 9) | **medium** ว่า "มีความเชื่อนี้อยู่จริง"; **low** ว่ามีผลต่อการรับรู้โฆษณา | tier B–C [ThailandFoundation2021_Colours], [AsianArt_Lotus], [Naresuan2023_Nine], [AlJazeera2016_Mourning] |
| ผลลัพธ์ case study (+62% calls, 97%, sales lift) | **low–medium** (agency self-report) | [THPF_SmokingKid2013], [Heinz_DrawKetchup] |

**จุดที่ยังถกเถียง:** (1) CMT แบบแรง vs structural similarity [Murphy1996] (2) crime beast/virus: ผลจริงหรือ artefact ของการ code คำตอบ [ThibodeauBoroditsky2011] vs [SteenReijnierseBurgers2014] (3) ความซับซ้อนของ visual metaphor: inverted-U vs fluency [Lagerwerf2023] (4) career of metaphor vs aptness [BowdleGentner2005] (5) Hall 3 ตำแหน่ง vs การอ่านที่ซับซ้อนกว่า (ไม่มีแหล่งใน session นี้)

**ข้อจำกัดใหญ่:** ไม่พบงานทดลอง visual/verbal metaphor กับ **ผู้ชมไทย** เลย; ความหมายสัญลักษณ์ไทยมาจากแหล่งบรรยาย ไม่ใช่การวัด; กลุ่มตัวอย่างตะวันตก/ฮีบรู/อเมริกันเป็นหลัก

## 6. การประยุกต์ใช้จริง (Applications)

### 6.1 วิธีวิเคราะห์ภาพ/โฆษณาเชิงสัญศาสตร์ ทีละขั้น (generic, ใช้กับงานใดก็ได้)
ประกอบจาก [Chandler_S4B], [Barthes1977], [Barthes1957], [Hall1973], [Pragglejaz2007] (+ Panofsky ใน semiotics README §2.4):

1. **ระบุตัวบท** — สื่อ, genre, ช่องทาง (feed/Reel/carousel/OOH), บริบทที่เห็น, ผู้ชมหลัก, จุดประสงค์ของการวิเคราะห์ [Chandler_S4B]
2. **Denotation inventory** — ลิสต์ทุกองค์ประกอบที่เห็นตามตัว (คน วัตถุ สี ข้อความ ท่าทาง เสียง) โดยยังไม่ตีความ [Barthes1977]
3. **จัดประเภท sign** — แต่ละองค์ประกอบเป็น icon / index / symbol? (symbol = เสี่ยงข้ามวัฒนธรรมที่สุด) [SEP_PeirceSemiotics]
4. **Codes** — textual (มุมกล้อง ขนาดช็อต ฟอนต์ จังหวะตัดต่อ) และ social (ภาษากาย การแต่งกาย ลำดับชั้น) [Chandler_S4B]
5. **Paradigmatic analysis + commutation test** — สำหรับแต่ละ signifier: ทางเลือกอื่นในชุดเดียวกันคืออะไร? ลองสลับในใจ (ขาว→ดำ, ล่าง→บน, ชาย→หญิง) ความหมายเปลี่ยนไหม? ถ้าเปลี่ยน = signifier นั้น "ทำงาน"; อะไร "ขาดหายไป" อย่างเห็นได้ชัด? [Chandler_S4B]
6. **Syntagmatic analysis** — ลำดับ/ตำแหน่ง/ขนาด: อะไรมาก่อน อะไรใหญ่ อะไรอยู่สูง; ในคลิป: ลำดับช็อตสร้างความหมายอะไร [Chandler_S4B]
7. **Connotation & myth** — แต่ละองค์ประกอบพาความหมายแฝงอะไร? รวมกันแล้วเสนอ "ความจริงที่เป็นธรรมชาติ" อะไร (เช่น "คนใส่แว่น = เก่ง")? ใครได้ประโยชน์จากที่มันดูธรรมชาติ? [Barthes1957]
8. **Tropes** — มีอุปมา/นามนัย (metonymy)/เล่นคำไหม: ระบุ target–source–คุณสมบัติที่ map; เป็น juxtaposition/fusion/replacement? [Forceville1996], [PhillipsMcQuarrie2004]; สำหรับข้อความใช้ MIP ทีละคำ [Pragglejaz2007]
9. **Anchorage/relay** — ข้อความล็อกความหมายไหน ปิดความหมายไหน; ข้อความ+ภาพรวมกันสร้างความหมายใหม่ที่ไม่ตั้งใจไหม [Barthes1977], [HM2018_Monkey]
10. **Decoding map** — เขียน preferred / negotiated / oppositional reading สำหรับ 2–3 กลุ่มผู้ชม (คนไทยทั่วไป, ลูกค้าต่างชาติ, กลุ่มเปราะบางที่เกี่ยวข้อง) [Hall1973]
11. **Misreading hunt** — ทำ §6.2
12. **Verdict** — สรุป: ความหมายหลักที่ผู้ชมจะได้, ความเสี่ยง, สิ่งที่ต้องแก้ (เพิ่ม anchor / เปลี่ยน signifier / ตัดออก)

> **เคล็ด:** วิเคราะห์เป็น **คู่** (งานเรา vs งานคู่แข่ง หรือ v1 vs v2) ง่ายกว่าวิเคราะห์เดี่ยว [Chandler_S4B]

### 6.2 Misreading hunt — จับความหมายที่ไม่ได้ตั้งใจ (protocol ของสตูดิโอ)
ฐาน: [Hall1973], [Eco1976], [Wardle2020], [Puntoni2010]; ขั้นตอนเป็น **(craft)** ที่ยังไม่ได้วัดผล

1. **Thumbnail test (0.5 วินาที):** ย่อภาพเหลือ ~150 px หรือหรี่ตา (squint) — อ่านได้ว่าอะไร? (pareidolia และ shape collision เห็นชัดที่ขนาดเล็ก เพราะสมองตัดสินก่อนรายละเอียด [Wardle2020])
2. **Silhouette test:** ทำภาพเป็นเงาดำ — รูปทรงหลักเหมือนอะไรที่มีความหมายแรงไหม (บ่วง, อาวุธ, กากบาท, สวัสดิกะ, อวัยวะ)
3. **Hot-zone scan:** ตรวจ "จุดร้อน" ที่ความหมายแรง: **รอบคอและศีรษะ** (เชือก สายไฟ สายกระเป๋า ผ้าพันคอ เงา), มือ (ท่ามือ), ปาก, ตา, หน้าต่าง/กระจก (หน้าคนที่ AI แอบวาด), พื้นหลังที่มีตัวอักษร
4. **Worst-reading brainstorm (60 วินาที):** ถาม "คนที่อยากล้อแบรนด์ / คนที่เพิ่งสูญเสีย / เด็ก / นักท่องเที่ยว จะอ่านภาพนี้ว่าอะไร?" เขียนอย่างน้อย 3 ข้อ
5. **Text-on-person check:** ข้อความทุกคำที่อยู่บนหรือข้างคน/สัตว์ — อ่านรวมกันแล้วเป็นการเหยียดไหม [HM2018_Monkey]
6. **Global-code check:** ถ้าโพสต์บนแพลตฟอร์มสาธารณะ ผู้ชมทั่วโลกถอดรหัสได้ — สัญลักษณ์ที่ "ท้องถิ่นมองว่าไม่เป็นไร" ใช้ไม่ได้ [Chula2013_Hitler], [Dunkin2013_Thailand]
7. **Fresh eyes:** ให้คนที่ไม่เคยเห็น brief ดู 3 วินาทีแล้วเล่า (comprehension test ย่อ — semiotics README §5)
8. **Log:** ทุกการอ่านผิดที่จับได้ → บันทึกใน `creative-intelligence/memory/store/error.jsonl` พร้อม "รูปทรง → ความหมายผิด"

**รายการรูปทรงความเสี่ยงสูง (ใช้เป็น checklist; (craft) + กรณีจริง):**
| รูปทรง/การจัดวาง | อ่านผิดเป็น | หลักฐาน |
|---|---|---|
| เชือก/สาย/ห่วง ที่คอหรือเหนือศีรษะ | บ่วงแขวนคอ (ฆ่าตัวตาย, lynching) | [Burberry2019_Noose]; สตูดิโอ set 104/3 และ 135/1+4 **(our test)** |
| จุดสองจุด + เส้นโค้ง บนวัตถุ/หัวกลม | หน้า/สีหน้า (ทำลาย "faceless") | [Wardle2020]; สตูดิโอ 134/04-1, 137/04-2, 139/02-1 **(our test)** |
| คนในหน้าต่าง/กระจก/รูปถ่ายเล็กในภาพ AI | หน้าคนจริงที่ไม่ได้ขออนุญาต | สตูดิโอ 109/1, 137/4+5 **(our test)** |
| คำบนเสื้อผ้า/ป้ายข้างคน | anchorage ที่ไม่ตั้งใจ | [HM2018_Monkey]; สตูดิโอ 110/5 **(our test)** |
| แขนยกตรงไปข้างหน้า, กากบาทเอียง, ไขว้ 4 แขน | Nazi salute / สวัสดิกะ | [Chula2013_Hitler]; SYMBOL_LIBRARY `x.swastika` |
| ผิวคล้ำ/ขาวเป็นมุก หรือ before/after | เหยียดสีผิว | [Dunkin2013_Thailand]; CULTURAL_CHECK F1 |
| คน + สัตว์ (ลิง) ในคำหรือภาพเดียว | เหยียดเชื้อชาติ | [HM2018_Monkey] |
| ซี่กรง/เงาซี่ บนหน้าคน | คุก/ถูกขัง | (craft) |
| ของแดงไหล/หยด | เลือด | (craft) |
| มือ/นิ้วในท่าที่ไม่ได้ตั้งใจ | ท่าหยาบ (ดู semiotics README §2.8) | MatsumotoHwang2013 ใน semiotics sources |

### 6.3 อุปมาในบทสนทนา/กลอนสำหรับเรื่องสั้นไทย (Mint & Tao, story clips)

**ก. ทำไมต้องระวัง cliché:** อุปมาที่ใช้จนตาย (conventional) ถูกประมวลเหมือน "คำธรรมดา" [BowdleGentner2005] — ไม่ผิด แต่ไม่สร้างความรู้สึก "ค้นพบ"; อุปมาใหม่ล้วนก็ชอบน้อย [Giora2004] → **เป้าหมาย = optimal innovation**

**ข. ตาราง cliché → fresh (ตัวอย่างเป็น (craft) ไม่ใช่ผลวิจัย):**
| cliché (ไทย) | อุปมาแฝง | ทำให้สดแบบ optimal innovation | หมายเหตุ |
|---|---|---|---|
| ร่ม = ที่พึ่ง | SUPPORT IS SHELTER | Tao กางร่มให้ Mint แต่ **ร่มเล็กเกิน ไหล่ทั้งคู่เปียกข้างละนิด** — "ที่พึ่ง" กลายเป็น "เปียกด้วยกัน" | ของคุ้นยังจำได้ + ความหมายใหม่ |
| ฝนตก = เศร้า | SADNESS IS RAIN | ฝนตก แต่ Mint **นับเม็ดฝนบนกระจกเป็นเกม** — ความเศร้ากลายเป็นการรอ | กลับขั้ว valence |
| แสงปลายอุโมงค์ | HOPE IS LIGHT | แสงไม่ได้อยู่ปลาย — **ไฟฉายอยู่ในมือเราเอง** | ย้ายตำแหน่ง source |
| ดอกไม้บาน = เติบโต | GROWTH IS BLOOMING | ต้นไม้ที่ **รากโต แต่ยังไม่มีดอก** — "Slowly Growing" ตรงตัว | เข้ากับชื่อช่อง |
| ภูเขา = อุปสรรค | DIFFICULTY IS HEIGHT | เดินขึ้นเขาแล้วพบว่า **ยอดเขาคือที่นั่งพัก** | |
| ใจสลาย, ใจหาย | HEART IS OBJECT/CONTAINER | ใช้ภาพ index แทนคำ: **แก้วน้ำที่มีรอยร้าวแต่ยังใส่น้ำได้** | ใจ = ภาชนะ [Bovonwiwat2023] |
| ถนนชีวิต | LIFE IS A JOURNEY | **แผนที่ที่ Mint วาดเอง ผิดมาตราส่วน** | ความไม่สมบูรณ์ = ความเป็นคน |

**ค. กฎสำหรับ bubble/บทพูด (craft, อิงหลักฐานที่มี):**
1. **หนึ่งเรื่อง หนึ่งอุปมาหลัก** ที่จัดโครงทั้งเรื่อง (extended / concept-level) — ผลแรงกว่าอุปมาคำเดี่ยวกระจาย [Brugman2019], [SoporyDillard2002]
2. **วางอุปมาตั้งแต่สไลด์ 1–2** ให้มันจัดกรอบสิ่งที่ตามมา; อุปมาท้ายเรื่องเป็นแค่บทสรุป [ThibodeauBoroditsky2011]
3. **ภาพแบก source, ข้อความแบก target** (multimodal): ภาพร่มเล็ก + bubble "เปียกนิดหน่อยก็ได้ ถ้าไม่ต้องเดินคนเดียว" [ForcevilleUrios2009]
4. **ห้ามอธิบายอุปมาของตัวเอง** ในสไลด์สุดท้าย ("ร่มก็เหมือนเพื่อน...") — ให้คำใบ้พอ [Phillips2000]
5. **ไม่ผสมอุปมาชนกัน** (mixed metaphor: "ปลูกความฝันบนสะพาน") — ตรวจด้วย MIP ทีละคำ [Pragglejaz2007]
6. **คำ "ใจ" ระวังซ้ำ** — ภาษาไทยมีคำประสม "ใจ" มากและส่วนใหญ่ตาย [Doherty2025]; ถ้าบทใช้ "ใจ" >2 ครั้ง ให้เปลี่ยนหนึ่งจุดเป็นภาพ index
7. **bubble ≤ ~12 ตัวอักษรไทย** (บทเรียนการ render ของสตูดิโอ) → อุปมาในข้อความต้องสั้น; อุปมายาวให้ภาพทำ **(our test)**
8. **TTS/คลิป:** อุปมาที่ได้ยินครั้งเดียวต้องเป็นแบบคุ้นหู + บิดนิดเดียว (optimal) ไม่ใช่ปริศนา **(craft)**

**ง. ตัวอย่างสั้น (Mint & Tao, 5 สไลด์) — (craft):**
1. ภาพ: ฝนตก Mint ยืนใต้กันสาด ไม่มีร่ม — bubble: "รอให้หยุดก่อน"
2. ภาพ: Tao เดินมาพร้อมร่มพับเล็กมาก — "มีแค่นี้"
3. ภาพ: สองคนเดินใต้ร่มเล็ก ไหล่นอกเปียกทั้งคู่ — (ไม่มี bubble)
4. ภาพ: ถึงบ้าน มองไหล่เปียกของกันและกัน — Mint: "เปียกเท่ากันเลย"
5. ภาพ: ร่มเล็กแขวนข้างประตู มีหยดน้ำ (index: เพิ่งใช้) — Tao: "พรุ่งนี้ก็ตกอีก"
→ อุปมาหลัก SUPPORT IS SHARED EXPOSURE (บิดจาก ร่ม = ที่พึ่ง); ไม่มีใครพูดว่า "ร่มคือมิตรภาพ"

### 6.4 อุปมาภาพสำหรับสินค้า (ตัวอย่างแว่น / สินค้าใดก็ได้)
- **เริ่มจาก juxtaposition** (กรอบกลม + พระจันทร์เต็มดวง) ในฟีดเร็ว; ใช้ fusion เฉพาะงานที่คนหยุดดู [Lagerwerf2023], [McQuarrieMick1999]
- **Target ต้องเห็นชัดว่าเป็นสินค้าจริง** (ตามกฎบ้าน: แว่นต้องเด่น) — อุปมาที่กลืนสินค้าจนหาย = ล้มเหลว **(craft)**
- **ระวัง causal claim:** "เลนส์ฟ้า = สบายตา" เป็นอุปมาสี ไม่ใช่ข้อเท็จจริงทางการแพทย์ — ดู `../marketing/ETHICS_AND_THAI_AD_RULES.md`; สีเป็น association ไม่ใช่สาเหตุ [Jonauskaite2020]
- **Index ของความจริง:** แสงสะท้อนบนเลนส์, รอยบานพับ — ช่วยให้ภาพ AI "ดูเป็นของจริง" **(craft)**; แต่ต้องตรงของจริง (CULTURAL_CHECK J2)

### 6.5 Brand semiotics: audit โลโก้/wordmark
1. **Sign type:** โลโก้เป็น icon/index/symbol อะไร? wordmark ล้วน = symbol ทั้งหมด → ต้องอาศัย repetition เพื่อสร้างความหมาย **(craft)** + [HendersonCote1998]
2. **Sound–shape fit:** ชื่อ/เสียงพูดชื่อแบรนด์ตรงกับรูปทรงไหม (เสียงสระหน้า = คม/เล็ก, หลัง = มน/ใหญ่) [Klink2000], [Cwiek2022] — สำหรับชื่อไทย/วรรณยุกต์ = hypothesis
3. **Hidden bonus ไม่ใช่สารหลัก** [Leader_FedEx]
4. **Category icon:** มีรูปทรงไหนที่แบรนด์ "เป็นเจ้าของ" ได้ (ขวด, ตัวละคร)? [Heinz_DrawKetchup]; ทดสอบด้วย cover-the-logo test (branding README)
5. **Myth check:** wordmark/สีสื่อ myth อะไร (หรู, คลินิก, ขี้เล่น) และตรงกับตำแหน่งแบรนด์ไหม [Oswald2012], [Barthes1957]
6. **Partner logos:** โลโก้แบรนด์กรอบแว่นมุมซ้ายบนในคลิป = co-branding sign → ตาม branding guide §9

### 6.6 ตรวจสี/สัญลักษณ์ข้ามวัฒนธรรมก่อนใช้
1. ใช้ภาษา "มักถูกเชื่อมโยงกับ" ไม่ใช่ "ทำให้" [Jonauskaite2020]
2. ไทย: ขาว+ดำ เป็นชุดหลัก → ระวังอ่านเป็นไว้ทุกข์ในช่วงไว้ทุกข์ [AlJazeera2016_Mourning]; ขาว = บริสุทธิ์/พุทธ [ThailandFoundation2021_Colours]
3. สีวัน/สีวันเกิด = ความเชื่อส่วนบุคคล → ใช้เป็นเกมสนุก ไม่ใช่สัญญาโชค [ThailandFoundation2021_Colours]
4. ดอกบัว/สัญลักษณ์พุทธ → ตาม SYMBOL_LIBRARY `th.lotus` (restriction = respect) [AsianArt_Lotus]
5. เลข 9 ในราคา/โปร = รหัสบวกในไทย [Naresuan2023_Nine]; ลูกค้าจีน/เกาหลี → ดู `num.4`, `num.8`

## 7. กรณีศึกษาที่ประสบความสำเร็จ (Success case studies)

> แยก **documented** (สิ่งที่แหล่งบอก) กับ **analysis** (การวิเคราะห์ของเรา)

### 7.1 Smoking Kid — Thai Health Promotion Foundation × Ogilvy Thailand (2012)
- **Documented:** เด็กนักแสดงถือบุหรี่ขอไฟจากผู้ใหญ่ที่สูบบุหรี่; ผู้ใหญ่ทุกคนปฏิเสธและสอนเด็กเรื่องโทษบุหรี่; เด็กยื่นโน้ต "คุณห่วงหนู แต่ทำไมไม่ห่วงตัวเอง" + 1600 Quitline; idea มาจาก "Thai cultural insight" เรื่องลำดับชั้น — ผู้ใหญ่ต้องเป็นตัวอย่างและสอนเด็ก; สายที่โทรสำเร็จเพิ่มจากเฉลี่ย 7,057/เดือน เป็น 11,461 ในเดือนมิถุนายน (+62%) และเฉลี่ย ก.ค.–พ.ย. 9,321 (+32%); งบ ~$5,000 ไม่มีค่าสื่อ; >5 ล้านวิวใน 10 วัน (agency/client self-report) [THPF_SmokingKid2013]
- **Analysis:** (1) **role reversal ภายในรหัสลำดับชั้นไทย** = incongruity ที่ทุกคนถอดรหัสได้ทันที (scheme ไม่ใช่ trope ซับซ้อน) (2) ผู้สูบกลายเป็น "ผู้ส่งสาร" ของตัวเอง — Hall: preferred reading ถูก "พูด" โดยผู้ชมเอง ทำให้ oppositional reading ยาก (3) โน้ตเป็น anchorage แบบ "คำถาม" ไม่ใช่คำสั่ง — ใกล้เคียงหลัก hint > เฉลย [Phillips2000]
- **บทเรียนสตูดิโอ:** ใช้รหัสสังคมไทยที่แข็ง (ผู้ใหญ่-เด็ก, ไหว้) เป็น "ฉาก" แล้วบิดหนึ่งจุด

### 7.2 Heinz "Draw Ketchup" — Rethink Canada (2021)
- **Documented:** ให้คนวาด "ketchup" แบบไม่บอกแบรนด์; D&AD รายงาน 97% วาด Heinz; ภาพวาดใช้ใน OOH, print, social, TV; agency อ้าง sales lift (ไม่มีการยืนยันอิสระ) [Heinz_DrawKetchup]
- **Analysis:** แบรนด์เป็นเจ้าของ **icon ระดับหมวดสินค้า** (รูปขวด + ป้าย) — Barthes: myth "ketchup = Heinz" ดูเป็นธรรมชาติจนคนวาดออกมาเอง; ตัวแคมเปญเป็น index (ภาพวาดจริงของคนจริง = หลักฐาน) ไม่ใช่การอ้าง
- **บทเรียน:** asset ที่จำได้ต้องเป็น **รูปทรงที่วาดได้ด้วยมือ** — ทดสอบว่าลูกค้าวาดตัวละคร/โลโก้เราได้ไหม

### 7.3 FedEx logo — Lindon Leader, Landor (1994)
- **Documented:** Leader เห็น "เค้าลูกศร" ระหว่าง E กับ x แล้วปรับตัวอักษรให้ลูกศรดูเป็นธรรมชาติ; ลูกศร = speed and precision; "hidden bonus" — เห็นหรือไม่เห็นก็ได้; Landor ปฏิเสธข้อเสนอให้เน้นลูกศรเป็นกราฟิกรอง [Leader_FedEx]
- **Analysis:** สองชั้นความหมาย — symbol (ชื่อ) + icon ที่ซ่อน (ลูกศร); ชั้นที่สองให้ "ความสุขของการค้นพบ" (คล้าย optimal innovation [Giora2004]) โดยไม่เพิ่มภาระการอ่าน
- **บทเรียน:** ความหมายซ่อนต้องเป็นโบนัส ไม่ใช่เงื่อนไขของความเข้าใจ — ตรงข้ามกับความหมายซ่อนที่ "ไม่ตั้งใจ" (§8)

### 7.4 Panzani — Barthes, *Rhetoric of the Image* (โฆษณาที่ถูกใช้เป็นตัวอย่างการวิเคราะห์)
- **Documented:** ถุงตาข่ายครึ่งเปิด มีพาสต้า ซอส ผัก → connotation "กลับจากตลาด/สด", "ความเป็นอิตาลี" (สีแดง-เขียว-ขาว + ชื่อ) — และ Barthes ชี้ว่าความเป็นอิตาลีเป็นรหัสสำหรับคนฝรั่งเศส [Barthes1977]
- **Analysis:** ตัวอย่างคลาสสิกของการวาง connotation หลายชั้นด้วยวัตถุธรรมดา + anchorage ด้วยชื่อแบรนด์; ใช้เป็นแบบฝึกหัด §12.1

## 8. วิเคราะห์ผลงานที่ผิดพลาด (Failure analysis)

### 8.1 สตูดิโอเอง: เชือกเหนือศีรษะ = บ่วงแขวนคอ (2026-11-24/25) — **(our test / observed)**
- **What:** story carousel set 104 สไลด์ 3 (เชือกที่วาดผ่านเหนือศีรษะตัวละคร) และ set 135 สไลด์ 1+4 (เชือกกระโดดที่ถือยกสูง) ถูกตรวจพบว่าดูเหมือนบ่วง ต้องวาดใหม่ (บันทึกใน memory store `err-20261124-002` และ auto-memory story-carousels)
- **Why:** shape-icon collision — วงเชือก + ศีรษะ/คอ = icon ที่มีพลังสูงมากและรู้ทั่วโลก; ตัวละครไร้หน้า (Mint & Tao) ทำให้คนดูอ่าน "สถานการณ์" จากวัตถุรอบตัวมากขึ้น **(opinion)**; FLUX ไม่รู้ความหมายเชิงสัญลักษณ์ของการจัดวาง
- **Lesson:** เชือก/สาย ต้อง "ต่ำ ใกล้พื้น" และไม่อยู่เหนือหรือรอบคอ; เพิ่มใน Hot-zone scan (§6.2); prompt FLUX: "rope low near the ground"
- **Benchmark ภายนอก:** Burberry 2019 (§8.2) — ข้อผิดพลาดชนิดเดียวกันในแบรนด์ระดับโลก

### 8.2 Burberry "noose" hoodie — London Fashion Week (ก.พ. 2019)
- **What:** ฮู้ดมีเชือกผูกเป็นห่วงรอบคอคล้ายบ่วง; ดีไซเนอร์บอกได้แรงบันดาลใจจากธีม nautical; นางแบบ Liz Kennedy โพสต์ "Suicide is not fashion" พูดถึงการฆ่าตัวตายในครอบครัวและประวัติ lynching และบอกว่าเคยเตือนก่อนโชว์แต่ไม่มีใครฟัง; CEO ขอโทษ ถอดชิ้นงานและภาพทั้งหมด [Burberry2019_Noose]
- **Why:** intent (เชือกเรือ) ≠ decoding (บ่วง) [Hall1973]; ตำแหน่ง (คอ) เปลี่ยน icon; กระบวนการภายในเพิกเฉยต่อผู้เตือน
- **Lesson:** ต้องมี "สิทธิ์ veto" สำหรับคนที่เห็นการอ่านเชิงลบ — แม้คนเดียว (Checklist ข้อ 13)

### 8.3 Chulalongkorn graduation banner with Hitler (ก.ค. 2013)
- **What:** นักศึกษาปีหนึ่งคณะศิลปกรรมวาดป้ายแสดงความยินดี มีฮิตเลอร์ทำท่าชูมือข้าง Batman, Captain America, Hulk, Iron Man; นักศึกษาบอกคอนเซปต์ "ซูเปอร์ฮีโร่ปกป้องโลก"; คณบดีอธิบายว่าคนดีกับคนเลวอยู่ร่วมกัน (ฮิตเลอร์เป็นขาวดำ = "conceptual paradox"); ขอโทษหลัง Simon Wiesenthal Center วิจารณ์; AP ระบุว่าหลักสูตรประวัติศาสตร์ไทยแทบไม่พูดถึง Holocaust [Chula2013_Hitler]
- **Why:** code-community mismatch — ในรหัสท้องถิ่นบางกลุ่ม ภาพฮิตเลอร์ถูกอ่านแบบ pop/ตัวละคร; ในรหัสโลกเป็นสัญลักษณ์การฆ่าล้างเผ่าพันธุ์ (aberrant decoding กลับทิศ) [Eco1976]
- **Lesson:** สัญลักษณ์ประวัติศาสตร์ความรุนแรง = ห้ามใช้เป็นมุก/ตกแต่ง ไม่ว่าผู้ชมหลักจะเป็นใคร

### 8.4 Dunkin' Donuts Thailand "Charcoal Donut" (ส.ค. 2013)
- **What:** โฆษณาไทยใช้ผู้หญิงทาหน้าดำ (blackface) ปากชมพูสด ถือโดนัทดำ; HRW เรียกว่า "bizarre and racist"; CEO แฟรนไชส์ไทยตอนแรกปกป้อง (รายงานว่าเรียกคำวิจารณ์ว่า "paranoid American thinking") และบอกยอดขายเพิ่ม ~50%; บริษัทแม่ในสหรัฐขอโทษและให้ถอด; ข่าวระบุว่าโฆษณาไม่ได้สร้างกระแสมากในไทย ที่โฆษณาใช้ stereotype เชื้อชาติบ่อย [Dunkin2013_Thailand]
- **Why:** connotation ที่ "ดูธรรมชาติ" ในตลาดหนึ่ง (myth) กลายเป็น oppositional reading ในอีกตลาด [Barthes1957], [Hall1973]; ยอดขายระยะสั้นไม่ได้แปลว่าความหมายปลอดภัย
- **Lesson:** "คนไทยไม่ว่า" ไม่ใช่เกณฑ์ — งานออนไลน์ถูกถอดรหัสโดยผู้ชมทั่วโลก; สีผิวห้ามเป็นมุก (CULTURAL_CHECK F1)

### 8.5 H&M "coolest monkey in the jungle" (ม.ค. 2018)
- **What:** ภาพสินค้าออนไลน์ เด็กผิวดำสวมฮู้ดข้อความ "coolest monkey in the jungle"; ถอดภาพ ขอโทษ 2 ครั้ง; The Weeknd ยุติความร่วมมือ [HM2018_Monkey]
- **Why:** anchorage collision — ข้อความ (สนุกสำหรับเด็กทั่วไป) + ภาพคน → รวมเป็นการเปรียบเทียบเชื้อชาติกับลิง ซึ่งมีประวัติการเหยียดยาวนาน; ไม่มีใครดู "ชุดเครื่องหมายรวม" ก่อนเผยแพร่
- **Lesson:** ตรวจ **ข้อความ × ร่างกาย** เสมอ (Checklist ข้อ 6); ใช้ commutation test: "ถ้าเปลี่ยนนายแบบ ความหมายเปลี่ยนไหม?" ถ้าเปลี่ยน = สัญญาณอันตราย [Chandler_S4B]

## 9. ข้อยกเว้นและบริบทที่ต่างกัน (Exceptions & context)

**วัฒนธรรม (ไทย vs ตะวันตก vs อื่น):**
- **Generic-level** อุปมา (แรงดัน/ความร้อน = โกรธ, ขึ้น = ดี, แสง = ความหวัง) มักใช้ร่วมกันหลายภาษา แต่ระดับรายละเอียดต่าง [Kovecses2005]; สี–อารมณ์มีแกนร่วม r = .88 แต่ปรับตามภาษา/ภูมิภาค [Jonauskaite2020] → **ใช้ generic ข้ามวัฒนธรรม, รายละเอียดต้องเช็ก**
- **ไทย:** "สูง-ต่ำ" เป็นทั้งอุปมาและมารยาท (หัวสูง เท้าต่ำ) — ตาม semiotics README §2.7; ลำดับชั้นผู้ใหญ่-เด็กเป็นรหัสแข็งที่ใช้สร้าง incongruity ได้ [THPF_SmokingKid2013]; ขาว/ดำ ผูกกับไว้ทุกข์และศาสนา [AlJazeera2016_Mourning], [ThailandFoundation2021_Colours]
- **อุปมาไทยเกี่ยวกับ "ใจ"** หนาแน่นกว่าภาษาอังกฤษ (ใจดี ใจร้อน ใจหาย ใจเย็น) และส่วนใหญ่ตายแล้ว [Bovonwiwat2023], [Doherty2025] → ในภาษาไทย การพูด "ใจ" ไม่นับว่าเป็นอุปมาสด
- **ความทนต่อ stereotype** ต่างกันระหว่างตลาด (ข่าว Dunkin) แต่แพลตฟอร์มทำให้ผู้ชมเป็นสากล [Dunkin2013_Thailand]
- **trope ต้องการ cultural competency** — ผู้ชมต่างชาติ/นักท่องเที่ยว → scheme (สัมผัสรูปทรง การซ้ำ) ปลอดภัยกว่า [McQuarrieMick1999]

**แพลตฟอร์ม/รูปแบบ:**
- **Reels/TikTok (เลื่อนเร็ว):** ภาพต้อง "อ่าน" ใน <1 วินาที → juxtaposition ง่าย, anchor ด้วยข้อความสั้น; pareidolia/shape collision มีผลมากที่สุดที่นี่ [Wardle2020], [Lagerwerf2023]
- **IG carousel (คนหยุดอ่าน):** fusion และ extended metaphor ข้ามสไลด์ได้ [Brugman2019]
- **คลิปมี TTS:** อุปมาในเสียงฟังครั้งเดียว → conventional + บิดนิด **(craft)**
- **ภาพ AI:** โมเดล (FLUX/Codex) ไม่ตรวจความหมายเชิงสัญลักษณ์ → ต้องมีมนุษย์ทำ misreading hunt ทุกภาพ **(our test)**

**ผู้ชม:**
- ผู้สูงอายุ/สายตายาว (ลูกค้าร้านแว่น): สัญลักษณ์ละเอียด/ซ่อน อาจมองไม่เห็นเลย → อย่าให้ความหมายหลักอยู่ในรายละเอียดเล็ก **(craft)**
- กลุ่มเปราะบาง (ผู้สูญเสีย, ผู้มีประวัติฆ่าตัวตายในครอบครัว): การอ่านเชิงลบรุนแรงกว่าและเจ็บกว่า [Burberry2019_Noose]
- เด็ก: อ่าน icon ได้ แต่อาจไม่รู้ symbol/ประวัติ → ผู้ปกครองจะเป็นผู้ถอดรหัสอีกชั้น **(opinion)**

**Genre:**
- **ตลก:** incongruity เป็นเครื่องมือหลัก — ยอมให้ polysemy มากกว่า แต่ห้ามเป้าเป็นกลุ่มคน (CULTURAL_CHECK E/F)
- **เรื่องเศร้า/เยียวยา (Slowly Growing):** อุปมาอ่อนโยน คุ้นเคย บิดเล็กน้อย; หลีกเลี่ยงภาพความตาย/ทำร้ายตนเองแม้โดยนัย **(craft)**
- **ข่าว/ประกาศร้าน:** ไม่ใช้อุปมา — denotation ชัดดีกว่า (closure notice style ในหน่วยความจำ) **(craft)**

## 12. แบบฝึกหัด (Exercises)

**12.1 (ง่าย) Denotation → connotation → myth** — เลือกโพสต์โฆษณา 1 ชิ้น (ของเราหรือคู่แข่ง) ลิสต์ denotation ≥ 8 รายการ แล้วเขียน connotation และ myth ที่ "ดูเป็นธรรมชาติ"
- *คำตอบที่ดีแสดง:* แยกสิ่งที่เห็นออกจากการตีความได้ชัด; myth ระบุว่า "ใครได้ประโยชน์จากที่มันดูธรรมชาติ" [Barthes1957], [Barthes1977]

**12.2 (ง่าย) Commutation test** — นำภาพ Mint & Tao 1 สไลด์ สลับ signifier 5 ตัว (สีร่ม, ตำแหน่งสูงต่ำ, ช่วงเวลา, วัตถุในมือ, ระยะห่าง) บันทึกว่าความหมายเปลี่ยนอย่างไร
- *ดี:* ระบุได้ว่าตัวไหน "ทำงาน" ตัวไหนเป็นกลาง; เห็น marked vs unmarked [Chandler_S4B]

**12.3 (กลาง) MIP บน bubble** — นำบทพูด 10 bubble ล่าสุด ใช้ MIP 4 ขั้นระบุคำที่เป็นอุปมา จัดเป็น conventional/novel และหาอุปมาที่ชนกัน
- *ดี:* ระบุ basic meaning ของแต่ละคำได้; จับคำ "ใจ" ที่ตายแล้ว; เสนอแก้ 1–2 จุด [Pragglejaz2007], [Doherty2025]

**12.4 (กลาง) Cliché → optimal innovation** — เลือก cliché 3 ตัวจาก §6.3 สร้างเวอร์ชัน "บิดหนึ่งจุด" อย่างละ 2 แบบ แล้วให้คน 5 คนจัดอันดับความชอบ (เดิม / บิด / ใหม่ล้วน)
- *ดี:* เวอร์ชันบิดยังให้คนจำของเดิมได้; รายงานผลจริงแม้ไม่ตรงทฤษฎี [Giora2004]

**12.5 (กลาง) Decoding map** — สำหรับคลิปสินค้า 1 ชิ้น เขียน preferred / negotiated / oppositional reading สำหรับ 3 กลุ่ม (คนไทยทั่วไป, ลูกค้าจีน, ผู้สูงอายุ)
- *ดี:* negotiated reading สมจริง ไม่ใช่แค่ "ไม่ชอบ"; ระบุจุดที่ทำให้เกิด oppositional ได้ [Hall1973]

**12.6 (ยาก) Misreading hunt แบบปิดตา** — เพื่อนร่วมทีมเตรียม 10 ภาพ AI (บางภาพมีกับดัก: เชือก, หน้า pareidolia, ตัวอักษรบนเสื้อ, ท่ามือ) ทำ §6.2 ภายใน 10 นาที
- *ดี:* จับกับดัก ≥ 80% และอธิบายกลไก (shape collision / pareidolia / anchorage) ได้ [Wardle2020], [HM2018_Monkey]

**12.7 (ยาก) Extended multimodal metaphor** — ออกแบบ carousel 5 สไลด์ หรือคลิป 15 วินาที ที่มีอุปมาหลัก 1 ตัว: source อยู่ในภาพ/เสียง, target อยู่ในข้อความ, ไม่มีการเฉลย
- *ดี:* อุปมาปรากฏตั้งแต่ต้น [ThibodeauBoroditsky2011]; จัดโครงทั้งเรื่อง [Brugman2019]; caption เป็น hint [Phillips2000]; ผ่าน checklist §13

**12.8 (ยาก) Evidence audit ของ brief** — นำ brief/caption ที่มีคำอ้าง "สีนี้ทำให้…", "ภาพนี้กระตุ้น…" ระบุระดับหลักฐานแต่ละข้อจาก §5 และเขียนใหม่ให้ซื่อตรง
- *ดี:* ใช้ "มักถูกเชื่อมโยงกับ"; ไม่อ้าง priming; อ้าง effect size จริงเมื่อจำเป็น [MacGiolla2024], [Jonauskaite2020]

## 13. Checklist (ตอบ ใช่/ไม่ ก่อนส่งงาน)

1. [ ] ระบุผู้ชมหลักและ "รหัสร่วม" ที่คาดว่าเขามีแล้ว [Hall1973]
2. [ ] ลิสต์ทุกองค์ประกอบที่มีความหมาย และระบุ icon/index/symbol แล้ว [SEP_PeirceSemiotics]
3. [ ] symbol ทุกตัวถูกเช็กกับ `SYMBOL_LIBRARY.json` (meaning ตามกลุ่มผู้ชม + restriction) แล้ว
4. [ ] เขียน preferred / negotiated / oppositional reading แล้ว และ oppositional reading ไม่ใช่สิ่งที่น่าแชร์ในทางลบ [Hall1973]
5. [ ] ผ่าน thumbnail test + silhouette test (ไม่มีรูปทรงที่ชนกับ icon แรง) [Wardle2020]
6. [ ] Hot-zone scan: ไม่มีเชือก/สาย/ห่วง ที่คอหรือเหนือศีรษะ; ไม่มีหน้า pareidolia บนวัตถุ/หัวตัวละคร faceless; ไม่มีคนในหน้าต่าง/รูปถ่าย **(our test)**
7. [ ] ข้อความทุกคำที่อยู่บน/ข้างคน อ่านรวมกับร่างกายแล้วไม่เหยียด [HM2018_Monkey]
8. [ ] ไม่มีสัญลักษณ์ประวัติศาสตร์ความรุนแรง/เหยียดเชื้อชาติ/สีผิวเป็นมุก [Chula2013_Hitler], [Dunkin2013_Thailand]
9. [ ] อุปมาหลักมีตัวเดียว จัดโครงทั้งงาน และปรากฏตั้งแต่ต้น [Brugman2019], [ThibodeauBoroditsky2011]
10. [ ] target (สินค้า/ประเด็น) และ source ของอุปมาระบุได้ชัด และสินค้ายังเด่น [Forceville1996]
11. [ ] อุปมาไม่ใช่ cliché ดิบ — มีการบิดหนึ่งจุดที่ของเดิมยังจำได้ หรือมีเหตุผลที่ใช้ cliché ตรง ๆ (เช่น TTS) [Giora2004]
12. [ ] caption เป็น hint ไม่ใช่เฉลย; ไม่มีอุปมาชนกันในข้อความ (MIP) [Phillips2000], [Pragglejaz2007]
13. [ ] มีคนอย่างน้อย 1 คนนอกทีมดูแล้ว และข้อกังวลของเขาถูกบันทึก/แก้ (ไม่เพิกเฉยผู้เตือน) [Burberry2019_Noose]
14. [ ] ไม่มีคำอ้างว่าสี/วัตถุ/อุปมา "ทำให้" คนรู้สึกหรือซื้อ — ใช้ภาษา association [MacGiolla2024], [Jonauskaite2020]
15. [ ] สี/ตัวเลข/สัญลักษณ์ไทยตรวจกับบริบทเวลา (ไว้ทุกข์, วันสำคัญ) แล้ว [AlJazeera2016_Mourning]
16. [ ] ถ้าภาพต้อง "พูดเอง" ไม่มี caption: ผ่าน comprehension test ≥ ~2/3 (semiotics README §5)
17. [ ] การอ่านผิดที่จับได้ระหว่างทำงาน ถูกบันทึกลง memory store แล้ว

## 14. Evaluation Rubric

**วิธีให้คะแนน:** ให้ระดับ 1–4 ต่อเกณฑ์ (A–F) แล้วคูณน้ำหนัก → รวมเต็ม 100 (สูตรด้านล่าง) · **ผ่าน ≥ 70** และไม่มี critical failure · ต้องเขียนหลักฐานที่สังเกตได้ (องค์ประกอบ/สไลด์/วินาที) ประกอบทุกคะแนน

| เกณฑ์ (น้ำหนัก) | 1 — อ่อน | 2 — พอใช้ | 3 — ดี | 4 — ดีเยี่ยม |
|---|---|---|---|---|
| **A. ความชัดของความหมายหลัก (25)** | คนนอกทีม < 1/3 เล่าความหมายหลักได้ | ~1/2 ได้ หรือได้แต่ต้องพึ่ง caption ยาว | ≥ 2/3 ได้ ด้วย anchor สั้น | ≥ 2/3 ได้ใน 3 วินาที; caption เป็นแค่ hint |
| **B. ความปลอดภัยของการถอดรหัส (25)** | พบรูปทรง/ข้อความที่อ่านเป็นความหมายร้ายแรง | มีจุดเสี่ยงที่ยังไม่แก้หรือไม่ได้ตรวจ hot-zone | ผ่าน §6.2 ครบ ไม่มีจุดเสี่ยงที่ทราบ | ผ่าน §6.2 + มีคนนอกกลุ่มเป้าหมายตรวจ + decoding map ครบ 3 กลุ่ม |
| **C. คุณภาพอุปมา (20)** | ไม่มีอุปมาที่ตั้งใจ หรือ cliché ดิบ/ชนกัน | อุปมามี แต่กระจายหลายตัวหรือเฉลยเอง | อุปมาหลัก 1 ตัว จัดโครงงาน มีการบิด | optimal innovation ชัด: ของเดิมจำได้ ความหมายใหม่ลึก; multimodal ใช้ทุกช่องสอดคล้อง |
| **D. ความเหมาะกับวัฒนธรรม/ผู้ชม (15)** | ใช้ symbol ที่ผิด restriction หรือผิดบริบทเวลา | ไม่ได้เช็ก symbol กับ library | เช็กครบ ใช้ generic-level สำหรับผู้ชมหลากหลาย | ใช้รหัสวัฒนธรรมแข็งของผู้ชมอย่างสร้างสรรค์ (เช่น role reversal) โดยไม่ล้อ |
| **E. ความซื่อตรงของคำอ้าง (10)** | อ้างว่าสี/ภาพ "ทำให้" ซื้อ/รู้สึก | มีคำอ้างคลุมเครือ | ใช้ภาษา association | ระบุระดับหลักฐานเมื่ออ้าง และไม่มีเคลมเกินหลักฐาน |
| **F. Brand sign fit (5)** *(เฉพาะงานแบรนด์; งานอื่นโอนน้ำหนักให้ A)* | โลโก้/wordmark ขัดกับความหมายงาน | วางโลโก้ถูกแต่ไม่สัมพันธ์ | asset แบรนด์ (ตัวละคร สี รูปทรง) จำได้ | asset ทำหน้าที่เป็น sign ของแบรนด์แม้ปิดโลโก้ |

**สูตร:** คะแนน = Σ (level ÷ 4 × น้ำหนัก) — เช่น A=3, B=4, C=3, D=3, E=4, F=2 → 18.75+25+15+11.25+10+2.5 = **82.5**

**Critical failures (ไม่ผ่านทันที ไม่ว่าคะแนนเท่าไร):**
1. รูปทรงอ่านเป็นบ่วง/อาวุธต่อคน/สัญลักษณ์การฆ่าล้างเผ่าพันธุ์ ที่ยังไม่แก้
2. ข้อความ+ภาพรวมกันเป็นการเหยียดเชื้อชาติ สีผิว เพศ ศาสนา
3. ใช้สัญลักษณ์ที่ `restriction = legal` ผิดวิธี (สถาบัน ศาสนา ธง — CULTURAL_CHECK B/C)
4. ตัวละคร "faceless" มีหน้า/สีหน้าโผล่ (pareidolia/AI) หรือมีหน้าคนจริงในฉาก
5. เคลมสุขภาพ/ผลทางจิตวิทยาที่ไม่มีหลักฐานใน caption โฆษณา
