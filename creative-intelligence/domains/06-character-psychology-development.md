### 1.2 ความคิดเปลี่ยนไปอย่างไร
1. **จาก "ตัวละครรับใช้ plot" → "ตัวละครขับ plot"**: Aristotle จัด plot ก่อน character `[Aristotle_Poetics_Butcher]`; ช่างยุคใหม่ (Egri, Stanislavski) เริ่มจาก "ตัวละครต้องการอะไร" แล้วให้การกระทำเกิดจากความต้องการนั้น `[Egri1946]` `[Campbell2022_Stanislavsky]` — ทั้งสองสายยังใช้อยู่ ไม่มีฝ่ายไหน "ถูก" (opinion: ในงานสั้น 20 วินาที ตัวละครแทบต้องเป็น "การกระทำหนึ่งครั้ง" แบบ Aristotle)
2. **จาก typology → dimension**: ตัวละครแบบ "ชนิด" (คนขี้เหนียว คนอิจฉา — flat ตาม Forster) ถูกเสริมด้วยความคิดว่าคนจริงแปรปรวนในตัวเองสูง แต่มีรูปแบบ `[Fleeson2001]` `[MischelShoda1995]`
3. **จาก "identification" คำเดียว → หลายกระบวนการแยกกัน**: Smith แยก recognition/alignment/allegiance `[Smith1995_EngagingCharacters]`; Cohen แยก identification ออกจาก liking, similarity, PSI `[Cohen2001]`; Tal-Or & Cohen แสดงว่า identification กับ transportation ถูกปั่นแยกกันได้ `[TalOrCohen2010]`
4. **จาก "fiction ทำให้คนดีขึ้น" (คำกล่าวอ้างใหญ่) → ผลเล็ก ต้องระวัง** หลังวิกฤต replication `[Panero2016]` `[DodellFederTamir2018]`
5. **จาก representation = ความสวยงาม → representation = จริยธรรม + ความเสี่ยงทางธุรกิจ** (Apu, Gemini, ละครไทย) `[Azaria2020_Apu]` `[Google2024_Gemini]` `[Townsend2016]`

## 2. หลักการพื้นฐาน (Fundamentals)

### 2.1 นิยาม
| คำ | นิยาม | ที่มา |
|---|---|---|
| **Character (ethos)** | คุณสมบัติที่เผยผ่าน *การเลือก* ว่าจะทำหรือไม่ทำอะไร | `[Aristotle_Poetics_Butcher]` |
| **Characterization** | ลักษณะภายนอกที่บอกผู้ชม (รูปร่าง ชุด คำพูด นิสัยเล็ก ๆ) — ต่างจาก character ที่เผยตอนเลือกภายใต้แรงกดดัน | (craft; สอดคล้องกับนิยาม Aristotle) |
| **Flat character** | สร้างรอบความคิด/คุณสมบัติเดียว อธิบายได้ในประโยคเดียว; จำง่าย จดจำง่าย; เหมาะกับบทตลก | `[Forster1927]` |
| **Round character** | ทำให้ประหลาดใจได้อย่างน่าเชื่อ; "ถ้าไม่เคยทำให้ประหลาดใจ = flat; ถ้าทำให้ประหลาดใจแต่ไม่น่าเชื่อ = flat ที่แกล้งกลม" | `[Forster1927]` |
| **Objective / super-objective** | สิ่งที่ตัวละครต้องการในฉาก ("I wish to…") / เป้าแกนของทั้งเรื่อง; through line = เส้นที่ร้อย objective ไปหา super-objective | `[Campbell2022_Stanislavsky]` |
| **Given circumstances** | ข้อเท็จจริงที่บทกำหนด (อายุ ความสัมพันธ์ สถานที่) | `[Campbell2022_Stanislavsky]` |
| **Three dimensions** | physiology (กาย) · sociology (สังคม ชนชั้น ศาสนา) · psychology (ศีลธรรม ความทะเยอทะยาน อารมณ์) | `[Egri1946]` (secondary) |
| **Want / Need** | Want = เป้าที่ตัวละครรู้ตัว ("ยาที่คิดว่าจะรักษาอาการของ Lie"); Need = Truth ที่ต้องยอมรับ | `[Weiland_CharacterArcs]` (craft) |
| **Lie / Truth / Ghost** | ความเชื่อผิดที่ตัวละครยึด / ความจริงตรงข้าม / เหตุการณ์ในอดีตที่ทำให้เชื่อ Lie | `[Weiland_CharacterArcs]` (craft) |
| **Identification** | รับเรื่อง "จากข้างใน" รับเป้าหมายและมุมมองตัวละคร ระหว่างดู | `[Cohen2001]` |
| **Wishful identification** | อยากเป็น/อยากทำแบบตัวละคร | `[HoffnerBuchanan2005]` |
| **PSI vs PSR** | PSI = ความรู้สึกระหว่างดูว่าตัวละคร "รับรู้เรา"; PSR = ความผูกพันระยะยาวข้ามตอน | `[Dibble2016]` `[HortonWohl1956]` |
| **Transportation** | ถูกพาเข้าโลกของเรื่อง (attention + imagery + feelings) | `[GreenBrock2000]` |
| **Recognition / alignment / allegiance** | รู้ว่าใครเป็นใคร / ได้เข้าถึงความรู้และความรู้สึกของใคร / ตัดสินทางศีลธรรมว่าเข้าข้างใคร | `[Smith1995_EngagingCharacters]` |
| **Empathy vs sympathy** | empathy = รู้สึกตาม (มี self-other distinction); sympathy/empathic concern = ห่วงใยเขา; contagion = ติดอารมณ์โดยไม่แยกตัวเอง | `[SEP_Empathy]` |
| **Trait** | แนวโน้มเฉลี่ยของพฤติกรรม (Big Five: E, A, C, N, O) | `[McCraeJohn1992]` |
| **Behavioural signature** | รูปแบบ if…then ที่คงที่ของคนหนึ่ง | `[MischelShoda1995]` |

### 2.2 หลักการแกน (10 ข้อ)
1. **ตัวละครคือการเลือกภายใต้แรงกดดัน** — ไม่ใช่รายการคำคุณศัพท์ `[Aristotle_Poetics_Butcher]` (THEORY, ใช้เป็นหลักเขียนบท)
2. **ความคงเส้นคงวาอยู่ที่ "รูปแบบ" ไม่ใช่ "พฤติกรรมเดิมทุกครั้ง"** — คนจริงแสดงเกือบทุกระดับของทุก trait ในชีวิตประจำวัน แต่ค่าเฉลี่ยของแต่ละคนคงที่มาก `[Fleeson2001]`; ความแปรปรวนข้ามสถานการณ์เป็นลายเซ็นที่คงที่ `[MischelShoda1995]` (FACT/THEORY) — ตรงกับ "consistently inconsistent" ของ Aristotle
3. **Surprise ที่ดีต้องมาจากสิ่งที่ปลูกไว้** — round = surprising *and* convincing `[Forster1927]`
4. **Flat ไม่ใช่ข้อเสีย** — ตัวประกอบ flat จำง่าย เหมาะกับงานสั้นและบทตลก; flat ในบทโศกยาว ๆ มักน่าเบื่อ `[Forster1927]`
5. **ผู้ชมผูกพันกับตัวละครหลายทาง ซึ่งเป็นคนละกระบวนการ** — liking ≠ identification ≠ PSI ≠ wishful identification `[Cohen2001]` `[Dibble2016]` `[HoffnerBuchanan2005]`
6. **ข้อมูลศีลธรรมของตัวละครคุม identification; จังหวะเหตุการณ์คุม transportation** `[TalOrCohen2010]` (THEORY, หลักฐาน 1 การทดลอง)
7. **ร่างกาย + บริบท บอกอารมณ์ได้แม้ไม่มีหน้า** — body แยกบวก/ลบได้ตอนอารมณ์พีคเมื่อหน้าแยกไม่ได้ `[Aviezer2012]`; บริบทก่อนหน้าย้อมสีหน้าเรียบ `[Barratt2016]` `[Calbi2017]`; รูปทรงเคลื่อนไหวก็กลายเป็นตัวละคร `[Ratajska2020]` (FACT ระดับปานกลาง)
8. **ใช้ trait dimension (Big Five) ไม่ใช่ type** — type systems ความน่าเชื่อถืออ่อน `[Pittenger2005]` `[Hook2021]`
9. **Want ≠ Need สร้างแรงขับของ arc** — (craft) `[Weiland_CharacterArcs]`
10. **ทุก character design คือการตัดสินใจ representation** — AI โดย default ขยาย stereotype `[Bianchi2023]`; การแก้แบบเหมารวมก็ผิด `[Google2024_Gemini]`

## 3. ทฤษฎีขั้นสูง (Advanced theory)

### 3.1 โมเดลการมีส่วนร่วมกับตัวละคร (competing models)

| โมเดล | กลไก | ทำนายอะไร | สถานะ |
|---|---|---|---|
| **Identification (Cohen)** | สวมมุมมอง เป้าหมาย อารมณ์ของตัวละครชั่วคราว ลดการรับรู้ตัวเอง | ยิ่ง identify ยิ่งรับผลของเรื่อง (ทัศนคติ) | THEORY; Cohen ยืนยันว่าเป็นคนละสิ่งกับ liking `[Cohen2001]` |
| **Structure of sympathy (Smith)** | recognition → alignment (narration ให้เข้าถึงใคร) → allegiance (ประเมินศีลธรรม) | เราอาจ "aligned" กับคนเลว (เห็นทุกอย่างผ่านเขา) โดยไม่ allegiance | THEORY `[Smith1995_EngagingCharacters]` — ข้อวิจารณ์: ระดับอาจเป็นความเข้มของ empathy มากกว่าขั้นตอน |
| **Disposition theory (Zillmann/Raney)** | ผู้ชม "ตัดสินศีลธรรม" → ชอบ/ไม่ชอบ → อยากให้คนที่ชอบได้ดี คนที่ไม่ชอบได้รับกรรม; Raney: schema ทำให้ตัดสินเร็ว แล้วผู้ชมปกป้องความชอบ (เช่นยอมให้ hero ทำผิดบ้าง) | ความสนุก = ความสอดคล้องระหว่าง disposition กับผลลัพธ์ | THEORY `[Raney2004]` |
| **Transportation** | absorption ลดการโต้แย้ง | ความเชื่อขยับตามเรื่อง | FACT (กลไกมี) ผลเฉลี่ยเล็ก `[GreenBrock2000]` `[VanLaer2014]` |
| **Parasocial (PSI/PSR)** | ตัวละคร/บุคคลสื่อ "พูดกับเรา" → รู้สึกถูกรับรู้ → ผูกพันข้ามตอน | ความภักดีต่อซีรีส์/ช่อง; parasocial contact ลดอคติต่อกลุ่ม | THEORY + หลักฐานหลายชิ้น `[HortonWohl1956]` `[Dibble2016]` `[SchiappaGreggHewes2005]` |
| **Simulation (Mar & Oatley)** | fiction = จำลองโลกสังคมแบบย่อ/บีบอัด → ฝึก social inference | อ่านมากระยะยาว → ToM ดีขึ้น | THEORY; หลักฐานเชิงเหตุผลเล็ก `[MarOatley2008]` `[DodellFederTamir2018]` |

**สังเคราะห์ (DERIVED):** Tal-Or & Cohen แยก identification กับ transportation ได้ในการทดลอง และพบว่า transportation ทำนายความสนุก แต่ identification ไม่เพิ่มเมื่อคุม transportation แล้ว `[TalOrCohen2010]` → สำหรับความสนุกของคลิป *จังหวะและความสงสัยของเรื่อง* อาจสำคัญกว่าการทำให้ "คนดูเป็นตัวละคร" (confidence: low — การศึกษาเดียว)

### 3.2 บุคลิกภาพ: trait, state, signature
- **Big Five** เป็นโครงสร้างที่ได้จากคำคุณศัพท์ในภาษาและแบบสอบถาม ใช้ได้ข้ามผู้ประเมินและวัฒนธรรม `[McCraeJohn1992]`; การเชื่อม trait กับผลลัพธ์ชีวิต replicate ได้ 87% แม้ผลเล็กลงเหลือ ~77% `[Soto2019]` → การเขียน "คน C สูง → ตรงเวลา วางแผน" มีฐานจริง
- **Density distribution** `[Fleeson2001]`: คนหนึ่งคนแสดง extraversion แทบทุกระดับในสองสัปดาห์ แต่ "จุดกลาง" ของเขาคงที่เกือบสมบูรณ์ และ *ปริมาณการแกว่ง* ก็เป็นลักษณะเฉพาะ → ตัวละคร introvert ที่ "เปิด" ในฉากหนึ่งไม่ใช่ความไม่คงเส้น ถ้ามีเหตุจากสถานการณ์
- **CAPS / if…then** `[MischelShoda1995]`: "ถ้า A เธอทำ X แต่ถ้า B เธอทำ Y" — นี่คือภาษาที่ดีที่สุดสำหรับ character bible เพราะบอกทั้งความคงที่และความแปรผัน
- **Type systems**: MBTI บังคับ trait ต่อเนื่องให้เป็นสองขั้ว type ที่ได้ไม่คงที่ (retest 5 สัปดาห์ 39–76% ตามมิติ ตามที่ Pittenger รายงาน) `[Pittenger2005]`; Enneagram — 104 samples: factor analysis มักได้น้อยกว่า 9 factor, ไม่มีงาน clustering ที่ได้ 9 type, wings/intertype movement แทบไม่มีหลักฐาน แต่ subscale สัมพันธ์กับ Big Five ตามทฤษฎี `[Hook2021]`

### 3.3 Arc theory (craft, ไม่ใช่วิทยาศาสตร์)
`[Weiland_CharacterArcs]`:
- **Positive change**: Lie → Truth (ไถ่ตัวเอง)
- **Flat / testing arc**: ตัวละครถือ Truth อยู่แล้ว ถูกทดสอบ และเปลี่ยน *โลกรอบตัว*
- **Negative change**: disillusionment (ได้ Truth แต่จบมืด), fall (ยึด Lie แย่ลง), corruption (เริ่มจาก Truth แล้วหันไปเชื่อ Lie)
- **ข้อสังเกต (opinion):** ไม่มีงานวิจัยที่ทดสอบว่า arc ชนิดใดทำให้ผู้ชมชอบหรือจำได้มากกว่า; Reagan et al. ศึกษา *emotional arc ของเรื่อง* ไม่ใช่ arc ของตัวละคร (ดู storytelling README §2.5) — อย่าสับสน

### 3.4 ตัวละครเรียบง่าย (minimal / faceless) — ทำไมยังอ่านอารมณ์ได้
1. **Agency จากการเคลื่อนไหว**: รูปทรงล้วน ๆ 13–23 วินาที ผู้ชมเขียนเป็นเรื่องสังคมเอง `[Ratajska2020]` `[HeiderSimmel1944]`
2. **Context transfer (Kuleshov)**: หน้าเรียบถูกอ่านตามภาพที่ตัดมาก่อน/หลัง — มีผลจริงแต่เล็ก: บริบทกลัวทำให้หน้าเรียบดูลบ (valence −1.25) แต่บริบทสุขเปลี่ยนแค่การเลือกหมวด ไม่เปลี่ยน rating; โมเดลอธิบายแค่ ~10% ของความแปรปรวน `[Calbi2017]` `[Barratt2016]`
3. **Body carries valence**: `[Aviezer2012]` (และรายละเอียดท่าใน acting README §2.1–2.2)
4. **Projection (craft/theory)**: หน้าว่าง/ง่ายชวนให้ผู้ชมใส่ความรู้สึกตัวเอง `[McCloud1993]`; Sanrio อธิบาย Hello Kitty ไม่มีปากว่าให้คนฉายความรู้สึกลงไป (แหล่ง tier E, คำอธิบายขัดกันเอง) `[HelloKitty_Wikipedia]`
5. **Shape valence**: เส้นโค้งถูกชอบมากกว่าเส้นแหลม (วัตถุ ไม่ใช่ตัวละคร) `[BarNeta2006]` — ฐานบางส่วนของ shape language (รายละเอียด: `visual-arts/SHAPE_LANGUAGE.md`)

**ข้อจำกัดสำคัญ:** ความว่างของหน้าทำให้ *ความคลุมเครือ* สูงขึ้น — ถ้าบริบทและท่าไม่ชัด ผู้ชมจะเติมเองแบบสุ่ม (DERIVED จาก Calbi2017: ผลบริบทสุขอ่อน)

### 3.5 Representation & stereotype mechanism
- **Empathy มีอคติ**: เอนไปทางคนใกล้ คล้าย น่ารัก in-group `[SEP_Empathy]` → การเลือกว่าใคร "ได้" ถูกวาดให้น่ารัก/เป็นตัวเอก คือการเลือกว่าใครได้รับ empathy
- **Parasocial contact**: การได้ "รู้จัก" ตัวละครจากกลุ่มน้อยที่เขียนดี สัมพันธ์กับอคติที่ลดลง `[SchiappaGreggHewes2005]`
- **AI default casting**: prompt ทั่วไป (อาชีพ ลักษณะนิสัย) ได้ภาพ stereotype และยังคงอยู่แม้ขอ counter-stereotype `[Bianchi2023]`
- **Overcorrection**: กฎ "ให้หลากหลายเสมอ" โดยไม่ดูบริบททำให้ภาพประวัติศาสตร์ผิด `[Google2024_Gemini]`
- **Visibility ≠ respect**: ในสื่อไทย LGBTQ+ เห็นมากขึ้นแต่ยังมี tokenism และ commodification `[SinghRana2026]`

| ละครไทย normalise ความรุนแรงทางเพศผ่านพระเอก | **medium** (content analysis เชิงวิพากษ์) | `[Townsend2016]` — ไม่ใช่การวัดผลต่อผู้ชม |

**Replication notes (สรุป)**
- **Kidd & Castano** คือบทเรียนหลักของโดเมนนี้: คำกล่าว "fiction ทำให้คน empathic ขึ้น" แพร่ในสื่อและการตลาดหนังสือ แต่ผลเฉพาะ "อ่านครั้งเดียว ดีขึ้นทันที" ไม่คงทน `[Panero2016]` `[Camerer2018]`; ผลรวมของ fiction ต่อ social cognition มีแต่เล็ก `[DodellFederTamir2018]` — **ห้ามเขียน caption หรือ pitch ว่า "คลิปนี้ทำให้คุณเข้าใจคนอื่นมากขึ้น"**
- **Camerer 2018** โดยรวม: ผลที่ replicate ได้ก็ยังเล็กลงครึ่งหนึ่ง → ตัวเลขจากงานเดี่ยวในหัวข้อนี้ให้ลดลงในใจ
- **PSI measures**: งานเก่าที่ใช้ PSI-Scale อาจวัด "ความชอบ" ไม่ใช่ PSI `[Dibble2016]` → ระวังเวลาอ่านงานเก่าที่อ้างว่า PSI ทำนายพฤติกรรม

## 6. การประยุกต์ใช้จริง (Applications)

### 6.1 Generic — สร้างตัวละครใหม่ (ทุกสาขา ทุกลูกค้า) ใน 8 ขั้น
1. **หน้าที่ในเรื่อง/แบรนด์ก่อน**: ตัวละครนี้มีไว้เพื่ออะไร (ผู้ชมสวมบท? ผู้แนะนำ? ตัวตลก? คู่ขัดแย้ง?) → ตัดสินว่า flat หรือ round `[Forster1927]`
2. **Super-objective + Want/Need**: เขียน 1 ประโยค "อยาก ___ แต่จริง ๆ ต้องการ ___ เพราะเชื่อ (Lie) ว่า ___" `[Campbell2022_Stanislavsky]` `[Weiland_CharacterArcs]` (craft)
3. **Trait profile (Big Five)**: ให้ค่า สูง/กลาง/ต่ำ ทั้ง 5 มิติ + 1 ประโยคต่อมิติว่าเห็นได้จากพฤติกรรมอะไร `[McCraeJohn1992]` — ห้ามใช้ MBTI/Enneagram เป็นฐาน `[Pittenger2005]` `[Hook2021]`
4. **If…then signature 5–8 ข้อ**: "ถ้าโดนชม → เปลี่ยนเรื่อง", "ถ้าอีกคนร้องไห้ → นั่งข้าง ๆ ไม่พูด" `[MischelShoda1995]`; เพิ่ม "ขอบของการแกว่ง" (ทำอะไรได้ถึงไหน) `[Fleeson2001]`
5. **Three dimensions สั้น ๆ**: กาย/สังคม/จิตใจ อย่างละ 2–3 บรรทัด เพื่อให้พฤติกรรมมีเหตุ `[Egri1946]` (craft)
6. **Engagement design**: recognition (silhouette, สีประจำ, prop) → alignment (เรื่องเล่าผ่านใคร เห็นความลับของใคร) → allegiance (การกระทำทางศีลธรรมเร็ว ๆ ในช่วงแรก) `[Smith1995_EngagingCharacters]` `[Raney2004]`
7. **Visual + body**: shape/silhouette (ลิงก์ CHARACTER_DESIGN.md), ท่าประจำอารมณ์ (POSE_LIBRARY), ถ้าไม่มีหน้า → วางแผนบริบท+ท่าทุกช็อต `[Aviezer2012]` `[Calbi2017]`
8. **Representation review**: ใครถูกวาดเป็นแบบไหน ทำไม; ตรวจ default ของ AI `[Bianchi2023]`; ตรวจบริบทเชิงประวัติศาสตร์/วัฒนธรรมก่อนกระจายความหลากหลาย `[Google2024_Gemini]`

### 6.2 Generic — เขียนฉากให้ตัวละคร "เป็นตัวเอง"
- เริ่มแต่ละฉากด้วย objective ในรูปกริยา ("ทำให้เธอยิ้ม", "ซ่อนว่าเจ็บ") ไม่ใช่อารมณ์ ("เศร้า") `[Campbell2022_Stanislavsky]` (practice)
- ให้ตัวละครเลือกระหว่างสองอย่างที่มีราคา — นั่นคือที่ character ปรากฏ `[Aristotle_Poetics_Butcher]`
- Surprise 1 ครั้งต่อ arc: ต้องย้อนกลับไปหาจุดที่ปลูกไว้ได้ (convincing) `[Forster1927]`
- ถ้าอยากให้ผู้ชม identify: ให้ข้อมูลเชิงบวกเรื่องศีลธรรมของตัวละครก่อน `[TalOrCohen2010]`; ถ้าอยากให้ผู้ชมจมในเรื่อง: คุมจังหวะ reveal (เวลาของเหตุการณ์) `[TalOrCohen2010]`

### 6.3 Generic — ซีรีส์และ character bible
- Bible ต้องมี: identity ที่ห้ามเปลี่ยน · if…then signature · ขอบการแกว่ง · arc ปัจจุบัน (Lie ตอนนี้คืออะไร) · ประวัติการเปลี่ยนแปลงตอนต่อตอน (changelog) · voice rules · visual masters (ดู CHARACTER_BIBLE_TEMPLATE.md และ CHARACTER_VOICE_BIBLE.md)
- ผู้ชมซีรีส์ซับซ้อนใช้ character chart/wiki เพื่อจัดระเบียบ `[Mittell2015]` → ซีรีส์ที่มีตัวละครมากกว่า 4 ตัว ควรมี "cast card" สำหรับผู้ชมด้วย (opinion)
- PSR สร้างข้ามตอน: ตัวละครประจำที่มีจังหวะการพูดกับผู้ชมสม่ำเสมอ (หันมาหา, ทักทายแบบเดิม) `[Dibble2016]` `[HortonWohl1956]`

### 6.4 สำหรับสตูดิโอ — Mint & Tao ("Slowly Growing", carousel 1:1/Reels, ไม่มีหน้า)
ฐาน: `slowly-growing/README.md` — Mint พูดความกังวล, Tao ตอบสั้นอบอุ่น
1. **Flat โดยตั้งใจ แต่มี 1 มุม round ต่อ 10 เรื่อง** (DERIVED จาก `[Forster1927]`): ทั้งคู่ถูกออกแบบเป็น flat (Mint = "คนที่กังวล", Tao = "คนที่ปลอบ") ซึ่งดีสำหรับรูปแบบสั้นและจำง่าย แต่เรื่อง dialogue ที่ "ซึ้ง" ยาว ๆ กับ flat ล้วนเสี่ยงน่าเบื่อตามที่ Forster เตือน → ทุก ~10 เรื่อง ให้มีเรื่องที่ **Tao เป็นคนไม่แน่ใจ และ Mint เป็นคนปลอบ** (surprise ที่ convincing เพราะปลูกไว้ว่า Mint ฟังมาเยอะ) (our test: ยังไม่ทดสอบ — วัด saves/shares เทียบเรื่องปกติ)
2. **If…then ของ Mint & Tao** (เสนอใส่ bible):
   - Mint: ถ้ากังวล → พูดเป็นคำถาม; ถ้าได้คำตอบดี → เงียบ แล้วพิงเล็กน้อย; ถ้าโดนชม → ก้มหน้า
   - Tao: ถ้า Mint กังวล → ไม่แก้ปัญหาทันที ถามกลับหนึ่งคำ; ถ้า Mint ดีใจ → ยิ้มด้วยร่างกาย (ไหล่ผ่อน) ไม่พูดมาก; ไม่เคยสั่งสอนยาว
3. **อารมณ์ไม่มีหน้า = บริบท + ระยะ + ท่า**: เพราะผลบริบทสุขอ่อนกว่าบริบทลบ `[Calbi2017]` ฉากที่ต้องการให้อ่านว่า "อบอุ่น/ดีใจ" ต้องใส่ท่าเปิด ศีรษะเงย ระยะชิด (acting README §2.2) ไม่พึ่งฉากหลังสวยอย่างเดียว; ฉากเศร้าใช้บริบท (ฝน ไฟดับ) ช่วยได้มากกว่า
4. **Projection**: หน้าว่างเปิดให้ผู้อ่านสวมตัวเอง `[McCloud1993]` (craft) → ข้อความไทยของ Mint ควรเป็นประโยค "ฉัน" ที่คนทั่วไปพูดได้ ไม่ใส่รายละเอียดชีวิตเฉพาะเกินไป (ชื่อบริษัท อายุ) — แต่ใส่ *รายละเอียดทางประสาทสัมผัส* หนึ่งอย่างเพื่อ transportation (storytelling README §2.2)
5. **PSR กับช่อง**: Reels ของ carousel ใช้ท่าเปิดเรื่องเดียวกันทุกตอน (ทั้งคู่นั่งม้านั่ง หันข้าง) เพื่อสร้างความคุ้นเคย; ไม่ให้ตัวละครหันมาหาผู้ชมบ่อย — สงวนไว้สำหรับตอนพิเศษ (ให้มีผลมากขึ้น) `[Dibble2016]` (DERIVED)

### 6.5 สำหรับสตูดิโอ — Story clips (ร้านแว่นตีสอง: ต้น, ยายจันทร์, ลุงชาญ)
- ต้น (ขี้กลัวตอนกลางคืน ใจดี): Lie เสนอ = "ถ้าสุภาพพอ จะไม่มีใครเห็นว่าฉันกลัว"; Need = ยอมรับว่ากลัวแล้วยังช่วยคนได้ → positive arc ข้าม season (craft `[Weiland_CharacterArcs]`)
- ลุงชาญ (ปากแข็ง ใจอ่อน) = ตัวละครแบบ "ดี + ข้อเสียตลก" ซึ่งตรงกับสูตรพระเอกละครไทยช่วงหลัง `[TanarojChansatitporn]` → ผู้ชมไทยอ่านง่าย
- ยายจันทร์ (ผี ไม่น่ากลัว): flat arc — ถือ Truth (ความรักไม่หายไป) และเปลี่ยนต้น `[Weiland_CharacterArcs]`
- เสียง: identity เดิม อารมณ์ขยับจาก baseline (CHARACTER_VOICE_BIBLE.md); EP01 ใช้เสียงเดียวอ่านหลายตัว = recognition ต่ำ `[Smith1995_EngagingCharacters]` (DERIVED)

### 6.6 สำหรับสตูดิโอ — Eyewear product clips/posts
- แว่นเป็น prop ที่ทำหน้าที่ recognition: ทรงกรอบสื่อบุคลิก (กลม→อบอุ่น, เหลี่ยม→เก่ง/ดื้อ; หลักฐานอ่อน n = 39) `[OkamuraUra2017]` → ตัวละคร "ผู้เชี่ยวชาญร้าน" ใส่กรอบเหลี่ยมบาง, ตัวละคร "เพื่อนชวนตรวจตา" ใส่กรอบกลม (our test: ยังไม่ได้ทดสอบ)
- โฆษณาสุขภาพตา (สายตายาวตามวัย/UV): ตัวละครที่คนดู *คล้าย* (อายุ อาชีพ) เพิ่ม wishful identification/ความเกี่ยวข้อง `[HoffnerBuchanan2005]`; ให้ตัวละครแสดงความสำเร็จหลังแก้ปัญหา (อ่านเมนูได้) มากกว่าตลกอย่างเดียว เพราะ humour ไม่ทำนาย wishful identification `[HoffnerBuchanan2005]`
- ห้ามอ้างผลทางจิตใจเกินหลักฐาน ("ดูคลิปนี้แล้วเข้าใจพ่อแม่มากขึ้น") `[DodellFederTamir2018]`

### 6.7 สำหรับสตูดิโอ — TTS voice
- if…then ทางเสียง: "ถ้าโกหก → ช้าลงและเสียงสูงขึ้นเล็กน้อย", "ถ้าพูดกับยาย → อนุภาค 'ครับ' ทุกประโยค" — ใส่ใน voice bible คู่กับ signature พฤติกรรม `[MischelShoda1995]` (DERIVED)
- เสียงต่างกันชัดต่อตัวละคร = recognition (Smith) — แก้ปัญหา EP01 ที่บันทึกไว้

### 6.8 แม่แบบ "Psychology layer" — เติมต่อท้าย CHARACTER_BIBLE_TEMPLATE.md (ไม่แทนของเดิม)
แม่แบบเดิมมี visual/costume/prompt block ครบ แต่ยังไม่มีชั้นจิตวิทยา เสนอเพิ่มส่วนนี้ (ทุกช่องเขียนเป็นพฤติกรรมที่ถ่าย/วาด/พากย์ได้):

```markdown
### Psychology layer — <Character ID>
- Function in the work: (สวมบทผู้ชม / ผู้นำทาง / ตัวตลก / คู่ขัดแย้ง / ผู้เชี่ยวชาญ)
- Flat or round: (flat = 1 ประโยค Forster | round = ระบุ surprise ที่วางแผน)
- Super-objective (season): "I want to ___"
- Want (conscious) / Need (Truth) / Lie / Ghost:            # craft
- Big Five (H/M/L + 1 visible behaviour each): E · A · C · N · O
- If…then signature (5–8):  if ___ → ___
- Range of variation: ทำได้ถึงไหน / ไม่มีวันทำอะไร (hard limits)
- Moral anchor beat: การกระทำแรกที่ทำให้ผู้ชมเข้าข้าง (allegiance)
- Recognition cues: silhouette · signature colour · prop · frame position · voice
- Body baseline (faceless or not): ท่าพัก, ระยะกับคนอื่น, tempo
- Representation note: กลุ่มที่ตัวละครอาจถูกอ่านว่าแทน + ความเสี่ยง stereotype + วิธีป้องกัน
- Arc state log: EP | Lie ตอนนี้ | สิ่งที่เปลี่ยน | surprise ที่ใช้ไปแล้ว
```

**ตัวอย่างเติม (ข้อเสนอ ยังไม่ได้รับอนุมัติจากผู้ใช้):**

| ช่อง | Mint | Tao |
|---|---|---|
| Function | สวมบทผู้ชม (คนที่กังวล) | ผู้นำทางอบอุ่น |
| Flat/round | flat ส่วนใหญ่ + round เล็ก ๆ ทุก ~10 เรื่อง | flat (testing arc) |
| Super-objective | "อยากรู้ว่าตัวเองโอเคแล้ว" | "อยากให้ Mint เชื่อตัวเอง" |
| Want / Need / Lie | Want: คำยืนยันจากคนอื่น · Need: ยอมรับจังหวะการโตของตัวเอง · Lie: "ถ้าโตช้ากว่าคนอื่น แปลว่าล้มเหลว" | ถือ Truth "การโตช้าก็คือการโต" (flat arc ไม่มี Lie) · Doubt: บางครั้งไม่แน่ใจว่าตัวเองช่วยได้ |
| Big Five | N สูง, A สูง, E ต่ำ-กลาง, O กลาง, C กลาง | N ต่ำ, A สูง, E ต่ำ, O สูง, C สูง |
| If…then (ตัวอย่าง) | ถ้ากังวล → ถามเป็นคำถาม; ถ้าโล่งใจ → พิงเล็กน้อย; ถ้าถูกชม → ก้มหน้า | ถ้า Mint กังวล → ถามกลับหนึ่งคำ; ถ้าถูกถามเรื่องตัวเอง → เลี่ยงด้วยรอยยิ้ม (ไหล่ผ่อน) |
| Hard limits | ไม่ประชดใคร | ไม่สั่งสอนยาว ไม่ตัดสิน |
| Recognition | สเวตเตอร์โอ๊ต (ค่าสว่าง), เตี้ยกว่า, ซ้ายเฟรม | โค้ทชาร์โคล (ค่าเข้ม), ผ้าพันคอน้ำตาล, ขวาเฟรม |
| Body baseline | ไหล่ห่อเล็กน้อย มือจับแก้ว/แขนเสื้อ | ยืน/นั่งตรง ผ่อน ศีรษะเอียงหา Mint |

แหล่งหลักของแต่ละช่อง: `[Forster1927]` `[Campbell2022_Stanislavsky]` `[Weiland_CharacterArcs]` `[McCraeJohn1992]` `[MischelShoda1995]` `[Fleeson2001]` `[Smith1995_EngagingCharacters]` `[Raney2004]`

### 6.9 วิธีตรวจ "consistency vs surprise" ในบท (procedure)
1. อ่านบททีละ beat; ทุก action ของตัวละครหลัก ติดป้าย: **S** (ตรง signature), **V** (อยู่ในขอบการแกว่ง มีเหตุจากสถานการณ์), **X** (นอกขอบ)
2. ทุก **X** ต้องเป็น surprise ที่ตั้งใจ → หา setup ย้อนหลังอย่างน้อย 1 จุด; ไม่มี = แก้บท `[Forster1927]`
3. นับ: ถ้า S เกิน 90% ในตัวนำของซีรีส์ยาว → เสี่ยง flat น่าเบื่อ; ถ้า X เกิน 1 ต่อตอนสั้น → เสี่ยง "flat pretending to be round" (craft threshold — ยังไม่ทดสอบ)
4. ตรวจว่า V แต่ละตัวมี "if" ที่ผู้ชมเห็น (สถานการณ์บนจอ) ไม่ใช่อยู่ในหัวผู้เขียน `[MischelShoda1995]`
5. บันทึก surprise ที่ใช้แล้วใน arc state log ห้ามใช้ซ้ำโดยไม่ตั้งใจ

### 6.10 Prompt สำหรับ AI (ภาพ/บท) ที่ใส่จิตวิทยาตัวละคร
- **ภาพ:** prompt block เดิม (traits คงที่) + บรรทัด "body state" จาก if-then ของฉากนั้น เช่น `Mint sits with shoulders slightly hunched, both hands around a cup, head lowered, leaning 10° away from Tao` — ไม่เขียนแค่ `sad` เพราะไม่มีหน้า `[Aviezer2012]`
- **บท (LLM):** ส่งแค่ psychology layer + objective ของฉาก แล้วสั่ง "เขียนบทพูดที่ตัวละครพยายามทำ objective โดยไม่บอกอารมณ์ตรง ๆ"; ตรวจผลด้วย §6.9
- **Casting:** ระบุอายุ รูปร่าง สีผิว เสื้อผ้า บริบทอย่างตั้งใจ และทบทวนผลทั้งด้าน stereotype และด้านความถูกบริบท `[Bianchi2023]` `[Google2024_Gemini]`

## 7. กรณีศึกษาที่ประสบความสำเร็จ (Success case studies)

### 7.1 Breaking Bad — negative arc ที่วางแผนตั้งแต่ pitch
- **Documented:** Vince Gilligan pitch ซีรีส์ว่า "เอา Mr. Chips มาทำให้เป็น Scarface"; Walter *เลือก* เข้าสู่อาชญากรรมเอง; ซีรีส์ที่มีจุดจบช่วยให้ตัวละครเปลี่ยนได้ (ตามการอ้างใน NPR Fresh Air 2011 และสื่ออื่น — ถ้อยคำต่างกันเล็กน้อย) `[Gilligan2011_NPR]`
- **Analysis (ของเรา):** ตรงกับ corruption/fall arc `[Weiland_CharacterArcs]`; ทำงานได้เพราะ alignment สูง (เรื่องเล่าผ่าน Walter) ขณะที่ allegiance ค่อย ๆ ลด — ตรงกับการแยก alignment/allegiance ของ Smith `[Smith1995_EngagingCharacters]`; และ disposition theory ทำนายว่าผู้ชมจะ "ปกป้อง" ความชอบเดิมระยะหนึ่ง `[Raney2004]`
- **บทเรียน:** arc ลบต้องการ alignment แน่นและแรงจูงใจที่เข้าใจได้ตั้งแต่ต้น; ใช้ได้ในซีรีส์ยาว ไม่ใช่โพสต์เดียว

### 7.2 Hello Kitty — หน้าเรียบเพื่อให้ฉายความรู้สึก (commercial)
- **Documented (tier E):** โฆษก Sanrio เคยอธิบายว่าไม่วาดปากเพื่อให้คนฉายความรู้สึกลงบนตัวละคร; มีคำอธิบายอื่นที่ขัดกัน (พูดจากหัวใจ / ปากซ่อนในขน) และเวอร์ชันแอนิเมชันปี 1987 มีปาก `[HelloKitty_Wikipedia]`
- **Analysis:** สอดคล้องกับแนวคิด projection `[McCloud1993]` และกลไก context transfer `[Barratt2016]` — แต่ **ไม่ใช่หลักฐาน** ว่าการไม่มีปากทำให้ขายดี (มีปัจจัยอื่นมากมาย)
- **บทเรียนสำหรับ Mint & Tao:** หน้าว่างใช้ได้กับตัวละครที่ "ให้ผู้ชมเป็น" — แต่เมื่อเรื่องต้องการให้ตัวละครแสดงอารมณ์เฉพาะ (เช่นแอนิเมชัน) แม้ Sanrio ก็เพิ่มปาก → เมื่อทำคลิปเคลื่อนไหวของ Mint & Tao ต้องชดเชยด้วยร่างกาย

### 7.3 Heider & Simmel → replication 2020 — ตัวละครจากการเคลื่อนไหวล้วน
- **Documented:** ผู้ชมเห็นรูปทรงเป็นตัวละครที่มีเจตนา (1944); 32 คลิปใหม่ยาว 13–23 วินาทีก็ได้ผลแบบเดียวกัน (N = 66) `[HeiderSimmel1944]` `[Ratajska2020]`
- **บทเรียน:** ความยาว 13–23 วินาทีพอสำหรับ "plot ทางสังคม" ด้วยการเคลื่อนไหว — ตรงกับคลิป 20 วินาที; ระยะ ความเร็ว การไล่/หนี/เข้าใกล้ คือภาษาหลักของตัวละครไม่มีหน้า

### 7.4 Sonic (2019→2020) — แก้ดีไซน์ตัวละครตามเสียงผู้ชม
- **Documented:** ตัวอย่างแรก 30 เม.ย. 2019 โดนวิจารณ์หนักเรื่อง CGI สมจริง (ฟันคน ตาเล็ก — ส่วนนี้เป็นคำอธิบายที่พบทั่วไปในสื่อ); ผู้กำกับประกาศแก้; เลื่อนฉายเป็น 14 ก.พ. 2020; รายงานต้นทุนแก้ ~5 ล้านดอลลาร์ (แหล่งไม่ระบุชื่อ); เปิดตัว ~58 ล้านดอลลาร์ และกลายเป็นแฟรนไชส์ `[Sonic2019_Redesign]`
- **Analysis:** ดีไซน์ใหม่กลับไปใกล้ตัวละครเกมที่ผู้ชมรู้จัก (recognition + appeal) — สอดคล้องกับ uncanny/stylisation ใน cartoon README
- **บทเรียน:** ตัวละครที่มีคนรักอยู่แล้ว มี "สัญญา" ทางภาพกับผู้ชม; การทดสอบดีไซน์กับกลุ่มเล็กก่อนเปิดตัวถูกกว่าการแก้ทีหลัง

### 7.5 Parasocial contact — ตัวละครกลุ่มน้อยที่เขียนดีลดอคติ (research case)
- **Documented:** 3 การศึกษา (Six Feet Under, Queer Eye, Eddie Izzard): การสัมผัสแบบ parasocial สัมพันธ์กับอคติที่ลดลง `[SchiappaGreggHewes2005]`
- **บทเรียน:** representation ที่ดีไม่ใช่แค่ "ไม่ผิด" แต่มีผลทางสังคมเชิงบวกได้ — ต่างจาก token (ดู §8)

## 8. วิเคราะห์ผลงานที่ผิดพลาด (Failure analysis)

### 8.1 Apu (The Simpsons) — stereotype ที่หมดอายุ
- **What (documented):** สารคดี *The Problem with Apu* (2017) วิจารณ์ Apu ว่าเป็น caricature ของคนเอเชียใต้; Hank Azaria ประกาศเลิกพากย์ (รายงานว่า ม.ค. 2020) บอกว่า "it just didn't feel right" หลังศึกษาเรื่อง representation `[Azaria2020_Apu]`
- **Why (analysis):** ตัวละคร flat สร้างรอบ "ความเป็นชาติพันธุ์ + สำเนียง" (Forster: flat รอบคุณสมบัติเดียว) — เมื่อคุณสมบัตินั้นคืออัตลักษณ์ของกลุ่มจริง flat = stereotype; ผู้ชมกลุ่มนั้นไม่มี allegiance เพราะถูกล้อ
- **Lesson:** อย่าสร้างตัวตลก flat รอบ เชื้อชาติ/ภาค/เพศสภาพ/ความพิการ/สำเนียง; ถ้ามีตัวละครจากกลุ่มนั้น ให้ trait มาจาก Big Five/if-then ของ *บุคคล*

### 8.2 Gemini image generation (ก.พ. 2024) — แก้ stereotype แบบเหมารวม
- **What (documented):** Google ยอมรับว่าการ tune ให้แสดงความหลากหลาย "ไม่ได้คำนึงถึงกรณีที่ไม่ควรแสดงความหลากหลาย" และโมเดลระมัดระวังเกินจนปฏิเสธคำขอธรรมดา; หยุดสร้างภาพคนชั่วคราว `[Google2024_Gemini]`
- **Why:** กฎระดับระบบแทนการตัดสินใจ casting ต่อเรื่อง/บริบท; ปัญหาตั้งต้น (default stereotype `[Bianchi2023]`) เป็นจริง แต่วิธีแก้ไม่ดูบริบท
- **Lesson:** ทุกภาพตัวละครจาก AI ต้องมี casting brief ที่ตั้งใจ (อายุ ผิว รูปร่าง ยุค สถานที่) และตรวจทั้งสองทิศ: stereotype และความผิดบริบท

### 8.3 Kidd & Castano — research hype failure
- **What (documented):** ผล "อ่าน literary fiction แล้ว ToM ดีขึ้น" ใน Science 2013 `[KiddCastano2013]` → replications ส่วนใหญ่ล้ม `[Panero2016]` `[Camerer2018]` `[FORRT_KiddCastano]`
- **Why:** ตัวอย่างเล็ก, การวัด RMET แคบ, ผลระยะสั้นจากการอ่านครั้งเดียว
- **Lesson สำหรับงานครีเอทีฟ:** อย่าขาย "พลังของตัวละคร/เรื่องเล่า" ด้วยตัวเลขจากงานเดี่ยว; ใช้ meta-analysis และพูดว่า "ผลเล็ก" `[DodellFederTamir2018]`

### 8.4 ละครไทย: พระเอกข่มขืนนางเอก — archetype ที่ฝังความรุนแรง
- **What (documented):** ความรุนแรงทางเพศเป็น plot device ทั่วไปในละครหลังข่าว; พระเอกข่มขืนนางเอกในพล็อต "คู่กันโดยชะตา" ถูกทำให้ดูชอบธรรม `[Townsend2016]`
- **Why (analysis):** disposition theory: ผู้ชมที่ชอบพระเอกแล้วจะ "ปกป้อง" ความชอบ แม้เขาทำผิด `[Raney2004]` — ละครใช้กลไกนี้ทำให้พฤติกรรมรุนแรงถูกยอมรับ
- **Lesson:** อย่ายืม archetype ไทยมาทั้งชุด; ยืม *ความอ่านง่าย* (พระเอกใจดี ตรงไปตรงมา `[ZhangIntaraporn2024]`) ไม่ยืม script ที่เป็นอันตราย (พระเอก "เอาชนะ" นางเอก, นางร้ายผู้หญิงเป็นตัวร้ายหลักเสมอ)

### 8.5 (Typical, labelled) ตัวละครคู่ไม่มีหน้าที่แยกไม่ออก
- **What (typical failure, ไม่ใช่กรณีจริงที่บันทึก):** สองตัวละครหัวกลม ไม่มีหน้า ชุดโทนเดียวกัน ขนาดใกล้กัน → ผู้ชมไม่รู้ว่าข้อความไหนของใคร
- **Why:** recognition ล้ม (Smith ระดับแรก) `[Smith1995_EngagingCharacters]`
- **Lesson / Mint & Tao:** รักษาความต่างที่เห็นในระดับ thumbnail: ความสูง, ชุด (สเวตเตอร์โอ๊ต vs โค้ทชาร์โคล), ค่าความสว่าง (Mint สว่าง / Tao เข้ม), ตำแหน่งในเฟรม (Mint ซ้าย Tao ขวา คงที่) และวางข้อความใกล้ตัวผู้พูด

## 9. ข้อยกเว้นและบริบทที่ต่างกัน (Exceptions & context)

### 9.1 ไทย vs ตะวันตก
- **Archetype ละครไทย**: พระเอก (phra-ek), นางเอก (nang-ek), นางร้าย (nang rai) เป็นแกนที่ผู้ชมไทยอ่านทันที; ตาม snippet ของ Townsend นางร้ายเป็นตัวจำเป็นอีกตัวเดียว และไม่มีคู่เทียบฝ่ายชาย `[Townsend2016]`
- **พระเอกในอุดมคติ 2013–2022**: คุณธรรมถูกวางตั้งแต่ต้น, หล่อ แต่งเครื่องแบบ มีอาชีพ, ฉลาด กล้า ใจกว้าง สุภาพบุรุษ รับผิดชอบ ใจดี มีอารมณ์ขัน ช่วยงานบ้าน `[ZhangIntaraporn2024]`
- **Round มากขึ้นในละครใหม่**: พระเอก/นางเอกช่อง 7HD 2019–20 ส่วนใหญ่ round — "ดี + ข้อเสียตลก" (ปากร้าย กวน ขี้เล่น); นางเอกกล้า ตรง ฉลาด แต่อ่อนไหวเรื่องรัก `[TanarojChansatitporn]`
- **LGBTQ+**: เห็นมากขึ้น (BL) แต่ยังมี tokenism/commodification `[SinghRana2026]`; ตัวละครกะเทยตลกเป็นธรรมเนียมเก่าที่ต้องระวัง (opinion; งานวิจัยตรงเรื่อง comic relief ไม่ได้อ่านในรอบนี้)
- **ตาราง archetype ละครไทย → วิธีใช้ในงานเรา**

| Archetype | สิ่งที่ผู้ชมไทยคาดหวัง (หลักฐาน) | ยืมได้ | ระวัง/ไม่ยืม |
|---|---|---|---|
| พระเอก | ดีตั้งแต่ต้น หล่อ อาชีพมั่นคง ใจดี รับผิดชอบ มีอารมณ์ขัน `[ZhangIntaraporn2024]`; ช่วงหลังมีข้อเสียตลก (ปากแข็ง กวน) `[TanarojChansatitporn]` | "ดี + ข้อเสียตลก 1 อย่าง" | ความรุนแรง/การบังคับที่ถูกทำให้โรแมนติก `[Townsend2016]` |
| นางเอก | กล้า ตรง ฉลาด ไม่อ่อนแอ แต่อ่อนไหวเรื่องรัก `[TanarojChansatitporn]` | ความกล้า+ความอ่อนไหว | การเป็นผู้ถูกกระทำเพื่อให้พระเอกไถ่บาป `[Townsend2016]` |
| นางร้าย | ตัวละครจำเป็นตัวที่สาม ไม่มีคู่เทียบฝ่ายชาย (ตาม snippet) `[Townsend2016]` | ฟังก์ชัน "แรงต้าน" | ผู้หญิงอิจฉาเป็นตัวร้ายเริ่มต้นเสมอ — สลับเพศ/ให้แรงจูงใจที่เข้าใจได้ |
| ตัวตลกประกอบ/คนใช้/กะเทยตลก | (ธรรมเนียม — ไม่ได้อ่านงานวิจัยตรงรอบนี้) | จังหวะตลก | อัตลักษณ์เป็นมุก `[SinghRana2026]` `[Azaria2020_Apu]` |
| ผู้ใหญ่ใจดี/ผี (เช่นยายจันทร์) | (craft/observed) | flat arc ผู้ถือ Truth | — |

- **งานวิจัย identification/PSI ส่วนใหญ่เป็นกลุ่มตัวอย่างอเมริกัน/ยุโรป/อิสราเอล** — ไม่มีหลักฐานตรงกับผู้ชมไทย (gap)
- **ความสุภาพ/เกรงใจ** ทำให้การแสดงความขัดแย้งในบทพูดไทยมักอ้อม — want/need ของตัวละครไทยอาจต้องแสดงผ่านการกระทำมากกว่าการพูดตรง (opinion; ดู domain 09)

### 9.2 แพลตฟอร์ม/ความยาว
| รูปแบบ | ผลต่อการออกแบบตัวละคร |
|---|---|
| Carousel/Reel 20 s | flat OK; recognition ต้องทันทีที่ thumbnail; allegiance ต้องได้ใน 1–2 ภาพแรก `[Raney2004]` |
| ซีรีส์ 10+ ตอน | PSR สะสม; ต้องมี bible + changelog; round อย่างน้อย 1 ตัว `[Forster1927]` `[Mittell2015]` |
| Product clip | ตัวละครมักเป็น "ผู้ใช้ที่คล้ายผู้ชม" → similarity `[HoffnerBuchanan2005]`; ไม่ต้องมี arc ยาว |
| แอนิเมชันเคลื่อนไหว vs ภาพนิ่ง | ภาพนิ่งอ่านอารมณ์จากร่างกายได้น้อยกว่าเคลื่อนไหว (acting README §2.1) → ภาพนิ่งต้องท่าชัดกว่า |

### 9.3 ผู้ชม/ประเภท
- **ตลก**: flat เหมาะที่สุด `[Forster1927]`
- **ดราม่า/โศก**: flat ยาว ๆ น่าเบื่อ → ต้อง round `[Forster1927]`
- **เด็ก**: ตัวละครเรียบง่าย/น่ารัก (cartoon README) แต่ระวัง stereotype เพศในอาชีพ (registry: `ASA2019_GenderStereotypes`)
- **Health/education**: identification + PSI ลดการต่อต้าน (theory, ดู storytelling README) แต่ข้อเท็จจริงในเรื่องต้องถูก `[GreenBrock2000]`

### 9.4 ข้อยกเว้นของหลัก "consistency"
- **Unreliable/twist**: ตัวละครที่ "ไม่คงเส้น" เพราะซ่อนความลับ — ยังต้อง consistently inconsistent `[Aristotle_Poetics_Butcher]`
- **Comedy break**: ตัวละครทำผิดนิสัยเพื่อมุก — ใช้ได้ถ้าเป็น one-off ที่ตัวละครเองรู้ตัว (opinion)

### 11.2 เลือก arc (craft)
```
ตัวละครเชื่อสิ่งผิดอยู่ตอนเริ่ม?
├─ ใช่ → จะเลิกเชื่อไหม?
│   ├─ เลิก และจบดี → Positive change
│   ├─ เลิก แต่จบมืด → Disillusionment
│   └─ ไม่เลิก/แย่ลง → Fall
└─ ไม่ (ถือ Truth อยู่แล้ว) → จะคงไว้ไหม?
    ├─ คงไว้ และเปลี่ยนคนรอบตัว → Flat (testing)
    └─ ทิ้ง Truth → Corruption
```
`[Weiland_CharacterArcs]` (craft) — งานสั้น 1 ภาพ/1 carousel: มักเป็น micro positive arc (Mint เปลี่ยนมุมมองนิดเดียว) หรือ flat (Tao)

## 12. แบบฝึกหัด (Exercises)

1. **(ง่าย) One-sentence test** — เขียนตัวละครประกอบ 3 ตัวของเรื่องที่ทำอยู่เป็น 1 ประโยคแบบ Forster แล้วเขียนตัวนำ 1 ตัวที่ *ไม่* ควรสรุปได้ในประโยคเดียว
   *คำตอบที่ดีแสดง:* flat ชัด จำง่าย; ตัวนำมีความขัดแย้งภายในอย่างน้อย 1 คู่ `[Forster1927]`
2. **(ง่าย) Big Five แทน MBTI** — ลูกค้าส่ง "ตัวละคร ENFP" มา แปลงเป็นค่า Big Five + พฤติกรรมที่เห็นได้ 5 ข้อ
   *ดี:* ไม่อ้าง type เป็นวิทยาศาสตร์, ทุก trait มีพฤติกรรมที่ถ่าย/วาดได้ `[McCraeJohn1992]` `[Pittenger2005]`
3. **(กลาง) If…then signature** — เขียน 6 if-then สำหรับ Tao รวม 2 ข้อที่ดู "ขัด" กับภาพลักษณ์ (เช่น ถ้าถูกถามเรื่องตัวเอง → เลี่ยง)
   *ดี:* ความขัดมีเหตุผลภายใน, ใช้ภาษาท่าทางแทนหน้า `[MischelShoda1995]`
4. **(กลาง) Faceless emotion plan** — วางแผน 4 ภาพ carousel ที่ Mint จากกังวล → โล่งใจ โดยไม่มีหน้า ระบุ บริบท/ระยะ/ท่า/ทิศศีรษะ ต่อภาพ
   *ดี:* ภาพบวกใช้ท่าชัด ไม่พึ่งฉากหลัง; มีข้อความใกล้ผู้พูด `[Calbi2017]` `[Aviezer2012]`
5. **(กลาง) Structure-of-sympathy diagnosis** — ดูคลิปเก่าของสตูดิโอ 1 ชิ้น ให้คะแนน recognition/alignment/allegiance 1–4 และเสนอแก้ข้อที่ต่ำสุด
   *ดี:* แยกสามระดับได้ ไม่ใช้คำว่า "identify" ลอย ๆ `[Smith1995_EngagingCharacters]`
6. **(ยาก) Want/Need/Lie สำหรับซีซัน** — ออกแบบ arc 10 ตอนของต้น (ร้านแว่นตีสอง) ระบุ Lie, Ghost, Want, Need, และจุดที่ Lie ถูกท้าทาย 3 ครั้ง
   *ดี:* Want กับ Need ขัดกันจริง, surprise ตอนท้ายย้อนหาได้ `[Weiland_CharacterArcs]` `[Forster1927]`
7. **(ยาก) Representation audit** — สร้าง prompt ภาพ "เจ้าของร้านแว่น", "ลูกค้าสูงอายุ", "นักเรียน" อย่างละ 4 ภาพ (FLUX ฟรี) บันทึกว่า default ออกมาแบบไหน แล้วเขียน casting brief ใหม่
   *ดี:* ระบุ stereotype ที่พบเป็นข้อสังเกต (our test), brief ใหม่เจาะจงโดยไม่ overcorrect บริบท `[Bianchi2023]` `[Google2024_Gemini]`
8. **(ยาก) Thai archetype remix** — เอาโครง พระเอก/นางเอก/นางร้าย มาเขียนเรื่อง 6 ภาพที่คงความอ่านง่ายแต่ตัด script อันตราย (ไม่มีการ "เอาชนะ" ด้วยกำลัง, ตัวร้ายไม่ถูกลดเป็นผู้หญิงอิจฉา)
   *ดี:* ผู้ชมไทยยังจำ role ได้ทันที; ไม่มี trope ที่ Townsend ระบุ `[Townsend2016]` `[ZhangIntaraporn2024]`

## 13. Checklist (ก่อนส่งงาน — yes/no)

1. ตัวละครแต่ละตัวมีหน้าที่ในงานนี้ที่เขียนได้ 1 บรรทัดไหม
2. ตัดสินใจแล้วว่าตัวไหน flat ตัวไหน round และเหมาะกับประเภทงาน (ตลก/ดราม่า) ไหม `[Forster1927]`
3. ตัวนำมี objective ต่อฉากในรูปกริยา (ไม่ใช่อารมณ์) ไหม `[Campbell2022_Stanislavsky]`
4. มีอย่างน้อย 1 ฉากที่ตัวละคร *เลือก* ระหว่างสองสิ่งที่มีราคาไหม `[Aristotle_Poetics_Butcher]`
5. พฤติกรรมทุกอย่างตรงกับ if-then/ขอบการแกว่งใน bible หรือมีเหตุจากสถานการณ์ไหม `[MischelShoda1995]` `[Fleeson2001]`
6. Surprise ทุกครั้ง ย้อนหาจุดที่ปลูกไว้ได้ไหม `[Forster1927]`
7. ผู้ชมแยกได้ไหมว่าใครเป็นใคร ที่ขนาด thumbnail (recognition) `[Smith1995_EngagingCharacters]`
8. ใน 1–2 beat แรก ผู้ชมรู้ไหมว่าจะเข้าข้างใคร (allegiance) `[Raney2004]`
9. ถ้าไม่มีหน้า: ทุกภาพมีท่า + ระยะ + บริบทที่ชี้อารมณ์เดียวกัน (ไม่ขัดกัน) ไหม `[Aviezer2012]` `[Calbi2017]`
10. ภาพอารมณ์บวกของตัวละครไม่มีหน้า มีคิวร่างกายชัด (ไม่พึ่งฉากหลังอย่างเดียว) ไหม `[Calbi2017]`
11. ไม่มีการอ้าง MBTI/Enneagram เป็นข้อเท็จจริงทางจิตวิทยาไหม `[Pittenger2005]` `[Hook2021]`
12. ไม่มีตัวละครที่ถูกสร้างรอบอัตลักษณ์กลุ่มเป็นมุกหลักไหม `[Azaria2020_Apu]`
13. ภาพคนจาก AI ผ่าน casting brief และตรวจ stereotype + ความถูกบริบทแล้วไหม `[Bianchi2023]` `[Google2024_Gemini]`
14. ถ้าใช้ archetype ไทย ตัด script อันตราย (ความรุนแรงทางเพศ, นางร้ายแบบเหมารวม) แล้วไหม `[Townsend2016]`
15. caption/pitch ไม่อ้างผลทางจิตใจเกินหลักฐาน (เช่น "ทำให้ empathic ขึ้น") ไหม `[DodellFederTamir2018]`
16. Signature (ชุด ทรงแว่น สี ตำแหน่งในเฟรม เสียง) ตรงกับ bible/master image ไหม (CHARACTER_BIBLE_TEMPLATE.md)
17. อัปเดต changelog ตัวละครใน bible หลังตอนนี้แล้วไหม `[Mittell2015]`

## 14. Evaluation Rubric

**วิธีให้คะแนน:** ให้ 1–4 ต่อเกณฑ์ (6 เกณฑ์ → เต็ม 24); น้ำหนักเท่ากัน ยกเว้นงาน faceless ให้ C5 ×1.5; งานตัวประกอบ/โฆษณาสั้น ข้าม C3 (คิดจาก 5 เกณฑ์). ผ่าน = ≥ 3 ทุกเกณฑ์ที่ใช้ และไม่มี critical failure. ผู้ให้คะแนนต้องชี้ "ตำแหน่ง" (ภาพที่/วินาทีที่/บรรทัดที่) ของหลักฐาน

| เกณฑ์ | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| **C1 Recognition & distinctness** `[Smith1995_EngagingCharacters]` | ตัวละครสับสนกัน ไม่รู้ใครพูด | แยกได้เมื่อดูนาน | แยกได้ทันทีที่ขนาดปกติ | แยกได้ที่ thumbnail/silhouette + เสียง/ตำแหน่งคงที่ |
| **C2 Motivation clarity** `[Campbell2022_Stanislavsky]` `[Weiland_CharacterArcs]` | ไม่รู้ว่าตัวละครต้องการอะไร | รู้ want แต่ไม่ชัดในฉาก | want ชัดทุกฉาก | want + need/Lie เห็นได้และขัดกันอย่างมีความหมาย |
| **C3 Dimensionality & surprise** `[Forster1927]` | ทำนายได้หมด หรือ surprise ไม่มีเหตุ | มี surprise แต่เหตุบาง | 1 surprise ที่ปลูกไว้ | surprise ที่ทำให้ผู้ชมมองตัวละครใหม่ และย้อนหาได้หลายจุด |
| **C4 Consistency (pattern)** `[MischelShoda1995]` `[Fleeson2001]` | ทำผิดนิสัยโดยไม่มีเหตุ | ส่วนใหญ่ตรง มี 1–2 จุดหลุด | ตรง if-then ทั้งหมด | ตรงทั้งหมด และความแปรผันเองบอกนิสัย (consistently inconsistent) |
| **C5 Embodied emotion (body/context)** `[Aviezer2012]` `[Calbi2017]` | อารมณ์อ่านไม่ออก/ขัดกัน | อ่านได้บางภาพ | อ่านได้ทุกภาพ คิวไม่ขัด | อ่านได้ทันที แม้ปิดข้อความ; อารมณ์บวกมีคิวร่างกายชัด |
| **C6 Representation & ethics** `[Bianchi2023]` `[Townsend2016]` | มี stereotype/trope อันตราย | ไม่มีเจตนาร้าย แต่ใช้ default/เหมารวม | casting ตั้งใจ ไม่มี stereotype | casting ตั้งใจ, บริบทถูก, ให้ความเป็นมนุษย์กับทุกตัว |

**Critical failures (ไม่ผ่านทันที ไม่ว่าคะแนนรวม):**
- ตัวละครสร้างรอบอัตลักษณ์กลุ่ม (เชื้อชาติ ภาค เพศสภาพ ความพิการ) เป็นมุกหลัก
- Normalise ความรุนแรงทางเพศ/การบังคับผ่านตัวละครที่ผู้ชมถูกชวนให้รัก
- ผู้ชมแยกไม่ออกว่าข้อความไหนเป็นของใคร (C1 = 1) ในงาน dialogue
- Signature ที่ล็อกไว้ใน bible เปลี่ยนโดยไม่ตั้งใจ (ชุด แว่น สี) ในซีรีส์
- Caption/บทอ้างผลทางจิตวิทยาเท็จหรือเกินหลักฐาน
