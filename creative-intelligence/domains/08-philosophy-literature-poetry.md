- ปรัชญาที่ใช้กับงานสร้างสรรค์: aesthetics of everyday life (Saito/SEP), meaning-making, อนิจจัง/ทางสายกลางแบบเคารพต้นทาง (ลิงก์ M03)

### 1.3 ความคิดเปลี่ยนไปอย่างไร
1. **จาก "กฎว่าควรเขียนอย่างไร" สู่ "ตัวบททำงานอย่างไร" สู่ "ผู้อ่านตอบสนองอย่างไร"** — Aristotle เป็น prescriptive; Formalism/Genette ดูกลไกตัวบท; Iser/Rosenblatt ย้ายความหมายไปที่การอ่าน; IGEL วัดผลจริง `[vanPeer2021_Foregrounding]` `[IGEL_About]`.
2. **"ความแปลก" ไม่ใช่สูตรสำเร็จเสมอ** — Shklovsky ชูความยาก/แปลก `[Shklovsky1917]` แต่ข้อมูลปี 2023 ชี้ว่า deviation ลดความชอบและความเข้าใจ ส่วน parallelism (ซ้ำ สัมผัส จังหวะ) ช่วยมากกว่า `[Menninghaus2023]` → foregrounding มีสองขา และขาที่ปลอดภัยกว่าสำหรับงานสั้นคือ parallelism.
3. **ข้ออ้างใหญ่ "วรรณกรรมทำให้คนดีขึ้น" ถูกลดขนาด** — ผล ToM ระยะสั้นไม่ replicate `[Panero2016]` `[FORRT_KiddCastano]`; ผล foregrounding ต่อ empathy มีแต่เล็กและขึ้นกับผู้อ่าน `[Koopman2016]` `[Scapin2023]`.
4. **ไทย:** ฉันทลักษณ์อนุรักษ์นิยมสูง — รูปแบบสัมผัส "เปลี่ยนน้อยมากตลอดประวัติวรรณคดีไทย" `[Hudak1986_MetaRhymes]`; ส่วนร้อยแก้ว/เรื่องสั้นสมัยใหม่โตบนความคาดหวังว่าวรรณกรรมต้อง "มีไว้เพื่อชีวิต" `[Limapichart2011]` แล้วค่อยหันสู่โลกภายใน `[Hiramatsu2007_KyotoReview]`.

## 2. หลักการพื้นฐาน (Fundamentals)

### 2.1 คำนิยามหลัก

| คำ | นิยาม (สั้น) | แหล่ง |
|---|---|---|
| **Mimesis** | การเลียนแบบการกระทำและชีวิต | `[Aristotle_Poetics_Butcher]` |

| **Defamiliarisation (ostranenie)** | ทำของคุ้นให้แปลกเพื่อให้ "รับรู้" ใหม่ | `[Shklovsky1917]` |
| **Foregrounding** | ส่วนของภาษาที่โดดออกมาเพราะ (ก) deviation — ผิดจากปกติ หรือ (ข) parallelism — ซ้ำแบบแผน; ระดับเสียง ไวยากรณ์ ความหมาย | `[vanPeer2021_Foregrounding]` `[MiallKuiken1994]` |
| **Parallelism** | การซ้ำแบบแผน: สัมผัส metre alliteration โครงประโยคคู่ขนาน | `[Menninghaus2023]` |
| **Fabula / sujet** | เรื่องตามลำดับเหตุ-เวลา / ลำดับที่เล่าจริง | `[LHN_Narratology]` |
| **Focalisation** | การจำกัดข้อมูลตามมุมของผู้เล่า/ตัวละคร: zero (ผู้เล่ารู้มากกว่า), internal (=ตัวละคร), external (น้อยกว่า) | `[Niederhoff2013_Focalization]` |
| **Voice** | ใครเป็นผู้เล่า/พูด (แยกจากใครมอง) | `[Niederhoff2013_Focalization]` |
| **Free indirect discourse (FID)** | เล่าบุรุษที่ 3 แต่ใช้ภาษา/ความคิดของตัวละคร | `[HakemulderKoopman2010]` |
| **Dialogism / Polyphony / Heteroglossia / Monologism** | ความหมายเกิดระหว่างเสียง / หลายเสียงเท่าเทียม / หลายลีลาภาษาสังคม / เสียงเดียวกลืนทุกเสียง | `[Robinson2011_Bakhtin]` |
| **Gaps (Leerstellen)** | ช่องว่างที่ตัวบทเว้นให้ผู้อ่านเชื่อม | `[Iser1972]` |
| **Efferent / Aesthetic stance** | อ่านเพื่อนำออกไปใช้ / อ่านเพื่อประสบการณ์ขณะอ่าน | `[Rosenblatt1982]` |
| **Apothegm vs Dictum** | คำคมที่เปิดความลึกลับ / คำคมที่ปิดคำตอบ ใช้ได้ "ทุกที่ทุกเวลา" ไม่มีเงื่อนไข | `[Morson2012]` |
| **Haiku / Senryu** | กวีสั้นภาพธรรมชาติ/ฤดูที่เชื่อมสภาพมนุษย์ / กวีสั้นเรื่องสภาพมนุษย์ | `[HSA_Definitions]` |
| **Flash / micro fiction** | เรื่องสั้นมาก; ป้ายคำศัพท์เป็น "สนามถกเถียง" ไม่ใช่นิยามตายตัว | `[Botha2016_Microfiction]` |
| **ฉันทลักษณ์** | คณะ (โครงสร้าง) + พยางค์/คำ + สัมผัส; วรรค → บาท → บท | `[Hudak1986_MetaRhymes]` |
| **สัมผัสนอก / สัมผัสใน** | สัมผัสระหว่างวรรค (บังคับ; สระ+ตัวสะกดเหมือน ต่างได้แค่พยัญชนะต้น/วรรณยุกต์) / ในวรรค (ไม่บังคับ; สระหรือพยัญชนะ) | `[Hudak1986_MetaRhymes]` `[TPP_KlonSuphap]` |

### 2.2 หลักการแกน 8 ข้อ (สำหรับงานสั้น)
1. **ภาษาที่ "โดด" ทำให้คนอ่านช้าลงและรู้สึกมากขึ้น** — แต่ต้องโดดจาก "พื้น" ที่เรียบ ถ้าโดดทุกบรรทัดก็ไม่มีอะไรโดด `[MiallKuiken1994]` `[Jacobs2015]` — FACT (correlational) + THEORY.
2. **สำหรับข้อความสั้นมาก: parallelism > deviation** — ซ้ำ/สัมผัส/คู่ขนานเพิ่มความเข้าใจและความชอบ; ความแปลกลดทั้งสอง `[Menninghaus2023]` — FACT.
3. **สัมผัสทำให้ "รู้สึกว่าจริง"** — ใช้กับความรู้สึกได้ ห้ามใช้ค้ำข้ออ้างข้อเท็จจริง `[McGloneTofighbakhsh2000]` — FACT (single study) + ethics.
4. **จุดพีคอยู่ท้าย** — chills กระจุกท้ายบรรทัด/บท/ชิ้น และตอนพูดตรงกับผู้ฟัง `[Wassiliwizky2017]` — FACT.
5. **ผู้อ่านเติมช่องว่างเอง** — ไม่ต้องสรุปข้อคิด `[Iser1972]` (THEORY) + ไม่มีรูปแบบสารใดชนะเสมอ (รวมการบอกข้อสรุปหรือไม่) `[OKeefeHoeken2021]` — S-tier ว่าผลเล็กและแปรผัน.
6. **สองเสียงต้องเป็นสองเสียงจริง** — ถ้า Tao เป็นปากผู้เขียน = monologism `[Robinson2011_Bakhtin]` — THEORY → craft.
7. **เลือกมุมก่อนเขียน** — ใครรู้อะไร (focalisation) และใครพูด (voice) `[Niederhoff2013_Focalization]`; FID ทำให้รู้สึกเห็นข้างในโดยไม่เพิ่มข้อมูล `[HakemulderKoopman2010]`.
8. **ภาษาไทย: ไม่มีสัมผัส = ไม่ใช่กวี** — "without rhyme, a poem cannot exist in Thai"; สัมผัสสร้างความ "ไพเราะ" และแบ่งจังหวะ `[Hudak1986_MetaRhymes]` — FACT (descriptive/cultural).

## 3. ทฤษฎีขั้นสูง (Advanced theory)

### 3.1 Foregrounding: สามขั้นของ Miall & Kuiken vs Neurocognitive Poetics
- **Miall & Kuiken (1994):** foregrounding → defamiliarisation (สะดุด) → affect → "refamiliarisation" (ใช้ความรู้สึกนำการตีความใหม่) `[MiallKuiken1994]`. ขั้นที่ 3 อนุมาน ไม่ได้วัด.
- **Jacobs (2015) NCPM:** ตัวบทมีสองโหมด — *backgrounding* (คุ้นเคย ไหลลื่น → immersion, "fiction feelings") และ *foregrounding* (สะดุด → aesthetic feelings) ผู้อ่านสลับระหว่างสองโหมด `[Jacobs2015]` — THEORY (มีคำวิจารณ์ Dixon & Bortolussi 2016 ที่ไม่ได้อ่าน).
- **Prediction-error account (Menninghaus 2023):** parallelism ทำให้เดาคำถัดไปได้ (ลด prediction error → fluency → ชอบ); deviation ทำให้เดาผิด (ต้นทุน) — ศิลปะ = การเล่นระหว่างสองอย่าง แต่ในตัวอย่างของเขา ผลบวกชนะ `[Menninghaus2023]`.
- **ความตึงที่ยังไม่คลี่:** Shklovsky (ความยากคือเป้าหมาย) vs fluency (ความง่ายคือความงาม). ทางประนีประนอมที่หลักฐานพอรองรับ: **deviation เล็ก 1 จุด บนโครง parallelism ที่แน่น** (craft synthesis จาก `[Menninghaus2023]` `[MiallKuiken1994]`) — ยังไม่มีการทดลองตรงกับรูปแบบ 2 บรรทัดของเรา **(our test)**.

### 3.2 Fluency และ "ความจริงจากเสียง"
- Rhyme-as-reason: ความลื่นของสัมผัสถูก "misattribute" เป็นความเชื่อมั่นว่าจริง; ผลลดลงเมื่อเตือนให้แยกรูปกับเนื้อ `[McGloneTofighbakhsh2000]`.
- Obermeier (2013) ตีความผล metre/rhyme ด้วย fluency แต่ **ไม่ได้วัด fluency ตรง ๆ** `[Obermeier2013]`.
- นัย: เสียงสวยเป็นเครื่องมือทางอารมณ์ที่มีพลังทางญาณวิทยา (epistemic) แฝง → ความรับผิดชอบสูงขึ้นเมื่อใช้กับเนื้อหาสุขภาพตา (ดู §11).

### 3.3 Narratology สำหรับข้อความ 2 บรรทัด
- ชิ้นงาน Mint & Tao คือ **dialogue ที่ไม่มีผู้เล่า** — voice ถูกแบ่งเป็นสองตัวละคร; focalisation อยู่ที่ภาพ (กล้อง) + caption. caption แบบ "เรา" (บุรุษที่ 1 รวม) เท่ากับเปิดผู้เล่าคนที่ 3 → ต้องเลือกว่ารู้มากกว่าตัวละคร (zero) หรือเท่ากัน (internal) `[Niederhoff2013_Focalization]` → craft.
- fabula/sujet: เรื่อง 20 วินาทีมี sujet 3 ฉาก (wide → medium → push-in) — การเลื่อน "ข้อมูลสำคัญ" ไปฉากสุดท้ายคือการจัด sujet ให้ anagnorisis ตกท้าย `[LHN_Narratology]` `[SEP_AristotleAesthetics]` + `[Wassiliwizky2017]` (พีคท้าย).
- FID ในแคปชัน: "ช้ากว่าคนอื่น ไม่ได้แปลว่าตกรถ" อ่านเป็นเสียงใน (Mint คิด) หรือเสียงผู้เล่า (สรุปสอน) ได้ทั้งคู่ — ถ้าต้องการให้รู้สึก "เห็นข้างใน" ให้เขียนเป็นความคิดในภาษาของตัวละคร `[HakemulderKoopman2010]` (ผลจำกัด) → **(our test)**.

### 3.4 Bakhtin: dialogism กับปัญหา "Tao เทศน์"
- monologism = เสียงเดียวรวบอำนาจความหมาย คนอื่นกลายเป็น "วัตถุ" `[Robinson2011_Bakhtin]`.
- ในคู่ Mint/Tao ปัญหาที่พบบ่อยคือ Mint = ปัญหา, Tao = คำตอบ — โครงนี้คือ monologic ในรูปบทสนทนา. ทางแก้แบบ dialogic **(craft)**: (ก) Tao ตอบด้วยคำถาม/มุมใหม่ ไม่ใช่ข้อสรุป; (ข) Mint มีความจริงบางส่วนที่ Tao ยอมรับ; (ค) ภาพทำหน้าที่ "เสียงที่สาม".
- heteroglossia กับภาษาไทย: ระดับภาษา คำลงท้าย สรรพนาม คือ "ลีลาสังคม" ที่บอกความสัมพันธ์ (ดู `creative-intelligence/knowledge/thai-language/STYLE_GUIDE.md` §1, §4) — เสียงของ Mint และ Tao ควรต่างกันในระดับคำ ไม่ใช่แค่ความเห็น.

### 3.5 Reader-response: gaps vs stance
- Iser: ช่องว่างคือแรงดึงให้อ่านต่อ (ตามแหล่งรอง) `[Iser1972]`; Rosenblatt: ผู้อ่านเลือก stance — งานเรื่องเล่าต้องการ aesthetic stance, งานให้ความรู้ต้องการ efferent `[Rosenblatt1982]`; และเตือนไม่ให้แทนประสบการณ์ด้วย "ข้อเท็จจริงเกี่ยวกับวรรณกรรม" `[Rosenblatt2005_MMWT]`.
- **ข้อขัดกันในงานเรา:** carousel ที่จบด้วย "takeaway" (efferent) อาจตัดประสบการณ์ (aesthetic) ของเรื่อง. ไม่มีหลักฐานตรงว่าแบบไหนดีกว่าบน IG; meta-analysis ทั่วไปบอกว่าการมี/ไม่มีข้อสรุปให้ผลเล็กและไม่แน่นอน `[OKeefeHoeken2021]` → ทำ A/B **(our test)**.

### 3.6 Short forms: ความสั้นแต่ละแบบต่างกัน
- Morson: apothegm (Heraclitus, Laozi, Wittgenstein) เปิดคำถามลึกขึ้น; dictum (Spinoza, Marx, Freud) ทำเหมือนไขปริศนาจบแล้ว; dictum ไม่รับเงื่อนไข; witticism ขึ้นกับจังหวะเวลา `[Morson2012]`.
- Haiku: ภาพ + "cut" ที่บอกความสัมพันธ์ระหว่างสองภาพ/ความคิด; 5-7-5 "ไม่ผิด" แต่ตั้งบนความเข้าใจผิดว่า on = syllable `[HSA_Definitions]`.
- Micro fiction: ความสั้นไม่ใช่นิยาม; ชื่อเรียกเป็นสนามถกเถียง `[Botha2016_Microfiction]`; ตัวอย่างคลาสสิก "For sale, baby shoes, never worn" มีบรรพบุรุษเป็นโฆษณาย่อยปี 1906–1921 `[QI_BabyShoes]`.
- **ข้อสังเกต (opinion):** คู่ Mint & Tao ที่ดีมีโครงแบบ haiku (ภาพ/สถานการณ์ → cut → สภาพมนุษย์) มากกว่าแบบ dictum.

### 3.7 ฉันทลักษณ์ไทย: meta-rhyme ของ Hudak
- Hudak เสนอว่ากฎสัมผัสที่ดูเฉพาะตัวของแต่ละฉันทลักษณ์ ลดได้เหลือ **3 แบบคู่สัมผัส (couplet meta-patterns)**: (1) ท้ายวรรคติดกันสัมผัสกัน; (2) ท้ายวรรคที่มีวรรคอื่นคั่น (เช่นโคลงสี่); (3) ท้ายวรรคสัมผัสกับคำต้น ๆ ของวรรคถัดไป (*ruat lek* — รอบเล็ก ใช้มากในร่าย) — แบบ 1–2 = *ruat yai* (รอบใหญ่) คือฐานของบท; แบบ 3 เป็นฐานของบทไม่ได้ `[Hudak1986_MetaRhymes]`.
- แบ่งเป็นสองกลุ่ม: ร่าย+โคลง (เก่าสุด, สัมผัสโคลงต้องเสียงวรรณยุกต์เดียวกัน) และ กาพย์+ฉันท์+กลอน `[Hudak1986_MetaRhymes]`.
- นัยต่องานเรา: บทสนทนาสองบรรทัดภาษาไทยมี "ช่อง" ตามธรรมชาติสำหรับ ruat lek — คำท้ายบรรทัด Mint ↔ คำต้น ๆ ของบรรทัด Tao (craft derivation).

### 3.8 วรรณยุกต์ × สัมผัส × ทำนอง
- สัมผัสนอกในภาษาไทย: สระและตัวสะกดเหมือน ต่างได้ที่พยัญชนะต้นและ **วรรณยุกต์** (ยุคก่อนวรรณยุกต์ต้องตรงกันด้วย) `[Hudak1986_MetaRhymes]`.
- กลอนสุภาพมีข้อกำหนด/ความนิยมเรื่องเสียงคำท้ายวรรค (รายละเอียด §6.3) `[TPP_KlonSuphap]`; บางแหล่งใช้คำ "นิยม/ไม่ควร" มากกว่า "ห้าม" (สรุปผลค้นหา DLTV; ไม่ได้บันทึกเป็น key) → ถือเป็น *ความนิยมที่เข้มข้น* ไม่ใช่กฎหมาย.
- เพลงไทย: ผู้แต่งทำนองเลี่ยงให้ทำนองเคลื่อน "สวนทาง" เสียงวรรณยุกต์ แต่ไม่ต้องตรงทุกพยางค์; เสียงตรีมักถูกทำให้ราบเมื่อร้อง `[Phikhatphairee2026_ThaiSongTone]` (case study เพลงเดียว). นัยต่อ TTS/เพลงประกอบ: ทำนองหรือ intonation ที่สวนวรรณยุกต์เสี่ยงทำให้ฟังเป็นคำอื่น.

### 3.9 ปรัชญาสำหรับงานสร้างสรรค์
- **Aesthetics of the everyday (Saito/SEP):** ความงามในงานบ้าน การกิน การเดิน การปฏิสัมพันธ์; รากจาก Dewey; ข้อถกเถียง — ต้องทำให้ของคุ้น "แปลก" ก่อนถึงมีคุณค่า (Shklovsky-แบบ) หรือความคุ้น ความอบอุ่น (comfort) มีคุณค่าในตัว; มี negative aesthetics (เบื่อ รก) และ atmosphere `[SEP_EverydayAesthetics]`. → ซีรีส์ "Slowly Growing" อยู่ฝั่ง "คุณค่าของความคุ้น" ได้โดยไม่ต้องทำให้ชีวิตดูพิเศษ.
- **Meaning-making:** ลิงก์ M03 §3.9 (SEP_LifeMeaning, Frankl) — ไม่ซ้ำ.
- **อนิจจัง / ทางสายกลาง:** ใช้ตามต้นทาง — "สิ่งใดไม่เที่ยง สิ่งนั้นเป็นทุกข์ ไม่ควรถือว่าเป็นเรา ของเรา" `[SN22_59_Mendis]`; ทางสายกลาง = เลี่ยงสองสุดโต่ง (กามสุขัลลิกานุโยค / อัตตกิลมถานุโยค) `[SN56_11_Thanissaro]`. การใช้ "ทางสายกลาง" เป็นคำเปรียบเรื่องความพอดีในชีวิตประจำวันต้องบอกว่าเป็นการเปรียบ (M03 §6 ตัวอย่าง 4).
- **วรรณกรรมไทยตั้งคำถามกับพุทธแบบชาวบ้านได้:** *ปีศาจ* เสนอกรรมเป็นการกระทำ (กรรมลิขิต) ไม่ใช่พรหมลิขิต; *คำพิพากษา* วิจารณ์การโทษกรรมและการทำบุญ `[Hiramatsu2007_KyotoReview]` → ความเคารพ ≠ ห้ามตั้งคำถาม แต่ต้องไม่ล้อเลียนหลักธรรม/สถาบัน (opinion, ดู §9).

### 5.1 ข้อโต้แย้งที่ยังไม่จบ (contested)
1. **"ยิ่งแปลกยิ่งดี" vs "ยิ่งลื่นยิ่งดี"** — Shklovsky/Miall & Kuiken ให้คุณค่าการสะดุด `[Shklovsky1917]` `[MiallKuiken1994]`; กลุ่ม Menninghaus พบว่า deviation ลดความชอบ `[Menninghaus2023]`. อาจไม่ขัดกันจริง: M&K วัด *ความสะดุด/affect* ส่วน Menninghaus วัด *ความชอบ/ความเข้าใจ* — สิ่งที่ทำให้หยุดคิดอาจไม่ใช่สิ่งที่ทำให้ชอบทันที (การตีความของเรา).
2. **foregrounding → empathy** — มีผลบวกในบางการทดลอง `[Koopman2016]` `[Bonasera2025]` แต่ Scapin ชี้ว่าตัวแปรคือ "การประมวลของผู้อ่าน" ไม่ใช่อุปกรณ์ทางภาษาเอง `[Scapin2023]`; ทุกงาน N เล็ก.
3. **Catharsis** — ความหมายยังเถียง (purgation/clarification/…) `[SEP_AristotleAesthetics]` → อย่าเขียนว่า "Aristotle บอกว่าเรื่องเศร้าช่วยระบายอารมณ์" เป็นข้อเท็จจริง.
4. **Focalisation** — แนวคิดเดียวที่ใช้กันกว้าง แต่ Klauk & Köppe ตั้งคำถามกับ internal focalisation และ Niederhoff ตอบว่าแนวคิด "perspective" กับ "focalisation" ใช้ได้ทั้งคู่ (ตามผลค้นของรายการ LHN) `[Niederhoff2013_Focalization]`.
5. **Rosenblatt เป็น reader-response หรือไม่** — เธอปฏิเสธการถูกจัดกลุ่มเพราะไม่ได้ยึด "ผู้อ่านเดี่ยว" แต่ยึด transaction (ตามแหล่งรอง) `[Rosenblatt1982]`.
6. **กฎเสียงท้ายวรรคกลอน** — "ห้าม" หรือ "นิยม" ต่างกันตามตำรา `[TPP_KlonSuphap]`.

**ข้อจำกัดใหญ่ของทั้ง domain:** (1) แทบทุกการทดลองใช้ภาษาตะวันตก (อังกฤษ เยอรมัน ดัตช์) และผู้ร่วมเป็นนักศึกษา; (2) วัดผลระยะสั้นหลังอ่าน ไม่ใช่การจดจำหรือการแชร์บนโซเชียล; (3) ไม่มีการทดลองกับข้อความ 2 บรรทัด + ภาพดินสอ + เสียง TTS แบบงานเรา; (4) ภาษาไทยมีวรรณยุกต์ — ผลของ rhyme/metre อาจต่างเพราะสัมผัสไทยไม่รวมวรรณยุกต์และจังหวะไทยเป็นแบบนับคำ ("demarcative rhythm" ตาม Mosel ใน `[Hudak1986_MetaRhymes]`).

## 6. การประยุกต์ใช้จริง (Applications)

### 6.1 แบบทั่วไป (domain-neutral) — ขั้นตอนเขียนข้อความสั้นที่มีปัญญา
1. **ตั้งสถานการณ์ก่อนความคิด** — เลือกสิ่งของ/ฉากธรรมดา 1 อย่าง (everyday aesthetics `[SEP_EverydayAesthetics]`).
2. **หาการรับรู้ใหม่ 1 อย่างต่อของชิ้นนั้น** (ostranenie) — มองจากมุมที่ไม่คุ้น แต่ใช้คำธรรมดา `[Shklovsky1917]` `[Menninghaus2023]`.
3. **สร้างโครงคู่ขนาน** — บรรทัด 2 สะท้อนโครงบรรทัด 1 (ซ้ำคำ/ซ้ำโครง/สัมผัส) `[Menninghaus2023]` `[Obermeier2013]`.
4. **ให้คำสำคัญตกท้าย** — คำที่แบกความหมายอยู่ท้ายบรรทัดสุดท้าย `[Wassiliwizky2017]`; สอดคล้องกับหลักน้ำหนักท้ายวลีของภาษาไทยใน STYLE_GUIDE §2 ข้อ 7.
5. **ลบบรรทัดสรุป** — ถ้ามี "เพราะฉะนั้น/จำไว้ว่า/ชีวิตก็เหมือน…" ให้ลองตัด แล้วดูว่าความหมายยังอยู่ไหม `[Iser1972]` (THEORY) — **(craft)**.
6. **ตรวจ dialogism** — คนพูดคนที่สองต้องไม่เป็นแค่คำตอบ `[Robinson2011_Bakhtin]` — **(craft)**.
7. **ตรวจความจริง** — ข้อความที่สัมผัส/คล้องจองแล้ว "ฟังดูจริง" ต้องเป็นความรู้สึก/มุมมอง ไม่ใช่ข้ออ้างข้อเท็จจริงที่ไม่มีหลักฐาน `[McGloneTofighbakhsh2000]`.
8. **ตรวจที่มา** — ถ้ายืมคำคม ทำ §6.6.

### 6.2 เครื่องมือ "ภาษาที่โดด" แบบวัดได้ (เลือก 1–2 ต่อชิ้น)

|---|---|---|---|
| เสียง | สัมผัสสระข้ามบรรทัด, ซ้ำพยัญชนะต้น (alliteration = สัมผัสในแบบหนึ่งในไทย) | เสียงที่ไม่คาด (คำเลียนเสียงแปลก) | `[Obermeier2013]` `[Hudak1986_MetaRhymes]` |
| ไวยากรณ์ | โครงประโยคซ้ำ "ไม่ใช่… แต่…", "ยิ่ง… ยิ่ง…" | ประโยคไม่ครบที่ตั้งใจ | `[Menninghaus2023]` |

### 6.3 การเขียนกลอน/คำคล้องจองภาษาไทย (ฉันทลักษณ์ที่ตรวจแหล่งแล้ว)

**กลอนสุภาพ (กลอนแปด)** `[TPP_KlonSuphap]` `[Hudak1986_MetaRhymes]` `[Wiki_ThaiPoetry]`
- วรรคละ 8 คำ (7–9 ได้); 2 วรรค = 1 คำกลอน (บาท); 2 คำกลอน = 1 บท (4 วรรค: สดับ รับ รอง ส่ง)
- สัมผัสบังคับ (สัมผัสสระ): คำท้ายวรรคสดับ → คำต้น ๆ (Hudak: "มักคำที่ 3") ของวรรครับ (*ruat lek*); คำท้ายวรรครับ → คำท้ายวรรครอง (*ruat yai*); ระหว่างบท: คำท้ายวรรคส่ง → คำท้ายวรรครับของบทถัดไป `[Hudak1986_MetaRhymes]` `[TPP_KlonSuphap]`
- เสียงคำท้ายวรรค (ตามหน้าเรียน TPP): สดับ — ได้ทุกเสียง ไม่นิยมสามัญ; รับ — ห้ามสามัญ/ตรี นิยมจัตวา; รอง/ส่ง — นิยมสามัญหรือตรี ห้ามเอก โท จัตวา `[TPP_KlonSuphap]` (บางแหล่งเขียนว่า "ไม่ควร" → ถือเป็นความนิยมเข้มข้น)
- สัมผัสใน (ไม่บังคับ) = ที่กวีโชว์ฝีมือ; สุนทรภู่ใช้หนาแน่น `[Hudak1986_MetaRhymes]` `[ThaiFoundation_SunthornPhu]`

**กาพย์** `[Wiki_ThaiPoetry]` — ยานี 11 (วรรค 5+6, จังหวะช้า มักพรรณนาความงาม/ธรรมชาติ); ฉบัง 16 (6+4+6, ใช้เล่าเรื่อง); สุรางคนางค์ 28 (7 วรรค × 4, จังหวะเร็ว ใช้ฉากโกรธ/สู้)
**โคลงสี่สุภาพ** `[Wiki_ThaiPoetry]` — 4 บาท วรรคแรก 5 คำ; บังคับ ไม้เอก 7 ตำแหน่ง ไม้โท 4 ตำแหน่ง (คำตายแทนเอกได้); สัมผัสโคลงต้องเสียงวรรณยุกต์ตรงกัน `[Hudak1986_MetaRhymes]`
**ฉันท์** `[Wiki_ThaiPoetry]` — ใช้ครุ (หนัก) / ลหุ (เบา) แทนวรรณยุกต์; เช่น อินทรวิเชียร 11
**ร่าย** — วรรคละ ~5 คำ ต่อกันไม่จำกัด สัมผัสท้ายวรรค → คำที่ 1–3 วรรคถัดไป; ร่ายสลับโคลง = ลิลิต `[Wiki_ThaiPoetry]` `[Hudak1986_MetaRhymes]`

> **คำเตือน:** ตำแหน่งเอก-โทของโคลงและผังสัมผัสละเอียดของกาพย์/ฉันท์ ต้องตรวจกับตำราฉันทลักษณ์ก่อนเผยแพร่บทกวีเต็มรูป — แหล่งรอบนี้เป็น tier D/E สำหรับรายละเอียดนี้.

### 6.4 สำหรับสตูดิโอ — Mint & Tao 2 บรรทัด

**สูตร A — "ภาพ → cut → ความจริงของมนุษย์" (haiku-style)** **(craft)** จาก `[HSA_Definitions]`
- Mint: สถานการณ์/ความรู้สึกจริงในภาพ · Tao: มองภาพเดิมจากมุมใหม่ ไม่สรุปเป็นคำสอน.

**สูตร B — "คู่ขนาน + ตัวเปลี่ยน 1 คำ"** **(craft)** จาก `[Menninghaus2023]`
- Tao ยืมโครงคำของ Mint แล้วเปลี่ยนคำเดียว. ตัวอย่าง (ใหม่ ไม่ได้ทดสอบ):
  > **Mint:** "ทุกคนเดินไปไกลแล้ว เหลือเราที่ยังอยู่ตรงนี้"
  > **Tao:** "ทุกคนเดินไปไกลแล้ว เหลือเราที่ยังเห็นทางนี้"
  (ซ้ำโครง ~80% → เปลี่ยน "อยู่" เป็น "เห็นทาง"; คำท้าย "นี้" ซ้ำกัน = parallelism แต่คำซ้ำไม่นับเป็นสัมผัสตามฉันทลักษณ์; ความหมายพลิกที่คำเดียว)

**สูตร C — "ruat lek ข้ามบรรทัด"** **(craft)** จาก `[Hudak1986_MetaRhymes]`
- คำท้ายบรรทัด Mint สัมผัสสระกับคำที่ 2–3 ของบรรทัด Tao → ฟัง "ไพเราะ" แบบกลอนโดยไม่ต้องเป็นกลอน.
  > **Mint:** "วันนี้ทำอะไรก็ช้าไปหมด"
  > **Tao:** "ช้าแต่**อด**ทน ก็ยังถึงนะ" (หมด ↔ อด: สัมผัสสระ โอะ+ด)

**สูตร D — "ท้ายบรรทัด = คำหนัก + พูดกับผู้ชม"** จาก `[Wassiliwizky2017]`
- แคปชันบรรทัดสุดท้ายลงด้วยคำสำคัญ ไม่ใช่อนุภาคยาว; ใช้ "เรา/เธอ" ได้ (direct address).

**วิเคราะห์ EP01 (รถเมล์คันถัดไป)** — ตัวบทจาก `slowly-growing/ALL-30-STORIES.md`
- Tao: "ก็เพราะคันของเรายังมาไม่ถึง ไม่ได้แปลว่าเราตกรถสักหน่อย" — แข็งแรงที่ reframing แบบไม่เทศน์ (ไม่มี "จงเชื่อมั่น"); **จุดปรับ (craft):** คำท้ายเป็น "สักหน่อย" (อนุภาคเบา) ทำให้พีคท้ายอ่อน; แคปชัน "ช้ากว่าคนอื่น ไม่ได้แปลว่าตกรถ" ดีกว่าเพราะจบที่ "ตกรถ" (คำหนัก) — สอดคล้อง `[Wassiliwizky2017]`. ไม่มีสัมผัสข้ามบรรทัด (นี้ / หน่อย) → ลองรุ่น: "…ยังมาไม่ถึง ไม่ได้แปลว่าเราตกรถ" **(our test)**.
- ภาพฉาก 3 (ไฟหน้ารถคันใหม่) ทำหน้าที่ anagnorisis เชิงภาพ ตกท้ายตาม sujet `[SEP_AristotleAesthetics]`.

**วิเคราะห์ EP02 (เหนื่อยที่ไม่มีชื่อ)** — Tao: "บางทีใจก็แบกของที่มือมองไม่เห็น…" = metaphor ที่ใหม่พอ (ไม่ใช่ "ใจหนัก" ธรรมดา) → semantic foregrounding 1 จุด; ส่วนหลัง "นั่งพักตรงนี้ก่อนก็ได้ ไม่ต้องอธิบาย" เป็นการกระทำ ไม่ใช่คำสอน → dialogic. ✔
**วิเคราะห์ EP03 (ขบวนที่เลือก)** — "เส้นทางอาจยาวขึ้น แต่ไม่เคยปิดตาย" — โครง "อาจ… แต่ไม่เคย…" เป็น parallelism แบบ antithesis; คำว่า "ไม่เคย" ใกล้ dictum (ใช้ได้ทุกที่ ไม่มีเงื่อนไข `[Morson2012]`) — เสี่ยงฟังเป็นคำปลอบสำเร็จรูป; ทางเลือก apothegm: "…เส้นทางอาจยาวขึ้น แล้วเราจะได้เห็นอะไรที่ขบวนตรงไม่ผ่าน" **(opinion/our test)**.

### 6.5 Carousel takeaways และแคปชันไทย
- **เรื่องเล่า (aesthetic stance):** slide สุดท้ายเป็นภาพ + บรรทัดเดียวที่เปิด ไม่ใช่ bullet สรุป `[Rosenblatt1982]` (THEORY) — **(our test)** A/B กับ slide takeaway.
- **ความรู้สายตา (efferent):** takeaway ชัด เป็นข้อเท็จจริงที่มีแหล่ง — **ไม่ใช้สัมผัสเพื่อเพิ่มน้ำหนักข้ออ้าง** `[McGloneTofighbakhsh2000]`; ใช้สัมผัสได้กับ CTA ที่เป็นคำชวน ไม่ใช่ข้ออ้าง.
- **แคปชัน TikTok/IG:** บรรทัดแรก = ภาพย่อของเรื่อง (สูตร D); ไม่ซ้ำบทพูดทั้งหมด (ให้ gap) `[Iser1972]`.
- **TTS:** เมื่อมีคำคล้องจอง ให้ตรวจว่า intonation ของเครื่องไม่ทำให้คำสัมผัสฟังผิดเสียงวรรณยุกต์ `[Phikhatphairee2026_ThaiSongTone]` — ฟังซ้ำก่อนส่ง (ดู `.claude/skills/ai-voice-director/`).

### 6.6 วิธีสืบคำคม (Quote Investigator method ดัดแปลง)
อ้างจากวิธีที่เห็นในกรณี baby shoes `[QI_BabyShoes]` และกลไกที่ O'Toole ระบุ `[BigThink_OToole]`:
1. **ค้นคำต่อคำ** ในคลังดิจิทัล (Google Books, HathiTrust, คลังหนังสือพิมพ์) หา **ครั้งแรกสุด** ที่มีข้อความ — ไม่ใช่เว็บคำคม.
2. **เทียบกับงานของบุคคลนั้นโดยตรง** (ต้นฉบับ/แปลที่เชื่อถือได้) — เช่นพระสูตรแปลใน M03 (`SN22_59_Mendis`).
3. **ตามดู "การเลื่อนชื่อ"** (attribution drift) — คำคมเดียวกันย้ายจากคนไม่ดังไปหาคนดัง (Kane/Moulton → Hopwood → Hemingway) `[QI_BabyShoes]`.
4. **ตรวจกลไกอ้างผิด:** textual proximity (ชื่อดังพิมพ์ใกล้ข้อความ), synthesis/streamlining (ย่อ/ผสมหลายแหล่ง), proverbial wisdom (สุภาษิตนิรนามถูกยกให้คนดัง), similar names, concoctions (แต่งขึ้น) `[BigThink_OToole]`.
5. **ตัดสิน:** ยืนยันได้ → ใส่ชื่อ + แหล่ง; ไม่แน่ → "สำนวนที่มักอ้างว่าเป็นของ…" หรือไม่ใส่ชื่อ; ปลอม → ไม่ใช้ หรือเขียนเป็นคำพูดตัวละครเราเอง.
6. **Plagiarism:** อย่าลอกบรรทัดจากเพจคำคม/เพลง/หนังสือมาเป็นบท Mint & Tao — แม้ไม่ได้ใส่ชื่อก็เป็นการลอก; ตรวจด้วยการค้นวลี 6–8 คำในเครื่องมือค้นหาก่อนเผยแพร่ **(craft)**.
7. รายการคำคมห้ามใช้ที่ตรวจแล้ว → `creative-intelligence/knowledge/philosophy/README.md` §7.

**ระดับคำตัดสิน (ใช้ในไฟล์ story.md ช่อง `quote-status:`)** **(craft)**
| สถานะ | เงื่อนไข | เขียนในงานว่า |
|---|---|---|
| `verified` | พบในงานต้นฉบับของบุคคล (ระบุงาน/หน้า/บท) | "— ชื่อ, *ชื่องาน*" |
| `paraphrase` | ความคิดตรงต้นทาง แต่ถ้อยคำเป็นของเรา | ไม่ใส่เครื่องหมายคำพูด; "แนวคิดจาก…" |
| `unverified` | หาครั้งแรกไม่ได้ / มีแต่เว็บคำคม | ไม่ใส่ชื่อ |
| `misattributed` | มีหลักฐานว่าเป็นของคนอื่น/แต่งขึ้น | ไม่ใช้ หรือใส่ชื่อที่ถูก |
| `ours` | เขียนเองทั้งหมด ตรวจแล้วไม่ซ้ำวลีสาธารณะ | เป็นคำพูดตัวละคร |

### 6.7 ตัวอย่าง before → after (ภาษาไทย, ทุกตัวอย่างเป็น **(craft)** ยังไม่ทดสอบกับผู้ชม)

**1. จากคำสอนสู่การกระทำ (dialogism)**
> before — Mint: "ทำงานพลาดอีกแล้ว" / Tao: "ความผิดพลาดคือครูที่ดีที่สุด จงเรียนรู้จากมัน"
> after — Mint: "ทำงานพลาดอีกแล้ว" / Tao: "งั้นเขียนไว้ตรงนี้ก่อน พรุ่งนี้เราจะได้รู้ว่าต้องระวังตรงไหน"
- ทำไม: before = dictum + คำสั่ง "จง" `[Morson2012]`; after = การกระทำในฉาก (กระดาษ ปากกา) ภาพทำงานแทนคติ.

**2. จาก metaphor ตายสู่การเห็นใหม่ (semantic foregrounding 1 จุด)**
> before — Tao: "ฟ้าหลังฝนย่อมสวยงามเสมอ"
> after — Tao: "ฝนหยุดแล้ว ถนนยังเปียกอยู่เลย แต่มันสะท้อนไฟได้สวยกว่าเมื่อวาน"
- ทำไม: "ฟ้าหลังฝน" ไม่โดดเพราะคุ้นเกิน; after มองของธรรมดา (ถนนเปียก) จากมุมใหม่ `[Shklovsky1917]` `[MiallKuiken1994]` และไม่ใช้ "เสมอ" (dictum).

**3. ย้ายคำหนักไปท้าย**
> before — "ไม่ได้แปลว่าเราตกรถสักหน่อย"
> after — "ไม่ได้แปลว่าเราตกรถ"
- ทำไม: พีคท้าย `[Wassiliwizky2017]`; อนุภาค "สักหน่อย" ทำให้อ่อนลง (แต่ในบทพูดกันเองอาจต้องการความนุ่มนี้ — เลือกตามตัวละคร).

**4. เพิ่มสัมผัสข้ามบรรทัดโดยไม่ฝืน**
> before — Mint: "ทำไมเราต้องรีบตลอดเวลา" / Tao: "ไม่ต้องหรอก ค่อย ๆ ไปก็ได้"
> after — Mint: "ทำไมเราต้องรีบตลอดเวลา" / Tao: "**ช้า**ลงสักนิด ก็ยังมาถึงได้นะ" (เวลา ↔ ช้า คำแรกของบรรทัด: สัมผัสสระ อา)
- ทำไม: ruat lek แบบไทย `[Hudak1986_MetaRhymes]`; parallelism ↑ความชอบ `[Menninghaus2023]`.

**5. แคปชันให้ gap แทนสำเนาบท**
> before — แคปชัน: "ทุกคนขึ้นรถไปหมดแล้ว แต่คันของเรายังมาไม่ถึง ไม่ได้แปลว่าตกรถ"
> after — แคปชัน: "ไฟหน้ารถคันถัดไป ยังอยู่ไกลอยู่เลย"
- ทำไม: before ซ้ำบท; after เพิ่มภาพที่ผู้ชมต้องเชื่อมเอง `[Iser1972]` (THEORY) — ต้องทดสอบว่าผู้ชมเข้าใจ.

**6. ใช้หลักธรรมโดยไม่บิด (อนิจจัง)**
> before — Tao: "ทุกอย่างไม่เที่ยง อย่าไปยึดติดกับอะไรเลย"
> after — Mint: "แก้วที่ชอบที่สุดแตกแล้ว" / Tao: "เก็บเศษไว้สักชิ้นไหม ไว้จำว่ามันเคยอยู่กับเราตอนไหนบ้าง"
- ทำไม: before เสี่ยงอ่านเป็น "ไม่ต้องใส่ใจ" (ดู M03 §6 ตัวอย่าง 3); after ยอมรับการเปลี่ยนแปลงพร้อมความรัก ไม่ต้องเอ่ยคำบาลี; ต้นทาง `[SN22_59_Mendis]` พูดเรื่องไม่ถือว่าเป็น "ของเรา" ไม่ใช่ห้ามรัก — after เป็น **การตีความเชิงวรรณกรรม** ไม่ใช่คำสอนตรง ห้ามติดป้ายว่า "พุทธพจน์".

### 6.8 งานสินค้า/โพสต์ร้าน (eyewear และ domain อื่น)
- **Tagline:** ใช้ parallelism กับ *ประสบการณ์* ("มองชัด ใส่สบาย" — สองวลีคู่ขนาน) ไม่ใช่กับ *ผลทางการแพทย์* `[McGloneTofighbakhsh2000]` **(craft)**.
- **Ostranenie แบบปลอดภัย:** เปิดคลิปด้วยมุมแปลกของสิ่งของ (เลนส์สะท้อนเมืองตอนเย็น) แล้วตัดกลับสู่ภาพสินค้าชัดภายใน 1–2 วินาที — deviation สั้น บนโครงที่คุ้น `[Menninghaus2023]` `[Jacobs2015]` **(our test)**.
- **คลิปเรื่องเล่ามีเสียง:** บรรทัดสุดท้ายของ VO เป็น direct address สั้น ("แล้วเธอล่ะ มองเห็นอะไรวันนี้") และตรงกับจุดพีคของดนตรี `[Wassiliwizky2017]`.
- **Domain อื่น (ร้านอาหาร คลินิก การศึกษา):** หลักเดียวกัน — ความรู้สึกใช้กวีได้, ข้ออ้างใช้ภาษาตรง; คำคมต้องผ่าน §6.6.

### 6.9 ตัวตรวจอัตโนมัติที่ทำได้ (สำหรับ domain 15)
| ตรวจ | วิธี | ระดับ |
|---|---|---|
| คำสั่งสอน | regex: `จง|ต้อง|เพราะฉะนั้น|ชีวิตคือ|จำไว้ว่า|เสมอ` ในบรรทัด Tao | เตือน |
| จบด้วยอนุภาคยาว | คำสุดท้าย ∈ {สักหน่อย, นะคะ, นะครับ, เนอะ, น่ะ} และบรรทัด > 12 คำ | เตือน |
| คำซ้ำซาก | รายการ cliché ไทย ("ฟ้าหลังฝน", "ชีวิตคือการเดินทาง", "สู้ๆ", "ไม่มีอะไรเกิดขึ้นโดยบังเอิญ") | เตือน |
| ชื่อบุคคล + เครื่องหมายคำพูด | ถ้ามีชื่อ (Buddha, Einstein, ไอน์สไตน์ ฯลฯ) และ `quote-status` ≠ verified | บล็อก |
| ลอกวลี | ค้น n-gram 6–8 คำบนเว็บ (manual หรือ API ที่อนุญาต) | บล็อกถ้าพบตรง |
| ความยาวบนจอ | จำนวนคำ ÷ เวลาค้าง (screenwriting §2.6–2.7) | เตือน |

## 7. กรณีศึกษาที่ประสบความสำเร็จ (Success case studies)

### 7.1 สุนทรภู่ — กลอนที่ "ง่ายแต่ไพเราะ"
- **เอกสาร:** UNESCO ยกย่อง 1986; *พระอภัยมณี* และ *นิราศภูเขาทอง* ได้รับยกย่องว่าดีที่สุดในประเภท; ภาษาเข้าใจง่าย จำง่าย เพราะชำนาญสัมผัสและจังหวะ; สัมผัสทั้งข้ามบทและในวรรค `[ThaiFoundation_SunthornPhu]`.
- **วิเคราะห์ (ของเรา):** ตรงกับหลักฐาน parallelism → fluency → liking `[Menninghaus2023]` — ความไพเราะของสัมผัสใน (internal rhyme) ทำงานแบบ parallelism ไม่ใช่ deviation. บทเรียน: ใช้คำธรรมดา + เสียงประณีต ดีกว่าคำแปลก.

### 7.2 ขุนช้างขุนแผน — จากการขับเสภาสู่มหากาพย์ชาติ
- **เอกสาร:** เริ่มเป็นการขับเสภาปากเปล่า (~ศ.17) กว่า 20,000 คำกลอน; ฉบับมาตรฐาน 1917–18; ตัวละครเข้าสู่ภาษาพูด ("ขุนแผน" = เจ้าชู้); มีคำวิจารณ์สตรีนิยมต่อการวาดภาพวันทอง `[Wiki_KCKP]`; แปลอังกฤษสมบูรณ์ 2010 `[BakerPhongpaichit2010_KCKP]`.
- **วิเคราะห์:** งานที่ "ฟัง" ก่อน "อ่าน" — กลอนแปดกับเสภาทำให้จำและเล่าต่อได้ (สอดคล้อง rhythm/rhyme literature แต่ไม่มีการทดลองตรง). บทเรียนสำหรับ TTS: เขียนให้หูก่อนตา. และ: งานที่ยิ่งใหญ่ยังถูกวิจารณ์เชิงจริยธรรมได้ — อ้างอิงต้องเคารพทั้งงานและคำวิจารณ์.

### 7.3 *คำพิพากษา* (ชาติ กอบจิตติ) — ตั้งคำถามกับกรรมโดยไม่เทศน์
- **เอกสาร:** Book of the Year 1981, ซีไรต์ 1982; พิมพ์ 39 ครั้งถึง 2007; ดัดแปลงเป็นละคร/หนัง; วิจารณ์การโยนความทุกข์ให้กรรมและการทำบุญ; อิทธิพล existentialism `[Hiramatsu2007_KyotoReview]` `[Wiki_SEAWrite]`.
- **วิเคราะห์:** ความนิยมยาวนานของงานที่ *ไม่ให้คำตอบสำเร็จรูป* — ใกล้ apothegm มากกว่า dictum `[Morson2012]`. บทเรียน: เรื่องไทยที่ใช้พุทธปรัชญาไม่จำเป็นต้องจบด้วยคติ.

### 7.4 "What sobriety conceals, alcohol reveals" — รูปที่รอดคือรูปที่สัมผัส
- **เอกสาร:** คำคมในรูปที่ "รอดมา" (สัมผัส) ถูกจัดว่าแม่นยำกว่ารูปที่เปลี่ยนคำ (unmasks) `[McGloneTofighbakhsh2000]`.
- **วิเคราะห์:** สัมผัสเป็นกลไกการอยู่รอดของคำคม — ใช้กับ tagline แบรนด์ที่เป็นความรู้สึกได้ ("ชัดทุกวัน สบายทุกวัย" — ตัวอย่างสมมติ, **(our test)**) แต่ต้องเป็นสิ่งที่จริง.

### 7.5 Tolstoy ผ่านสายตาม้า (*Kholstomer*) — defamiliarisation ต้นแบบ
- **เอกสาร:** Shklovsky ยก Tolstoy ที่เล่าเรื่องผ่านม้า ทำให้ "ทรัพย์สิน" ดูแปลก และบรรยายการโบยเหมือนไม่เคยเห็น `[Shklovsky1917]`.
- **วิเคราะห์:** ใช้กับสินค้า: แว่นตาจากมุมของ "ของที่อยู่บนหน้าทุกวันแต่ไม่เคยถูกมอง" — ostranenie แบบอ่อน ๆ ในคลิปสินค้า (ไม่ทำให้สับสน).

## 8. วิเคราะห์ผลงานที่ผิดพลาด (Failure analysis)

### 8.1 "For sale, baby shoes, never worn — Hemingway" (จริง, documented)
- **อะไร:** เรื่องหกคำถูกอ้างเป็นของ Hemingway ในหนังสือ บทความ NYT, Reader's Digest.
- **ทำไม:** ต้นเรื่องเป็นโฆษณาย่อยนิรนาม 1906–1921; ชื่อ Hemingway โผล่ครั้งแรกในละคร 1984/1989 และหนังสือ 1991 ที่เล่าจาก "คำบอกเล่า" `[QI_BabyShoes]` — กลไก concoction + ชื่อดังดูดเครดิต `[BigThink_OToole]`.
- **บทเรียน:** แม้แต่ตัวอย่างสอน flash fiction ก็ปลอมได้ — ในงานเราเขียน "เรื่องหกคำที่มักอ้างว่าเป็นของ Hemingway (ไม่มีหลักฐาน)".

### 8.2 "Anger is like grasping a hot coal — Buddha" (จริง, documented)
- **อะไร:** คำคมยอดฮิตที่อ้างพระพุทธเจ้า.
- **ทำไม:** หนังสือ 1988 ยกให้พระพุทธเจ้าโดยตรง `[QI_HotCoal]`; ไม่พบในพระไตรปิฎก (ดู M03 §7).
- **บทเรียน:** เนื้อหาพุทธในงานไทยเสี่ยงสูงสุดเพราะผู้ชมเชื่อถือ — อ้างพระสูตรจากฉบับแปล `[SN22_59_Mendis]` หรือไม่อ้างชื่อเลย.

### 8.3 "เผาวรรณคดี" 1970s — การอ่านแบบเสียงเดียว (documented event; การตีความเป็นของเรา)
- **อะไร:** นักศึกษาหัวรุนแรงบางกลุ่มเรียกวรรณคดีคลาสสิกว่าเครื่องมือศักดินาและเรียกร้องให้เผา `[Limapichart2011]`.
- **วิเคราะห์ (opinion):** เป็นตัวอย่างของ monologic reading — ตัดสินงานด้วยเกณฑ์เดียว `[Robinson2011_Bakhtin]`. บทเรียนเชิง craft: เมื่อเราใช้งานเก่า (ขุนช้างขุนแผน รามเกียรติ์) อย่าทั้ง "ยกย่องไม่วิจารณ์" และ "ปัดทิ้งทั้งหมด"; ระบุบริบท.

### 8.4 Tao ผู้เทศน์ (typical failure — สมมติเพื่อสอน)
- **อะไร:** "Mint: เหนื่อยจัง" / "Tao: ชีวิตคือการเดินทาง จงเชื่อมั่นในตัวเองและอย่ายอมแพ้ เพราะความสำเร็จรออยู่"
- **ทำไม:** dictum ซ้อน 3 ชั้น (ไม่มีเงื่อนไข ใช้ได้ทุกที่) `[Morson2012]`; ไม่มีภาพ/สถานการณ์เฉพาะ; monologic `[Robinson2011_Bakhtin]`; metaphor ตาย ("ชีวิตคือการเดินทาง") ไม่ foreground อะไร `[MiallKuiken1994]`.
- **บทเรียน:** เปลี่ยนคำสอนเป็นการกระทำเล็ก ๆ ในฉาก (ดู EP02 "นั่งพักตรงนี้ก่อนก็ได้").

### 8.5 "กวีเกินไป" — deviation ล้น (typical failure)
- **อะไร:** แคปชันที่ทุกคำเป็น metaphor ใหม่ ไวยากรณ์บิด เพื่อให้ "ดูลึก".
- **ทำไม:** deviation ลดทั้งความเข้าใจและความชอบ `[Menninghaus2023]`; foreground ทุกบรรทัด = ไม่มีพื้นให้โดด `[Jacobs2015]`; ผู้ชมเลื่อนผ่านเร็ว ไม่มีเวลา "ประมวลเต็ม" (Scapin: full processing จำเป็น) `[Scapin2023]`.
- **บทเรียน:** deviation ได้ 1 จุดต่อชิ้น บนโครงที่ลื่น.

### 8.6 สัมผัสขายข้ออ้าง (typical risk)
- **อะไร:** tagline เช่น "เลนส์ดี ตาไม่มีวันเสีย" (สมมติ) — คล้องจองแต่เป็นข้ออ้างสุขภาพที่ผิด.
- **ทำไม:** rhyme-as-reason ทำให้ฟังจริง `[McGloneTofighbakhsh2000]` → ผิดจริยธรรมและอาจผิดกฎโฆษณาสุขภาพ.
- **บทเรียน:** สัมผัสใช้กับความรู้สึก/คำชวน; ข้ออ้างใช้ภาษาตรง + แหล่ง.

## 9. ข้อยกเว้นและบริบทที่ต่างกัน (Exceptions & context)

| บริบท | ต่างอย่างไร | แนวทาง |
|---|---|---|
| **ไทย vs ตะวันตก: สัมผัส** | อังกฤษสมัยใหม่ยอมรับกลอนไร้สัมผัส; ไทย "ไม่มีสัมผัส = ไม่ใช่กวี" ผู้ฟังไม่รู้ตัวว่าเป็นกลอนเปล่า (เกร็ดพระองค์เจ้าบิดยาลงกรณ์ ผ่าน Mosel) `[Hudak1986_MetaRhymes]` | ถ้าจะทำให้ "ฟังเป็นกวี" ในภาษาไทย ต้องมีสัมผัสอย่างน้อย 1 คู่ |
| **ไทย: จังหวะนับคำ** | กลอนไทย (ยกเว้นฉันท์) มี "demarcative rhythm" — แบ่งกลุ่มคำคงที่ หยุดท้ายกลุ่ม สัมผัสช่วยบอกขอบกลุ่ม (Mosel/Kuo ใน `[Hudak1986_MetaRhymes]`) | VO ไทย: วางจุดหายใจที่ขอบกลุ่มคำ ไม่ใช่ตาม stress แบบอังกฤษ |
| **ไทย: วรรณยุกต์** | สัมผัสไม่รวมวรรณยุกต์ แต่คำท้ายวรรคมีความนิยมเรื่องเสียง `[TPP_KlonSuphap]`; ทำนองไม่ควรสวนวรรณยุกต์ `[Phikhatphairee2026_ThaiSongTone]` | ตรวจด้วยหูทุกครั้ง โดยเฉพาะ TTS |
| **ไทย: ความคาดหวังเชิงสอน** | ประเพณี "วรรณกรรมเพื่อชีวิต" ทำให้ผู้อ่านไทยคุ้นกับวรรณกรรมที่มีสาร `[Limapichart2011]`; โพสต์ "ข้อคิดดีๆ" เป็นวัฒนธรรมแชร์ | มีสารได้ แต่ส่งผ่านสถานการณ์ ไม่ใช่คำสั่ง (opinion) |
| **ไทย: พุทธศาสนา** | ผู้ชมจำนวนมากถือศรัทธา; วรรณกรรมไทยเองก็ตั้งคำถามกับพุทธแบบชาวบ้าน `[Hiramatsu2007_KyotoReview]` | ไม่ล้อพระ/หลักธรรม; ไม่อ้างพุทธพจน์ที่สืบไม่ได้; ใช้คำบาลีถูกความหมาย `[SN22_59_Mendis]` |
| **ไทย: วรรณคดีร่วม (รามเกียรติ์)** | เชื่อมกับสถาบันและศาสนสถาน (จิตรกรรมวัดพระแก้ว) `[SmartHistory_Ramakien]` | อ้างอิงอย่างเคารพ ไม่ทำเป็นมุก/โลโก้สินค้า |
| **Haiku/short form ข้ามภาษา** | 5-7-5 ไม่ใช่แก่นในภาษาอังกฤษ `[HSA_Definitions]`; ภาษาไทยนับ "คำ" (พยางค์) แบบของตัวเอง | อย่าบังคับ 5-7-5 ในไทย; ใช้ "cut" แทน |
| **แพลตฟอร์ม: IG carousel vs Reel vs TikTok** | carousel อ่านช้าได้ (ผู้ชมกำหนดเวลา) → foregrounding มีเวลาทำงาน `[MiallKuiken1994]`; Reel/TikTok เวลาถูกกำหนด → ต้องให้เวลาข้อความค้าง | ข้อความที่มี deviation ต้องค้าง ≥ เวลาอ่าน 2 รอบ (craft; ดู screenwriting §2.7) |
| **ผู้ชม** | ผลหลายตัวขึ้นกับ trait empathy, ประสบการณ์อ่าน, สาขา `[Koopman2016]` `[HakemulderKoopman2010]` | อย่าคาดว่าชิ้นเดียวทำงานกับทุกคน; ทดสอบกับกลุ่มจริง |
| **Genre: ตลก/ประกาศร้าน** | witticism ขึ้นกับจังหวะเวลา `[Morson2012]`; ประกาศทางการไม่ควรมีลีลากวีเกินจำเป็น | แยกโหมดตามงาน (STYLE_GUIDE §1) |

## 12. แบบฝึกหัด (Exercises)

1. **(ง่าย) ล่า foregrounding** — เลือก 5 ตอนจาก `slowly-growing/ALL-30-STORIES.md` ขีดเส้นใต้คำที่ "โดด" และระบุว่าเป็น parallelism หรือ deviation ระดับเสียง/ไวยากรณ์/ความหมาย. *คำตอบที่ดี:* แยกสองขาได้ถูก, เห็นว่าบางตอนไม่มีจุดโดดเลย, ไม่นับ metaphor ตาย.
2. **(ง่าย) ย้ายคำหนักไปท้าย** — เขียนบรรทัด Tao ของ EP01–EP05 ใหม่ให้คำสำคัญอยู่ท้าย. *ดี:* ความหมายเดิม, อนุภาคไม่ยาวท้าย, อ่านดังแล้วเป็นธรรมชาติ.
3. **(กลาง) สัมผัสข้ามบรรทัด (ruat lek)** — เขียน 5 คู่ที่คำท้าย Mint สัมผัสสระกับคำที่ 2–3 ของ Tao. *ดี:* สัมผัสสระ+ตัวสะกดถูกตามนิยาม `[Hudak1986_MetaRhymes]`, ไม่ฝืนคำ, ไม่ใช่คำซ้ำ (คำซ้ำไม่นับเป็นสัมผัสที่ดี).
4. **(กลาง) Dictum → Apothegm** — แปลงคำคมสำเร็จรูป 5 อัน ("อย่ายอมแพ้" ฯลฯ) เป็นคู่ Mint & Tao ที่เปิดคำถาม. *ดี:* มีสถานการณ์เฉพาะ, Tao ไม่สรุป, Mint ไม่ถูกทำให้โง่ `[Morson2012]`.
5. **(กลาง) สืบคำคม** — เลือกคำคม 3 อันจากเพจไทยยอดนิยม ทำ §6.6 และรายงาน: ครั้งแรกที่พบ, ใคร, ตัดสิน. *ดี:* ใช้แหล่งต้นฉบับ/คลังดิจิทัล ไม่ใช่เว็บคำคม; บอกระดับความมั่นใจ; ไม่สรุปว่า "ปลอม" ถ้าแค่หาไม่เจอ (เขียน "ยืนยันไม่ได้").
6. **(ยาก) กลอนสุภาพ 1 บท** สำหรับแคปชันวันสุนทรภู่ — ตามฉันทลักษณ์ §6.3 พร้อมผังสัมผัส. *ดี:* 8±1 คำ/วรรค, สัมผัสบังคับครบ, เสียงท้ายวรรครับ/รอง/ส่งตามความนิยม, มีสัมผัสใน ≥2, ไม่ใช้คำโบราณเกินจำเป็น.
7. **(ยาก) Polyphony test** — เขียนตอนใหม่ที่ Mint ถูกบางส่วนและ Tao ยอมรับ แล้วเขียนอีกรุ่นแบบ monologic; ให้คน 3 คนเลือกว่าอันไหน "ไม่สอน" กว่า. *ดี:* บันทึกผลเป็น (our test), อธิบายว่าคำไหนทำให้ต่าง.
8. **(ยาก) Ostranenie สินค้า** — เขียน 3 บรรทัดเปิดคลิปแว่นที่มองแว่นจากมุมที่ไม่คุ้น (เช่นจากมุมของแว่นเอง) โดยไม่ทำให้สับสนว่าขายอะไร. *ดี:* deviation 1 จุด, ภาพสินค้ายังชัด, ไม่มีข้ออ้างเกินจริง.

## 13. Checklist (ก่อนส่ง)

1. [ ] ข้อความมีสถานการณ์/ภาพเฉพาะ ไม่ใช่คำสอนลอย ๆ
2. [ ] บรรทัดที่สองไม่มีคำสั่งสอน ("จง", "ต้อง", "เพราะฉะนั้น", "ชีวิตคือ…")

4. [ ] มี foregrounding อย่างน้อย 1 จุด และ deviation ไม่เกิน 1 จุด
5. [ ] คำที่แบกความหมายอยู่ท้ายบรรทัดสุดท้าย (ไม่จบด้วยอนุภาคยาว)
6. [ ] ไม่มี metaphor ตาย/คำซ้ำซาก ("ชีวิตคือการเดินทาง", "ฟ้าหลังฝน") เว้นแต่ถูกพลิกใหม่
7. [ ] ถ้ามีสัมผัส: สัมผัสถูกตามนิยาม (สระ+ตัวสะกด) และอ่านดังแล้วไม่ฝืน
8. [ ] สัมผัส/คล้องจองไม่ได้ใช้ค้ำข้ออ้างข้อเท็จจริงหรือสุขภาพ
9. [ ] คำคมที่ใส่ชื่อบุคคลผ่านการสืบ §6.6 (หรือไม่ใส่ชื่อ)
10. [ ] ไม่มีวลี 6–8 คำที่ลอกจากเพจ/เพลง/หนังสือ (ค้นแล้ว)
11. [ ] หลักธรรมที่ใช้ตรงความหมายต้นทาง หรือถูกบอกว่าเป็นการเปรียบ
12. [ ] อ้างวรรณคดีไทย/รามเกียรติ์/สถาบันอย่างเคารพ ไม่ล้อ
13. [ ] แคปชันไม่ซ้ำบทพูดทั้งหมด และเพิ่มมุม/ภาพย่อ

## 14. Evaluation Rubric

| เกณฑ์ | 1 — อ่อน | 2 — พอใช้ | 3 — ดี | 4 — ยอดเยี่ยม |
|---|---|---|---|---|
| **A. ความเฉพาะและภาพ** (everyday aesthetics) | คำสอนลอย ไม่มีฉาก | มีฉากแต่ทั่วไป ("วันที่เหนื่อย") | ฉาก/สิ่งของเฉพาะ 1 อย่างที่เห็นภาพ | สิ่งของธรรมดาถูก "เห็นใหม่" อย่างชัดและเรียบ |
| **B. ภาษาที่โดด** (foregrounding) | ไม่มีจุดโดด หรือโดดทุกคำจนงง | มี 1 จุดแต่เป็นคำซ้ำซาก | parallelism ชัด + คำสำคัญท้ายบรรทัด | parallelism แน่น + deviation 1 จุดที่พลิกความหมาย |
| **C. เสียง** (rhyme/rhythm/ไทย) | อ่านดังสะดุด ต้องหายใจกลางวรรค | ลื่นแต่ไม่มีเสียงคล้องจอง | มีสัมผัส/จังหวะคู่ขนาน 1 คู่ถูกนิยาม | สัมผัสนอก+ใน เป็นธรรมชาติ เสียงท้ายวรรคเหมาะ ฟัง TTS แล้วไม่เพี้ยน |
| **D. Dialogism / ไม่เทศน์** | Tao สั่งสอน/สรุปคติ | ไม่สั่ง แต่ Tao เป็นแค่คำตอบ | สองเสียงต่างกัน มี gap ให้ผู้ชมเติม | สองเสียงจริง ผู้ชมเติมความหมายเอง และยังรู้สึกชัด |
| **E. ความซื่อตรงทางปัญญา** | อ้างคำคมปลอม/บิดหลักธรรม/ลอก | อ้างชื่อโดยไม่ตรวจ | ตรวจที่มาแล้ว ไม่มีข้ออ้างเกินจริง | ตรวจที่มา + ใช้แนวคิดตรงต้นทาง + ระบุการเปรียบเมื่อเปรียบ |
| **F. ความเหมาะกับบริบท** (ไทย/แพลตฟอร์ม) | ผิดระดับภาษา/ไม่เคารพวัฒนธรรม | เหมาะแต่ไม่คำนึงแพลตฟอร์ม | ระดับภาษาถูก เวลาบนจอพอ | ใช้จุดแข็งของไทย (สัมผัส จังหวะคำ) และแพลตฟอร์มอย่างตั้งใจ |

**วิธีให้คะแนน:** ให้ A–F ละ 1–4 (รวม 24). น้ำหนักแนะนำสำหรับ Mint & Tao: B, D ×1.5; E เป็น gate. ส่งได้เมื่อ ≥ 17/24 และไม่มีเกณฑ์ใดได้ 1. ผู้ให้คะแนน 2 คน ถ้าต่างกัน ≥ 2 แต้มในเกณฑ์ใด ให้คุยหาหลักฐานในตัวบท (บรรทัด/คำ) ก่อนตกลง.

**Critical failures (ตกทันทีไม่ว่าคะแนนรวม):**
- คำคมที่ใส่ชื่อบุคคลแต่สืบไม่ได้หรือพบว่าปลอม
- ลอกวลีจากงานผู้อื่นโดยไม่ได้รับอนุญาต
- สัมผัส/คล้องจองค้ำข้ออ้างสุขภาพหรือสินค้าที่ไม่มีหลักฐาน
- บิดหลักธรรม (เช่น อนิจจัง = "ไม่ต้องรักอะไร") หรือล้อเลียนศาสนา/สถาบัน
- อ้าง "วิทยาศาสตร์พิสูจน์ว่าอ่านแล้ว empathy ดีขึ้น" (ข้อมูลไม่รองรับ)
