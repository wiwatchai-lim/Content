# Video Retention Review Framework (กรอบรีวิวการดูต่อของคลิป)

ใช้รีวิวคลิปก่อนส่ง (story clips, beat clips, คลิปหลับตา, Reels จาก carousel) — ทีละช่วงเวลา ถามคำถามเดียวกันซ้ำ ๆ แล้วจดคำตอบเป็นตาราง

**กติกาของกรอบนี้**
- **ไม่มีตัวเลขที่แต่งขึ้น** ช่วงเวลาที่ใช้ (0–1 s, 1–3 s, ...) เป็น *จุดตรวจ* ไม่ใช่ "เกณฑ์วิทยาศาสตร์" ตัวเลข 3 s / 6 s มาจาก **คำแนะนำของแพลตฟอร์ม** (Meta, TikTok — tier C) `[MetaIGVideoBP]` `[TikTokCreative]` ไม่ใช่งานวิจัย peer-reviewed
- **ห้ามใช้ "attention span 8 วินาที"** เป็นเหตุผล (ตำนาน ดู README 2.2) เหตุผลที่ถูกคือ *opportunity cost* — ทางเลือกอื่นอยู่ห่างแค่ปัดเดียว `[Fortenbaugh2017]`
- แต่ละคำถามมีป้ายหลักฐาน: **[EVID]** มีงานวิจัยหนุน (ระบุ key), **[PLATFORM]** คำแนะนำแพลตฟอร์ม, **[CRAFT]** ประสบการณ์วิชาชีพ/อนุมาน
- หลังโพสต์ ให้เทียบกับ retention graph จริง (YouTube/IG Insights): เส้นแบน = ดูต่อ, dip = ออก/ข้าม, spike = ดูซ้ำ (ดีมาก *หรือ* งงจนย้อน — ต้องดูว่าแบบไหน) `[YouTubeRetention]`

## ส่วน A — คำถามหลัก 6 ข้อ (ถามทุกช่วง)

| # | คำถาม | ถ้าตอบ "ไม่" ให้ทำ | หลักฐาน |
|---|---|---|---|
| Q1 | **เหตุผลที่จะดูต่อคืออะไร?** (คำถามที่ยังไม่ตอบ / สิ่งที่สัญญาว่าจะเห็น / อารมณ์ที่กำลังขึ้น) พูดออกมาเป็นประโยคเดียวได้ไหม | เพิ่มคำถาม/สัญญาใหม่ หรือย้ายช่วงที่ดีที่สุดขึ้นมา | [EVID] curiosity `[Loewenstein1994]` (M01), opportunity-cost `[Fortenbaugh2017]` |
| Q2 | **แน่นเกินไหม?** ช่วงนี้ผู้ชมต้องรับข้อมูลใหม่กี่ "ก้อน" พร้อมกัน (ภาพใหม่ + ข้อความใหม่ + เสียงพูดใหม่ + กราฟิก) | เหลือก้อนใหม่ทีละ 1–2; ให้ภาพเดิมค้างตอนพูดเรื่องใหม่ | [EVID] working memory ~4 chunks, CLT (M04); LC4MP limited capacity `[Huskey2020]` |
| Q3 | **ซ้ำซ้อนไหม?** VO พูดตรงกับข้อความบนจอทุกคำ? ภาพบอกแล้วแต่ยังพูดซ้ำ? | บนจอเหลือ keyword; ตัดประโยคที่ภาพพูดแทนได้ | [EVID] redundancy principle (Mayer, M04) |
| Q4 | **ช่วงนี้มีอะไร "ใหม่" ไหม?** (มุมใหม่ ระยะใหม่ เสียงใหม่ ข้อมูลใหม่) ถ้าค้างนาน ผู้ชมได้อะไร | เปลี่ยนมุม/ระยะภายในฉากเดิม (edit) หรือเพิ่มรายละเอียด punch-in | [EVID] edits↑arousal&memory `[Lang2000]`, novelty `[Bunzeck2006]` |
| Q5 | **การเปลี่ยนนี้มีเหตุผลไหม?** ทุกคัต/เสียง/กราฟิกที่ "ดึงตา" พาไปสู่ข้อมูลหรืออารมณ์ที่ต้องการ หรือแค่ทำให้สะดุ้ง | ลบ effect ที่ไม่มีหน้าที่; เก็บ effect ไว้ตรงจุดสำคัญ | [CRAFT] "pattern interrupt" ไม่มีหลักฐานเฉพาะ (README 2.6); orienting response `[Huskey2020]` |
| Q6 | **เข้าใจได้ตอนปิดเสียง และเข้าใจได้ตอนเปิดเสียง?** | ปิดเสียง: ข้อความ/ภาพต้องเล่าเรื่องหลัก; เปิดเสียง: ดนตรีไม่กลบ VO | [PLATFORM] `[MetaIGVideoBP]`; [EVID] ผู้สูงอายุแยกเสียงซ้อนยาก `[W3C_Older]` |

## ส่วน B — จุดตรวจตามช่วงเวลา (คลิปแนวตั้ง 15–60 s)

### B1. เฟรมแรก (0 s, ภาพนิ่งตอนยังไม่เล่น / thumbnail)
- [ ] มี **จุดเด่นเดียว** ที่ต่างจากพื้นหลังชัดที่สุด (แว่น / หน้า / คำถาม) — [EVID] salience, attentional capture (M04)
- [ ] ถ้าเป็นคลิปแว่น: แว่นเห็นชัด พื้นหลังสงบ (กฎบ้าน) — [EVID] inattentional blindness / limited attention (M01, M04)
- [ ] มีการเคลื่อนไหวหรือภาพที่น่าสนใจตั้งแต่เฟรมแรก — [PLATFORM] `[MetaIGVideoBP]`
- [ ] ตรงกับ caption/ปก (สิ่งที่สัญญา = สิ่งที่จะได้) — [PLATFORM] `[YouTubeRetention]` (intro ตรง title/thumbnail)

### B2. ช่วงเปิด (≈ 0–3 s)
- [ ] ผู้ชมรู้แล้วว่า "นี่เรื่องอะไร / ทำไมต้องสนใจ" — [PLATFORM] TikTok: content proposition ใน 3 s; Meta: แบรนด์+สารหลักใน 3 s `[TikTokCreative]` `[MetaIGVideoBP]`
- [ ] มีคำถาม/ความขัดแย้ง/ภาพที่ไม่คาดคิด 1 อย่าง (Q1) — ไม่ใช่ 3 อย่างพร้อมกัน (Q2)
- [ ] ข้อความบนจออ่านจบทันภายในเวลาที่ขึ้น (TikTok แนะนำ 5–10 คำ/วินาที — สำหรับภาษาไทยไม่มีตัวเลข ให้ทดสอบด้วยการอ่านออกเสียงในใจ 2 รอบ) — [PLATFORM] + [CRAFT]
- [ ] ไม่มีโลโก้/อินโทรยาวที่ไม่มีเนื้อหา — [CRAFT]

### B3. ช่วง hook ต่อเนื่อง (≈ 3–6 s)
- [ ] hook ยังไม่หมด: ถ้าคำถามถูกตอบแล้ว มีคำถามใหม่ตามมาไหม (Q1) — [PLATFORM] TikTok: hook ใน 6 s แรก `[TikTokCreative]`
- [ ] แบรนด์/แว่นปรากฏแล้ว **ระหว่าง** ที่ผู้ชมกำลังรอคำตอบ — [EVID] curiosity เพิ่มความจำสิ่งรอบข้าง `[Gruber2014]` (อนุมานจาก trivia + ใบหน้า)
- [ ] มีการเปลี่ยนมุม/ระยะอย่างน้อย 1 ครั้งที่มีเหตุผล (Q4, Q5)

### B4. ช่วงกลาง (เนื้อหา) — ตรวจทุก ~3–5 s หรือทุกครั้งที่เปลี่ยนประโยค VO
- [ ] Q1–Q6 ครบ
- [ ] **ไม่มีช่วงที่ "ไม่มีอะไรใหม่ + ไม่มีคำถามค้าง"** — นี่คือจุดเสี่ยง dip — [CRAFT] + opportunity-cost `[Fortenbaugh2017]`
- [ ] open loop ที่เปิดไว้ ยังจำได้ว่ารออะไร (ไม่เกิน 1–2 loop ค้างพร้อมกัน) — [EVID] working memory (M04); Zeigarnik ไม่ใช่หลักประกัน `[Ghibellini2025]`
- [ ] ข้อมูลสำคัญ (ราคา, ประโยชน์หลัก, ที่ตั้ง) ไม่ได้ถูกเก็บไว้แค่ตอนท้าย — คนออกก่อนจบเสมอ — [PLATFORM] `[MetaIGVideoBP]` "provide key info early"; `[YouTubeRetention]` audience size shrinks
- [ ] ความเร็วเสียง TTS ไม่ถูกเร่งเพื่อยัดเนื้อหา — [EVID] `[Tinnemore2022]`

### B5. จุดพีค
- [ ] มีจุดพีคทางอารมณ์/ข้อมูล 1 จุดที่ชัด — [EVID] peak-end (M01)
- [ ] ถ้า top moment อยู่ท้ายคลิป — พิจารณาย้ายขึ้นหรือให้ตัวอย่างไว้ตอนต้น — [PLATFORM] `[YouTubeRetention]`

### B6. ตอนจบ (≈ 2–3 s สุดท้าย)
- [ ] **ปิด loop ที่เปิดไว้ทั้งหมด** (ไม่ปิด = clickbait, M29) — [EVID] clickbait ไม่ได้คลิกมากกว่า และอาจลดความน่าเชื่อถือ `[Molina2021]` (M29)
- [ ] จบอบอุ่น/ชัด (peak-end) + CTA ที่บอกว่าให้ทำอะไร (ทักแชท, มาร้าน) — [EVID] peak-end (M01); [PLATFORM] CTA `[TikTokCreative]`
- [ ] TIMEOPTIC wordmark + โลโก้แบรนด์กรอบตามกฎบ้าน (ไม่ใช่ line-art ร้าน) — [CRAFT/house rule]
- [ ] ถ้าเป็นโปรโมชัน: ราคา/เงื่อนไขชัด ไม่มี countdown ปลอม (M29 ethics)

## ส่วน D — ปรับตามผู้ชม (ไม่ใช่ตาม generation)

- **ลูกค้า 45+ / สายตายาวตามวัย:** ซับใหญ่พอแต่ไม่ใหญ่เกิน, contrast สูง, ข้อความอยู่นานพอ, TTS ความเร็วปกติ, ดนตรีเบาใต้เสียงพูด `[Hou2022]` `[Tinnemore2022]` `[W3C_Older]`
- **นักท่องเที่ยวต่างชาติ:** ภาพเล่าได้เอง, ประโยคอังกฤษสั้นพื้นฐาน, ตัวเลขชัด (ราคา/เวลา/ที่ตั้ง), ไม่ใช้มุก/สำนวนท้องถิ่น `[ISO24495]`
- **ดูในที่สาธารณะ/ปิดเสียง:** Q6 ฝั่งปิดเสียงต้องผ่าน 100% `[MetaIGVideoBP]`
- **อย่าใช้:** "Gen Z → ตัดเร็วขึ้น" เป็นเหตุผล `[Pew2023]` `[Costanza2012]`

## ส่วน E — หลังโพสต์: อ่าน retention graph
1. หา **dip** แรกที่ลึก → ย้อนดูตารางส่วน C ช่วงนั้น: Q ข้อไหน ✗?
2. หา **spike** → ดูว่าเป็นช่วงดีจนดูซ้ำ หรือช่วงที่งง (ข้อความเร็วเกิน?) `[YouTubeRetention]`
3. เทียบกับคลิปความยาวใกล้กันของเพจเอง (YouTube ใช้ "typical retention" เทียบ 10 คลิปล่าสุดความยาวใกล้กัน) — **เทียบกับตัวเอง ไม่ใช่กับตัวเลข benchmark ลอย ๆ จากอินเทอร์เน็ต** `[YouTubeRetention]`
4. บันทึกบทเรียนลง `story-clips/_craft/LEARNING-LOG.md` (กฎ CLAUDE.md)
