## 2. Core concepts

รูปแบบ: **คืออะไร · กลไก · ใช้งาน · ข้อจำกัด · tier + keys · ความมั่นใจ**

### 2.1 Icon / Index / Symbol (Peirce)
- **คืออะไร**: sign มี 3 ส่วน: ตัว sign, object ที่มันหมายถึง, และ interpretant (ความเข้าใจที่เกิดในผู้ดู) ; แบ่งตามวิธีที่ sign โยงกับ object: **icon** = เหมือน (ภาพถ่ายแว่น, ไอคอนแว่น) · **index** = มีเหตุ/ร่องรอยจริง (ไอน้ำ = ร้อน, รอยเท้า, เลนส์มีรอยนิ้วมือ = ใช้งานจริง) · **symbol** = ตกลงกัน (ตัวอักษร, ธง, ไฟจราจร)
- **กลไก**: icon อาศัยการรับรู้ความเหมือน จึงข้ามวัฒนธรรมได้ดีที่สุด; symbol ต้องมี "รหัส" ร่วม จึงพลาดง่ายที่สุดเมื่อคนดูต่างวัฒนธรรม
- **ใช้งาน**: เวลาออกแบบภาพ ให้ถามทีละองค์ประกอบว่า "มันบอกความหมายด้วยวิธีไหน" — ถ้าเป็น symbol และคนดูเป็นนักท่องเที่ยว ให้มี caption ช่วย ; Mint & Tao หน้าว่าง → อารมณ์ต้องมาจาก index (ท่าทาง, ร่องรอย, สภาพแวดล้อม) ไม่ใช่สีหน้า
- **ข้อจำกัด**: Peirce เองยอมรับว่า icon/index บริสุทธิ์หายาก sign ส่วนใหญ่ผสมกัน ; ภาพ "เหมือนจริง" ก็มีส่วนที่เป็นธรรมเนียม (มุมกล้อง, การครอป)
- **Tier/keys**: B — SEP_PeirceSemiotics · **ความมั่นใจ**: high (เป็นกรอบคิด ไม่ใช่การทดลอง)

### 2.2 Signifier / Signified และความ arbitrary (Saussure)
- **คืออะไร**: sign = รูป (signifier) + แนวคิด (signified) ; ความสัมพันธ์ถูกกำหนดโดยชุมชนผู้ใช้ ไม่ใช่ธรรมชาติ
- **ใช้งาน**: รูปเดียวกันมีความหมายต่างกันได้ — เลข 9 (ไทย: ก้าวหน้า) vs เลข 4 (จีน/เกาหลี/ญี่ปุ่น: ความตาย) ; ช้างเผือก (ไทย: บารมี) vs "white elephant" (อังกฤษ: ของแพงไร้ประโยชน์)
- **ข้อจำกัด**: เป็นทฤษฎีภาษา การขยายไปภาพเป็นการตีความ (ผ่าน Barthes) ; มีข้อโต้แย้งว่าความ arbitrary ไม่สมมาตร
- **Tier/keys**: A (primary text excerpt, full_text) — Saussure1916 · **ความมั่นใจ**: medium

### 2.3 Denotation / Connotation / Myth และ Anchorage / Relay (Barthes)
- **คืออะไร**: ภาพมี 3 ชั้นสาร: ข้อความภาษา, ภาพตามตัวอักษร (denotation — "มีถุงผักเปิดอยู่"), ภาพเชิงนัย (connotation — "สด ทำเองที่บ้าน ความเป็นอิตาลี") ; "myth" = connotation ที่ถูกทำให้ดูเป็นธรรมชาติ ; ตัวหนังสือกับภาพสัมพันธ์กันแบบ **anchorage** (ข้อความล็อกความหมายเดียว) หรือ **relay** (ข้อความกับภาพเติมกันเล่าเรื่อง เช่น การ์ตูน)
- **กลไก**: connotation ต้องอาศัยความรู้ทางวัฒนธรรม — Barthes ชี้เองว่าคนอิตาลีอาจไม่เห็น "ความเป็นอิตาลี" ในโฆษณาที่ทำให้คนฝรั่งเศสดู
- **ใช้งาน**: แคปชันโพสต์ = anchorage → เขียนเพื่อปิดความหมายที่ไม่ต้องการ ; bubble ของ Mint & Tao = relay ; ภาพ "ไทย" ที่ทำให้ต่างชาติดู (ตุ๊กตุ๊ก, ช้าง) มัก connote ภาพจำนักท่องเที่ยวมากกว่าความเป็นไทยที่คนไทยรู้สึก
- **ข้อจำกัด**: วิเคราะห์เชิงตีความ ไม่ใช่การวัด ; อ่านผ่านสรุปของรายวิชา
- **Tier/keys**: A (primary, full_text) — Barthes1977 · **ความมั่นใจ**: medium

### 2.4 Iconography 3 ระดับ (Panofsky)
- **คืออะไร**: (1) pre-iconographic — เห็นอะไรตามตัว (2) iconography — ธรรมเนียมบอกว่าเป็นเรื่อง/บุคคลอะไร (3) iconology — ทำไมสังคมนั้นให้ความหมายนั้น
- **ใช้งาน**: ใช้เป็นขั้นตอนตรวจสัญลักษณ์: "เห็นอะไร → มันอ้างถึงธรรมเนียมไหน → ธรรมเนียมนั้นมีความหมาย/ข้อห้ามอะไรกับคนดูกลุ่มนี้" (เช่น ดอกบัว → พุทธ → บริสุทธิ์ แต่ใช้ในงานศพด้วย)
- **ข้อจำกัด**: Panofsky บอกว่า 3 ระดับรวมเป็น "วงจรการตีความ" เดียวในทางปฏิบัติ และโมเดลเปลี่ยนไปมากระหว่างฉบับ 1930/1932/ภาษาอังกฤษ ; ตัวอย่างของเขา: โต๊ะอาหาร 13 คน = พระกระยาหารมื้อสุดท้าย (ระดับ 2) ; อ่านผ่านตำรา Lorenz 2016 (อ่านเต็มบทที่ 1) ไม่ใช่ต้นฉบับ
- **Tier/keys**: A — Panofsky1939, Lorenz2016_PanofskyModel · **ความมั่นใจ**: medium

### 2.5 Visual rhetoric ในโฆษณา (Scott; McQuarrie & Mick)
- **คืออะไร**: ภาพโฆษณาไม่ใช่กระจกสะท้อนความจริง แต่เป็นระบบสัญลักษณ์ที่ "ให้เหตุผล" ได้ (Scott1994) ; rhetorical figure = "การเบี่ยงเบนอย่างมีศิลปะ" (artful deviation) แบ่งเป็น **scheme** (ซ้ำ/สัมผัส — ระเบียบเกิน) กับ **trope** (อุปมา/เล่นคำ — ผิดคาด) และ 4 ปฏิบัติการ: repetition, reversal, substitution, destabilization (McQuarrieMick1996)
- **หลักฐาน**: McQuarrieMick1999 — visual rhyme, antithesis, metaphor, pun ทำให้คิดต่อมากขึ้น (elaboration) และชอบโฆษณามากขึ้น **โดยไม่ลดความเข้าใจ** ; แต่ผลของ trope (metaphor, pun) **ลดลงหรือหายไป** ในคนที่ขาด cultural competency
- **ใช้งาน**: คนดูไทยทั่วไป → trope ได้ถ้าใช้ของที่คนไทยคุ้น ; นักท่องเที่ยวหลายชาติ → ใช้ scheme (ภาพสัมผัสรูปทรง, การซ้ำ) หรือ metaphor ที่ใช้ร่วมกันกว้าง ๆ
- **ข้อจำกัด**: อ่าน abstract เท่านั้น ; โฆษณาและกลุ่มตัวอย่างอเมริกัน
- **Tier/keys**: A — Scott1994, McQuarrieMick1996, McQuarrieMick1999 · **ความมั่นใจ**: medium

### 2.6 ประเภท visual metaphor (Phillips & McQuarrie 2004) และหลักฐานเรื่องความซับซ้อน
- **คืออะไร**: โครงสร้างภาพ 3 แบบ เรียงจากง่ายไปยาก: **juxtaposition** (วางคู่กัน) → **fusion** (หลอมเป็นวัตถุเดียว/hybrid) → **replacement** (แทนที่ของที่ควรอยู่ตรงนั้น) ; คูณกับปฏิบัติการความหมาย: **connection** (A เกี่ยวกับ B) vs **comparison** (A เหมือน B)
- **หลักฐาน (ขัดกันบางส่วน — ดู §3)**:
  - van Mulken et al. 2010 (3 ประเทศยุโรป): hybrid ได้รับความชอบสูงสุด ; ความผิดคาด (deviation) และความเข้าใจ (comprehension) เพิ่มความชอบ ; ความซับซ้อนที่รับรู้ **ลด** ความชอบ ; งานต่อ (2014) เสนอ "tipping point" — ท้าทายปานกลางดีที่สุด
  - Lagerwerf et al. 2023 (3 การทดลอง): คู่ที่เป็นของประเภทเดียวกัน (ง่ายสุด) ถูกระบุเร็วสุดและชอบที่สุด ตามด้วย metaphor ; คู่ที่ไม่เกี่ยวกันแย่สุด ; ไม่พบ inverted-U ; fluency theory อธิบายได้ดีกว่า "ความสนุกจากการไขปริศนา"
  - แหล่งรอง: juxtaposition กระตุ้นการคิดมากกว่า fusion และ fusion เข้าใจยากที่สุด (snippet, ยังไม่ยืนยัน)
- **ใช้งาน**: ฟีดที่เลื่อนเร็ว (Reels/TikTok) → ใช้ juxtaposition ที่อ่านออกใน < 1 วินาที ; โพสต์ carousel ที่คนหยุดอ่าน → fusion ได้ ; replacement ใช้เมื่อมี caption ล็อกความหมาย
- **Tier/keys**: A — PhillipsMcQuarrie2004 (bibliographic), vanMulken2010 (search_summary), Lagerwerf2023 (full_text) · **ความมั่นใจ**: medium (ทิศทาง: "เข้าใจได้ก่อน แล้วค่อยแปลก")

### 2.7 Archetype vs ความหมายเฉพาะวัฒนธรรม
- **คืออะไร**: Jung เสนอว่ามีภาพต้นแบบสากล (archetype) ใน collective unconscious
- **หลักฐาน**: งานทดลองน้อยมาก ("extremely sparse") ; มีการทำซ้ำในเยอรมันที่สนับสนุนผลความจำต่อ archetypal symbol แต่นักวิจารณ์ชี้ว่ากลุ่มตัวอย่างเป็นตะวันตก ; ข้อเสนอที่หนักแน่นกว่าคือ "ธีมที่มาจากประสบการณ์/แรงจูงใจร่วมของมนุษย์" (แม่-ลูก, สถานะ, สว่าง-มืด, สูง-ต่ำ) ไม่ใช่ภาพที่ถ่ายทอดทางพันธุกรรม
- **ใช้งาน**: ใช้ธีมประสบการณ์ร่วมเป็นฐาน แต่ **รายละเอียด** (สี สัตว์ ตัวเลข ท่ามือ) ต้องเช็กตามวัฒนธรรมเสมอ ; ในไทย "สูง-ต่ำ" ไม่ใช่แค่ metaphor แต่เป็นกฎมารยาท (หัวสูง เท้าต่ำ พระพุทธรูปอยู่สูงสุด)
- **Tier/keys**: A (search_summary) — ArchetypeReplication2013 · **ความมั่นใจ**: low สำหรับ archetype แบบ Jung ; medium สำหรับธีมประสบการณ์ร่วม

### 2.8 ท่ามือ (emblems) ต่างวัฒนธรรม
- **หลักฐาน**: Matsumoto & Hwang — emblem จำนวนมากใช้ร่วมกัน แต่บางรูปเดียวกันมีความหมายต่างกัน (วงแหวน = OK / เงิน / อื่น ๆ) และบางท่ามีเฉพาะวัฒนธรรม ("ขอโทษ" เฉพาะเอเชียใต้, "หิว" เฉพาะเอเชียตะวันออก — ตามสรุปของแล็บ) ; ตำรา OER (อ่านเต็ม): thumbs-up = ดีมาก (อเมริกาเหนือ) แต่เป็นคำหยาบในกรีซและบางประเทศ ; A-OK = ท่าหยาบใน "หลายวัฒนธรรมยุโรป" ; ชูสองนิ้วหันหลังมือออก = ดูถูกในอังกฤษ/ออสเตรเลีย (ข้อ "OK หยาบในบราซิล" ที่เคยเขียน **ไม่อยู่ในแหล่งนี้** — ถือเป็น common claim ที่ยังไม่ยืนยัน) ; ไทย: ห้ามชี้นิ้วใส่คน, กวักมือคว่ำฝ่ามือ, ห้ามแตะหัว, ห้ามชี้เท้า
- **ใช้งาน**: อย่าให้ท่ามือเป็น "ตัวสาร" หลักในงานที่นักท่องเที่ยวหลายชาติดู ; มาสคอต/ตัวละครใช้มือเปิด (open palm) หรือไหว้ในบริบทขอบคุณ
- **Tier/keys**: A/B/C — MatsumotoHwang2013, Maricopa_Nonverbal, culture:Scroope2025, culture:ThailandFoundation2024 · **ความมั่นใจ**: medium

### 2.9 ตัวเลข
- 4 = ความตาย (จีน เกาหลี ญี่ปุ่น — ตึกข้ามชั้น 4, ราคาจีนเลี่ยง 4) ; 8 = รุ่งเรือง (จีน — ราคาลงท้าย 8 พบบ่อยมาก) ; 9 = ก้าวหน้า (ไทย — พ้องเสียง "ก้าว") ; 13 = โชคร้าย (ตะวันตก — unsourced)
- งานที่อ้างว่าเลข 4 "ทำให้ตาย" จริง (Phillips 2001) **ถูกโต้แย้ง** และทำซ้ำไม่ได้ — ใช้ได้แค่ "คนเลี่ยงเลข 4 จริง" ไม่ใช่ผลต่อสุขภาพ
- **Tier/keys**: A — Yang2012, Phillips2001_BMJ, Naresuan2023_Nine ; E — KoreaNet2020 · **ความมั่นใจ**: high (เรื่องการปฏิบัติ) / low (เรื่องผลต่อพฤติกรรมที่วัดได้ นอกจากราคา)

### 2.10 สัญลักษณ์ไทยที่มีข้อจำกัดทางกฎหมายหรือความเคารพ

## 4. Applied patterns for our production
1. **Symbol audit 3 ขั้น (Panofsky + Peirce)** ก่อนส่งทุกภาพ: (ก) ลิสต์ทุกองค์ประกอบที่มีความหมาย (ข) ระบุว่าเป็น icon/index/symbol (ค) ถ้าเป็น symbol → เปิด `SYMBOL_LIBRARY.json` ดู meanings ตามกลุ่มผู้ชม + `restriction`
2. **Mint & Tao (หน้าว่าง)**: อารมณ์มาจาก index — ไหล่ตก, ถ้วยกาแฟที่เย็นแล้ว (ไม่มีไอน้ำ = รอนาน), รองเท้าวางเรียงหน้าบ้าน (มาเยี่ยมผู้ใหญ่) ; ใช้ความสูงในเฟรมแสดงความเคารพ (คนที่อายุมากกว่าอยู่สูงกว่า) ; Tao ไหว้ขอโทษแทนการพูดยาว
3. **คลิปสินค้าแว่น (product clips)**: juxtaposition ของรูปทรง (กรอบกลม + ดวงจันทร์ / กรอบเหลี่ยม + หน้าต่างตึก) = scheme ที่ข้ามวัฒนธรรมได้ ; blur → sharp = icon ของ "เห็นชัด" แต่ห้ามโยงไปเคลมรักษาโรค (ดู `../marketing/ETHICS_AND_THAI_AD_RULES.md`)
4. **แคปชันเป็น anchorage**: ภาพที่มีหลายความหมาย ให้แคปชันบรรทัดแรกล็อกความหมาย ; ภาพสำหรับนักท่องเที่ยวต้องอ่านได้แม้ไม่มีภาษา หรือมีภาษาอังกฤษสั้น ๆ
5. **โปรโมชันตามตัวเลข**: คนไทย → 9.9, 99 บาท ; ลูกค้าจีน → 8/88, เลี่ยง 4 ; ลูกค้าเกาหลี → เลี่ยงชื่อสีแดงในภาพขอบคุณ
6. **โปรตรุษจีน**: มังกรท่าทางเป็นมิตร/เต้นรำ ; ห้ามนาฬิกา ร่ม ดอกเบญจมาศขาวเป็น "ของขวัญ"
7. **ฉากวัด/ศาสนาในเรื่องเล่า**: ถ่ายพระพุทธรูปจากระดับเท่าหรือต่ำกว่า ไม่ให้อะไรอยู่สูงกว่า ไม่วางสินค้าในเฟรมเดียวกัน ; ภาพ AI ไม่สร้างพระพุทธรูป/พระสงฆ์/บุคคลในราชวงศ์

## 5. How to test whether a symbol reads (comprehension test)
อิงวิธีของ ISO 9186-1 (วัดสัดส่วนคนที่เข้าใจถูกโดยไม่มีข้อความประกอบ) แบบย่อสำหรับสตูดิโอ:
1. เตรียมภาพ **ไม่มีแคปชัน** 1–3 เวอร์ชัน
2. ถามคำถามปลายเปิด: "ภาพนี้บอกอะไร / ถ้าเห็นในร้าน คิดว่าหมายถึงอะไร" (ห้ามชี้นำ ห้ามให้ตัวเลือก)
3. คนดูอย่างน้อย 8–10 คนต่อกลุ่มเป้าหมาย (เช่น คนไทยทั่วไป / ลูกค้าต่างชาติ) — เป็นการทดสอบหยาบ ไม่ใช่สถิติ
4. ให้คะแนน ถูก / ถูกบางส่วน / ผิด / ไม่รู้ ; บันทึก "ความหมายผิด" ทุกตัว (สำคัญกว่าคะแนน)
5. เกณฑ์ทำงาน: ≥ ~2 ใน 3 ถูก (อิงเกณฑ์ 67% ของ ISO 3864 ที่แหล่งรองอ้าง) ถึงจะปล่อยให้ภาพ "พูดเอง" ; ต่ำกว่านั้น → เพิ่ม caption (anchorage) หรือเปลี่ยนเป็น icon
6. ถามเพิ่ม 1 ข้อ: "มีอะไรในภาพที่รู้สึกไม่เหมาะ/ไม่สบายใจไหม" — จับความเสี่ยงด้านความเคารพ
7. อัปเดต `test_status` ใน library เป็น `"tested:YYYY-MM-DD:n=?:pass|fail"` พร้อมความหมายผิดที่พบ

## 6. Anti-patterns
- เชื่อว่า "ภาพเป็นภาษาสากล" — trope/symbol ต้องมีรหัสร่วม (McQuarrieMick1999)
- ใช้ archetype แบบ Jung เป็นเหตุผลว่า "ไม่ต้องทดสอบ"
- ใช้พระพุทธรูป/ดอกบัว/วัด เป็น "zen decor" ขายของ ; ใช้ตราครุฑ/ภาพราชวงศ์/สีที่ผูกกับสถาบันเป็นจุดขาย
- ภาพ "ไทย" แบบนักท่องเที่ยว (ตุ๊กตุ๊ก ขี่ช้าง) เป็นตัวแทนความเป็นไทย
- อ่านสีหน้า/รอยยิ้มแล้วติดป้ายอารมณ์ (ดู `../emotions/README.md` §2.10)
- อ้าง "เลข 4 ทำให้คนตาย" หรือ "สีนี้ทำให้ซื้อ" เป็นข้อเท็จจริง
- Metaphor ซับซ้อนในโฆษณาที่คนเลื่อนผ่านเร็ว
