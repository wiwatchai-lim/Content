## 1. หลักใหญ่ 7 ข้อ

1. **ร่างกายพอสำหรับอารมณ์หลัก — แม้ไม่มีหน้า** [R] คนอ่านอารมณ์จากร่างกายได้แม่นพอ ๆ กับหน้า (deGelder2009); นักแสดงปิดหน้าก็ยังอ่านออก (Atkinson2004); แค่จุดไฟ 13 จุดบนตัวนักเต้นยังอ่านถูก 63% (Dittrich1996). ตอนอารมณ์พีค ร่างกายบอกบวก/ลบได้ ส่วนหน้าบอกไม่ได้ (Aviezer2012). → Mint & Tao ที่ไม่มีหน้าคือการออกแบบที่ถูก ไม่ใช่ข้อจำกัด
2. **คันโยก 3 ตัวก่อนอย่างอื่น: ศีรษะ (ขึ้น/ลง/เอียง) · ความเปิดของลำตัว · ทิศการเอน** [R] (Kleinsmith2013). เพิ่มตัวที่ 4 = **tempo**: เร็ว/กระตุก = arousal สูง (โกรธ ดีใจ), ช้า/ลื่น = arousal ต่ำ (เศร้า) (Pollick2001)
3. **Arousal อ่านง่าย, valence อ่านยาก** [R] ร่างกายแยก "พลังสูง vs ต่ำ" ได้ดีกว่า "ดี vs ร้าย" (Dael2012, Kleinsmith2013). คู่ที่สับสนบ่อย: ดีใจ↔ตกใจกลัว, เศร้า↔โล่งใจ↔สิ้นหวัง, สนใจ↔หงุดหงิด, ชนะ↔หัวเสีย, ยอมแพ้↔จดจ่อ → แก้ด้วย **ทิศทาง** (ขึ้น/ออก vs ถอย/หด), **มือ** (กำ vs กุมหัว), **บริบท/prop** (มีอะไรในเฟรม), **ลำดับเวลา** (ท่าก่อนหน้า)
4. **ภาพนิ่งอ่อนกว่าภาพเคลื่อนไหว** [R] (Atkinson2004, deGelder2009 ~10%). ภาพนิ่งที่อ่านง่ายที่สุด: โกรธ, เศร้า (Coulson2004 บางท่า >90%); ยากสุด: รังเกียจ (บางท่า 0%), ตกใจ (ต้องการ "ก่อน/หลัง"). → carousel ต้องให้บริบทช่วย (ข้อความ, prop, ช่องถัดไป)
5. **มุมกล้องเปลี่ยนการอ่าน** [R] (Coulson2004: viewpoint dependence). การเอนหน้า/หลังเห็นจากด้านข้าง/3/4 เท่านั้น; มือประกบ (ไหว้) เห็นจากด้านหน้า/3/4. เลือกมุมตามคิวหลักของท่า
6. **ขยาย (exaggerate) แต่สมดุล** [R]+[C] การเคลื่อนไหวที่ขยายเพิ่มความแม่น (Atkinson2004) — ยกเว้นความเศร้าที่ไม่ดีขึ้น (ตาม secondary summary). Lasseter1987 [C]: ขยายทุกองค์ประกอบให้สมดุล ไม่ใช่องค์ประกอบเดียว
7. **ความคิดมาก่อนการกระทำ** [C] "การกระทำทุกอย่างเป็นผลของกระบวนการคิด" (Lasseter1987); objective → obstacle → action, acting is reacting, status transactions (Hooks2023, จากสารบัญ)

## 2. Workflow กำกับหนึ่งช็อต (ใช้ได้ทั้ง 3 สื่อ)

1. **ตัวละครต้องการอะไร (objective) และอะไรขวาง (obstacle)?** เขียนเป็นประโยคเดียว [C]
2. **ระดับ arousal เท่าไร?** (1–5) → กำหนด tempo และขนาดท่า [R]
3. **เลือกท่าจาก `POSE_LIBRARY.json`** ตาม id; อ่าน `confusable_with` แล้วใส่ `disambiguate_with` ลงในช็อต
4. **เลือกมุมกล้อง** ให้คิวหลักเห็นใน silhouette (ข้อ 1.5) [R]+[C]
5. **ระยะห่างระหว่างตัวละคร** = ความสัมพันธ์ (ข้อ 4) [R]
6. **ทิศศีรษะ/ลำตัว** ชี้ไปที่ที่อยากให้คนดูมอง (ข้อ 5) [R]
7. **เช็กธรรมเนียมไทย** (ข้อ 6) [T]
8. **Silhouette test**: ถมดำทั้งตัว ยังอ่านออกไหม? (Lasseter1987) [C]
9. **ทดสอบกับคนดู**: ทุกท่าใน library เป็น `untested` — ถาม 3–5 คน "ตัวละครรู้สึกอะไร" โดยไม่บอกบท แล้วอัปเดต `test_status`

## 3. คำศัพท์การเคลื่อนไหว (Laban effort) — ใช้เป็นภาษากลาง ไม่ใช่เครื่องวัด

Melzer2019 [R] พบว่าชุดองค์ประกอบ Laban ทำให้คนดูอ่านเป็นอารมณ์นั้นได้เหนือโอกาส แม้ผู้เคลื่อนไหวไม่ได้ตั้งใจแสดงอารมณ์:

| อารมณ์ | องค์ประกอบ (คำสั่งกำกับ) |
|---|---|
| ดีใจ | jumping, rhythmic, spreading, free flow, lightness, up, rising → "ขยาย ลอยขึ้น เด้ง" |
| เศร้า | passive weight, arms touching upper body, sinking, head dropping → "ปล่อยน้ำหนัก จมลง ก้มหัว" |
| กลัว | retreating, condensing, bound flow, backwards, enclosing → "ถอย หด เกร็ง ห่อตัว" |
| โกรธ | strong weight, sudden time, advancing, direct → "หนัก ฉับพลัน พุ่งเข้า ตรงเป้า" (อ่านถูกแค่ 47%) |

**สถานะหลักฐาน**: ความน่าเชื่อถือระหว่างผู้ให้รหัส Laban อยู่ระดับ "อ่อน ถึง พอรับได้" (Bernardet2019) และ Melzer2019 ใช้ผู้หญิงผิวขาวเท่านั้น → ใช้ Laban เป็นภาษาสั่งงาน/prompt ไม่ใช่หลักฐานว่า "ท่านี้ = อารมณ์นี้แน่นอน"

## 4. ระยะห่าง (proxemics) = ปุ่มปรับความสัมพันธ์

- Sorokowska2017 [R] (42 ประเทศ, 8,943 คน): ระยะที่ชอบ — คนแปลกหน้า ~135 ซม., คนรู้จัก ~92 ซม., คนสนิท ~32 ซม.; ลำดับนี้เหมือนกันทุกประเทศ แต่ค่าจริงต่างกันมาก; ผู้หญิงและคนอายุมากชอบห่างกว่า. **ไทยไม่อยู่ในกลุ่มตัวอย่าง**
- การแบ่ง "วัฒนธรรมสัมผัส/ไม่สัมผัส" ของ Hall1966 (เอเชีย = ไม่สัมผัส) ได้รับการสนับสนุนเพียงบางส่วน → อย่าใช้เป็นกฎ
- ในเฟรม (character สูง ~450 px): ห่าง ~1 ความกว้างลำตัว = สนิท; 2–3 = รู้จัก; มากกว่านั้น = แปลกหน้า/บาดหมาง [C แปลงจาก R]
- **เล่าเรื่องด้วยการเปลี่ยนระยะ**: ทะเลาะ → ห่างขึ้น; คืนดี → ระยะหดลงช้า ๆ ระหว่างช็อต (`standoff_conflict` → `reconcile`)

## 5. ทิศศีรษะ = สายตาของตัวละครไร้หน้า

- Langton2000 [R]: คนดูหันความสนใจตามสายตา/ศีรษะ/ลำตัว/การชี้ของคนอื่นแบบอัตโนมัติ แม้ไม่มีประโยชน์และแม้ถูกสั่งให้เมิน; ทิศศีรษะเปลี่ยนการรับรู้ทิศสายตา
- → Mint & Tao ไม่มีตา: **ใช้มุมศีรษะที่กว้างกว่าคนจริง** + หมุนลำตัวตาม + ชี้มือ เพื่อพาสายตาคนดูไปที่ของ/ข้อความ/สินค้า [C แปลงจาก R]
- หันเข้าหา = มีส่วนร่วม; หันหนี = เมิน/ยอม/อาย — ความหมายขึ้นกับ status (Emery2000) [R]
- **ศีรษะเงย/ก้ม กับ อำนาจ: ข้อมูลขัดกัน** (Mignault2003 ถูกอ้างสองทิศ; งานปี 2020 ว่าทั้งเงย 30° และก้ม 20° ดูมีอำนาจกว่าระดับตรง) → ทดสอบก่อน อย่าใช้สูตร

## 6. ธรรมเนียมไทยที่ต้องเช็กทุกฉาก [T]

แหล่ง: AnumanRajadhon_wai (คำบรรยายต้นฉบับ, กลางศตวรรษที่ 20) และ ThailandFoundation2024

- **ไหว้**: ผู้น้อย (อายุ/ตำแหน่ง) ไหว้ก่อน ผู้ใหญ่รับ; มือยิ่งสูงยิ่งเคารพ (ระหว่างอกถึงหน้า); ข้อศอกแนบตัว ยกและลดมือ **ช้า นุ่ม ไม่กระชาก**; มือรูป "ดอกบัวตูม". ผู้ใหญ่รับไหว้ที่ระดับอกหรือแค่พยักหน้า; **พระไม่ไหว้ตอบฆราวาส**
- **กราบ** (เบญจางคประดิษฐ์ 3 ครั้ง) สำหรับพระรัตนตรัย; หมอบกราบครั้งเดียวสำหรับพ่อแม่/ครู → ห้ามใช้เป็นมุกตลก
- **เท้า**: ต่ำสุด — ห้ามชี้เท้า/ฝ่าเท้าไปที่คนหรือพระพุทธรูป; นั่งพับเพียบเก็บเท้า; ห้ามวางเท้าบนโต๊ะ, ห้ามข้ามหมอน/หนังสือ
- **ศีรษะ**: สูงสุด — ห้ามแตะหัวใคร แม้เด็ก; ห้ามส่งของข้ามหัว
- **ระดับตัว**: อย่าให้ตัวสูงกว่าศีรษะผู้ใหญ่ที่นั่งอยู่; เดินผ่านผู้ใหญ่ให้ก้มตัว; ผ่านพระ/ผู้ใหญ่ที่นั่งให้ย่อหรือเข่า
- **มือประกบที่อก** คนไทยอ่านเป็น "ไหว้/สวด" — ถ้าอยากได้ "หวัง/ลุ้น" ให้ใช้นิ้วประสานกัน (`hope_anticipation`)
- ข้อสังเกตที่ **ยังไม่ยืนยัน** (ระบุใน library ว่า unverified): ชี้นิ้วใส่ผู้ใหญ่ไม่สุภาพ, รับของสองมือ, การกอดในที่สาธารณะระหว่างผู้ใหญ่ต่างเพศ, การปฏิเสธแบบอ้อม
- คนรุ่นใหม่/ในเมืองเคร่งน้อยกว่า และพระยาอนุมานราชธนเองย้ำว่าต่างกันตามชนชั้น/ท้องถิ่น

## 7. กำกับตามสื่อ

### 7.1 2D puppet (`rig.js`)
- ท่าที่มีอยู่: `R.emote` (neutral, happy, joy, sad, shock, fear, angry, think, shy, tender) และ `R.pose` (idle, open, shrug, chest, chin, point, wave, cover, hug, hips, reach, fistsUp, behind). ทุก entry ใน library มี `rig_hint`
- **ช่องว่างของ rig** (เสนอเพิ่ม): `wai` (สำคัญที่สุดสำหรับฉากไทย), `clasp` (นิ้วประสาน), `wring` (บิดมือ), ท่านั่ง/คุกเข่า/พับเพียบ, ท่าหันหลัง. `hips` ถูกใช้ใน `angry` — Tracy & Matsumoto พบว่ามือเท้าเอว *ไม่* เป็นคิวที่สม่ำเสมอของ pride; สำหรับโกรธยังเป็น craft
- **Gesture timing**: preparation → **stroke ตรงพยางค์ที่เน้น** → hold → retraction (ShattuckHufnagelRen2018 [R], ภาษาอังกฤษ; ภาษาไทยซึ่งมีวรรณยุกต์ยังไม่มีข้อมูล). GUIDE.md มีกลไกอยู่แล้ว
- เลือก gesture ที่ **เพิ่มข้อมูล** (ขนาด รูปร่าง การกระทำ) ดีกว่าท่าที่ซ้ำคำพูด (Hostetter2011 [S])
- ใบหน้า puppet: การขยับหน้าเบา ๆ <20% แทบมองไม่เห็นบนตัวละครเสมือน (McDonnell2021 [R], ทดสอบกับคนเสมือนแบบสมจริง) → บนจอมือถือให้ขยับหน้าแรงขึ้นหรือย้ายไปที่ร่างกาย

### 7.2 Mint & Tao (ภาพนิ่ง ดินสอ ไม่มีหน้า)
- ทุกภาพ: **หนึ่งอารมณ์หลักต่อตัวละคร** ที่อ่านได้จาก silhouette + ทิศศีรษะ + ระยะห่าง
- Mint (กังวล/เหนื่อย): `anxiety_worry`, `tired_exhausted`, `loneliness`, `sadness_low` — ระวังทั้งหมดนี้หน้าตาคล้ายกันในภาพนิ่ง → ใช้ prop/ฉากแยก (โทรศัพท์ = กังวล, โต๊ะทำงานดึก = เหนื่อย, หน้าต่าง = เหงา)
- Tao (อบอุ่น ลึกซึ้ง): `listening_engaged`, `comfort_consoling`, `tender_affection`, `calm_serene` — ลำตัวหันหา Mint เสมอ, สูงกว่าเล็กน้อยแต่ **ก้มลงหา** เมื่อปลอบ
- ข้อความ Thai อยู่ด้านบน 1/3 → ท่าที่ต้องใช้ "แขนชูสูง" (joy/pride) จะชนพื้นที่ข้อความ: ย่อขนาดตัวหรือใช้มุมกว้าง

### 7.3 AI image / video prompt
- เขียน **ร่างกายเป็นคำกริยาและส่วนของร่างกาย** ไม่ใช่ชื่ออารมณ์อย่างเดียว: ใช้ `ai_prompt_phrase` ใน library (เช่น "shoulders slumped, chest caved in, turning away" แทน "ashamed")
- ใส่ **tempo/quality** สำหรับ video ("slow, heavy steps", "sudden recoil then freeze") — Pollick2001/Melzer2019 [R]
- ระบุ **มุมกล้อง** ที่ทำให้คิวอ่านออก ("side view" สำหรับการเอน, "front view" สำหรับไหว้)
- ฉากไทย: ระบุ "feet tucked away", "palms pressed together at chest level, slight bow" ตรง ๆ; โมเดล AI มักทำไหว้ผิด (มือสูง/ศอกกาง/ไหว้มือเดียว) → ตรวจทุกเฟรม [C]
- ห้ามอ้างอารมณ์จากหน้าตาที่ AI สร้าง — ตัดสินจากท่า + บริบท (emotions README §2.10)

### 7.4 คนจริงในคลิป (พนักงาน, ลูกค้า)
- อย่าสั่ง "ทำหน้าดีใจ" — สั่ง **การกระทำ + objective**: "หยิบแว่นขึ้นมาแล้วหันไปให้เพื่อนดู เหมือนเจอของที่ตามหา" [C, Hooks2023]
- ให้ **มือมีงานทำ** (ถือแว่น เช็ดเลนส์ ชี้) → ลดความเกร็ง และ gesture ที่บอกการกระทำช่วยคนดูเข้าใจ (Hostetter2011) [R]
- เช็กทิศลำตัว/ศีรษะหาสินค้าในช็อตโปรโมท (Langton2000) [R]
- เช็กธรรมเนียมไทยกับลูกค้า: ไหว้ลูกค้า, ไม่ยืนค้ำผู้สูงอายุที่นั่งลองแว่น — ย่อตัวลงระดับเดียวกัน [T]

## 8. Checklist ก่อนส่ง

- [ ] ทุกตัวละครในช็อตมี objective และระดับ arousal
- [ ] ท่าหลักผ่าน silhouette test ในมุมกล้องที่ใช้จริง
- [ ] คู่ท่าที่สับสนได้ (`confusable_with`) มีตัวแยก (ทิศ มือ prop ลำดับเวลา)
- [ ] ระยะห่างตรงกับความสัมพันธ์ในบท
- [ ] ทิศศีรษะ/ลำตัวพาคนดูไปที่จุดสำคัญ
- [ ] ไหว้ถูก (ใครก่อน ระดับมือ ความช้า ศอกแนบ) · เท้าไม่ชี้ใส่คน/พระ · ไม่มีใครแตะหัวใคร
- [ ] ท่าใหม่หรือท่าที่ไม่แน่ใจ → ถามคนดู 3–5 คนแล้วบันทึกผลใน `POSE_LIBRARY.json` (`test_status`)
