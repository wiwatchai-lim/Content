# CULTURAL CHECK — checklist ก่อนโพสต์ (ใช้กับงานทุกสาขา ทุกลูกค้า)

ใช้กับทุกโพสต์ คลิป carousel และภาพ AI ที่ส่งถึงคนไทยหรือคนต่างชาติ ใช้เวลา 3–5 นาที
**วิธีใช้**: ตอบทีละข้อ ถ้าข้อที่มี [STOP] ตอบว่า "ไม่ผ่าน" → ห้ามโพสต์จนกว่าจะแก้ ; [WARN] = แก้หรือบันทึกเหตุผล ; ถ้าไม่แน่ใจ → **ตัดออก** หรือถามคนในวัฒนธรรมนั้น
คีย์ในวงเล็บอ้างถึง `sources.json` ของโมดูลนี้ ; `S:` = `../semiotics/sources.json` ; สัญลักษณ์รายตัวดู `../semiotics/SYMBOL_LIBRARY.json`
กฎโฆษณา/เคลมสุขภาพ/PDPA/Meta อยู่ใน `../marketing/ETHICS_AND_THAI_AD_RULES.md` §7 — ใช้คู่กัน
**ไม่ใช่คำปรึกษากฎหมาย**

## A. ผู้ชม (ทำก่อนเริ่มงาน)
- [ ] A1 ระบุผู้ชมหลัก: คนไทยที่ตามเพจ / คนไทยทั่วไป / นักท่องเที่ยว (ระบุชาติหลัก 1–2 ชาติ) / ลูกค้าในประเทศอื่น
- [ ] A2 ถ้าเป็นนักท่องเที่ยว: จำไว้ว่าตลาดใหญ่สุดปี 2025 คือ มาเลเซีย จีน อินเดีย รัสเซีย เกาหลีใต้ — ไม่ใช่แค่ "ฝรั่ง" (MOTS2025_Nation)
- [ ] A3 ผู้ชมมีบริบทร่วมกับเราแค่ไหน? น้อย → เล่าให้ชัด ภาพต้องอ่านได้เอง (อย่าใช้ป้ายประเทศ "high-context" แทนการคิด — Cardon2008)
- [ ] A4 [WARN] ใช้ Hofstede/GLOBE เป็นแค่สมมติฐาน ไม่ใช่เหตุผลตัดสินใจ (TarasKirkmanSteel2010, McSweeney2002)

## B. สถาบันพระมหากษัตริย์ และสัญลักษณ์ชาติ [STOP]
- [ ] B1 [STOP] ไม่มีการล้อเลียน ดัดแปลง ครอป มีม หรือสร้างภาพ AI ของพระมหากษัตริย์/พระบรมวงศานุวงศ์ (ป.อาญา ม.112 — ThaiPenalCode)
- [ ] B2 [STOP] ไม่วางสินค้า/ราคา/โปรโมชันในเฟรมเดียวกับพระบรมฉายาลักษณ์ ; ประกาศวันสำคัญใช้รูปแบบทางการ ไม่ขายของในโพสต์เดียวกัน
- [ ] B3 [STOP] ไม่ใช้รูปครุฑ (ทุกท่า ทุกสไตล์ แม้เป็นลายตกแต่ง) ตราราชวงศ์ หรือเครื่องหมายแบบ "By Royal Appointment" — ใช้โดยไม่มีสิทธิ์ให้คนเชื่อว่ามีสิทธิ์ = จำคุกไม่เกิน 1 ปี/ปรับไม่เกิน 6,000 บาท (พ.ร.บ.ครุฑพ่าห์ ม.13 — KhrutPhaAct2535 ; ต้องขออนุญาตก่อน — NationGaruda2021)
- [ ] B4 [STOP] ธงชาติ (และธงชาติอื่น) อยู่ในสภาพสมบูรณ์ ไม่อยู่บนพื้น รองเท้า ถังขยะ ไม่ถูกบิดเป็นลาย — ป.อาญา ม.118/135: กระทำการใด ๆ ต่อธงเพื่อเหยียดหยาม = จำคุกไม่เกิน 2 ปี/ปรับไม่เกิน 40,000 บาท ; พ.ร.บ.ธง ม.54 ด้วย (ThaiPenalCode, ChulaFlagThesis)
- [ ] B5 [WARN] สีที่ผูกกับสถาบัน/ช่วงไว้ทุกข์: ตรวจปฏิทินและ `../visual-arts/ADVANCED_COLOR_SCIENCE.md` §7.2 ก่อนใช้เป็นสีหลักของโปร
- [ ] B6 [WARN] ช่วงไว้ทุกข์/วันสำคัญของชาติ: เลื่อนโพสต์ตลก/ขายแรงออกไป

## C. ศาสนาและความเชื่อ [STOP]
- [ ] C1 [STOP] พระพุทธรูปไม่ถูกใช้เป็นของตกแต่ง ฉากหลังสินค้า มุก รอยสัก หรือครอปเฉพาะเศียร ; ไม่มีอะไรอยู่สูงกว่าพระพุทธรูปในเฟรม ; ไม่วางบนพื้น/ในห้องน้ำ (Coconuts_BuddhaMisuse ; ม.206 เหยียดหยามวัตถุทางศาสนา = จำคุก 1–7 ปี หรือปรับ 20,000–140,000 บาท — ThaiPenalCode ; ThailandFoundation2024)
- [ ] C2 [STOP] ไม่มีพระสงฆ์ (จริง ปลอม หรือ AI) โฆษณาสินค้า ; ไม่ใช้ภาพพระเกจิ ยันต์ พระเครื่อง บนสินค้า/กราฟิก (มารยาท + ความเสี่ยง ม.206 ; ม.208 เอาผิดเฉพาะการแต่งกาย/ใช้เครื่องหมายพระ "เพื่อให้คนเชื่อว่าเป็นพระ" — นักแสดงในฉากที่ชัดว่าเป็นเรื่องแต่งไม่ใช่ข้อนี้โดยตรง แต่ยังห้ามในงานของเรา ; กรณี Supreme ใช้ภาพหลวงพ่อคูณ 2021 — FashionLaw2021_Supreme)
- [ ] C3 [STOP] ไม่ดูหมิ่นศาสนาใด ๆ หรือบุคคล/สถานที่/สิ่งศักดิ์สิทธิ์ — รวมศาสนาของนักท่องเที่ยว (อิสลาม ฮินดู คริสต์) (AVIA2024_ThaiAdMatrix)
- [ ] C4 [WARN] ฉากวัด: แต่งกายสุภาพ ถอดรองเท้าในโบสถ์ ไม่เหยียบธรณีประตู ไม่ชี้เท้าไปที่พระพุทธรูป ไม่มีท่าทางเชิงเพศ (ThailandFoundation2024)
- [ ] C5 [WARN] ความเชื่อพื้นบ้าน (ศาลพระภูมิ นาค นางกวัก สายสิญจน์): ใช้อย่างเคารพ ไม่เป็นมาสคอตลดราคา ไม่ใช้เป็นตัวตลก
- [ ] C6 [WARN] สวัสดิกะ/มันจิ ในฉากศาสนา: งานที่ต่างชาติตะวันตกดู → ครอปออกหรืออธิบาย (S:Britannica_Swastika)

## D. ร่างกาย ท่าทาง และมารยาท
- [ ] D1 ไม่มีการแตะศีรษะ (แม้เด็ก) หรือยื่นของข้ามศีรษะ (Scroope2025, ThailandFoundation2024)
- [ ] D2 ไม่ชี้เท้า/โชว์พื้นรองเท้าใส่คนหรือพระ ไม่วางเท้าบนโต๊ะในฉากจริงจัง
- [ ] D3 ไม่ชี้นิ้วใส่คน ; กวักมือแบบคว่ำฝ่ามือ (Scroope2025)
- [ ] D4 ไหว้ถูกลำดับ: ผู้น้อยไหว้ก่อน ความลึกตามสถานะ ; ไม่ใช้ไหว้แบบล้อเลียน
- [ ] D5 [WARN] งานสำหรับต่างชาติ: thumbs-up / OK / V-sign ไม่เป็นตัวสารหลัก (S:MatsumotoHwang2013, S:Maricopa_Nonverbal)
- [ ] D6 [WARN] ผู้อาวุโส/ครู/ลูกค้า อยู่ตำแหน่งที่ให้เกียรติในเฟรม (สูง-ต่ำ = ความเคารพในไทย)

## E. หน้า เกรงใจ บุญคุณ (โทนและบท)
- [ ] E1 มุกตลกเล่นกับสถานการณ์ ไม่ทำให้ใคร (โดยเฉพาะลูกค้า/พนักงานจริง) เสียหน้า (Persons2008, Scroope2025)
- [ ] E2 ไม่ตะคอก/ประจานในคอนเทนต์แบรนด์ ; การตอบรีวิวติรักษาหน้าทั้งสองฝ่าย
- [ ] E3 [WARN] ข้อความชวนถาม/ลอง "ไม่ต้องเกรงใจ" ถ้าเป้าหมายคือให้คนเข้าร้าน/ทักแชต (Wongkitrungrueng2019)
- [ ] E4 [WARN] ของแถม/คำขอบคุณ ไม่ทำให้รู้สึกเป็นหนี้บุญคุณที่ต้องซื้อ (Jittichanon2018)

## F. Representation และ stereotype
- [ ] F1 [STOP] ไม่ใช้สีผิวเป็น before/after หรือสัญลักษณ์ความสำเร็จ ; ไม่มีฟิลเตอร์ทำให้หน้าขาวขึ้นเพื่อ "สวยกว่า" (SlutskiyHamilton2017)
- [ ] F2 บทบาทไม่ผูกกับเพศเดียว และไม่ล้อคนที่ไม่ตรงบทบาท (ASA2019_GenderStereotypes — ใช้เป็น best practice)
- [ ] F3 ไม่ล้อสำเนียง ภูมิภาค ชาติ ศาสนา อายุ ความพิการ รูปร่าง
- [ ] F4 [WARN] ความเป็นไทยไม่ถูกย่อเหลือภาพโปสการ์ด (ตุ๊กตุ๊ก ช้าง พระ) ; ช้างไม่ถูกขี่/ล่ามโซ่ในภาพ
- [ ] F5 [WARN] ภาพคนหลากหลาย (อายุ ผิว รูปร่าง) เมื่อแสดง "ลูกค้า" — แต่ไม่ tokenism

## G. Appropriation vs appreciation (เมื่อใช้วัฒนธรรมอื่น หรือแบรนด์อื่นใช้ของไทย)
- [ ] G1 สิ่งที่หยิบมาเป็นของศักดิ์สิทธิ์หรือมีความหมายพิธีกรรมไหม? ถ้าใช่ → ไม่ใช้เป็นของตกแต่ง (SEP_EthicsCulturalHeritage)
- [ ] G2 มีบริบท/เครดิต/คนในวัฒนธรรมร่วมหรือรับรู้ไหม?
- [ ] G3 เป็นภาพเหมารวม/ล้อเลียนไหม? (ชุดประจำชาติเป็นคอสตูมตลก, สำเนียงปลอม)
- [ ] G4 [WARN] ถ้าคนในวัฒนธรรมนั้นเห็นแล้วรู้สึกภูมิใจ หรือรู้สึกถูกเอาเปรียบ? — ถามจริงถ้าทำได้

## H. สัญลักษณ์ ตัวเลข ของขวัญ (ดู SYMBOL_LIBRARY.json)
- [ ] H1 ทุกสัญลักษณ์ในภาพถูกตรวจ meaning ตามกลุ่มผู้ชม และ `restriction` ไม่ใช่ `legal` ที่ใช้ผิด
- [ ] H2 [WARN] ตัวเลข: ลูกค้าจีน/เกาหลี/ญี่ปุ่น → เลี่ยง 4 ; จีน → 8 ดี ; ไทย → 9 ดี
- [ ] H3 [WARN] ของขวัญ/โปรตรุษจีน: ไม่มีนาฬิกา ร่ม เบญจมาศขาว เป็น "ของขวัญ" ; ชื่อลูกค้าเกาหลีไม่เขียนสีแดง (S:SCMP2025_GiftTaboos, S:KoreaNet2020)
- [ ] H4 [WARN] visual metaphor: ถ้าผู้ชมหลากหลาย/เลื่อนเร็ว → juxtaposition ง่าย ๆ ไม่ใช่ replacement (S:McQuarrieMick1999, S:Lagerwerf2023)
- [ ] H5 [WARN] ภาพที่ต้อง "พูดเอง" โดยไม่มีแคปชัน: ผ่าน comprehension test ≥ ~2/3 (`../semiotics/README.md` §5) — ไม่งั้นเพิ่มแคปชัน

## I. Localisation (ไม่ใช่แค่แปล)
- [ ] I1 ภาษาตรงกับกฎบ้าน (โพสต์/คลิปแบรนด์ภาษาอังกฤษ ยกเว้นชุดที่กำหนดเป็นไทย) และอ่านได้ในพื้นที่ปลอดภัยของแพลตฟอร์ม
- [ ] I2 ภาษาอังกฤษสำหรับนักท่องเที่ยว: ประโยคสั้น ไม่มีสแลง/มุกเล่นคำที่แปลไม่ได้ (transcreate แทน)
- [ ] I3 วันที่ (พ.ศ./ค.ศ.), เวลา, ราคา (฿/THB), หน่วย, เบอร์โทร รูปแบบสากลถ้าเป็นงานต่างชาติ (W3C_L10n)
- [ ] I4 [WARN] ภาษาไทย: ตรวจตาม `../thai-language/STYLE_GUIDE.md` ; ชื่อบุคคล/สถานที่สะกดถูก
- [ ] I5 [WARN] คนในวัฒนธรรมเป้าหมายอ่านแล้ว (อย่างน้อย 1 คน) สำหรับงานที่ทำเฉพาะชาติ (CulturalAdaptationMeta2023)

## J. AI และความจริงของสินค้า
- [ ] J1 [STOP] โพสต์/คลิปโฆษณาที่มีภาพหรือวิดีโอสร้างหรือแก้ด้วย AI หรือโปรแกรม → ใส่ป้าย **ภาษาไทย** ที่อ่านออกบนมือถือ เช่น "ภาพสร้างโดย AI" / "ภาพเคลื่อนไหวสร้างโดย AI" / "ภาพจริงหรือภาพจำลองจากของจริง โดยใช้ปัญญาประดิษฐ์ (AI) ปรับแต่งภาพ" (เติม "Image created by AI" ได้ แต่อย่าใช้อังกฤษอย่างเดียว) ในภาพหรือแคปชัน + เปิด AI label ของ IG/FB (OCPB2025_AIAdGuidance, OPTNews2025_OCPBAI, Tilleke2026_AIAds). ข้อความตามประกาศ: ภาพนิ่ง/ภาพเคลื่อนไหวในโฆษณาสินค้า/บริการที่ **สร้างหรือปรับแต่งด้วยโปรแกรมหรือ AI** → ต้องแสดงข้อความบอกผู้บริโภค ให้เห็น/ฟัง/อ่านได้ชัดตามประเภทสื่อ เช่น "ภาพสร้างโดย AI", "ภาพเคลื่อนไหวสร้างโดย AI", "ภาพจริงหรือภาพจำลองจากของจริง โดยใช้ปัญญาประดิษฐ์ (AI) ปรับแต่งภาพ", "ภาพถ่ายจากสินค้าจริงหรือภาพจำลองจากของจริง โดยมีการปรับแต่ง" ; ขนาด/ปริมาณ/จำนวน/ส่วนประกอบในภาพต้องตรงของจริง ; ถ้ามีกฎหมายเฉพาะให้ขออนุญาตก่อนโฆษณา ต้องได้รับอนุญาต (บทความ สคบ. พ.ย. 2025 อ้าง ประกาศคณะกรรมการว่าด้วยการโฆษณา เรื่อง แนวทางการใช้ข้อความโฆษณาที่มีลักษณะเป็นการยืนยันข้อเท็จจริงอันยากแก่การพิสูจน์ฯ พ.ศ. 2565 — OCPB2025_AIAdGuidance ; ข่าว อปท.นิวส์ 28 ก.ค. 2025 เรียกเป็นประกาศใหม่ "แนวทางการโฆษณา...ที่อาจก่อให้เกิดความเข้าใจผิดในสาระสำคัญ" — ชื่อฉบับไม่ตรงกัน, ตัวบทราชกิจจาฯ เปิดไม่ได้ (Cloudflare)) ; AI ทำให้เข้าใจผิดในสาระสำคัญ = อาจเป็นโฆษณาไม่เป็นธรรม ม.22 พ.ร.บ.คุ้มครองผู้บริโภค (OCPB2025_AINews)
- [ ] J2 [STOP] ขนาด สี รูปทรง ส่วนประกอบของสินค้าในภาพตรงกับของจริง (กรอบแว่น เลนส์)
- [ ] J3 [STOP] ไม่มีบุคคลจริง (ดารา พระ ราชวงศ์ ลูกค้า) ที่สร้างด้วย AI โดยไม่ได้รับอนุญาต
- [ ] J4 ตรวจว่า AI ไม่ใส่สัญลักษณ์ศาสนา/ตัวอักษรมั่ว/ธงผิดลงในฉากเอง (ซูมดูพื้นหลัง)

## K. จังหวะเวลา
- [ ] K1 [WARN] ตรวจปฏิทิน: วันพระใหญ่, วันสำคัญทางศาสนา (รวมรอมฎอน/Hari Raya สำหรับลูกค้ามาเลเซีย, ตรุษจีน, Diwali), วันสำคัญของชาติ, ช่วงไว้ทุกข์, ภัยพิบัติ
- [ ] K2 [WARN] เหตุการณ์ที่กำลังเป็นกระแสด้านลบ: เลื่อนโพสต์ขำ/ขาย
