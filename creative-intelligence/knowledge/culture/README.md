## 2. Core concepts
รูปแบบ: **คืออะไร · กลไก · ใช้งาน · ข้อจำกัด · tier + keys · ความมั่นใจ**

### 2.1 Hofstede cultural dimensions — และทำไมต้องใช้อย่างระวัง
- **คืออะไร**: คะแนนระดับชาติ (power distance, individualism, uncertainty avoidance, masculinity ฯลฯ) จากแบบสอบถามพนักงาน IBM
- **หลักฐาน**: meta-analysis Taras, Kirkman & Steel 2010 (598 งาน, >200,000 คน): ค่านิยมสัมพันธ์กับผลลัพธ์ระดับบุคคลแบบ **เล็ก** (ρ ≈ 0.18) — สัมพันธ์กับอารมณ์และทัศนคติมากกว่าพฤติกรรม ; ความแปรปรวนของค่านิยม **ส่วนใหญ่ (ถึง ~90%) อยู่ภายในประเทศ** (Steel & Taras 2010)
- **คำวิจารณ์**: McSweeney, Brown & Iliopoulou 2010 (อ่านเต็ม) — ทดสอบ case study ของ Hofstede (ชาติ "masculine" สู้กันเรื่องแรงงาน, ชาติ "feminine" เจรจา) กับข้อมูลการพิพาทแรงงานและอัตราฆาตกรรม: ไม่มีแม้ความสัมพันธ์อ่อน ๆ ; 4 มิติอธิบายได้แค่ 49% ของ variance ค่าเฉลี่ยประเทศ (ตัวเลขของ Hofstede เอง) และเป็นคำตอบแบบสอบถาม ไม่ใช่พฤติกรรม. McSweeney 2002 (snippet) — แบบสอบถามออกแบบวัดความพึงพอใจงาน, ตัวอย่าง IBM ไม่เป็นตัวแทน, วัฒนธรรมชาติไม่ใช่เหตุของพฤติกรรมอย่างเป็นระบบ ; Hofstede ตอบ "Dimensions do not exist" ; McSweeney 2013 — การใช้คะแนนชาติกับคนรายบุคคล = ecological fallacy
- **ใช้งาน**: ใช้เป็น "สมมติฐานตั้งต้น" ตอนบรีฟตลาด (เช่น ครอบครัว/กลุ่ม vs ความสำเร็จส่วนตัว) แล้ว **ทดสอบกับคนจริง** ; ห้ามใช้ทำนายลูกค้ารายคน
- **Tier/keys**: S/A/B — TarasKirkmanSteel2010, McSweeney2002, McSweeneyBrownIliopoulou2010, deMooijHofstede2010 · **ความมั่นใจ**: medium (ว่ามีผลเล็ก) / low (สำหรับการทำนายรายบุคคล)

### 2.2 GLOBE
- **คืออะไร**: ผู้จัดการ ~17,000+ คน 62 สังคม, 9 มิติ ; แยก **practices ("as is")** กับ **values ("should be")**
- **ใช้งาน**: ช่องว่างระหว่าง "เป็นอยู่" กับ "อยากให้เป็น" เป็นวัตถุดิบเล่าเรื่อง — ภาพโฆษณาที่ดีมักแสดงโลกที่ผู้ชม "อยากให้เป็น"
- **ข้อจำกัด**: ไม่ได้ดึงคะแนนไทย ; โดนวิจารณ์เรื่อง ecological fallacy เช่นกัน
- **Tier/keys**: A — House2004_GLOBE · **ความมั่นใจ**: medium

### 2.3 Hall: high- vs low-context
- **คืออะไร**: วัฒนธรรม high-context พึ่งบริบทร่วม พูดอ้อม ; low-context พูดตรง ระบุชัด
- **หลักฐาน**: Cardon 2008 (meta-analysis 224 บทความ) — เป็นกรอบที่ถูกอ้างมากที่สุด แต่ **ทดสอบเชิงประจักษ์น้อย และข้อเสนอที่ทดสอบบ่อย (เรื่องความตรง) ส่วนใหญ่ไม่ได้รับการสนับสนุน** ; Kittler et al. 2011 — ยังไม่มีการจัดประเทศที่เชื่อถือได้
- **ใช้งาน**: ใช้เป็นคำถามออกแบบ ("คนดูมีบริบทร่วมกับเราแค่ไหน?") ไม่ใช่ป้ายประเทศ ; คนไทยที่ตามเพจอยู่แล้ว = บริบทร่วมสูง ; นักท่องเที่ยวที่เห็นครั้งแรก = ต้องสะกดให้ชัด (low-context) ไม่ว่าเขามาจากประเทศไหน
- **Tier/keys**: A — Cardon2008 · **ความมั่นใจ**: low (เป็นทฤษฎีที่หลักฐานอ่อน)

### 2.4 ค่านิยมไทย (Thai social values)
- **เกรงใจ (kreng jai)**: ความเกรงใจ/ไม่อยากรบกวน/ให้เกียรติ มี ~15 ความหมาย (WyattPromkandorn2012) ; ในบริการ ลูกค้าไทยที่เกรงใจมีความรู้สึกไม่สบายใจ หาทางรับมือ และ **อาจเลิกมาแทนการบ่น** (Wongkitrungrueng2019)
  - ใช้งาน: ข้อความที่ "อนุญาตให้ถาม" ช่วยจริง ("ลองได้ทุกอัน ไม่ต้องเกรงใจ") ; ตัวละครปฏิเสธอ้อม ๆ คนไทยอ่านออก ต่างชาติอาจงง
- **หน้า / เสียหน้า (face, sia na)**: มีคำศัพท์เรื่องหน้ามากมาย ; Persons 2008 (abstract) เสนอว่า "หน้า" ของไทยประกอบด้วย 5 แนวคิด — หน้าตา เกียรติ ศักดิ์ศรี ชื่อเสียง บารมี — คนไทยคิดรวมกันแต่ความหมายแยกกัน ; การขึ้นเสียง = เสียการควบคุม ทำให้เสียหน้า (Scroope2025)
  - ใช้งาน: มุกตลกเล่นกับ **สถานการณ์** ไม่ใช่ทำให้คนดูโง่ ; ห้ามเอาลูกค้าจริง/พนักงานมาเป็นตัวตลก ; รีวิวติต้องตอบแบบรักษาหน้า
- **บุญคุณ (bunkhun)**: การตอบแทนความดี/บุญคุณที่ไม่มีวันชดใช้หมด (พ่อแม่ ครู) ; วาทกรรมกตัญญูผูกกับความคาดหวังตอบแทนและความไม่เท่ากันทางอำนาจ (Jittichanon2018 + corpus study)
  - ใช้งาน: เรื่องขอบคุณพ่อแม่/ลูกค้าเก่าได้ผล ; **อย่า**ทำให้ของแถมดูเหมือนสร้างหนี้บุญคุณกดดันให้ซื้อ
- **สนุก (sanuk) / ความกลมกลืน / ลำดับชั้น**: Komin 1990 (สำรวจ 2,469 คน) ชี้ค่านิยมความสัมพันธ์ กตัญญู และความกลมกลืนระหว่างบุคคล ; ไหว้ตามลำดับอาวุโส ผู้น้อยไหว้ก่อน (ThailandFoundation2024)
- **ข้อจำกัด**: ทุกค่านิยมเป็น "แนวโน้ม" ไม่ใช่คุณสมบัติของคนไทยทุกคน ; Komin ข้อมูลเก่า ; คนรุ่นใหม่/เมือง vs ชนบทต่างกัน
- **Tier/keys**: A/B/C — Komin1990, WyattPromkandorn2012, Wongkitrungrueng2019, Jittichanon2018, Persons2008, Scroope2025 · **ความมั่นใจ**: medium

### 2.5 Cross-cultural advertising: standardise หรือ adapt?
- **หลักฐาน**: Hornikx & O'Keefe 2009 — appeal ที่ปรับตามค่านิยมวัฒนธรรม **โดยเฉลี่ย** โน้มน้าวและถูกชอบมากกว่า (แต่ไม่พบผลในยุโรป/ละตินอเมริกา) ; meta-analysis 2023 (~120 การเปรียบเทียบ) — ผล **มีจริงแต่เล็กมาก** (r ≈ .05) "ได้ผลแต่พึ่งพาไม่ได้" ; เมื่อนักวิจัยมีวัฒนธรรมเดียวกับผู้ชม ผลชัดขึ้น (r ≈ .08) ; McQuarrieMick1999 (ดู M12) — metaphor ไม่ได้ผลกับคนที่ไม่มี cultural competency
- **ใช้งาน**: การปรับตามค่านิยมเป็น "ตัวเสริมเล็ก ๆ" ; สิ่งที่สำคัญกว่าคือ **ไม่ทำผิด** (ข้อห้าม/ความหมายผิด) และให้คนในวัฒนธรรมนั้นตรวจ
- **Tier/keys**: S/A — HornikxOKeefe2009, CulturalAdaptationMeta2023, deMooijHofstede2010 · **ความมั่นใจ**: medium

### 2.6 Representation & stereotype avoidance
- **คืออะไร**: ภาพเหมารวม (เพศ ผิว อายุ ชาติพันธุ์ ภูมิภาค) ทำร้ายและสร้างกระแสต่อต้าน
- **หลักฐาน/มาตรฐาน**: ASA (UK, อ่านหน้า advice เต็ม) — CAP 4.9/BCAP 4.14 มีผล 14 มิ.ย. 2019: โฆษณา "must not include gender stereotypes that are likely to cause harm, or serious or widespread offence" ; แนวทางแยก 5 หมวด (บทบาท/ลักษณะ, sexualisation, มุกตลก, การเทียบคู่ตรงข้าม, อื่น ๆ) ; รีวิว 12 เดือนพบว่าได้ผล (จาก search เดิม) ; ไม่ห้ามภาพคนสวย/ความสำเร็จ หรือการใช้ stereotype เพื่อท้าทายมัน ; ไทย: โฆษณา Seoul Secret ม.ค. 2016 "Whiteness makes you win" ไวรัลจนสื่อโลก (CNN, Guardian) รายงาน และมีเสียงเรียกร้องให้เอาผิดทางกฎหมาย ; งานวิเคราะห์สื่อไทยพบว่า "เสรีภาพในการพูด" แทบไม่ปรากฏในวาทกรรมเรื่องโฆษณาเลือกปฏิบัติ (abstract — SlutskiyHamilton2017) ; การถอดโฆษณา/ขอโทษมาจาก search เดิม
- **ใช้งาน**: ถามเสมอ: บทบาทนี้ถูกผูกกับเพศ/สีผิว/อายุเดียวหรือไม่? ใครเป็นตัวตลก? ใครถูกวาดให้ "ด้อยกว่า"? ; สำหรับ Mint & Tao (หน้าว่าง) เลี่ยงการกำหนดว่าใครทำงานบ้าน/ใครซ่อมของตามเพศเสมอ
- **Tier/keys**: S/B — ASA2019_GenderStereotypes, SlutskiyHamilton2017 · **ความมั่นใจ**: medium (ไทยยังไม่มีกฎแบบ ASA — ใช้เป็น best practice)

### 2.7 Cultural appropriation vs appreciation
- **คืออะไร**: คนนอกนำผลผลิตทางวัฒนธรรม (เรื่องเล่า สไตล์ ลวดลาย สิ่งศักดิ์สิทธิ์ การปฏิบัติทางศาสนา) ไปใช้ ; ที่ผิดมักตั้งอยู่บนความไม่เท่าเทียม
- **เหตุผลว่าผิด**: ทำให้ขุ่นเคืองลึก (profound offence), เอาเปรียบ (กำไรโดยไม่ขออนุญาต/ไม่ตอบแทน), บิดเบือนเป็น stereotype, ละเมิดความเป็นส่วนตัวของกลุ่ม ; **ข้อโต้แย้ง**: ความขุ่นเคืองอาจถูกชั่งน้ำหนักด้วยคุณค่าอื่น, คนในก็บิดเบือนได้, การแลกเปลี่ยนวัฒนธรรมสร้างสรรค์, เส้นแบ่ง "คนใน/คนนอก" เป็น essentialism
- **ใช้งาน (appreciation test)**: ให้เครดิต · ให้บริบท · ร่วมงาน/ขออนุญาตเจ้าของวัฒนธรรม · ไม่ล้อเลียน · ไม่ใช้สิ่งศักดิ์สิทธิ์เป็นของตกแต่ง · แบ่งประโยชน์ ; ใช้ทั้งเมื่อเราใช้วัฒนธรรมอื่น (ญี่ปุ่น เกาหลี จีน อินเดีย) และเมื่อแบรนด์ต่างชาติใช้ของไทย (กรณี Supreme)
- **Tier/keys**: B — SEP_EthicsCulturalHeritage ; C — FashionLaw2021_Supreme · **ความมั่นใจ**: medium (เป็นข้อถกเถียงเชิงจริยศาสตร์ ไม่มีคำตอบเดียว)

### 2.8 ศาสนาและสถาบันในสื่อไทย
- **กฎหมาย** (ตรวจตัวบท 2026-11-25): ป.อาญา ม.112 (หมิ่นประมาท ดูหมิ่น แสดงความอาฆาตมาดร้าย พระมหากษัตริย์ ราชินี รัชทายาท ผู้สำเร็จราชการ — จำคุก 3–15 ปี; ศาลฎีกาตีความรวมอดีตกษัตริย์ตามสรุปข่าว) · ม.118/135 (กระทำต่อธง/เครื่องหมายของรัฐไทย/รัฐต่างประเทศที่มีไมตรี เพื่อเหยียดหยาม — ไม่เกิน 2 ปี/40,000 บาท) · ม.206 (เหยียดหยามวัตถุ/สถานที่ทางศาสนา — 1–7 ปี หรือ 20,000–140,000 บาท) · ม.207 (ก่อความวุ่นวายในพิธีศาสนา) · ม.208 (แต่งกาย/ใช้เครื่องหมายนักบวชโดยมิชอบเพื่อให้คนเชื่อ — ไม่เกิน 1 ปี/20,000 บาท) · พ.ร.บ.เครื่องหมายครุฑพ่าห์ 2534 แก้ไข 2535 (รูปครุฑทุกท่า; ใช้โดยไม่มีสิทธิ์ ไม่เกิน 1 ปี/6,000 บาท; รองนายกฯ: ต้องขออนุญาตสำนักนายกฯ ก่อน) · พ.ร.บ.ธง 2522 ม.54 (ตัวบทยังไม่ได้อ่าน; ข้อเสนอให้ยกเลิกเพราะซ้ำ ม.118 — ChulaFlagThesis)
- **กฎโฆษณา**: ห้ามองค์ประกอบดูหมิ่นพระมหากษัตริย์/ประมุขรัฐ ; ห้ามดูหมิ่นศาสนาหรือบุคคล สถานที่ สิ่งศักดิ์สิทธิ์ ; ต้องตาม พ.ร.บ.คุ้มครองผู้บริโภค (AVIA2024_ThaiAdMatrix) ; **กฎ สคบ. เรื่องภาพ AI** (อ่านจากแหล่ง สคบ. เอง): ภาพนิ่ง/ภาพเคลื่อนไหวในโฆษณาสินค้า/บริการที่ **สร้างหรือปรับแต่งด้วยโปรแกรมหรือ AI** → ต้องแสดงข้อความบอกผู้บริโภค ให้เห็น/ฟัง/อ่านได้ชัดตามประเภทสื่อ เช่น "ภาพสร้างโดย AI", "ภาพเคลื่อนไหวสร้างโดย AI", "ภาพจริงหรือภาพจำลองจากของจริง โดยใช้ปัญญาประดิษฐ์ (AI) ปรับแต่งภาพ", "ภาพถ่ายจากสินค้าจริงหรือภาพจำลองจากของจริง โดยมีการปรับแต่ง" ; ขนาด/ปริมาณ/จำนวน/ส่วนประกอบในภาพต้องตรงของจริง ; ถ้ามีกฎหมายเฉพาะให้ขออนุญาตก่อนโฆษณา ต้องได้รับอนุญาต (บทความ สคบ. พ.ย. 2025 อ้าง ประกาศคณะกรรมการว่าด้วยการโฆษณา เรื่อง แนวทางการใช้ข้อความโฆษณาที่มีลักษณะเป็นการยืนยันข้อเท็จจริงอันยากแก่การพิสูจน์ฯ พ.ศ. 2565 — OCPB2025_AIAdGuidance ; ข่าว อปท.นิวส์ 28 ก.ค. 2025 เรียกเป็นประกาศใหม่ "แนวทางการโฆษณา...ที่อาจก่อให้เกิดความเข้าใจผิดในสาระสำคัญ" — ชื่อฉบับไม่ตรงกัน, ตัวบทราชกิจจาฯ เปิดไม่ได้ (Cloudflare)) ; AI ทำให้เข้าใจผิดในสาระสำคัญ = อาจเป็นโฆษณาไม่เป็นธรรม ม.22 พ.ร.บ.คุ้มครองผู้บริโภค (OCPB2025_AINews) — ป้ายต้องเป็นข้อความที่ผู้บริโภคไทยอ่านเข้าใจ (ตัวอย่างทางการเป็นภาษาไทยทั้งหมด)
- **บรรทัดฐาน (ไม่ใช่กฎหมายเสมอไป)**: พระพุทธรูปไม่ใช่ของตกแต่ง/รอยสัก ; ภาพพระเกจิ/ยันต์บนสินค้า ; ศีรษะสูงเท้าต่ำ ; วางสิ่งศักดิ์สิทธิ์สูงกว่าศีรษะ
- **ใช้งาน**: ประกาศวันสำคัญ/ไว้ทุกข์ ใช้รูปแบบทางการที่ร้านเคยใช้ (ดู memory "Closure notice style") ไม่สร้างสรรค์ดัดแปลง ; ห้ามสร้างภาพ AI ของพระพุทธรูป พระสงฆ์ ราชวงศ์
- **Tier/keys**: S/C — ThaiPenalCode, KhrutPhaAct2535, OCPB2025_AIAdGuidance, OCPB2025_AINews, OPTNews2025_OCPBAI, AVIA2024_ThaiAdMatrix, Tilleke2026_AIAds, NationGaruda2021, ChulaFlagThesis, Coconuts_BuddhaMisuse · **ความมั่นใจ**: high (ทิศทาง) — **ไม่ใช่คำปรึกษากฎหมาย** ถ้าสงสัยให้ตัดออก

### 2.9 นักท่องเที่ยวต่างชาติ — ใครคือคนดูจริง
- **ข้อมูล MOTS (ผ่าน The Nation 6 ม.ค. 2026)**: ปี 2025 นักท่องเที่ยวต่างชาติ 32,974,321 คน (ลดลง ~7%), รายได้ 1.53 ล้านล้านบาท ; 5 อันดับ: **มาเลเซีย 4.52 ล้าน, จีน 4.47 ล้าน, อินเดีย 2.49 ล้าน, รัสเซีย 1.90 ล้าน, เกาหลีใต้ 1.56 ล้าน**
- **ความหมาย**: "ต่างชาติ" ≠ "ฝรั่ง" ; ตลาดใหญ่สุดคือมุสลิม-มาเลย์ จีน และอินเดีย → ภาษาอังกฤษง่าย ๆ + ภาพที่อ่านได้โดยไม่ต้องอ่านภาษา + ระวังสัญลักษณ์ศาสนา/อาหาร/ตัวเลขของแต่ละกลุ่ม
- **ข้อจำกัด**: ตัวเลขทั้งประเทศ — สัดส่วนในหัวหิน/ร้านเราอาจต่าง (ควรดูจาก insight เพจ/ลูกค้าจริง) ; อันดับ 6–10 ยังไม่ได้ดึง
- **Tier/keys**: C — MOTS2025_Nation · **ความมั่นใจ**: high (ตัวเลขทางการผ่านข่าว)

### 2.10 Localisation ≠ Translation
- **คืออะไร**: localisation = ปรับเนื้อหาให้เข้ากับ locale: รูปแบบวันที่/ตัวเลข/สกุลเงิน, สัญลักษณ์ ไอคอน สี, สิ่งที่อาจถูกอ่านผิดหรือไม่เหมาะ, ข้อกำหนดกฎหมาย, ลำดับชื่อ, การอ่านง่ายของตัวอักษร และบางครั้งต้องคิดตรรกะ/การออกแบบใหม่ (W3C_L10n) ; translation เป็นแค่ส่วนหนึ่ง
- **ใช้งาน**: งานสำหรับต่างชาติไม่ใช่แค่แปลแคปชัน — ตรวจ ราคา (บาท + ไม่ลงท้ายเลขต้องห้าม), วันที่ (พ.ศ. vs ค.ศ.), ภาพ, มุก, ท่ามือ ; มุกเล่นคำไทยแปลไม่ได้ → เปลี่ยนมุก (transcreation) ; บ้านกฎ: โพสต์/คลิปแบรนด์เป็นภาษาอังกฤษ ยกเว้นชุดที่กำหนดเป็นไทย (ดู CLAUDE.md, memory)
- **Tier/keys**: B — W3C_L10n · **ความมั่นใจ**: high (เป็นแนวปฏิบัติมาตรฐาน)

## 4. Applied patterns for our production
1. **บรีฟทุกงานมีช่อง "ผู้ชมคือใคร"**: คนไทยที่ตามเพจ (บริบทสูง) / คนไทยทั่วไป / นักท่องเที่ยว (ระบุ 1–2 ชาติหลัก) → เลือกระดับความชัด ภาษา สัญลักษณ์ตาม
2. **Mint & Tao**: ความขัดแย้งแบบไทย — เกรงใจ ไม่กล้าขอ, กลัวเสียหน้า, ตอบแทนบุญคุณ — คลี่คลายด้วยความเข้าใจ ไม่ใช่การทำให้อีกฝ่ายเสียหน้า ; ไหว้ผู้ใหญ่ถูกลำดับ ; ไม่แตะหัว ไม่ชี้เท้า
3. **คลิปเรื่องเล่า (story clips)**: ฉากวัด บ้านผู้ใหญ่ ศาลพระภูมิ — ใช้ staging rules จาก ThailandFoundation2024 ; ไม่มีพระพุทธรูป/พระสงฆ์ที่สร้างด้วย AI
4. **คอนเทนต์นักท่องเที่ยว (หัวหิน)**: ภาษาอังกฤษสั้น + ภาพอ่านได้เอง ; หลีกเลี่ยง thumbs-up/OK เป็นตัวสาร ; ราคาไม่ลงท้าย 4 ถ้าเน้นลูกค้าจีน ; เคารพลูกค้ามุสลิม (ไม่ใช้ภาพแอลกอฮอล์/หมูประกอบโปร — HYPOTHESIS ต้องหาแหล่งยืนยัน)
5. **ภาพ AI**: โพสต์/คลิปโฆษณาที่ภาพหรือวิดีโอสร้าง/แก้ด้วย AI หรือโปรแกรม → ป้ายไทยในภาพหรือแคปชัน เช่น "ภาพสร้างโดย AI" / "ภาพเคลื่อนไหวสร้างโดย AI" (เติมอังกฤษได้ — กฎบ้าน English-only ของโพสต์ต้องยกเว้นบรรทัดนี้) ตาม สคบ. (OCPB2025_AIAdGuidance) ; ห้าม AI แก้รูปทรง/สีกรอบให้ต่างจากของจริง (ตรงกับ memory "IG Reels … AI label ON")
6. **ใช้คนในวัฒนธรรมตรวจ**: งานที่ทำเพื่อชาติอื่น ให้คนชาตินั้น (ลูกค้า/เพื่อน/พนักงาน) ดูก่อนโพสต์ — หลักฐาน 2023 meta ชี้ว่าคนในวัฒนธรรมเดียวกันทำ adaptation ได้ผลกว่า

## 5. Anti-patterns
- ใช้คะแนน Hofstede/ป้าย "high-context" ตัดสินคนรายบุคคล
- "ต่างชาติ = ฝรั่ง" (ตลาดใหญ่สุดคือมาเลเซีย จีน อินเดีย)
- แปลตรงตัวแล้วถือว่า localise แล้ว
- มุกที่ทำให้คนเสียหน้า, colourism, gender role ตายตัว, ล้อสำเนียงภูมิภาค/ชาติ
- ใช้พระพุทธรูป ภาพพระสงฆ์ สถาบัน ธง ตราครุฑ เป็นจุดขาย ; สร้างภาพ AI ของสิ่งเหล่านี้
- "exotic Thailand" แบบโปสการ์ด (ตุ๊กตุ๊ก ช้าง พระ) เป็นตัวแทนความเป็นไทย
- อ้างงานวิจัยไม่ได้อ่าน หรือเขียน craft เป็นวิทยาศาสตร์
