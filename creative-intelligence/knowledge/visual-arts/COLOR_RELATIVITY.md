## 0. ใจความเดียวที่ต้องจำ
"สีของวัตถุในฉากซับซ้อน **ไม่ได้ถูกกำหนดด้วยแสงที่มาจากวัตถุนั้นเพียงอย่างเดียว**" [ShevellKingdom2008 full_text] — สมองตีความสีจาก
พื้นรอบ, สิ่งที่เพิ่งเห็น, สมมติฐานเรื่องแสง, ความรู้ว่าวัตถุคืออะไร, และขนาด · หน้าที่หลักของการเห็นสีคือ *แยกวัตถุ จำวัตถุ และสื่อสารเรื่องวัตถุ*
ไม่ใช่วัดแสง [WitzelGegenfurtner2018 full_text] → สำหรับงานเรา: **ตัดสินสีในภาพที่ประกอบเสร็จ ในขนาดและพื้นหลังที่ผู้ชมเห็นจริงเท่านั้น**

Albers สอนเรื่องนี้ด้วยแบบฝึกกระดาษสี (สีเดียวดูเป็นสองสี, สองสีดูเป็นสีเดียว) [Albers1963 — bibliographic, CRAFT pedagogy] ส่วนวิทยาศาสตร์ด้านล่างอธิบายกลไก

## 1. Simultaneous contrast (ความต่างพร้อมกัน)

| ฟิลด์ | เนื้อหา |
|---|---|
| นิยาม | สีที่วางติดกันดูต่างกันมากขึ้นทั้ง hue และ lightness — เทาบนพื้นแดงดูอมเขียว, เทาบนพื้นดำดูสว่างขึ้น |
| Foundation | **EVIDENCE**: Chevreul (1839) เริ่มจากปัญหาด้ายทอพรม Gobelins [Chevreul1839]; งานสมัยใหม่พบว่าไม่ใช่แค่ "ค่าเฉลี่ยของพื้นรอบ": พื้นรอบที่มี *ความแปรปรวนของสี* สูงลด contrast ที่รับรู้ของตรงกลาง (Brown & MacLeod 1997 ตามที่ Shevell & Kingdom อ้าง) และสมมติฐาน "equivalent uniform background" ทุกรูปแบบใช้ไม่ได้กับฉากซับซ้อน [ShevellKingdom2008]; local contrast เป็นหนึ่งในสองกลไกหลักของ constancy (คู่กับ adaptation) [WitzelGegenfurtner2018] |
| อธิบายแบบช่าง | พื้นรอบ "ผลัก" สีกลางไปทางตรงข้ามของมัน (hue ตรงข้าม, value ตรงข้าม) — ยิ่งพื้นใหญ่และสดยิ่งแรง |
| ตัวอย่างงานเรา | แว่นกรอบใส/เทา (TR90 สีเทาควัน) บนพื้นหลังส้มสดใน promo: กรอบจะดูอมฟ้า-เขียว; ลูกค้ามาร้านเห็นของจริง "สีไม่เหมือนรูป" |
| ใช้ถูก | ตั้งพื้นให้ "ช่วย" สีสินค้า: กรอบน้ำตาลอุ่นบนพื้นเทาอมฟ้าอ่อน → น้ำตาลดูอุ่นขึ้นเล็กน้อยอย่างเป็นธรรมชาติ |
| ใช้ผิด | ใช้พื้นสีจัดกับสินค้าที่ต้องโชว์สีจริง (เลนส์ tint, กรอบเทา/ใส) โดยไม่มีช็อตพื้นกลางเทียบ |
| ข้อยกเว้น | ถ้าวัตถุมีขอบเส้นดำ/ขาวหนาแยกจากพื้น ผลจะเปลี่ยน (มีงานพบว่า flanking contours ขยายผลได้ด้วย — search summary, ไม่ได้ลง key) |
| ใช้เชิงอารมณ์ | ทำให้สีหนึ่ง "เปล่ง" โดยไม่ต้องเพิ่ม chroma — เช่น accent peach ดูอุ่นจัดขึ้นบนพื้นเขียว Phthalo |
| ใช้เชิงเทคนิค | Product: มีอย่างน้อย 1 ภาพบนพื้นกลาง (เทา L≈0.9, C≈0) · ตรวจโดยวางภาพสินค้าบนพื้นเทาเทียบข้างกัน |
| ผิดบ่อย | เลือกสีพื้นจาก swatch แยก แล้วไม่ดูรวมกับสินค้า |
| Keys / tier / conf | Chevreul1839, ShevellKingdom2008, WitzelGegenfurtner2018, Albers1963 · A · **high** |

## 2. Assimilation (การกลืน / Bezold-type spreading)

| ฟิลด์ | เนื้อหา |
|---|---|
| นิยาม | ตรงข้ามกับ contrast: เมื่อลวดลายบาง/ถี่ สีพื้นที่ถูกเส้นแทรกจะดู *เหมือน* สีของเส้นมากขึ้น |
| Foundation | **EVIDENCE**: พื้นหลังลายสองสี (patterned chromatic backgrounds) ทำให้สีเปลี่ยนมากกว่าพื้นสีเดียวของสีใดสีหนึ่งในลายนั้น และ assimilation กับ contrast ทำงานร่วมกันจนเกิดการเปลี่ยนขนาดใหญ่ [MonnierShevell2003 — abstract/search summary] |
| ตัวอย่างงานเรา | carousel ถ่าน/ดินสอ Mint & Tao ที่ลง tint สีพาสเทลบาง ๆ ใต้เส้นแรเงาถี่: เส้นดำถี่ทำให้ tint ดูหม่น/เข้มขึ้น; เส้นขาว (highlight) ถี่ทำให้ดูซีดขึ้น |
| ใช้ถูก | อยากให้พื้นที่ดูอ่อนลงโดยไม่เปลี่ยนสีพื้น → เพิ่ม hatch สีอ่อน; อยากให้หนักขึ้น → hatch เข้ม |
| ใช้ผิด | ใส่ texture เส้นดำถี่บนสีแบรนด์แล้วสงสัยว่าทำไมเขียว Phthalo ดูดำ |
| ใช้เชิงเทคนิค | วัดสีพื้นที่ที่มี hatch ด้วย `analyze_image.py` จะได้ "ค่าเฉลี่ย" ที่ใกล้กับสิ่งที่ตาเห็นมากกว่าค่าสีพื้น — **DERIVED** |
| Keys / tier / conf | MonnierShevell2003 · A · medium (ไม่ได้อ่านฉบับเต็ม) |

## 3. Successive contrast และ afterimage (ความต่างตามลำดับเวลา)

| ฟิลด์ | เนื้อหา |
|---|---|
| นิยาม | หลังจ้องสีหนึ่งนาน แล้วมองพื้นกลาง จะเห็นภาพติดตาสีตรงข้าม (negative afterimage); สิ่งที่เห็นถัดไปจะเอียงไปทางตรงข้ามของสิ่งที่เพิ่งเห็น |
| Foundation | **EVIDENCE**: บันทึก ganglion cells ในลิง: สัญญาณ afterimage เกิดที่ **retina** (slow adaptation ของ RGC population) แม้ cortex จะปรับต่อได้ [Zaidi2012 abstract]; Shevell & Kingdom รวมบริบท "successive" ในนิยามฉากซับซ้อน [ShevellKingdom2008] |
| ตัวอย่างงานเรา | story clip: ฉากผีโทนฟ้าเข้ม 6 วินาที → ตัดไปหน้าร้านตอนเช้าโทนกลาง: ช็อตเช้าจะดูอุ่น/เหลืองกว่าที่เกรดไว้ในช่วงแรก |
| ใช้ถูก | ใช้เป็นเครื่องมือ: ให้ฉาก "ปลอดภัย" รู้สึกอุ่นขึ้นโดยวางหลังฉากเย็นยาว ๆ (ไม่ต้องเกรดอุ่นจัด) — **DERIVED** |
| ใช้ผิด | เกรดช็อตแยกทีละช็อตบนพื้นจอขาว แล้วต่อกันโดยไม่ดูต่อเนื่อง |
| ข้อยกเว้น | ช็อตสั้นมาก (< ~1 วินาที) ผลน้อย — **HYPOTHESIS** (เวลาที่แน่นอนไม่ได้ยืนยันใน batch นี้) |
| ใช้เชิงเทคนิค | ตรวจ colour script ด้วยการดูคลิปทั้งตัวต่อเนื่องอย่างน้อยหนึ่งรอบก่อนส่ง |
| Keys / tier / conf | Zaidi2012, ShevellKingdom2008 · A · medium-high |

## 4. Chromatic adaptation และ colour constancy

### 4.1 Adaptation
- **von Kries (1905)**: แต่ละชนิด cone ปรับ gain ของตัวเองตามแสงรอบ (ตามที่ Shevell & Kingdom อ้างในรายการคลาสสิก) [ShevellKingdom2008 — อ้าง von Kries] — เป็นพื้นของ
  chromatic adaptation transforms (CAT) ใน CIECAM02 (CAT02) และ CAM16 (CAT16) [Moroney2002, Li2017_CAM16] · **EVIDENCE**
- ความเร็ว: ส่วนใหญ่ปรับในเสี้ยววินาที แต่ **ปรับเต็มที่ใช้หลายนาที** [WitzelGegenfurtner2018 อ้าง Rinner & Gegenfurtner 2000]
- ผลต่องานเรา (DERIVED): ผู้ชมดู IG บนมือถือในห้องไฟส้มตอนกลางคืน จะปรับตัวกับแสงห้อง+จอไม่ครบ → ภาพโทนเย็นจะดูเย็นกว่าที่เราเห็นบนจอทำงานตอนกลางวัน;
  ตั้ง night shift/true tone ไว้หรือไม่ก็เปลี่ยนภาพ — ไม่มีทางคุมได้ จึงเลี่ยงการพึ่ง "ความต่างสีเล็ก ๆ" เพื่อสื่อสาร

### 4.2 Constancy — ดีแค่ไหน?
- ผลวัดในห้องทดลองกระจายตั้งแต่ "แทบไม่มี" ถึง "เกือบสมบูรณ์" (constancy index 0–1); งานที่ให้ adapt ได้หรือใช้ฉากเหมือนจริงได้ **≥ 90%**; ดัชนีสูงขึ้นตามปีที่ตีพิมพ์
  (r(64) = 0.43) เพราะใช้ฉากเหมือนจริงมากขึ้น; คำสั่งแบบ "appearance match" ได้ค่าต่ำ, "surface match" ได้ค่าสูง [WitzelGegenfurtner2018 full_text; Foster2011 search_summary]
- Cue ที่ใช้: adaptation, local contrast, interreflection/shading 3D [Bloj1999], depth segmentation, specular highlights, memory colours [WitzelGegenfurtner2018];
  การประมาณแสงแบบ gray-world / brightest patch "fail to capture many available physical cues" [ShevellKingdom2008]
- Retinex: การรับรู้สีพื้นผิวขึ้นกับการเปรียบเทียบความสว่างสัมพัทธ์ในแต่ละช่วงคลื่นทั่วฉาก [Land1977] — โมเดลหนึ่งในหลายโมเดล
- ข้อจำกัดทางฟิสิกส์: metamer mismatching ทำให้ constancy เป็นไปไม่ได้ในบางคู่ (เสื้อในร้าน vs แดดนอกร้าน) แต่เกิดไม่บ่อยในธรรมชาติ [WitzelGegenfurtner2018]
- Constancy น่าจะ "จูน" มากับแสงกลางวัน/เงา (blue bias) — หลักฐานผสม [WitzelGegenfurtner2018]

**ผลต่องานเรา**
1. ภาพที่มี cue ของแสงครบ (เงามีทิศ, highlight, interreflection, วัตถุที่รู้สีอยู่แล้วเช่นผิว/ใบไม้) → ผู้ชม "อ่าน" สีกรอบได้ถูกแม้แสงอุ่น/เย็น (**DERIVED** จาก cue list)
2. cutout แว่นบนพื้นเรียบไม่มี cue → ผู้ชมเหลือแค่สีพิกเซล + พื้นรอบ → simultaneous contrast ครองการรับรู้
3. ภาพ AI ที่แสงไม่สอดคล้องกัน (เงาเย็นแต่ highlight ขาว + ผิวอุ่น) ทำลาย cue → สีวัตถุอ่านยาก, ดู "ปลอม" (**DERIVED**)

## 5. #TheDress — กรณีศึกษาที่ต้องรู้สำหรับรูปสินค้า

- แบบสำรวจตอบอิสระ N = 1,401: **57% blue/black, 30% white/gold, 11% blue/brown, 2% อื่น**; ผู้หญิงและผู้สูงอายุตอบ white/gold มากกว่า; บางคนสลับการรับรู้เมื่อทดสอบซ้ำ;
  การจับคู่สีให้ 3 ยอด = 3 percept เสถียร [LaferSousa2015 full_text]
- คำอธิบาย: พิกเซลของชุดเรียงตาม **daylight locus** (น้ำเงิน–เหลือง/น้ำตาล) จึงตีความได้ทั้ง "ผ้าสีนี้" หรือ "แสงสีนี้"; คนที่สมมติว่าแสงเย็น (เงา/ฟ้า) หักฟ้าออก → ขาว-ทอง;
  คนที่สมมติแสงอุ่น/สว่าง → น้ำเงิน-ดำ [LaferSousa2015, WitzelGegenfurtner2018]; หมุนสีพิกเซลออกจากแกน daylight (เป็นเขียว/ม่วง) ความเห็นต่างลดลงมาก [WitzelGegenfurtner2018]
- **ใส่ cue แสงที่ชัด** (ใส่ชุดในฉากที่มี global tint ทั้งฉากรวมผิวนางแบบ): ของคนที่เคยเห็นขาว-ทอง 64% เปลี่ยนเป็นน้ำเงิน-ดำใต้แสงอุ่น; ของคนที่เคยเห็นน้ำเงิน-ดำ 80% เปลี่ยนเป็น
  ขาว-ทองใต้แสงเย็น [LaferSousa2015 supplementary]
- ขนาดภาพมีผล: ภาพใหญ่ขึ้น → ตอบ white/gold มากขึ้น (รายละเอียดเนื้อผ้ามากขึ้น); ภาพเบลอ → ลดลง [LaferSousa2015]
- เปลี่ยนได้ด้วย priming แต่เปลี่ยนด้วยความตั้งใจไม่ได้ → การตีความสีเป็น "unconscious inference" [WitzelGegenfurtner2018]

**กฎ DERIVED สำหรับรูปแว่น/เลนส์**
- สินค้าที่สีอยู่บนแกน น้ำเงิน–เหลือง/น้ำตาล (กรอบน้ำเงินกรมท่า, กระดองเต่าน้ำตาล-ทอง, เลนส์ tint น้ำตาล/ฟ้า, เลนส์ blue-cut ที่สะท้อนอมฟ้า) = เสี่ยงตีความต่างกันที่สุด
  → ต้องมี cue แสงที่ไม่กำกวม (เงามีทิศ, ผิวคนในแสงเดียวกัน, วัตถุขาวอ้างอิงในเฟรม)
- tint ที่ใส่ทั้งภาพ (รวมผิวและฉาก) = ผู้ชมอ่านเป็น "แสง"; tint ที่ใส่เฉพาะวัตถุ = อ่านเป็น "สีวัตถุ" — เลือกให้ตรงกับเจตนา
- ตรวจภาพที่ขนาด thumbnail ด้วย เพราะขนาดเปลี่ยนการตีความ

## 6. Memory colour
- วัตถุที่รู้จัก (กล้วย, ผิว, ท้องฟ้า) ถูกเห็นเอียงไปทาง "สีที่จำไว้" — กล้วยที่เป็นเทาแท้ทางสียังดูเหลืองอ่อน; ผลแรงสุดในแกนน้ำเงิน/เหลือง; ช่วยทั้งการจำวัตถุและ constancy
  [WitzelGegenfurtner2018 full_text] · **EVIDENCE**, medium-high
- งานเรา: ผิวคน ใบไม้ ทะเล เป็น "ตัวอ้างอิง" ที่ผู้ชมใช้ตัดสินว่าภาพเพี้ยนไหม → เกรดอะไรก็ได้แต่ **ปกป้องผิว** (ดู Deakins/O Brother ใน `COLOR_SCRIPTING.md`) ·
  ในงานถ่านขาวดำ Mint & Tao (ไม่มีสี) ผู้ชมอาจ "เติมสี" ให้วัตถุที่สีจำง่าย — **HYPOTHESIS** น่าทดลอง

## 7. Helmholtz–Kohlrausch: สีอิ่มดูสว่างกว่าค่าที่วัด
- ที่ luminance เท่ากัน สีที่อิ่มกว่าดูสว่างกว่า; แดงและน้ำเงินดูสว่างกว่าเหลืองและเขียวที่ luminance เท่ากัน (น้ำเงิน > แดงเล็กน้อย); V1 ตอบสนองตาม brightness ไม่ใช่ luminance
  [Corney2009 full_text] · **EVIDENCE**, medium (กลไกยังถกเถียง)
- งานเรา: ตัวอักษรแดง/น้ำเงินสดบนพื้นมืด "ดูอ่านง่าย" แต่ค่า WCAG อาจต่ำ → วัดเสมอ; และ accent น้ำเงินสดใน palette จะดูหนักกว่าที่ L บอก — **DERIVED**

## 8. Size / area effect
- พื้นที่ใหญ่ดูต่างจาก swatch เล็ก (มีงานต่อยอด CAM16 เพื่อชดเชย size effect) [Li2017_CAM16 — follow-up จาก search summary]; ขนาดภาพเปลี่ยนการตีความ #TheDress [LaferSousa2015]
- ช่าง (CRAFT): สีทาผนังที่เลือกจาก chip เล็กมักดูจัดกว่าเมื่อทาทั้งห้อง → เลือกสีพื้นใหญ่ให้ "หม่นกว่าที่ชอบใน swatch" นิดหนึ่ง
- งานเรา: palette ที่ดูดีในตาราง swatch ของ `COLOR_PALETTE_LIBRARY.json` อาจจัดเกินเมื่อเป็นพื้นหลัง 1080×1350 เต็มจอ → ทดสอบที่ขนาดจริง

## 9. Warm / cool และ colour temperature เป็นของสัมพัทธ์
- **Temperature ของแสง** (CCT, K) เป็นค่าวัดได้ของแหล่งแสงที่ใกล้ Planckian locus [McCamy1992]; **warm/cool ของสีพื้นผิว** เป็นความรู้สึก/association —
  แกน warm–cool เป็นหนึ่งในมิติ colour-emotion ที่เสถียรข้ามวัฒนธรรม [Ou2004] แต่การตัดสินว่าสีหนึ่ง "อุ่น" ขึ้นกับสีข้าง ๆ (ม่วงแดงข้างน้ำเงิน = อุ่น, ข้างส้ม = เย็น)
  — **CRAFT** [Albers1963, Itten1961]; ไม่มีหลักฐานแข็งว่า CCT ทำให้คนรู้สึกสบายขึ้นแบบ Kruithof [Fotios2017]
- หลังปรับตัวกับแสงอุ่น (หลอด 2700 K) สักพัก ขาวจะกลับมาดูขาว → "อุ่น" ของแสงรับรู้ชัดที่สุด *ตอนเปลี่ยน* หรือเมื่อเห็นเทียบกับแสงเย็นในเฟรมเดียวกัน (หน้าต่างฟ้าข้างโคมไฟ) —
  **DERIVED** จาก adaptation (§4.1)
- `analyze_image.py` วัด warm/cool แบบ bin hue ตายตัว → ใช้เป็น indicator สัดส่วน ไม่ใช่คำตอบว่าผู้ชมรู้สึกอุ่น

## 10. แบบฝึก/ทดสอบที่ทำได้ใน pipeline ของเรา (ยังไม่ได้ทำ)
1. **Albers swap** (HTML): วางกรอบแว่น cutout เดียวกันบนพื้น 4 สี (เทากลาง, ส้มสด, ฟ้าอ่อน, ดำ) → render → ถามทีมว่ากรอบสีอะไร → จดผล
2. **Cue test**: กรอบน้ำเงินกรมท่าบนพื้นเรียบ vs ในฉากที่มีมือคน + เงา + กระดาษขาว → ทีมระบุสีกรอบ (ใช้ #TheDress logic)
3. **Successive test**: ต่อฉากฟ้า 6 วิ → ฉากกลาง vs ฉากกลางเดี่ยว → ถามว่าฉากกลางอุ่นแค่ไหน
4. **HK test**: ตัวอักษรราคาแดงสด vs เทาที่ luminance เท่ากันบนพื้นเขียว Phthalo → ทีมจัดลำดับความเด่น แล้วเทียบกับ `contrast`
