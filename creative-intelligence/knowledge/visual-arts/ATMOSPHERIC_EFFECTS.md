## 1. ฟิสิกส์พื้นฐาน

**Extinction & in-scattering (EVIDENCE, PBRT4 Volume Scattering):** ตามแนวสายตา แสงจากวัตถุถูกลดลง (absorption + out-scatter,
Beer–Lambert) และ "เติม" ด้วยแสงที่อากาศกระเจิงเข้ามา (in-scatter) → ของไกล = ความคอนทราสต์ลด + สีเข้าหาสีอากาศ

**Rayleigh vs Mie (EVIDENCE, Preetham1999 full text + HyperPhysics_Scattering เดิม):**
- Rayleigh (โมเลกุล < ~0.1λ): extinction ∝ λ⁻⁴ "ยืนยันด้วยการทดลอง" → น้ำเงิน 400 nm กระเจิง "ประมาณ 10 เท่า" ของแดง 700 nm
  (คำนวณ (700/400)⁴ = 9.4) → **ฟ้าสีฟ้า**; แสงแดดที่เหลือจึงเหลือง/ส้ม "โดยเฉพาะเมื่อดวงอาทิตย์ต่ำ เพราะผ่านบรรยากาศยาวขึ้น" → **พระอาทิตย์ตกสีส้ม**
- Mie/haze (อนุภาคใหญ่กว่าความยาวคลื่น — ฝุ่น เกลือ ละอองน้ำ): กระเจิงแทบเท่ากันทุกสี → **haze ขาวขึ้น, ฟ้าใกล้ขอบฟ้าขาว,
  แสงจ้าขาวรอบดวงอาทิตย์**; Mie กระเจิงไปข้างหน้าแรง (forward) → ย้อนแสงแล้วหมอก/ละอองเรืองสว่าง (DERIVED จาก forward scattering ที่แหล่งระบุ "phase function")
- **Turbidity T** = optical thickness (haze+โมเลกุล) / optical thickness (โมเลกุลอย่างเดียว); Preetham จัด T: ~2 ใสมาก, 6 ฟ้าหลัว, 10 overcast
  (ภาพตัวอย่างในเปเปอร์) และโยงกับ **meteorological range** = ระยะที่คอนทราสต์ของเป้าดำต่อฟ้าลดเหลือ 0.02
  → **DERIVED (Koschmieder):** V ≈ 3.912 / σ (เพราะ ln(1/0.02) = 3.912) — ใช้คุม "จำนวนชั้นของภูเขา/เกาะที่มองเห็น" ในฉากทะเล
- Bruneton2008 (abstract): จำลอง Rayleigh+Mie **multiple scattering**, สีฟ้ายามกลางวันและสนธยา, aerial perspective ทุกทิศ,
  "เงาของโลกและภูเขา = light shafts ในบรรยากาศ"

## 2. Aerial perspective (ทัศนียภาพอากาศ)

| field | |
|---|---|
| Definition | ของไกล: คอนทราสต์ลด, ค่าดำยกขึ้น, สีอิ่มลดและเข้าหาสีฟ้า/สีอากาศ, ขอบนุ่มลง |
| Foundation | **Primary text (Leonardo, Richter ed. §295):** ของไกลดูฟ้า "เพราะมีบรรยากาศปริมาณมากระหว่างตากับมัน" — "ถ้าไกลกว่าห้าเท่า ทำให้ฟ้ากว่าห้าเท่า" · **EVIDENCE:** Rayleigh in-scatter + extinction (Preetham1999 ระบุว่า Leonardo สังเกต 3 อย่างที่โมเดลต้องจับ: ฟ้าขาวขึ้นใกล้ขอบฟ้า, aerial perspective หนาขึ้นใกล้พื้น, ของไกลเปลี่ยนเฉด) · **EVIDENCE (perception):** Preetham อ้างนักจิตวิทยาว่า aerial perspective เป็น depth cue พื้นฐาน "และเป็น absolute depth cue เดียวสำหรับวัตถุไกลที่ไม่คุ้นเคย" (อ้างทุติยภูมิ) |
| Leonardo vs ฟิสิกส์ | กฎ "5 เท่าไกล = 5 เท่าฟ้า" เป็นเส้นตรง แต่ฟิสิกส์เป็น exponential (Beer–Lambert) → ระยะใกล้ไล่เร็ว ระยะไกลอิ่มตัวที่สีฟ้าของอากาศ (DERIVED). Leonardo เชื่อว่าอากาศเองไม่ได้สีฟ้า แต่เป็นไอน้ำที่ถูกแดดส่องหน้าฉากมืด — ใกล้เคียงหลัก in-scatter หน้าพื้นมืด (Britannica summary) |
| Practical (เรา) | ฉากทะเลหัวหิน: เขาตะเกียบ/เขาไกรลาส/เกาะ → 3–4 ชั้นค่า: ใกล้ = คอนทราสต์เต็ม, กลาง = ค่าดำยก 20–30%, ไกล = เกือบเป็นสีฟ้า (ค่า % เป็น CRAFT) |
| Correct | ใส่ aerial perspective แม้ในภาพการ์ตูนชาร์โคล: ชั้นหลังใช้เส้นจางและไม่มีดำเข้ม |
| Incorrect | ภูเขาไกลดำเข้มเท่าของใกล้ (ภาพแบน); ทำ haze สีฟ้าทั้งที่ฝุ่นหนา (haze ฝุ่น/เกลือ = ขาว-เทา-น้ำตาล ไม่ใช่ฟ้า) |
| Exceptions | อากาศใสมากหลังฝน (T ≈ 2) ของไกลยังคม; ย้อนแสงตอนเย็น ของไกลอมส้ม/ทองไม่ใช่ฟ้า (Mie forward + แสงแดดที่ถูก Rayleigh กรองแล้ว — DERIVED) |
| Emotional | haze มาก = ฝัน คิดถึง ร้อนชื้น · ใสคม = สดชื่น ชัดเจน (เหมาะโฆษณาเลนส์ "เห็นชัด") |
| Mistakes (AI) | FLUX ชอบใส่ haze ทุกภาพ "cinematic" → ทำให้สินค้าคอนทราสต์ตก; ต้องสั่ง "clear air on the product, haze only in the far background" |
| Sources · conf. | Leonardo_Richter (primary), Preetham1999 (A full), Britannica_AerialPerspective (C summary), Bruneton2008 · **high** |

## 3. Sun rays: crepuscular & anticrepuscular

**EVIDENCE (Atoptics_Crepuscular, full text):** crepuscular rays = ลำแสงแดดผ่านช่องเมฆ สลับกับแถบเงาเมฆ; "ภาพลวงจาก perspective"
— ลำขนานกันจริงแต่ดูแผ่ออก เหมือนร่องไถนา; **anticrepuscular rays** ปรากฏฝั่งฟ้าตรงข้ามดวงอาทิตย์ (ลู่เข้าจุด antisolar);
มองเห็นได้เพราะ "ฝุ่น เกลือ อนุภาคอินทรีย์ ละอองน้ำ และแม้แต่โมเลกุลอากาศ" กระเจิงแสง — อนุภาคมากยิ่งเห็นชัด
Bruneton2008: เงาภูเขาในบรรยากาศ = light shafts

**กฎภาพ (DERIVED):**
1. ลำแสงทุกเส้นต้องลู่เข้าจุดเดียว (ตำแหน่งดวงอาทิตย์ แม้อยู่นอกเฟรม) — ลำที่ขนานกันในภาพมุมกว้างคือผิด perspective
2. ลำแสงสว่าง = อากาศมีอนุภาคตรงนั้น → ต้องมี haze โดยรวมสอดคล้อง (ไม่ใช่ฟ้าใสคมกับลำแสงหนา)
3. ในร้าน: ลำแสงหน้าต่างเห็นได้เมื่อมีฝุ่น/ควัน (ไลบรารีเดิม `volumetric_god_rays`); ใช้เป็น motif "ช่วงเวลาสงบ" ในคลิปพักสายตา
4. หัวหิน: เมฆคิวมูลัสยามบ่ายฤดูฝน + ละอองทะเล = เงื่อนไขดีสำหรับ crepuscular rays เหนือทะเล (DERIVED จากสาเหตุ; ไม่มีข้อมูลความถี่)

## 4. หมอก / mist / haze / smoke / dust

| ปรากฏการณ์ | ฟิสิกส์ | หน้าตา | ป้าย |
|---|---|---|---|
| Haze | ละอองลอย (aerosol) Mie มากกว่าโมเลกุล แต่น้อยกว่าหมอก (Preetham: "haze กระเจิงมากกว่าโมเลกุลแต่น้อยกว่า fog") | ฟ้าขาวขึ้น ของไกลจาง | EVIDENCE |
| Fog / mist | หยดน้ำ (Mie) หนาแน่น; mist บางกว่า | ขาวเทาเท่ากันทุกสี; ทัศนวิสัยสั้น (Preetham Fig.3 "thin fog" อยู่ปลายสุดของสเกล) | EVIDENCE (ระดับนิยามจาก Preetham) |
| Smoke | อนุภาคเล็กมาก → อาจกระเจิงน้ำเงินมากกว่า (ควันบางอมฟ้าเมื่อมองหน้าฉากมืด, อมส้มเมื่อมองผ่านไปหาแสง) | DERIVED จากหลัก Rayleigh กับอนุภาคเล็ก — ยังไม่มีแหล่งเฉพาะรอบนี้ | DERIVED |
| Dust (ฝุ่นในลำแสง) | อนุภาคใหญ่ กระเจิงไปข้างหน้า → เห็นชัดเมื่อย้อนแสง | จุดลอยสว่างในลำแสง ไม่เห็นเมื่อแสงอยู่หลังกล้อง | DERIVED |
| Sea spray (ละอองทะเลหัวหิน) | เกลือทะเลดูดน้ำ (hygroscopic) ในความชื้นสูง → อนุภาคโตขึ้น กระเจิงมากขึ้น; Zieger2017: เกลือทะเลจริงโตน้อยกว่า NaCl บริสุทธิ์ 8–15%, ปรับแล้ว AOD ในโมเดลลดได้ถึง 15%; ความชื้นทะเลถึง 80–90% (search summary) | ชายหาดยามบ่าย: ขอบฟ้าทะเลเป็นแถบขาวนวล เกาะไกลซีด; ย้อนแสงเป็นม่านเรือง | EVIDENCE (กลไก) + DERIVED (หน้าตา) |
| Dry-season haze (ไทย) | biomass burning PM2.5 — ภาคเหนือเกินมาตรฐานทุกปีช่วง ~ม.ค.–เม.ย. (บางงาน พ.ย.–เม.ย. หรือ ก.พ.–พ.ค.) | ฟ้าขาวขุ่นอมเหลือง ดวงอาทิตย์ส้มแดงก่อนตกถึงขอบฟ้า | EVIDENCE (ภาคเหนือ; **ไม่มีข้อมูลหัวหินโดยตรง**) |

## 5. ฝน หิมะ เมฆ

- **Rain (EVIDENCE, GargNayar2007 abstract):** การมองเห็นฝนในภาพขึ้นกับ **exposure time และ depth of field** มาก เพราะหยดฝนเล็ก เร็ว และกระจาย;
  เส้นฝนยาว = เวลาที่หยดค้างบนพิกเซล → **DERIVED:** shutter เร็ว = จุด, shutter ช้า = เส้น; ฝนเห็นชัดสุดเมื่อมีแสงย้อน (back light) เพราะหยดน้ำ
  หักเห/สะท้อนแหล่งแสงตรงหน้า (CRAFT ทั่วไป) · พื้นเปียก = กระจกเงามืด (ดู §6)
- **Snow:** ไม่ใช่เงื่อนไขหัวหิน — ใช้ `snow_bounce` เดิม; หิมะ = กระเจิงสูง ดูดกลืนต่ำ → ขาว (หลักเดียวกับ Hoffman2013 "white = high scattering + low absorption")
- **Clouds:** หยดน้ำ Mie → ขาว/เทา; เมฆหนาเป็นเทาเพราะแสงถูกกระเจิงออกก่อนถึงฐานเมฆ (DERIVED); overcast = softbox ใหญ่ทั้งฟ้า (`overcast_soft` เดิม)

## 6. Water reflections & colour of water

**EVIDENCE:** น้ำ n 1.333, F0 ≈ 2% ที่มุมตั้งฉาก แต่เข้าใกล้ 100% ที่มุมเฉียด (Fresnel; PBRT4/Hoffman2013)
**CRAFT (Gurney2007_WaterReflections, full text):** "โทนสว่างเหนือน้ำ สะท้อนออกมามืดลงเล็กน้อย เพราะแสงบางส่วนทะลุลงน้ำ" ;
น้ำเป็น "กระจกเงาเกือบสมบูรณ์เมื่อมองเฉียดผิวมาก" แต่มองชันลงไปจะเห็นแสงฟ้าสะท้อนน้อย (= เห็นทะลุลงน้ำ)
→ **mapping:** กฎจิตรกร = Fresnel โดยตรง. ข้อเสริมจากแหล่งช่างอื่น: ของมืดสะท้อนออกมาสว่างขึ้นเล็กน้อย (เพราะผิวน้ำสะท้อนฟ้าซ้อนบนภาพนั้น — DERIVED)

**กฎภาพ (DERIVED + CRAFT):**
1. เงาสะท้อนอยู่แนวดิ่งใต้วัตถุ (ผิวน้ำราบ) — กล้องอยู่สูงกว่าน้ำจึงเห็น "ด้านใต้" ของวัตถุในเงาสะท้อน ไม่ใช่สำเนาพลิกกลับเป๊ะ
2. ระลอกคลื่นยืดเงาสะท้อนในแนวดิ่ง (โดยเฉพาะแหล่งแสงจุด เช่น ดวงอาทิตย์/ไฟถนน → เส้นทาง "glitter path" ยาวถึงผู้ดู)
3. **สีน้ำ (EVIDENCE, BraunSmirnov1993):** น้ำดูดกลืนแดงจาก vibrational overtone ของ O–H; สีฟ้าในตัวต้องผ่าน "หลายเมตร" (ท่อ 3 m ส่ง 660 nm ~44%); สีที่เห็นจริงที่ผิวยังรวมสะท้อนฟ้าและการกระเจิงของตะกอน
   → ทะเลหัวหินน้ำตื้นใกล้ฝั่ง: ฟ้า-เขียวจาง + ตะกอนทรายอมเหลือง, ไม่ใช่ฟ้าคราม Maldives (ห้ามแต่งเกินจริงในภาพที่อ้างว่าหัวหิน)
4. ใต้น้ำตื้นแดดแรง → caustic ที่ก้นทะเล (`underwater_caustics` เดิม)

## 7. Golden hour, blue hour, twilight — ที่ละติจูดหัวหิน (~12.6°N)

- ทางการมีแค่ civil/nautical/astronomical twilight (0/−6/−12/−18°) — golden/blue hour ไม่มีนิยามทางการ (R2: USNO_Twilight, TPE)
- **DERIVED (เรขาคณิตทรงกลมฟ้า):** อัตราขึ้น/ลงของดวงอาทิตย์ที่ขอบฟ้า ≈ 15°/ชม. × cos(ละติจูด) × cos(declination)
  → ที่ 12.6°N ช่วงดวงอาทิตย์ 0→6° ใช้ **~25 นาที** (equinox) ถึง **~27 นาที** (solstice); blue hour (−4 ถึง −8°) ก็สั้นพอกัน
  — สอดคล้องกับ Singapore วัดได้ ~24 นาที (GoldenHour_timeanddate, search summary)
  → **วางแผนถ่ายจริง: ได้ราว 2–3 เทคต่อรอบ**; ฉากที่สร้างด้วย AI ไม่มีข้อจำกัดนี้แต่ "แสงทอง + เงายาวมาก" ต้องสอดคล้อง (ดวงอาทิตย์ <10°)
- **พระอาทิตย์ขึ้นจากทะเลที่หัวหิน** (ชายฝั่งหันทิศตะวันออกสู่อ่าวไทย — DERIVED จากภูมิศาสตร์): golden hour ชายหาดคือ **เช้า** ส่วนเย็นแดดอยู่หลังเมือง/เขา

## 8. Moonlight, Purkinje, day-for-night, night lighting

- **EVIDENCE (Purkinje_sources, search summary):** luminous efficiency ของ cone peak 555 nm, rod 507 nm; เมื่อแสงลดลง (mesopic → scotopic)
  แดงดูมืดลง น้ำเงิน/เขียวดูสว่างขึ้นโดยเปรียบเทียบ, สีจางลง; mesopic ราว 0.01–3 cd/m²
- **Moonlight:** จันทร์เต็มดวงให้ ~0.05–0.3 lux (Moonlight_illuminance, search summary; ค่าต่างกันตามแหล่ง) — แสงจันทร์จริงเป็นแสงแดดสะท้อน
  ไม่ได้ฟ้า "ความฟ้าเป็นผลการรับรู้" (Purkinje)
- **Day-for-night (CRAFT/ประวัติ, DayForNight_sources):** ถ่ายกลางวัน underexpose ~2 stop + ย้อมฟ้า; ใช้ฟิลเตอร์อุ่นในช็อตใกล้เพื่อรักษาสีผิว;
  **อย่าให้ฟ้าเข้าเฟรม** (ฟ้าสว่างทำลายภาพลวง); ธรรมเนียมย้อมฟ้ากลางคืนมีตั้งแต่ละครเวทีและหนังเงียบ
  → **mapping:** convention "กลางคืน = ฟ้า" ไม่ใช่ฟิสิกส์ของแสง แต่ตรงกับการรับรู้ Purkinje ของผู้ชม
- **Night lighting (DERIVED จาก Purkinje + curriculum-04):** ambience เย็นจางสีน้อย + practical อุ่นอิ่มเป็นจุด + rim แยกตัว; ลดความอิ่มสีในเงา
  (ไม่ใช่แค่ทำให้มืด) — ร้านแว่นตีสอง EP ใช้ได้ทันที

## 9. หัวหิน — เงื่อนไขเฉพาะ (Hua Hin conditions)

| เงื่อนไข | ฟิสิกส์ | ผลต่อภาพ | ทำอย่างไร |
|---|---|---|---|
| **เที่ยงแดดแรง (harsh noon)** | ละติจูด 12.6°N: ดวงอาทิตย์ผ่านจุดเหนือหัว (declination = 12.6°) สองครั้งต่อปี ราวปลายเมษายนและกลางสิงหาคม (DERIVED จากเรขาคณิต) → เงาใต้คิ้ว/จมูกดำ เงาตกกระทบสั้นมาก; UV สูงสุดช่วงเที่ยงและยิ่งสูงใกล้เส้นศูนย์สูตร (WHO_UVI_2002, summary) | ตาลึกดำ (raccoon eyes), เลนส์สะท้อนฟ้าเต็ม, คอนทราสต์สูงเกิน | หลบเข้า open shade / silk เหนือหัว (setup ใหม่); หรือใช้เป็นสไตล์ "hard summer" ที่ตั้งใจ + แว่นกันแดดคือพระเอก (เรื่องเล่า UV/ต้อเนื้อมีอยู่แล้วใน kit huahin-uv) |
| **Tropical haze + ความชื้นสูง** | Mie จากละอองเกลือ/ไอน้ำ, turbidity สูง (T ~4–8 ประมาณ — DERIVED ไม่มีการวัด) | ฟ้าขาวซีดใกล้ขอบฟ้า, ของไกลจาง, เงาไม่ดำสนิท (sky fill ขาว) | ยอมรับ haze ในฉากหลัง แต่สินค้าต้องคม; เกรดฟ้าให้ฟ้าขึ้นด้านบนเท่านั้น |
| **Sea spray ย้อนแสง** | Mie forward scattering | ม่านเรืองขาว-ทองรอบคน/ขอบฟ้า | back light 150–180° ตอนเช้า |
| **ทรายขาว = reflector** | ทรายแห้งสว่าง (ไม่มีค่าวัดในรอบนี้) | fill จากล่าง ลดเงาใต้คาง, แต่สะท้อนขึ้นบนเลนส์ด้านล่าง | ใช้เป็น fill ฟรี; ระวังขอบล่างเลนส์สว่าง |
| **ฝนฟ้าคะนองบ่าย (ฤดูฝน)** | Cumulonimbus + rain shafts | crepuscular rays, ฟ้าดำ-ทะเลสว่าง (คอนทราสต์ดราม่า) | ใช้กับ story clip; ห้ามใส่ในภาพที่อ้างวันแดดดี |
| **หมอกควันฤดูแล้ง** | biomass burning PM2.5 (หลักฐานภาคเหนือ) | ฟ้าขาวอมเหลือง ดวงอาทิตย์ส้มก่อนแตะขอบฟ้า | อย่าเกรดเป็นฟ้าใส ถ้าภาพสารคดี/อ้างวันที่จริง |

## 10. Environmental colour (สีของสิ่งแวดล้อม)
- แดด (direct) อุ่นขึ้นเมื่อดวงอาทิตย์ต่ำ (Rayleigh กรองน้ำเงินออก) · เงาได้แสงฟ้า → เย็น · พื้น/ผนังให้สีของตัวเองผ่าน GI
- **DERIVED กฎตรวจ:** ในภาพกลางแจ้ง สีเงาต้องเย็นกว่าสีด้านสว่างเสมอ (ยกเว้นเงาที่ได้ bounce จากพื้นอุ่นแรง เช่น ทรายส้ม/ผนังอิฐ)

## 11. Anti-patterns
1. ลำแสงขนานกันในภาพมุมกว้าง / ลำแสงในอากาศใสคม
2. haze สีฟ้าในวันที่ฝุ่นหนา (ควรขาว-เทา-เหลือง); ภูเขาไกลดำเท่าของใกล้
3. เงาสะท้อนบนน้ำสว่างเท่าวัตถุ หรือเป็นสำเนาพลิกเป๊ะทั้งที่กล้องอยู่สูง
4. "golden hour" แต่เงาสั้น (ดวงอาทิตย์สูง) หรือแสงทองยาว 2 ชั่วโมงในเรื่องที่อ้างว่าเป็นหัวหิน
5. กลางคืนที่สีอิ่มจัดทั้งภาพ (ขัด Purkinje) หรือฟ้าสว่างในช็อต day-for-night
6. ทะเลหัวหินแต่งเป็นฟ้าครามใสแบบเกาะทะเลลึก

## 12. Open questions
- หาข้อมูลวัด AOD/visibility ของชายฝั่งอ่าวไทยตะวันตก (Prachuap Khiri Khan) แทนข้อมูลภาคเหนือ
- ตรวจตัวเลข UV index category ของ WHO จากฉบับเต็ม (ลิงก์ archive ล่มในรอบนี้)
- อ่านเรื่อง mirage/heat shimmer จากแหล่งอื่น (ถนนเพชรเกษมกลางวัน, ชายหาดร้อน)
