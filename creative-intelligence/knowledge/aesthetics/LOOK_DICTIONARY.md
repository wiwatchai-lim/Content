# LOOK DICTIONARY — แปลง "คำบรรยายลุค" เป็นสิ่งที่ตรวจได้

ใช้เมื่อ brief/ลูกค้าพูดคำอย่าง "อยากได้ premium", "ดูถูกไป", "รก", "ดู AI" — แปลงเป็น feature ที่วัด/เช็คได้
ก่อนสั่ง prompt หรือก่อนวิจารณ์ภาพ. เป็นความรู้ทั่วไป (ทุกสินค้า ทุกลูกค้า) — ตัวอย่างร้านแว่นเป็นแค่ตัวอย่าง

**ป้าย evidence** (ใช้แบบเดียวกับ `visual-arts/SHAPE_LANGUAGE.md`):
- **EVIDENCE** = มีงานวิจัยรองรับโดยตรง (อ้าง key ใน `sources.json` ของโมดูลนี้ หรือ `../neuroaesthetics/sources.json`)
- **DERIVED** = อนุมานจากงานวิจัย แต่ยังไม่มีใครทดสอบในบริบทนี้
- **CRAFT** = ธรรมเนียมนักออกแบบ (tier D) — ใช้ได้ แต่ห้ามเขียนว่าเป็นข้อเท็จจริงทางวิทยาศาสตร์; ตัวเลขทุกตัวที่ติด CRAFT คือจุดเริ่มต้น ไม่ใช่กฎ

**ตัววัดที่ใช้ซ้ำ** (วัดได้ด้วย `tools/analyze_image.py` ของ ai-visual-artist หรือดูด้วยตา):
- *value key* = ค่าเฉลี่ยความสว่าง (OKLCH L 0–1): low key < 0.35 · mid 0.35–0.65 · high key > 0.65
- *chroma* = ความสด (OKLCH C): neutral < 0.03 · muted 0.03–0.08 · medium 0.08–0.15 · vivid > 0.15
- *hue count* = จำนวนกลุ่ม hue หลักที่กินพื้นที่ > 5%
- *density* = จำนวนองค์ประกอบที่แยกได้ (ตัวอักษรนับเป็นกลุ่ม) + % พื้นที่ว่าง (negative space); proxy เร็ว: ขนาดไฟล์ PNG ที่บีบอัด เทียบระหว่าง variant ขนาดเท่ากัน (r ≈ .95 กับความซับซ้อนที่รับรู้ในงานหนึ่ง `[GucluturkJacobsVanLier2016]`)
- *type* = ตระกูล (serif/sans/rounded/script/mono), น้ำหนัก, ความกว้าง, letter-spacing, จำนวนฟอนต์
- *light* = ทิศ/ความนุ่ม/อุณหภูมิ/contrast ratio ของแสง

**หลักใหญ่ 3 ข้อก่อนใช้ตาราง**
1. คำลุคเป็น **convention ที่เรียนรู้** ไม่ใช่คุณสมบัติในตัวภาพ — white space "แปลว่า" prestige เพราะประวัติศาสตร์ภาพโฆษณา และคนทั่วไปเข้าใจตรงกับครีเอทีฟแม้ไม่รู้ที่มา `[Pracejus2006]` → ต้องเช็คว่ากลุ่มเป้าหมายใช้รหัสเดียวกัน (ตลาดลดราคาไทยอาจอ่านต่าง — ยังไม่มีข้อมูล)
2. ลุคเดียวกันให้ผลต่างตามหมวด: ความเรียบ = premium/บริสุทธิ์ สำหรับของใช้สุขภาพ แต่ไม่ใช่สำหรับของตามใจปาก และไม่ช่วย store brand `[Ton2023]`
3. ความซับซ้อน 2 แบบ: **feature complexity** (รายละเอียดดิบ สี ขอบ ถี่) ลดความสนใจต่อแบรนด์ vs **design complexity** (ไอเดียการจัดวางที่ซับซ้อนแต่มีโครงสร้าง) เพิ่มความสนใจและความชอบ `[Pieters2010]`

## 1. Premium (ดูมีราคา)
| มิติ | feature ที่ตรวจได้ | ป้าย |
|---|---|---|
| spacing | สินค้าหลักมีพื้นที่ว่างรอบตัวมาก (เช่น ≥ 40% ของเฟรมเป็น negative space); ไม่วางสินค้าหลายชิ้นเบียด | EVIDENCE: พื้นที่ว่างรอบสินค้าเพิ่ม aesthetic appeal + prestige `[Sevilla2016]`; white space = prestige `[Pracejus2006]` · ตัวเลข 40% = CRAFT |
| density | องค์ประกอบน้อย (≤ 5 กลุ่ม), ข้อความสั้น, ไม่มี burst/sticker ราคา | DERIVED จาก `[Pieters2010]` `[Ton2023]` |
| palette | hue หลัก 1–2 + neutral; chroma muted–medium; accent จุดเดียว | CRAFT (สอดคล้อง harmony ใน ADVANCED_COLOR_SCIENCE) |
| value key | mid หรือ low key ที่คุม contrast; หรือ high key สะอาด — ไม่ใช่ทุกอย่างสว่างจ้าเท่ากัน | CRAFT |
| type | 1–2 ฟอนต์; น้ำหนัก light–regular; letter-spacing กว้างขึ้นใน headline ตัวพิมพ์ใหญ่ | CRAFT (ใกล้ "delicate" `[OrthMalkewitz2008]`) |
| material/light | วัสดุจริงคมชัด (ขอบโลหะ เงาสะท้อนเลนส์ถูกต้อง), แสงนุ่มทิศเดียว + rim light | CRAFT |
| branding | โลโก้เล็ก/เงียบ | EVIDENCE: ของ luxury ที่โลโก้เงียบราคาสูงกว่า `[Han2010]` |
**พังเมื่อ:** ว่างแต่ไม่มีจุดเด่น (ว่างแบบ "ลืมใส่ของ"), ใช้ในหมวด indulgent/สนุก, ใช้กับแบรนด์ราคาถูกแล้วดูเหมือน "ไม่ลงทุน" `[Ton2023]`, ภาพสินค้าเบลอ/ผิดรูป (premium ยอมไม่ได้เรื่อง technical), ใส่ป้ายราคาแดงตัวโต

## 2. Luxury (หรูระดับสูง)
เหมือน premium แต่เข้มข้นกว่า:
- branding เงียบมากหรือไม่มี — จำแบรนด์ได้จากรูปทรง/วัสดุ; โลโก้ใหญ่ = สัญญาณ "อยากให้คนเห็น" (parvenu) ซึ่งคนวงในอ่านว่าระดับต่ำกว่า · EVIDENCE `[Han2010]`
- negative space สูงมาก, จังหวะช้า (คลิป: ช็อตยาว กล้องเคลื่อนช้า) · DERIVED `[Sevilla2016]` + CRAFT
- palette: neutral ลึก (ดำ ครีม ทอง/โลหะ chroma ต่ำ), low key บ่อย · CRAFT
- type: serif contrast สูง หรือ sans บาง letter-spacing กว้าง · CRAFT
**พังเมื่อ:** ใส่ทองเยอะ/ฟอนต์ script หรูเกิน (อ่านเป็น "พยายามหรู"), โลโก้ซ้ำทั่วภาพ, ส่วนลด/ราคาโต้ง ๆ, กลุ่มเป้าหมายต้องการ "คุ้มค่า" ไม่ใช่ status

## 3. Minimal (มินิมอล)
- density: องค์ประกอบ ≤ 3 กลุ่ม, negative space ≥ 50%, hue ≤ 2 · CRAFT
- order สูง: grid ชัด, alignment, ระยะซ้ำเท่ากัน — order ทำให้ความเรียบอ่านว่า "ตั้งใจ" · DERIVED `[VanGeertWagemans2020]`
- type: sans เรขาคณิต/grotesk, 1 ฟอนต์ 2 น้ำหนัก · CRAFT
- light: แสงนุ่ม เงาเบา หรือ flat · CRAFT
- สื่อ "บริสุทธิ์ ส่วนผสมน้อย" ได้ · EVIDENCE `[Ton2023]`
**พังเมื่อ:** เรียบแต่ไม่มี hierarchy (ทุกอย่างเล็กเท่ากัน), เรียบจนข้อมูลหลักหาย, ความเรียบที่ทำให้ "อ่านยาก" (ความเรียบไม่เท่ากับความง่ายเสมอ `[ReberSchwarzWinkielman2004]`), ใช้กับเรื่องที่ต้องการความอบอุ่น/ความรู้สึก — ได้ความเย็นชา

## 4. Cheap-looking (ดูถูก/ราคาต่ำ) — ใช้เป็น checklist "อาการ"
| อาการ | ทำไมอ่านว่าถูก | ป้าย |
|---|---|---|
| สินค้าหลายชิ้นเบียด ไม่มีพื้นที่ว่าง | พื้นที่ว่างน้อย = ลด appeal/prestige | EVIDENCE (กลับด้าน) `[Sevilla2016]` |
| ราคา/ส่วนลดตัวแดงใหญ่ | สีแดงราคา = รหัส "ประหยัด/ดีล" | EVIDENCE `[Puccinelli2013]` (ผลในผู้ชายชัดสุด) |
| feature complexity สูง: ขอบถี่ สีเยอะ (hue ≥ 5), gradient/เงาตกแต่งหลายชั้น | ลดความสนใจต่อแบรนด์ | EVIDENCE `[Pieters2010]` |
| ฟอนต์หลายแบบ (≥ 3), stroke/outline/เงาตัวอักษรหนา | ไม่ congruent, ไม่มีระบบ | DERIVED `[DoyleBottomley2006]` `[Henderson2004]` + CRAFT |
| โลโก้ใหญ่ซ้ำหลายจุด | brand prominence สูง = สัญญาณระดับ mass/ของก๊อป | DERIVED `[Han2010]` |
| ภาพสินค้าความละเอียดต่ำ, ตัดพื้นมีขอบขาว (halo), แสงไม่เข้ากับฉาก | technical error อ่านเป็น "ไม่ลงทุน" | CRAFT |
| stock/AI ดูทั่วไป ไม่มีของจริง | ลดความสมจริง → ลดความอยากได้ | EVIDENCE (อาหาร) `[Diel2026]` |
**หมายเหตุ:** "ดูถูก" ไม่ใช่ผิดเสมอ — โพสต์โปรลดราคาตั้งใจใช้รหัสดีล; ปัญหาคือ **ใช้ผิดที่** (แบรนด์ที่อยากดู premium)

## 5. Cluttered (รก)
- แยกให้ได้ก่อนว่ารกแบบไหน `[Nadal2010]`: (a) **ธาตุเยอะ** (นับกลุ่ม > 7 · CRAFT), (b) **จัดไม่เป็นระเบียบ** (ไม่มี grid/alignment), (c) **เสียสมดุล** (น้ำหนักภาพเทข้างเดียว)
- ตรวจ thumbnail 150 px: ถ้าตาไม่รู้จะลงที่ไหน = รก · CRAFT (ขั้นตอนใน IMAGE_CRITIQUE_ENGINE)
- ความซับซ้อนสูงลดความชอบแรกเห็นชัดที่สุด (เว็บ 500 ms) `[Reinecke2013]` และ low complexity + typical = ชอบสุดตั้งแต่ 17–50 ms `[Tuch2012]` · EVIDENCE
- แก้: (a) ตัด/รวมกลุ่ม, (b) เพิ่ม order — grid, ซ้ำ, palette จำกัด, (c) ย้ายน้ำหนัก · DERIVED `[VanGeertWagemans2020]`
**พังของการแก้:** ตัดจนเหลือว่างไร้ข้อมูล; ระวังว่ากลุ่มผู้ชมบางกลุ่มชอบความซับซ้อนจริง `[GucluturkJacobsVanLier2016]` (เช่น ตลาดนัด สายสะสม)

## 6. Authentic (จริงใจ/ของจริง)
- มีร่องรอยมนุษย์: มือ กระบวนการ หน้าร้านจริง พนักงานจริง — "ทำด้วยมือ" เพิ่มความน่าดึงดูดเพราะสื่อว่า "มีความรัก" `[Fuchs2015]` · EVIDENCE
- provenance บอกตรง: label "คนทำ" เพิ่มความชอบ/คุณค่า; story + effort ที่รับรู้ได้ขยายผล `[Bellaiche2023]` · EVIDENCE
- ภาพ: แสงที่มีแหล่งจริง (หน้าต่าง หลอดในร้าน), ความไม่สมบูรณ์เล็ก ๆ (รอยใช้ งานไม่จัดเกินไป), สีใกล้ธรรมชาติ chroma ไม่เกิน medium · CRAFT
- ความสมจริงขับความอยากได้ (ภาพอาหาร AI ที่ดูไม่จริง = อยากกินน้อยลง) `[Diel2026]` · EVIDENCE (หมวดอาหาร)
**พังเมื่อ:** "ปลอมความจริง" (ใส่ grain/รอยขีดข่วนลงในภาพ AI แล้วบอกว่าของจริง) — ขัดหลักจริยธรรมและถ้าถูกจับได้เสียความเชื่อใจหนักกว่า; ใช้ภาพบุคคล AI แทนพนักงาน/ผู้ให้บริการจริง (ดู §17)

## 7. Cinematic (แบบภาพยนตร์)
- **value key ต่ำลง + คุม contrast** (หนังร่วมสมัยมืดลงเรื่อย ๆ ใน 75 ปี; dynamic range กว้างให้คุมความสนใจด้วยแสง) `[Cutting2011]` · EVIDENCE (เชิงพรรณนา ไม่ใช่การทดสอบความชอบ)
- ช็อตสั้น + การเคลื่อนไหวมีเหตุผล; ช็อตสั้นมีการเคลื่อนไหวสัดส่วนมากขึ้น `[Cutting2011]` · EVIDENCE (เชิงพรรณนา)
- แสงมีแรงจูงใจ (motivated) ทิศชัด, แยก subject จากฉากด้วยแสง/ระยะชัด; aspect ratio กว้าง/letterbox; ระยะชัดตื้น; color grade แยกโทนผิวกับฉาก · CRAFT
- ลิงก์: `story-clips/_craft/GUIDE.md` และ curriculum บทเลนส์/แสง สำหรับรายละเอียดช่าง
**พังเมื่อ:** มืดจนบนมือถือดูไม่ออก (จอเล็ก แสงรอบตัวสว่าง), teal-orange สำเร็จรูปทุกช็อต, letterbox ในฟีด 9:16 กินพื้นที่ข้อความ, "cinematic" ใน prompt AI ได้ภาพ generic (เลนส์แฟลร์ หมอก) — ระบุแสง/เลนส์/อารมณ์จริงแทน

## 8. Clinical (สะอาดแบบคลินิก)
- high key (L > 0.75), พื้นขาว/เทาอ่อน/ฟ้าอ่อน chroma ต่ำ, แสง flat เงาน้อย, ระยะห่างสม่ำเสมอ, sans เรียบ · CRAFT
- ใช้ได้เมื่อต้องการ "ปลอดภัย ถูกต้อง ไว้ใจได้" (การตรวจตา ผลิตภัณฑ์สุขภาพ)
**พังเมื่อ:** เย็นชา/ห่างเหิน (ไม่มีคน ไม่มีความอบอุ่น), เหมือนโรงพยาบาลที่คนกลัว — เติมสัญญาณมนุษย์ (มือ รอยยิ้ม แสงอุ่นจุดเดียว) · DERIVED `[Fuchs2015]`
**หมายเหตุ:** ไม่พบงานวิจัยตรงเรื่อง "clinical look" ในรอบนี้ — ทั้งหมดเป็น CRAFT

## 9. Scientific (ดูเป็นวิทยาศาสตร์/น่าเชื่อถือแบบข้อมูล)
- ข้อมูลจริง: ตัวเลขมีหน่วยและที่มา, แผนภาพที่อธิบายกลไกจริง, grid ชัด, ฟอนต์ sans/mono ตัวเลขตรงคอลัมน์ (tabular figures), palette จำกัดเพื่อ encode ข้อมูล · CRAFT
- **ห้ามคิดว่าใส่กราฟแล้วน่าเชื่อขึ้น:** งานเดิมอ้างว่ากราฟเล็ก ๆ ไร้สาระเพิ่มความน่าเชื่อ แต่ทำซ้ำ 4 ครั้ง (N = 623) ไม่พบผล; กราฟช่วยความเข้าใจเล็กน้อยเท่านั้น `[DragicevicJansen2018]` · EVIDENCE (replication failure)
**พังเมื่อ:** กราฟประดับ, สูตรที่ไม่มีความหมาย, "ทดสอบทางคลินิก" ที่ไม่มีแหล่ง, ภาพสมอง/neuro-claim (ดู M05 §5)

## 10. Playful (ขี้เล่น)
- รูปทรงโค้งมน, ฟอนต์ rounded — rounded type ถูกจับคู่กับ "หวาน", ชอบมากกว่า และอ่านง่ายกว่า angular `[Velasco2015]` `[VelascoHyndmanSpence2018]` · EVIDENCE; ความชอบเส้นโค้ง → ดู `visual-arts/SHAPE_LANGUAGE.md`
- palette: hue 3–4 สด (chroma medium–vivid) แต่จัดกลุ่ม, high–mid key · CRAFT
- จังหวะไม่สม่ำเสมอแบบตั้งใจ (เอียง กระโดด ขนาดต่างกัน) แต่ยังมี grid ซ่อน · DERIVED `[VanGeertWagemans2020]` (order + variety)
- "contrasting" design สัมพันธ์กับบุคลิก exciting `[OrthMalkewitz2008]` · EVIDENCE (summary)
**พังเมื่อ:** สีสดทุกจุดไม่มี hierarchy (= รก/ถูก), ใช้ในเรื่องจริงจัง (สุขภาพตาที่น่ากังวล), ตัวการ์ตูนเด็กเกินกลุ่มเป้าหมาย

## 11. Modern (ทันสมัย)
- **โมเดิร์น = "ใหม่แต่ยังรับได้"** (MAYA): typical ในหมวด + ความใหม่ 1 จุด `[Hekkert2003]`; ความเป็นต้นแบบอ่านง่าย ชอบเร็ว `[Winkielman2006]` `[Tuch2012]` · EVIDENCE/DERIVED
- ตอนนี้ (2026) ธรรมเนียมนิยม: sans grotesk/geometric, พื้นที่ว่างมาก, palette จำกัด + accent สด 1 สี, มุมโค้งเล็ก, ภาพจริงคุณภาพสูง · CRAFT (เปลี่ยนตามยุค)
**พังเมื่อ:** ไล่เทรนด์จนเหมือนทุกแบรนด์ (typical 100% ไม่มี novelty), หรือใหม่จนคนไม่รู้ว่าเป็นอะไร (novelty ไม่มี coping `[Silvia2005]`); "modern" ล้าสมัยเร็ว — ระบุปีของ reference เสมอ

## 12. Friendly (เป็นมิตร)
- ใบหน้า/คนจริง สบตา ยิ้ม; รูปทรงโค้ง; rounded/humanist sans; สี warm–medium chroma; ภาษาง่าย · CRAFT + EVIDENCE เรื่องความโค้ง/rounded type `[Velasco2015]`
- "sincere" บุคลิก ↔ design แบบ natural `[OrthMalkewitz2008]` · EVIDENCE (summary)
**พังเมื่อ:** ใบหน้า AI ที่สวยเฉลี่ยเกิน (ดู §17), ตัวการ์ตูนยิ้มกว้างในบริบทที่ลูกค้ากังวล (ดูไม่ฟัง)

## 13. Warm (อบอุ่น)
- แสง: อุณหภูมิต่ำ (≈ 2700–3500K), แหล่งแสงจริง (โคม หน้าต่างเย็น), เงานุ่ม; palette hue แดง-ส้ม-เหลือง-น้ำตาล chroma medium; value mid; วัสดุไม้ ผ้า กระดาษ · CRAFT
- อบอุ่นทางอารมณ์ (ไม่ใช่แค่สี): ความผูกพัน/การดูแล, ร่องรอยมือ — "warm feeling in the chest" ของ kama muta มาจาก "ความใกล้ชิดที่เพิ่มขึ้นฉับพลัน" ไม่ใช่จากสีส้ม `[Zickfeld2019]` (ใน M05) `[Fuchs2015]` · EVIDENCE
**พังเมื่อ:** ส้มทั้งภาพ (sepia filter) จนผิวคนดูป่วย/สินค้าเพี้ยนสี — สีสินค้าต้องตรงของจริงเสมอ (product fidelity)

## 14. Editorial (แบบนิตยสาร)
- type-led: headline ใหญ่ contrast ของขนาดสูง (เช่น 1:6+), serif contrast สูงคู่ sans, grid หลายคอลัมน์, ขอบเฟรมตัดภาพกล้าหาญ, พื้นที่ว่างเป็นจังหวะ · CRAFT
- design complexity สูงแต่ feature complexity ต่ำ (ไอเดียซับซ้อน รายละเอียดสะอาด) · DERIVED `[Pieters2010]`
- ภาพถ่ายมีมุมมอง (point of view) ไม่ใช่ภาพสินค้าแบบแคตตาล็อก · CRAFT
**พังเมื่อ:** อ่าน headline ไม่ออกเพราะ "ศิลป์เกิน" ในจอเล็ก, ภาษาไทยตัดคำผิดในบรรทัดแคบ (ดู THAI_TYPOGRAPHY.md ของ ai-visual-artist)

## 15. Elegant (สง่า)
- เส้นบาง โค้งยาวต่อเนื่อง, สัดส่วนยาว, palette จำกัด chroma ต่ำ–กลาง, serif/sans เส้นบาง letter-spacing กว้าง, จังหวะช้า, สมมาตรหรือสมดุลนิ่ง · CRAFT
- ใกล้ "delicate" (muted, sleek) ที่สัมพันธ์กับบุคลิก competent/sophisticated `[OrthMalkewitz2008]` · EVIDENCE (summary)
- สมมาตรเป็นค่าเริ่มที่คนทั่วไปชอบ (implicit) `[Weichselbaum2018]` · EVIDENCE
**พังเมื่อ:** เส้นบางจนหายบนมือถือ/ตัวอักษรไทยบางเกินอ่านไม่ออก, script font ตกแต่งเกิน (= ถูก/งานแต่งงาน)

## 16. Futuristic (อนาคต)
- palette: neutral เย็น (เทา-ฟ้า-ดำ) + accent สดเรืองแสง (cyan, magenta) chroma vivid เฉพาะจุด, low key, แสงเส้น/rim/emissive, วัสดุมันวาว โปร่งแสง, sans เรขาคณิตกว้าง/mono · CRAFT
**พังเมื่อ:** สูตรสำเร็จ "neon + grid + หุ่น" ที่ดู generic/AI ทันที; ขัดกับแบรนด์ที่ต้องการความอบอุ่นหรือความจริงใจ; ไม่พบงานวิจัยตรง — CRAFT ทั้งหมด

## 17. Artificial / "AI-looking" (ดูเป็นภาพ AI)
| สัญญาณ | หลักฐาน | ป้าย |
|---|---|---|
| ใบหน้าเฉลี่ยเกิน สวยเกิน ไม่มีลักษณะเฉพาะ | ใบหน้า AI เฉลี่ยกว่า/จำเพาะน้อยกว่า; ความสวยสูงชี้ไปทาง AI; ผู้ชมแยกไม่ได้และมั่นใจผิด | EVIDENCE `[Miller2023]` (summary) `[NightingaleFarid2022]` |
| ภาพสินค้า/อาหาร "ดูไม่จริง" (มันวาว เรียบ เกิน) | AI อาหารถูกมองว่าสมจริงน้อยกว่า → อยากกินน้อยลง | EVIDENCE `[Diel2026]` |
| ผิวเนียนเกิน, รายละเอียดละลาย, ข้อความปลอม, แว่นงอ/สะพานเกิน, เงาสะท้อนไม่ตรง, แสงทั่วไปไร้ทิศ | ข้อผิดพลาดทางเทคนิคของโมเดล | CRAFT (รายการเต็มใน IMAGE_CRITIQUE_ENGINE §1.11, §3) |
| องค์ประกอบสมมาตรรกแบบ "ทุกอย่างสวยเท่ากัน" ไม่มี hierarchy | feature complexity สูง ไม่มีจุดเด่น | DERIVED `[Pieters2010]` |
**ผลต่อความเชื่อใจ (หลักฐาน):**
- ป้าย "AI สร้าง" ลดความชอบ ความงาม ความลึก และคุณค่า แม้ภาพเหมือนกันทุกพิกเซล; ความรู้สึกว่ามี story/effort ช่วย `[Bellaiche2023]`
- การเปิดเผยว่าใช้ AI ลด trust ต่อโฆษณาและองค์กรโดยเฉลี่ย (มีเส้นทางบวกเล็กน้อยด้วย) `[KoningVoorveld2025]`
- ใบหน้า AI (GAN) ถูกให้คะแนนน่าไว้ใจกว่าเล็กน้อย (4.82 vs 4.48) และแยกไม่ออก (48%) `[NightingaleFarid2022]` → "ดูไม่ออก" ไม่ได้แปลว่า "ไม่ต้องบอก"
**แนวทาง:** ใช้ AI สำหรับฉาก/พื้นหลัง, ใช้ของจริงสำหรับสินค้าและคน (สอดคล้องบ้าน: composite แว่นจริง); เปิดเผยตามกติกาแพลตฟอร์ม (IG AI label) + เล่าเจตนามนุษย์; งานข่าว (secondary) รายงานว่า trust กลับมาเมื่อ "คน/ผู้ให้บริการเป็นภาพจริง ฉากเป็น AI" — ยังไม่ได้อ่านต้นฉบับ จึงเป็น **DERIVED/low**
