# STORY_TEMPLATES — แม่แบบเรื่องเล่าตามความยาว (5 s → 10 min)

ใช้ได้กับทุกสาขา/ลูกค้า ตัวอย่างในวงเล็บเป็นงานของสตูดิโอเท่านั้น
ทฤษฎีและแหล่งอ้างอิง: `README.md` + `sources.json` ในโฟลเดอร์เดียวกัน

> **สำคัญเรื่องเวลา:** ไม่พบงานวิจัยที่กำหนด "วินาทีของ beat" สำหรับคลิปสั้น ทุกเวลาในเอกสารนี้จึงเป็น **CRAFT** (แนวปฏิบัติ ปรับได้) ยกเว้นบรรทัดที่ติดป้าย **SCIENCE** พร้อม key
> เปอร์เซ็นต์คือสัดส่วนของความยาวทั้งหมด ตัวเลขวินาทีคือค่าตัวอย่างที่ปัดแล้ว
> จุดตรวจ hook/retention รายวินาที → `knowledge/audience/RETENTION_REVIEW.md` · ความยาว VO ต้องวัดจากไฟล์ TTS จริง → `knowledge/screenwriting/SCRIPT_CHECKER.md`

---

## 0. หลักที่ใช้ทุกความยาว
1. **เขียน fabula 1 บรรทัดก่อน:** "[ใคร] อยาก [อะไร] แต่ [อุปสรรค] จน [การเปลี่ยนแปลง]" ถ้าเขียนไม่ได้ → อาจไม่ใช่เรื่อง (ดู §11)
2. **เลือกโหมดอารมณ์ 1 อย่าง:** suspense / curiosity / surprise `[BrewerLichtenstein1982]` — SCIENCE (A)
3. **ต้องมี resolution:** ตัดตอนจบทิ้งทำให้คะแนน "เป็นเรื่อง" ตกจาก 5.05 → 2.75 `[BrewerLichtenstein1981]` — SCIENCE (B, การทดลองเดียว)
4. **วาดเส้นอารมณ์:** ค่าเริ่มต้นของ problem-solution = Man in a hole (ลง-ขึ้น) `[Reagan2016]` — รูปมีหลักฐานในนิยาย, การใช้กับคลิป = DERIVED
5. **แบรนด์/CTA หลัง resolution** เพื่อไม่ตัด transportation `[GreenBrock2000]` — กลไก SCIENCE (A), ตำแหน่ง = CRAFT
6. **show อารมณ์, tell ข้อเท็จจริง** (สุขภาพ/ราคา/เงื่อนไขต้องพูดหรือเขียนชัด) — DERIVED จาก `[Mar2021]` `[Dahlstrom2014]`
7. **คาดหวังให้ถูก:** เรื่องเล่าโน้มน้าวเพิ่มขึ้นเล็กน้อยโดยเฉลี่ย (r ≈ .06–.07) และบางครั้งแพ้ `[OKeefeHoeken2021]` `[ShenSheerLi2015]` — SCIENCE (S)

ตัวย่อโครง: **3A** three-act · **F5** Freytag · **SS** Story Spine · **SC** Story Circle · **KSTK** kishōtenketsu · **MIH** Man in a hole · **BA** before/after · **NL** nonlinear (ผลก่อน)

## 1. 5 วินาที — "ภาพเดียวเปลี่ยนสถานะ"
| beat | เวลา (CRAFT) | หน้าที่ |
|---|---|---|
| A สถานะเดิม | 0–1.5 s (~30%) | ปัญหา/ฉากที่จำได้ทันที |
| เหตุ | 1.5–3 s | การกระทำเดียว (ใส่แว่น, เปิดไฟ) |
| B สถานะใหม่ + แบรนด์ | 3–5 s | ผลลัพธ์ ภาพค้างพอให้อ่านโลโก้ |
- **โครงที่เหมาะ:** BA, MIH แบบย่อสุด
- **ข้อควรรู้:** 5 s ไม่มีที่ให้ตัวละครหรือ conflict จริง → เป็น "micro-story" ระดับภาพ ไม่มีงานวิจัยรองรับเฉพาะ (CRAFT)
- **ไม่ควรใช้เรื่องเมื่อ:** bumper/โลโก้/ประกาศ (วันหยุด, ราคา) → ใช้ภาพ+ข้อความตรง

## 2. 8 วินาที — "ปัญหา–หักมุม–คำตอบ"
| beat | เวลา | หน้าที่ |
|---|---|---|
| Hook / ปัญหา | 0–2 s | สถานการณ์ที่คนดูรู้ "ครึ่งหนึ่ง" (curiosity gap — psychology §2.3) |
| Turn | 2–5 s | สิ่งที่เปลี่ยน/เฉลย |
| Payoff + แบรนด์ | 5–8 s | ผลลัพธ์ + โลโก้/ชื่อ |
- **โครง:** BA, NL (ผลก่อนแล้วย้อน), surprise เล็ก ๆ
- **ไม่ควรใช้เมื่อ:** ต้องอธิบายข้อเท็จจริงมากกว่า 1 ข้อ → แยกเป็นหลายคลิป หรือใช้ 15–30 s

## 3. 15 วินาที — "Story Spine แบบย่อ" (ความยาวมาตรฐาน Reels/eye-break)
| beat | เวลา | หน้าที่ |
|---|---|---|
| Once upon a time / Every day | 0–3 s (~20%) | ใคร + ชีวิตปกติ + ปัญหาเห็นทันที |
| But one day | 3–6 s | เหตุกระตุ้น |
| Because of that | 6–11 s | 1–2 ผลต่อเนื่อง (ใช้ "เพราะ" ไม่ใช่ "แล้วก็") |
| Until finally | 11–13.5 s | จุดพีค/เฉลย |
| Ever since then + CTA | 13.5–15 s | สถานะใหม่, แบรนด์ |
- **โครง:** SS `[Adams_StorySpine]`, MIH, KSTK แบบ 4 ช็อต
- **eye-break 15 s:** มักเป็น "guided experience" ไม่ใช่เรื่อง → ใช้โครงคำสั่งทีละขั้น (ดู skill `eye-break-clip`) ไม่ต้องบังคับ conflict
- **ไม่ควรใช้เรื่องเมื่อ:** โชว์สินค้าจากหลายมุมกับเพลง (beat clip) — จังหวะเพลงคือโครง ไม่ใช่เรื่อง

## 4. 30 วินาที — "Man in a hole / Freytag ย่อ"
| beat | เวลา | หน้าที่ |
|---|---|---|
| Exposition + hook | 0–5 s | ตัวละคร + want + ภาพปัญหา |
| Rising action | 5–15 s | อุปสรรคเพิ่ม 2 ขั้น (escalate) |
| Climax / insight | 15–21 s | จุดต่ำสุดหรือการเฉลยข้อเท็จจริง |
| Falling action | 21–26 s | ทางออกทำงาน |
| Resolution + CTA | 26–30 s | ชีวิตใหม่ + แบรนด์ + 1 การกระทำ |
- **โครง:** MIH `[Reagan2016]`, F5 `[Freytag1900]`; โฆษณาที่ครบ 5 ส่วนได้คะแนนชอบสูงกว่า `[QuesenberryCoolsen2014]` — SCIENCE (A, correlational, Super Bowl 30–60 s)
- **อารมณ์บวกต้นคลิป** ช่วยให้ดูต่อในโฆษณา 30 s `[Teixeira2012]` — SCIENCE (A, lab)
- **ไม่ควรใช้เรื่องเมื่อ:** โปรโมชันที่ข้อมูลหลักคือราคา/วันหมดเขต — ใช้ offer-first (ดู `marketing/CONTENT_TYPES.md`)

## 5. 45 วินาที — "Three-act พร้อมข้อเท็จจริงกลางเรื่อง"
| beat | เวลา | หน้าที่ |
|---|---|---|
| Act 1: hook + setup | 0–9 s (~20%) | ปัญหาในชีวิต + setup ของสิ่งที่จะ payoff |
| Inciting incident | 9–12 s | เหตุที่ทำให้ต้องทำอะไรสักอย่าง |
| Act 2a: พยายาม/ล้มเหลว | 12–24 s | วิธีผิด ๆ ที่คนดูก็เคยทำ |
| Midpoint fact | 24–30 s | ข้อเท็จจริงที่ตรวจแล้ว 1 ข้อ (tell ชัด) |
| Act 2b → climax | 30–38 s | ใช้ความรู้ใหม่ |
| Act 3: payoff + CTA | 38–45 s | payoff ของ setup + 1 CTA |
- **โครง:** 3A, MIH, SS เต็ม
- **ไม่ควรใช้เรื่องเมื่อ:** ไม่มีข้อเท็จจริงหรือการเปลี่ยนแปลงจริง — เรื่องจะยืด ให้ตัดเหลือ 15–30 s

## 6. 60 วินาที — "Story Spine เต็ม / Freytag เต็ม"
| beat | เวลา | หน้าที่ |
|---|---|---|
| Hook (ผลก่อนหรือคำถาม) | 0–5 s | curiosity |
| Setup ชีวิตปกติ | 5–12 s | ตัวละคร + want + setup |
| Inciting | 12–17 s | |
| Escalation ×2–3 | 17–38 s | "because of that" แต่ละขั้นแรงขึ้น |
| Climax | 38–46 s | จุดพีค (peak) |
| Resolution | 46–54 s | payoff + ความหมาย |
| End card / CTA | 54–60 s | ตอนจบอบอุ่น — ตอนจบมีน้ำหนักในความทรงจำ (peak-end, psychology README §2.2) |
- **โครง:** SS, F5, MIH, Cinderella (ขึ้น-ลง-ขึ้น) ถ้ามี twist
- **ไม่ควรใช้เรื่องเมื่อ:** tutorial ทีละขั้น (เช่นวิธีทำความสะอาดเลนส์) → โครง "ปัญหา → ขั้น 1-2-3 → ผล" ดีกว่า; เรื่องเล่าใช้เป็นแค่กรอบเปิด-ปิด

## 7. 90 วินาที — "Freytag + B-story"
| beat | เวลา | หน้าที่ |
|---|---|---|
| Cold open / hook | 0–8 s | ฉากกลางเหตุการณ์ (in medias res) |
| Exposition | 8–20 s | ย้อนบอกใคร/อะไร |
| Rising (A-story + B-story ความสัมพันธ์) | 20–55 s | 3 ขั้น escalate |
| Climax | 55–68 s | |
| Falling / reveal | 68–80 s | |
| Denouement + CTA | 80–90 s | |
- **โครง:** F5, 3A, NL (cold open), Icarus/Oedipus ถ้าเป็นเรื่องเตือนใจ
- **ไม่ควรใช้เรื่องเมื่อ:** ผู้ชมต้องการข้อมูลเปรียบเทียบ (สเปกเลนส์ A vs B) → ใช้ตาราง/explainer

## 8. 3 นาที — "Story Circle ฉบับสั้น"
| ขั้น (SC) | เวลา | |
|---|---|---|
| 1 You (โซนสบาย) | 0–15 s | hook + ตัวละคร |
| 2 Need | 15–30 s | |
| 3 Go | 30–50 s | ข้ามเข้าสถานการณ์ใหม่ |
| 4 Search | 50–85 s | ปรับตัว/ล้มเหลว |
| 5 Find | 85–110 s | ได้สิ่งที่อยาก |
| 6 Take | 110–135 s | ราคาที่ต้องจ่าย |
| 7 Return | 135–160 s | |
| 8 Change | 160–180 s | ตัวละครเปลี่ยน + ความหมาย/CTA |
- **โครง:** SC `[Harmon_StoryCircle]`, 3A, documentary participatory (สัมภาษณ์ + B-roll) `[Nichols2001]`
- **ไม่ควรใช้เรื่องเมื่อ:** ไม่มีตัวละครที่เปลี่ยนจริง → ทำ explainer แบบ expository แทน

## 9. 5 นาที — "Three-act เต็ม + sequence"
| ส่วน | เวลา | |
|---|---|---|
| Act 1 (hook, setup, inciting ≈ 25%) | 0:00–1:15 | inciting ประมาณ 0:30–0:45 |
| Act 2a (พยายาม, ตัวละครรอง) | 1:15–2:30 | |
| Midpoint (พลิก/เปิดเผย) | ~2:30 | |
| Act 2b (แย่ลง → จุดต่ำสุด) | 2:30–3:45 | |
| Act 3 (climax, resolution) | 3:45–4:40 | |
| Coda / CTA | 4:40–5:00 | |
- **โครง:** 3A, SC, Hero's Journey ย่อ (ไม่ต้องครบ 17 ขั้น — Campbell ถูกวิจารณ์ว่าไม่สากล `[Dundes2005]`)
- **Documentary:** observational + participatory ผสม `[Nichols2001]`
- **ไม่ควรใช้เรื่องเมื่อ:** เป็นการบรรยายสด/Q&A — ใช้โครงคำถาม-คำตอบ

## 10. 10 นาที — "ตอนซีรีส์: A/B story + Story Circle"
| ส่วน | เวลา | |
|---|---|---|
| Cold open | 0:00–0:45 | hook + คำถามหลักของตอน |
| Act 1 | 0:45–2:30 | |
| Act 2 (escalate 3 ครั้ง, B-story) | 2:30–7:00 | midpoint ~5:00 |
| Act 3 | 7:00–9:15 | climax + resolution ของตอน |
| Tag / ปมตอนหน้า | 9:15–10:00 | cliffhanger ได้ **เฉพาะ** ถ้าตอนหน้ามีจริง |
- **โครง:** SC ต่อตอน + ปมใหญ่ข้ามตอน; KSTK ทั้งตอนได้ถ้าเป็นแนวชีวิตประจำวัน `[Oh2025]`
- **วิดีโอให้ความรู้ 10 min:** narrative ช่วยเข้าใจ/จำ g ≈ .55 `[Mar2021]` — SCIENCE (S) แต่แบ่งเป็น segment และสรุปข้อเท็จจริงชัดท้ายแต่ละ segment (DERIVED)
- **ไม่ควรใช้เรื่องเมื่อ:** คอร์ส/สาธิตเทคนิค ที่ผู้ชมกระโดดหาเฉพาะส่วน → chapter + expository

## 11. เมื่อไร **ไม่ควร** ใช้เรื่องเล่า (ทุกความยาว)
| สถานการณ์ | ใช้อะไรแทน | เหตุผล |
|---|---|---|
| ประกาศ (วันหยุดร้าน, เปลี่ยนเวลา) | ข้อความตรง + ภาพ | ผู้ชมต้องการข้อมูลเร็ว (CRAFT) |
| ราคา/โปร/เงื่อนไข | offer-first | ความชัดเจนสำคัญกว่า transportation; ผลโน้มน้าวของ narrative เล็กอยู่แล้ว `[OKeefeHoeken2021]` |
| ข้อมูลทางการแพทย์ที่ต้องแม่นยำ (ขนาด, ความเสี่ยง) | plain language + ตัวเลขแบบ natural frequency (M14) | เรื่องเล่าแพร่ข้อมูลผิดได้ `[Dahlstrom2014]` |
| โชว์ความงามของสินค้ากับเพลง | beat/montage | จังหวะเพลงคือโครง |
| ข้อความ "เลิกทำ X" | ข้อเท็จจริง + ทางเลือกใหม่ | narrative แบบ cessation ไม่พบผลมีนัยสำคัญ `[ShenSheerLi2015]` |
| tutorial ทีละขั้น | step list | ผู้ชมต้องย้อนดูได้ (CRAFT) |
| ไม่มีการเปลี่ยนแปลงจริงให้เล่า | explainer | เรื่องปลอม = clickbait/ไม่จริงใจ |
| เรื่องที่อาจถูกเข้าใจว่าเป็นลูกค้าจริงแต่แต่งขึ้น | ระบุว่าเป็นการจำลอง หรือไม่ทำ | จริยธรรม/กฎโฆษณา (`marketing/ETHICS_AND_THAI_AD_RULES.md`) |

## 12. Checklist ก่อนส่งบท (ใช้คู่กับ M14 SCRIPT_CHECKER)
- [ ] เขียน fabula 1 บรรทัดได้
- [ ] ตัวละครมี want ใน 20% แรก
- [ ] เลือกโหมด suspense/curiosity/surprise ชัด
- [ ] ทุก payoff มี setup และทุก setup ถูกใช้
- [ ] มี resolution (หรือ cliffhanger + ตอนต่อไปมีจริง)
- [ ] ข้อเท็จจริงถูก "tell" ชัดและตรวจแล้ว
- [ ] แบรนด์/CTA ไม่ขัดจังหวะกลางเรื่อง
- [ ] ความยาวจริงของ VO วัดจากไฟล์ TTS แล้วพอดีกับ beat (ปรับเวลา beat ตามเสียงจริง ไม่ใช่กลับกัน)
