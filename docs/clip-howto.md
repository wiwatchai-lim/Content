# ทำคลิปแว่นแบบคลิปเรฟ (cinematic 9:16)

แบ่งงานกัน: Claude เตรียมข้อมูลและตัดต่อ ส่วนคุณกดใน CapCut แค่ขั้นที่ทำให้รูปขยับ
คลิปเรฟอยู่ที่ `refs/clips/1-cinematic/`

## 1. สุ่มแว่น (Claude)
พิมพ์ "สุ่มแว่น" จะได้โฟลเดอร์ `kits/<วันที่>_<รุ่น>/` ใน `kit.md` มี
- prompt รูปฉาก **C1 C2 C3** (ฉากเดียวกัน 3 มุม แนวตั้ง ไม่มีตัวอักษร)
- prompt วิดีโอ **V** สำหรับ CapCut (คลิปเดียว 10 วินาที)

## 2. ทำรูปฉากด้วย Codex (Claude ทำให้ หรือคุณรันเอง)
- พิมพ์ "ทำรูป C ให้หน่อย" Claude จะถามก่อน แล้วรัน Codex 3 รูป (ใช้โควตา ChatGPT)
- รันเองก็ได้ ใช้คำสั่งท้าย `kit.md`
- รูปที่ได้เก็บไว้ที่ `gen/C1.png` `gen/C2.png` `gen/C3.png`
- ดูรูปทุกครั้ง: ถ้าแว่นเปลี่ยนทรง สีไม่ตรง หรือมีตัวอักษรโผล่ ให้ทำใหม่

## 3. ทำคลิปใน CapCut (คุณทำ ครั้งเดียว)
ใช้ CapCut Pro บนคอม โมเดล **Seedance 2.5** ได้คลิปเดียวยาว 10 วินาทีจาก 3 รูป
1. เปิด CapCut แล้วไปที่ AI video / Image to video
2. ตั้งค่าแนวตั้ง **9:16** ยาว **10 วินาที** ปิดเสียงที่ AI สร้าง (ถ้ามีให้เลือก)
3. ใส่รูป
   - ใส่รูปอ้างอิงได้หลายรูป: ใส่ C1 C2 C3 ตามลำดับ แล้วก๊อป **V แบบ A** จาก `kit.md`
   - ใส่ได้แค่เฟรมแรกกับเฟรมสุดท้าย: C1 เป็นเฟรมแรก C3 เป็นเฟรมสุดท้าย แล้วก๊อป **V แบบ B**
4. กดสร้าง ดูคลิป ถ้าแว่นบิด ทรงเปลี่ยน หรือมีตัวอักษร ให้สร้างใหม่
5. ส่งออกเป็น MP4 ตั้งชื่อ `V.mp4` แล้ววางไว้ใน `kits/<ชื่อ kit>/gen/`

## 4. ตัดต่อ (Claude)
พิมพ์ "ตัดคลิปให้หน่อย" Claude จะ
- ใส่ข้อความ แบรนด์ × เลนส์ ชื่อเลนส์ รุ่นแว่น และโลโก้ TIMEOPTIC
- ส่งออกเป็น `kits/<ชื่อ kit>/export/clip.mp4` ขนาด 1080×1920 ยาว 10 วินาที มีเฟดเข้าออกแบบคลิปเรฟ

คลิปที่ได้ยังไม่มีเพลง ถ้าจะใส่เพลง ให้เปิดไฟล์นี้ใน CapCut แล้วใช้เพลงจากคลังของ CapCut (ใช้ได้ถูกลิขสิทธิ์) จากนั้นส่งออกเพื่อโพสต์

ไม่มีเวลาทำขั้น 3 ก็บอก Claude ได้ว่า "ทำ 2.5D แทน" Claude จะทำให้รูป C ขยับเองแบบกล้องเคลื่อน ฟรีไม่เสียเครดิต แต่แว่นจะหมุนไม่ได้
