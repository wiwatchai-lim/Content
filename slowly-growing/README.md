## ลายเส้น (ใส่ใน prompt ทุกภาพแล้ว)
ดินสอกราไฟต์ละเอียดบนกระดาษครีมเก่า · beige / warm gray / charcoal / muted brown · ไม่มีตัวหนังสือในภาพ · เว้นที่ว่างด้านบน 1/3 สำหรับข้อความ

**เคล็ดลับให้ตัวละครเหมือนเดิมทุกเรื่อง:** พอได้ภาพ EP01 ที่ชอบแล้ว ให้แนบภาพนั้นเป็นภาพอ้างอิง (`-i` ใน Codex / image reference ในเครื่องมืออื่น) ทุกครั้งที่สร้างเรื่องถัดไป แล้วเติมว่า *"Keep the same two characters and drawing style as the reference image."*

## สูตรคลิป (20 วินาที)
| ช่วง | ภาพ | ข้อความ |
|---|---|---|
| 0–6 วิ | ภาพกว้าง เปิดฉาก | ประโยคคนแรกเฟดขึ้น |
| 6–13 วิ | ขยับเข้าหาตัวละคร | ประโยคคนที่สองเฟดขึ้นใต้ประโยคแรก |
| 13–20 วิ | ภาพปิด ค้างไว้ | ข้อความค้าง แล้วเฟดออกพร้อมภาพ |

- ข้อความ: ฟอนต์ไทยลายมือ/เรียบ ๆ สีชาร์โคล บนพื้นที่ว่างด้านบน ไม่มีกรอบคำพูด
- เพลง: เปียโนเบา ๆ + เสียงธรรมชาติตามเรื่อง ไม่มี transition ฉูดฉาด
- วิดีโอจากภาพได้ครั้งละ ~5 วิ → ทำ 3–4 ช็อตจากภาพเดียว (ซูมช้า/แพนช้า) หรือ loop ช้า ๆ
