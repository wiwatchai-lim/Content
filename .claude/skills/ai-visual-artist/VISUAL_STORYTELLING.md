# Visual Storytelling

Every image must *do* something in the story — reveal, build, turn, resolve — not just decorate. Sources: research/R3
(McCloud1993, Eisner2008, Block2008, Mascelli1965, Lynch1960) and the project's own craft guide
(`story-clips/_craft/GUIDE.md`, curriculum 08-storyboard). [craft] = practice.

## 2. Shot grammar
- **Shot size by intimacy:** establishing/wide = where & who; medium = interaction; close-up = emotion; insert = the object that matters (the bird, the glasses) [Mascelli1965; curriculum-08].
- **Angle by power:** low = strong/heroic; high = small/vulnerable; eye level = equal; POV = identification [Mascelli1965; craft].
- **Screen direction:** keep characters on the same sides across a sequence (180° rule); hooded friend left, coat friend right in this series.
- **Contrast vs affinity:** rising tension → more tonal/colour contrast, more diagonals, smaller shot sizes; resolution → affinity, horizontals, wider [Block2008].

## 3. Sequences (carousel, comic strip, storyboard)
- **Transitions (McCloud):** moment-to-moment (slow time), action-to-action (plot), subject-to-subject (within a scene), scene-to-scene (time/space jump), aspect-to-aspect (mood, no time passing), non-sequitur. Choose on purpose; leave gaps for closure [McCloud1993].
- **Colour script:** plan the palette per frame across the story (e.g. cool worry → warm relief at the turning point).
- **Rhythm of shot sizes:** vary; don't repeat the same medium shot five times.
- **Anchors:** same props, landmark and character signature features in every frame (Gestalt similarity) [Wagemans2012].
- **Carousel structure:** slide 1 hook (question or striking image), middle builds, turning point second-to-last, last = resolution/CTA.
- **Comic panel:** one action per panel; speech bubbles in the HTML layer, placed in reading order (left→right, top→bottom), tails pointing to the speaker's mouth; leave negative space for them in the plate [Eisner2008; craft].

## 4. Single images that tell a story
Show a *moment before or after* the climax (the viewer completes the story); include cause and effect in one frame
(the fallen nest and the bird; the cracked lens and the letter); use environment as storytelling (props, wear,
light from a specific time of day) [craft].

## 5. Environments in stories
Give each recurring location one memorable landmark and a clear spatial edge so viewers stay oriented across cuts
[Lynch1960]; add scale cues (people, doors, glasses on a counter) [craft] → ENVIRONMENT_DESIGN.md.

## 6. Output types
| type | what to deliver |

| cinematic frame | 16:9 / 2.39:1, lens & light stated, colour grade intent |

| key visual | one strong image + type-safe area + versions per format |
