# EP02 — รถในความมืด (follows EP01's end card)

Thai only. Same look and pipeline as EP01 (see ../README.md). 84 s.
Science: a lit cabin turns the windows into mirrors (you see yourself, outside sees you); a day/night rear-view mirror's tab tilts the prism
so only the front glass reflects (~4% vs ~80%); with oncoming high beams look at the left edge line (left-hand traffic);
glare recovery takes seconds — 80 km/h ≈ 22 m/s, so 2 s ≈ 44 m driven blind.

Lines: see audio/tts_all.py (18 lines). This take read every pause alike, so audio/split.py groups phrases by count (PHRASES).
