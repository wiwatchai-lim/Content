# เกมทดสอบสายตา (TikTok)

คลิปแนวตั้ง 1080×1920 แยกโฟลเดอร์ละเกม ในแต่ละโฟลเดอร์มี
- `export/clip.mp4` คลิปพร้อมลง (ใส่เพลงเองตอนลง TikTok)
- `caption.txt` แคปชั่น + แฮชแท็ก · `answer.txt` เฉลย
- `make.mjs` ตัวสร้าง `clip.html` (ส่วนกลางอยู่ที่ `_lib/clip.mjs`)

| โฟลเดอร์ | เกม | ยาว |
|---|---|---|
| `01-find-the-6` | หาเลข 6 · 3 ด่าน (5→4→3 วิ, ด่าน 3 มีเลข 9/5/0 ปน) | 27.8 วิ |
| `02-odd-glasses` | หาแว่นที่ต่าง 3 ด่าน: เลนส์กลม → มุมเลนส์มนกว่า → สะพานคู่ (6/5/4 วิ) | 30.8 วิ |
| `03-same-color` | สีเดียวกันไหม 3 ด่าน: ไล่สี (ใช่) → หมากรุก+เงา (ใช่) → ลายทาง White's (ไม่ใช่ ด่านหักมุม) (5/4/3 วิ) | 27.8 วิ |
| `04-count-black-dots` | นับจุดดำบนตารางลวงตา 3 ด่าน: 3 → 5 → 6 จุด ตารางถี่ขึ้น (6/5/4 วิ) | 30.8 วิ |
| `05-odd-letter` | 3 เลเวล: Q ใน O (5 วิ) → 8 ใน B (4 วิ) → rn ใน m (4 วิ) | 28.8 วิ |
| `06-follow-the-line` | 3 เลเวล: ตามเส้น 3 เส้น (5 วิ) → 5 เส้น (6 วิ) → 7 เส้น (6 วิ) | 32.8 วิ |
| `07-hidden-animal` | ทดสอบตาบอดสี 3 เลเวล (จุดสีแบบ Ishihara): ปลา ส้ม/ฟ้า (6 วิ) → กระต่าย แดง/เขียว (5 วิ) → แมว สีใกล้กัน (5 วิ) · คลิปชุดเพิ่มใน `plates/` · ข้อเดี่ยวแบบลายเส้นอีก 10 ตัวใน `puzzles/` | 31.8 วิ |
| `08-count-triangles` | นับสามเหลี่ยม 3 เลเวล: 8 → 18 → 35 รูป (นับด้วยสคริปต์) | 36.8 วิ |
| `09-spot-the-difference` | แว่นสองอันต่างกัน 3 เลเวล: 3 → 4 → 5 จุด (7/6/5 วิ, ด่าน 3 แว่น B เอียง) สุ่มจุดต่างใหม่ทุกคลิป · คลิปชุดเพิ่มใน `series/` | 33.8 วิ |
| `10-hidden-number` | เลขซ่อนในลายเส้น 3 เลเวล: 73 → 58 (จางลง) → 264 | 33.8 วิ |

`hidden-letter/` คือชุดหาตัวอักษร 10 ข้อที่ทำไว้ก่อน

## ทำข้อใหม่ (สุ่มตำแหน่งใหม่)
```
node games/01-find-the-6/make.mjs <seed อะไรก็ได้>     # เกม 10 ใส่ตัวเลข 3 ชุดแทน seed เช่น 47 61 385
npm run video -- games/01-find-the-6
```

## จับผิดภาพแว่นเพิ่ม (สุ่มจุดต่างใหม่)
```
node games/09-spot-the-difference/make.mjs series 5 <seed>   # 5 คลิปใหม่ใน series/ เลขต่อจากของเดิม
npm run video -- games/09-spot-the-difference/series/06       # เรนเดอร์ (ใส่หลายโฟลเดอร์ได้)
```

## ทดสอบตาบอดสีเพิ่ม (คลิป 3 ด่าน สัตว์/สีสุ่มใหม่)
```
node games/07-hidden-animal/make.mjs plates 5 <seed>     # 5 คลิปใหม่ใน plates/ เลขต่อจากของเดิม
npm run video -- games/07-hidden-animal/plates/07_cat-fish-duck   # เรนเดอร์ (ใส่หลายโฟลเดอร์ได้)
```
สัตว์แบบตัวหนาสำหรับจุดสี (9 ตัว: cat fish rabbit elephant turtle duck butterfly snail bird) อยู่ใน `PLATE_ANIMALS` ใน `animals.mjs`

## หาสัตว์เพิ่ม (แบบลายเส้นหญ้า ข้อเดี่ยว)
```
node games/07-hidden-animal/make.mjs 10 <seed>          # สุ่มสัตว์/ตำแหน่งใหม่ เลขต่อจากของเดิมใน puzzles/
npm run video -- games/07-hidden-animal/puzzles/11_owl   # เรนเดอร์ (ใส่หลายโฟลเดอร์ได้)
```
รูปสัตว์อยู่ใน `games/07-hidden-animal/animals.mjs` (มี 10 ตัว ถ้าสั่งเกิน 10 จะวนซ้ำแต่ตำแหน่ง/ทิศใหม่)
