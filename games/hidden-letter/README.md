# เกมหาตัวอักษรที่ซ่อนอยู่ (TikTok)

คลิปแนวตั้ง 1080×1920 ยาว 14 วิ: ตารางตัวอักษรเต็มจอ มีตัวต่างซ่อนอยู่ 1 ตัว → นับถอยหลัง 10 วิ → วงเฉลยสีแดง + บอกแถว/คอลัมน์
ยากขึ้นตามเลเวล 1–5 (ตารางใหญ่ขึ้น ตัวอักษรเหมือนกันมากขึ้น)

- `puzzles/<เลข>_<ตัวที่ต้องหา>-in-<ตัวหลอก>/export/clip.mp4` — คลิปพร้อมลง
- `.../caption.txt` — แคปชั่น + แฮชแท็ก
- `answers.txt` — เฉลยทุกข้อ
- ใส่เพลงเองตอนลง TikTok

## สร้างชุดใหม่ (สั่ง Claude: "ทำเกมหาตัวอักษรเพิ่ม 10 ข้อ")
```
node games/hidden-letter/make.mjs 10            # สุ่มชุดใหม่ เลขต่อจากของเดิม
npm run video -- games/hidden-letter/puzzles/11_X-in-Y   # เรนเดอร์ทีละโฟลเดอร์ (ใส่หลายโฟลเดอร์ได้)
```
