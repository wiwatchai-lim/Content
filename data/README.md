# Data

## frames/
- `frames-stock-*.csv` — รายการกรอบในสต็อก (Brand, Model)
- `images/<Brand>/<Model>_1.jpg` — รูปกรอบ `_1` ด้านหน้า, `_2` มุมเอียง, `_3` ด้านข้าง
- ชื่อรุ่นที่มี `/` (เช่น `REILLY/G 807`, `ADALYN/G 06J`) ให้เปลี่ยนเป็น `-` ในชื่อไฟล์ → `REILLY-G 807_1.jpg` เพราะ Windows ใส่ `/` ในชื่อไฟล์ไม่ได้ ห้ามสร้างโฟลเดอร์ซ้อนแทน
- ความละเอียดต้องพอกับ**ความกว้างที่สไตล์เอาไปวางจริง** ห้ามขยายเกินขนาดไฟล์ · รูปจากร้านส่วนใหญ่กว้าง 980px ซึ่งคมพอสำหรับสไตล์ที่วางแว่นกลางภาพ (680-880px) แต่จะเบลอกับสไตล์ที่ให้แว่นล้นขอบอย่าง `2-titanium-center` (1480px) ต้องหารูป 1500px ขึ้นไป · ต่ำกว่า ~600px ใช้ไม่ได้กับสไตล์ไหนเลย ให้บันทึก `ข้อมูลไม่พอ`
- `images/_check/*.csv` — ผลตรวจรูป: `ยืนยัน` (รุ่น + สีตรง), `รุ่นตรง สีต่าง`, `ไม่แน่ใจ`, `ไม่พบ`, `ข้อมูลไม่พอ` พร้อมลิงก์ที่มา

มีรูปถ่ายเองจากร้าน ใส่ทับชื่อไฟล์เดิมได้เลย

## lenses/ และ coatings/
ไฟล์ละ 1 ยี่ห้อ (`hoya.md`, `zeiss.md`, `shamir.md`, `essilor.md`) ข้อมูลจากเว็บผู้ผลิต มีลิงก์ที่มาทุกรายการ

เลนส์กับ coating ต้องยี่ห้อเดียวกันเสมอ และต้องเป็นรุ่นที่ใช้ด้วยกันได้ — ดูบรรทัด `ใช้คู่กับ` ในรายการเลนส์ก่อน ถ้าไม่มีให้ดูบรรทัด `ใช้คู่กับ` ของ coating
