## Shamir Glacier Expression™
- ประเภท: anti-reflective (AR) พรีเมียม (มีในเว็บ Shamir ไทย)
- จุดเด่น: ผู้ผลิตระบุว่าลดแสงสะท้อนหน้าเลนส์ได้สูงสุด 70% เทียบกับเลนส์เคลือบ AR มาตรฐานของ Shamir; เพิ่ม contrast sensitivity 25%; ผู้ผลิตระบุว่าผู้สวมใส่ราวครึ่งหนึ่งมีปฏิกิริยาตอบสนอง (reaction time) เร็วขึ้น; มีคุณสมบัติกันน้ำ (hydrophobic) กันไฟฟ้าสถิต (anti-static) ทนรอยขีดข่วน และป้องกัน UV ในตัว ด้วยเทคโนโลยี LayerCalc™
- เหมาะกับ: ผู้ใช้อุปกรณ์ดิจิทัล คนขับรถ (โดยเฉพาะกลางคืน) และผู้ต้องการเลนส์เคลือบพรีเมียมทั้งด้านความสวยงามและการมองเห็น
- ที่มา: https://shamir.com/for-professionals/lenses_and_more/shamir-glacier-expression/ , https://shamir.com/us/for-professionals/blog/get-selfie-ready-with-shamirs-glacier-expression-lens-coating/

## Shamir Glacier Sun UV™
- ประเภท: anti-reflective + UV สำหรับเลนส์กันแดด/โฟโตโครมิก (มีในเว็บ Shamir ไทย; เว็บ US ใช้ชื่อ "Glacier Sun™")
- จุดเด่น: ลดแสงแดดที่สะท้อนจากผิวเลนส์ด้านหลังเข้าตา; คงสีเลนส์ไว้แบบ achromatic ไม่ทำให้สีเพี้ยนหรือซีดจาง; ทนรอยขีดข่วน ทนน้ำ คราบ และรอยนิ้วมือ; มีคุณสมบัติกันน้ำและกันไฟฟ้าสถิต
- เหมาะกับ: ผู้ใส่เลนส์กันแดด เลนส์โฟโตโครมิก เลนส์ใส และเลนส์ Blue Zero ที่ต้องการเคลือบ AR คู่กับเลนส์มีสี (เป็นส่วนหนึ่งของชุด Shamir Driver Intelligence™ ด้วย)
- ใช้คู่กับ: เลนส์ใส เลนส์ Blue Zero เลนส์ Transitions® และเลนส์กันแดด ทุกค่า index
- ที่มา: https://shamir.com/for-professionals/lenses_and_more/shamir-glacier-sun-uv/ , https://shamir.com/us/for-professionals/lenses_and_more/shamir-glacier-sun/

## Shamir Glacier Plus UV™
- ประเภท: anti-reflective + UV (มีในเว็บ Shamir ไทย; เว็บ US ใช้ชื่อ "Glacier PLUS™")
- จุดเด่น: ป้องกัน UV ทั้งแสงที่ส่องเข้าตาโดยตรงและแสงสะท้อนจากผิวเลนส์ด้านหลัง (เลนส์ index 1.53 ขึ้นไป); ลดแสงสะท้อนช่วยให้มองเห็นชัดและสบายตา; ทนรอยขีดข่วน ทำความสะอาดง่าย; มีคุณสมบัติกันน้ำและกันไฟฟ้าสถิต
- เหมาะกับ: ผู้ใส่แว่นทุกคน
- ใช้คู่กับ: เลนส์ใส เลนส์ Blue Zero เลนส์ Transitions® และเลนส์กันแดด ทุกกรอบและทุกค่า index
- ที่มา: https://shamir.com/for-professionals/lenses_and_more/shamir-glacier-plus-uv/

## Shamir Glacier+ UV IR™
- ประเภท: anti-reflective + UV + ป้องกันรังสีอินฟราเรด (มีในเว็บ Shamir ไทย)
- จุดเด่น: ป้องกัน UVA/UVB ทั้งแสงตรงและแสงสะท้อนจากผิวเลนส์ด้านหลัง (เลนส์ index 1.53 ขึ้นไป); ผู้ผลิตระบุว่าป้องกันรังสีอินฟราเรดได้มากกว่าเลนส์ไม่เคลือบสูงสุด 3 เท่า; คุณสมบัติ AR เพิ่มการส่องผ่านของแสง; ทนทาน กันน้ำ กันไฟฟ้าสถิต
- เหมาะกับ: ผู้ต้องการป้องกันแสงแดดครบทั้ง UV และอินฟราเรด
- ใช้คู่กับ: เลนส์ใส เลนส์ Blue Zero เลนส์ Transitions® และเลนส์กันแดด ทุกกรอบและทุกค่า index
- ที่มา: https://shamir.com/for-professionals/lenses_and_more/shamir-glacier-uv-ir/

## Shamir Glacier Anti-fog™
- ประเภท: anti-fog (มีในเว็บ Shamir ไทย)
- จุดเด่น: เคลือบผิวเลนส์ด้านหลังชั้นบางพิเศษ ป้องกันไม่ให้เกิดฝ้า/หมอกจากไอน้ำ; พร้อมใช้งานได้ทันทีไม่ต้องกระตุ้น; ช่วยให้มองเห็นชัดขณะออกกำลังกายหรือใส่หน้ากากอนามัย
- เหมาะกับ: นักกีฬา ผู้ที่ต้องใส่หน้ากากอนามัยเป็นเวลานาน บุคลากรทางการแพทย์ และผู้ทำงานที่ต้องสวมแว่นนิรภัย
- ใช้คู่กับ: เลนส์ polycarbonate, Trivex และ index 1.6 (ผู้ผลิตระบุห้ามเขียน/ประทับหมึกที่ผิวเลนส์ด้านหลัง เพราะลบออกไม่ได้)
- ที่มา: https://shamir.com/for-professionals/lenses_and_more/shamir-glacier-anti-fog/

## Shamir Glacier Blue-shield UV™
- ประเภท: anti-reflective + กรองแสงสีฟ้า (blue light) + UV (ปัจจุบันพบเป็นหน้าสินค้าที่ยังใช้งานอยู่เฉพาะเว็บ Shamir Portugal (pt) เท่านั้น — ตรวจสอบแล้วไม่พบในหน้ารายการ coatings ของเว็บ Global EN, US, UK, Australia, New Zealand หรือ Mexico ปัจจุบัน และไม่พบในเว็บ Shamir ไทย จึงควรเช็กกับตัวแทน Shamir Thailand ก่อนโพสต์ขายว่ายังมีจำหน่ายหรือไม่)
- จุดเด่น: ผู้ผลิตระบุว่ากรองแสงสีฟ้าได้มากกว่าเลนส์เคลือบทั่วไปสูงสุด 5 เท่า; เพิ่มการส่องผ่านของแสงและความคมชัด (contrast); ช่วยลดอาการตาล้าและความเมื่อยล้า; มีชั้นป้องกันรอยขีดข่วน กันน้ำ และกันไฟฟ้าสถิต
- เหมาะกับ: ผู้ผลิตระบุว่าเหมาะกับผู้สวมแว่นทุกวัย (เด็ก ผู้ใหญ่ สายตาสั้นหรือปกติ) ที่อยู่ในอาคารและเจอแสงหน้าจอบ่อย
- ที่มา: https://shamir.com/pt/for-professionals/shamir-glacier-blue-shield-uv/

- จุดเด่น: ลดแสงสะท้อนและแสงจ้า มองเห็นคมชัดสบายตาขึ้น; ผิวเคลือบทนรอยขีดข่วน; กันน้ำและคราบ ทำความสะอาดง่าย; ผู้ผลิตระบุว่าออกแบบโดยอิงเทคโนโลยีจาก Glacier Expression™ และ Glacier PLUS® แต่ปรับให้ราคาเข้าถึงง่ายขึ้น
- เหมาะกับ: ผู้ใส่แว่นทั่วไปที่ต้องการความคมชัด ความทนทาน และดูแลง่าย ในราคาประหยัด
- ใช้คู่กับ: เลนส์ Hard Resin 1.50, Trivex™ 1.53, Polycarbonate 1.59 และ 1.67

## Shamir Glacier Achromatic UV™
- ประเภท: anti-reflective + UV สองด้าน (dual-side UV protection) (พบในเว็บ Shamir Australia และ New Zealand เป็นสินค้าคนละตัวแยกจาก Glacier Sun UV™ และ Glacier Plus UV™ ในแคตตาล็อกเดียวกัน; ไม่พบในเว็บ Shamir ไทย)
- จุดเด่น: ป้องกัน UV ทั้งสองด้านของเลนส์ (dual side UV protection); คุณสมบัติ anti-reflective ช่วยให้มองเห็นชัดและสว่างขึ้น; มีคุณสมบัติกันน้ำ กันคราบมัน (hydrophobic, oleophobic) และกันไฟฟ้าสถิต; ทนทานและทนรอยขีดข่วนสูง
- เหมาะกับ: ผู้ผลิตระบุว่าเหมาะกับผู้สวมแว่นและแว่นกันแดดทุกวัย รวมถึงกรอบแฟชั่น/ดีไซเนอร์
- ใช้คู่กับ: เลนส์ใส เลนส์ Blue Zero เลนส์ Transitions® และเลนส์กันแดด ทุกกรอบและทุกค่า index
