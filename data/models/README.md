**`arm-suit_1.png`** — แขนผู้ชายสวมสูทดำ ข้อมือเชิ้ตขาว เนกไทเขียว Phthalo โผล่มุมล่าง เข้าเฟรมจากขวาล่าง **มือว่างเปล่า นิ้วจีบค้างไว้เป็นช่องวางกรอบแว่นจริง** — เจตนาเดียวกับ `model-a_1.png` คือห้ามให้ AI สร้างแว่น ต้องเอาสินค้าจริงวางทับ · **ตัวที่สไตล์ 4 ใช้อยู่จริง** เพราะตรงโครง ref ที่เห็นแค่แขน

**`arm-suit_2.png`** — ครึ่งอก ไม่มีศีรษะ สูทดำ เชิ้ตขาว **เนกไทเขียว Phthalo เต็มเส้นกลางอก** มือจีบนิ้วยกอยู่หน้าอก มือว่างเปล่า · ต่างจาก `_1` ตรงที่เนื้อภาพเต็มเฟรมไม่มีขอบโปร่งรอบ ต้องวางด้วยค่าคนละชุด (`left:50 bottom:-80 width:780`)

**บทเรียนจากการวางแว่นในมือ (ลองห้ารอบ ไม่สำเร็จ)** — รูปกรอบที่มีเป็นภาพ**หน้าตรงกางออก** ถ่ายจากด้านหน้า เป็นของแบนขนานจอ ส่วนมือในภาพ AI อยู่ในระนาบลึกเข้าไป สองอย่างนี้คนละระนาบ วางทับยังไงก็ได้แค่ "แว่นลอยหน้าอก" ไม่ใช่ "มือหนีบแว่น" · ถ้าอยากได้ท่าหนีบจริงต้องใช้กรอบที่มีภาพมุมเอียง `_2` ซึ่งมีมิติความลึกในตัว (ตอนนี้มี 15 รุ่น) · สไตล์ 4 จึงเปลี่ยนไปวางแว่นกึ่งกลางภาพแทน และแยก layer ไว้ให้ลบขาแว่นที่พาดมือเองใน PSD

**prompt ที่ใช้:** ครึ่งตัว ผู้ชายเอเชีย 25-35 ผมสั้น เสื้อเชิ้ตสีเรียบ **ไม่ใส่แว่นตา** มองกล้อง ไหล่ตรง แสงสตูดิโอนุ่มจากซ้าย พื้นหลังโปร่งใส ห้ามมีตัวอักษร โลโก้ ลายน้ำ

## กติกาการใช้รูปคน AI

1. **ต้อง gen แบบไม่ใส่แว่นเสมอ** แล้วเอากรอบจริงที่ตัดพื้นหลังจาก `data/frames/images/` ประกบเข้าไป — ถ้าปล่อยให้ AI ใส่แว่นให้ จะได้แว่นที่ร้านไม่มีขาย กลายเป็นโฆษณาสินค้าที่ขายไม่ได้จริง
2. **ห้ามสื่อว่าเป็นลูกค้าจริง พนักงานจริง หรือรีวิวจริง** — เป็นภาพนายแบบ ไม่ใช่หลักฐาน
3. **ห้ามให้หน้าเหมือนคนจริงคนใดคนหนึ่ง** ถ้าดูคล้ายใครให้ gen ใหม่
4. สินค้าและโลโก้จริงของแบรนด์ **ห้าม gen ขึ้นเอง** — เจนได้แค่คน ฉากหลัง และบรรยากาศ · ยกเว้นแนบรูปแว่นจริงด้วย `-i` แล้วสั่งให้ใช้ตามรูปเป๊ะ (prompt ใน `kits/*/kit.md`) และต้องเทียบผลกับรูปจริงก่อนใช้ ถ้าทรงเพี้ยนห้ามใช้

## วิธี gen เพิ่ม

ต้องมี Codex CLI ที่ล็อกอินด้วยบัญชี ChatGPT (ดู `CLAUDE.md` หัวข้อ Codex) ไม่ต้องมี `OPENAI_API_KEY` — **หักโควตาแพลน ChatGPT ทุกครั้ง ต้องถามเจ้าของร้านก่อน**

```
codex exec -m gpt-5.6-luna -c model_reasoning_effort="low" -C <โฟลเดอร์โปรเจกต์> --skip-git-repo-check -s workspace-write -o tmp/codex-last.txt "Call the built-in image_gen tool exactly once with the prompt below, verbatim. Transparent background. Do not rewrite the prompt, do not generate variants, do not inspect or edit the result. Reply with only the saved file path. PROMPT: <prompt>"
```

**เลือกโมเดลยังไง** — ความสวยของภาพมาจากเครื่องมือ `image_gen` ไม่ได้มาจากโมเดลที่คุม Codex โมเดลที่คุมทำแค่ส่ง prompt ต่อ จึงใช้ตัวถูกสุด `gpt-5.6-luna` + reasoning `low` เพื่อประหยัดโควตา ส่วนที่ทำให้ภาพสวยคือ **prompt** — Claude ต้องเขียน prompt ละเอียดเอง (ท่า แสง มุมกล้อง สี พื้นหลัง สิ่งที่ห้ามมี) แล้วให้ Codex ส่งต่อตรง ๆ ห้ามให้ Codex คิดเอง
- ถ้า `gpt-5.6-luna` ไม่มีในบัญชี หรือไม่ยอมเรียก `image_gen` (ได้แต่ข้อความ ไม่มีไฟล์ใหม่ใน `generated_images`) ให้ใช้ `-m gpt-6-astra` แทน โดยคง `low` ไว้
- เช็กรายชื่อโมเดลที่บัญชีมีได้จาก `~/.codex/models_cache.json`

**ข้อควรรู้จากรอบแรก (2026-09-16):**
- ถ้าสั่ง `codex exec` จากสคริปต์/พื้นหลัง ต้องต่อท้าย `< /dev/null` ไม่งั้นค้างที่ "Reading additional input from stdin..." และถ้าไป kill ทีหลัง Codex จะได้ EOF แล้ววาดต่อ = เสียโควตาซ้ำ (เจอ 2026-11-13)
- แม้ส่ง `-s workspace-write` ไป แซนด์บ็อกซ์ยังขึ้นเป็น `read-only` — Codex **เซฟไฟล์ลงโปรเจกต์ไม่ได้** ต้องไปก๊อปเอาเองจาก `~/.codex/generated_images/<session-id>/` (Windows: `%USERPROFILE%\.codex\generated_images\`) เลือกไฟล์ใหม่ล่าสุด
- Codex รายงานว่า "ภาพยังมีพื้นหลัง" ทั้งที่ตรวจแล้วมี alpha โปร่งจริง — **อย่าเชื่อรายงาน ให้เปิดไฟล์ตรวจเอง** (วางบนพื้นขาวและพื้นเข้มดูว่ามีฝ้าไหม)
- ถ้าได้ภาพพื้นทึบมาจริง ๆ ตัดพื้นด้วย `npm run cutout -- data/models <ไฟล์>` (สั่งใน prompt ให้พื้นหลังเป็นสีเรียบสีเดียวจะตัดได้สะอาด) ไม่ต้องใช้ Python
